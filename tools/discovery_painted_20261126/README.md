# 발견물 회화 원화 출력

발견 그림에는 2D 유화·과슈의 붓질과 자연스러운 재질을 사용한다. 폴리곤·3D 렌더·미니어처·디오라마·모형 조립·회전 전시 양식으로 되돌리지 않는다. 이는 2026-11-26 사용자의 명시적인 그림 양식 지시다.

`plan.json`의 새 원화 657종과 기존 회화 연출 재구성 271종을 `python build.py`로 게임에 반영한다. 원화는 `sources/`, 교체 전 그림은 `before/`, 출력 증명은 `receipts/`에 남긴다.

단순히 파일이 존재하고 움직이는지만으로 그림 양식을 승인하지 않는다. 새 그림과 GIF의 앞·중간·끝 장면을 미리보기에서 확인하고 `tests/discovery_painted_20261126_files.py`로 실제 회화 원화와 게임 파일이 일치하는지 확인한다.
