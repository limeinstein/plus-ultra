目的 — 図書館・酒場・交易所で発見物の手がかりを集め、王宮や屋敷の支援者に冒険を提案します。契約を結び、期限までに目的地を見つけて報告すると、謝礼と名声を得られます。名声が高まれば、より有力な支援者や仲間に出会えます。
街 — 右側のメニューから建物を選びます。初期設定では↑↓で移動、Enter・Spaceで決定、Escで閉じます。港：出航・補給・艦隊編成 / 交易所：売買・値引き交渉 / 造船所：船の購入・修理・改造 / 酒場：船員募集・情報・仲間・給仕・ポーカー / 宿屋：宿泊・記録 / 城門：陸上探検。
航海 — 海をクリックすると、その場所まで海路を探して進みます。街の印をクリックするとその港へ向かい、到着すると入港します。
  矢印キー：押している間、船首がその方角へ徐々に回ります。←西・→東・↑北・↓南。二つ同時に押すと北西や南東などの斜め方向です。離すとそのまま直進します（向かい風では減速）。初期設定のSpaceで帆を畳んで停止します。港の近くで停止すると停泊し、自動航海や針路を設定したまま停止した場合はもう一度押すと再開します。テンキーの1〜9でも八方位を指定できます。
  従来の手動で舵を取る方式（↑を押して前進、←→で旋回）は、手帳 → 設定 →「海上の矢印キー」で選べます。
  F11：全画面表示の切り替え。ゲームの全画面表示では、マウスを上端へ動かしてもブラウザーのメニューは表示されません。
  初期設定：1/2/3 航海速度・M 海図・Enter 入港・ホイール 拡大/縮小・右クリック 針路解除。方向・決定・キャンセル・海上速度のキーは、手帳 → 設定 →「キー設定」で変更できます。
  風に逆らうと遅くなります。自動航海と指定針路では向かい風でも直進します。設定の「向かい風での間切り」で、沖合のみ、または常に左右交互に進む方式へ変更できます。到着日は同じです。手動操縦では自分で斜め方向を交互に取ってください。三角帆は向かい風に、四角帆は追い風に強く、食料と水が尽きると船員が倒れます。
上陸・探検 — 海岸の近くで上陸するか、城門から探検に出ます。船員全員が探検隊に加わります。地面をクリックして歩き、遺跡や生物を探し、内陸の街へ入れます。現地の人々に贈り物をすると食料や水を分けてもらえ、ときには多めにもらえたり、焚き火のそばで休ませてもらえたりします（宿屋と同じく疲労が回復）。
発見した遺物 — 発見場所では宝・装身具・武器・書物・船首像などを得られます。発見の証拠なので、支援者へ報告すると引き渡します（書物や次の探検につながる品は返してもらえることもあります）。港で自ら発表すると提督の所有物となり、市場で売れます。書物は所持品から読むと、新たな手がかりが得られます。
陸戦 — 探検隊を提督隊と各部隊（歩兵・騎兵・銃兵・砲兵）に分けて戦います。1 攻撃・2 防御・3〜6 特殊作戦（奇襲・罠・狙撃・炸裂弾）。敵部隊をクリックして標的にします。騎兵は後列の首領も攻撃できます。首領を倒すと勝利し、提督隊が崩れると敗北です。
海戦 — 矢印キーで旗艦を動かし、Space（初期設定）で止めます。海をクリックして移動し、敵艦をクリックすると接近して攻撃します。舷側を敵へ向けると砲撃します（射角内の敵には自動射撃）。接近してBで白兵戦、Pで一時停止します。船には番号があり、1番が旗艦です。敵旗艦を沈めるか拿捕すると勝利し、味方旗艦を失うと敗北です。
一騎討ち — 甲板や酒場で二人が戦います。まず方針（1 決死の突撃・2 強力攻撃・3 必ず生け捕り・4 防御重視）を選ぶと、武力と剣術に応じて自動で打ち合います。各合で次の技（0 自動・1 斬り・2 突き・3 打ち）を選べます。突き → 斬り → 打ち → 突きの順で、矢印の先の技に勝ちます。剣術が高いほど相手の狙いを読みやすくなります。気勢がたまると特技（一撃必殺・先制攻撃・側面攻撃・生け捕り・偽装退却・秘密武器・誘導・交代・説得・虚歩・一喝・必殺技）を使えます。Space 一時停止・Esc 退く。
記録 — プレイ中は1分ごとに自動セーブします。5枠が埋まると古いものから更新されます。宿屋の「機能」には、自動セーブとは別に航海日誌が5枠あります。
