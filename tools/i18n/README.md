# 다국어 번역 원본 (tools/i18n)

`js/lang/en.js`는 이 폴더에서 만든다. en.js를 손으로 고치면 다음에 만들 때 덮어써지니, 고칠 때는 여기를 고친다.

- `en/*.tsv` — 한 줄에 `한국어 원문<TAB>영어`.
  - 원문에 틀을 쓸 수 있다:
    - `#` 숫자
    - `@` 이름이나 이어지는 글. 번역 쪽에서 이름 표(G.N)·사전·틀로 다시 옮긴다.
    - `(을|를)` 한국어 조사
    - `/정규식/` 그대로 쓰는 틀. `$1`과 `⟦$1⟧`(옮겨 넣기), `⟪R$2⟫`(로마 숫자)를 쓴다.
  - 번역 쪽에서 `#`·`@`는 원문의 차례대로 들어간다. 차례가 다르면 `{1}`·`{2}`처럼 쓴다.
  - 원문이 그냥 글이면 사전(text)에, 틀이면 틀(pat)에 들어간다. 틀은 글자가 많은(덜 넓게 붙잡는) 것부터 맞춰 본다.
- `en_text.py` — 처음 만든 사전·틀과 이름 표(NAMES: 사람·나라·지역·배·음식·물건 이름).
- `en/help.ko.html`·`help.en.html` — 타이틀 「조작 안내」 본문.
- 만들기: `python tools/i18n/build_en.py` → `js/lang/en.js`
- 빠진 글 찾기: `node tools/i18n_missing.js en`
  - 대사·알림 통문장(api)과 화면 조각(dom)을 `tmp/i18n_missing_en.json`에 적는다.
  - 대사는 `docs/번역_말투_영어.md`의 말투 기준을 따른다.
