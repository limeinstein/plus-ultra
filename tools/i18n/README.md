# 다국어 번역 원본 (tools/i18n)

`js/lang/*.js`의 번역은 이 폴더에서 만든다. 적용본을 손으로 고치면 다음에 만들 때 덮어써지니, 번역을 고칠 때는 각 언어의 원본을 고친다.

## 아홉 언어 점검 (2026-11-15)

| 언어 | 현재 상태 | 원본 |
|---|---|---|
| 한국어 | 게임 원문 | `js/`의 화면 글·대사 |
| 영어 | 작성된 번역 선택 가능 | `en/`, `en_text.py`, `js/lang/en_names.js` |
| 중국어 간체 | 작성된 번역 선택 가능 | `zh-Hans/` |
| 중국어 번체 | 작성된 번역 선택 가능 | `zh-Hant/` — 간체에서 변환 |
| 일본어 | 빈 준비 파일만 있음 | `js/lang/ja.js` |
| 베트남어 | 작성된 번역 선택 가능 · 대사 등 미번역 묶음 남음 | `vi/` |
| 스페인어 | 작성된 번역 선택 가능 · `other_g1`·`other_g1h` 반영, 나머지 묶음 남음 | `es/` |
| 포르투갈어 | 언어 목록·게임·도감 등록, 번역 원본 없음 | `js/lang/pt.js` |
| 독일어 | 빈 준비 파일만 있음 | `js/lang/de.js` |

선택할 수 있다는 것은 전체 번역 완료를 뜻하지 않는다. 현재 동작대로 미번역 문장은 한국어로 나온다. 일본어·포르투갈어·독일어는 실제 번역 원본을 받은 뒤 해당 언어 폴더를 채우고 검증한다. 빈 번역에 `_ready`를 만들지 않는다. 베트남어·스페인어의 미완성 부분과 스페인어 가이드북 부재도 [점검 결과](../../docs/qa/i18n-2026-11-15.json)에 남겼다.

- 전체 점검: `node tools/i18n/audit.cjs --build-check --out docs/qa/i18n-2026-11-15.json`
  - 게임·도감에 아홉 언어가 같은 순서로 등록되었는지, 번역 열에 한국어나 손상된 글자가 남았는지, 원본을 다시 만든 결과와 적용본이 같은지 확인한다.
  - 영어 사전에 있는 열쇠와 각 언어의 열쇠 수를 비교한다. 이 수치는 실제 게임 전체의 번역 완료율이나 번역 품질 점수가 아니다.
  - 포르투갈어 `pt-BR`·`pt-PT`를 모두 인식한다. 번역 공개 전의 첫 방문은 영어로, 공개 뒤에는 포르투갈어로 열린다.
- 영어 재생성: `python tools/i18n/build_en.py`
- 그 밖의 언어 재생성: `python tools/i18n/build_lang.py es` (마지막 값을 언어 ID로 바꾼다.)
- 번체 원본 갱신: `python tools/i18n/make_hant.py` 다음 `python tools/i18n/build_lang.py zh-Hant` (OpenCC 필요).
- 화면 확인: `node tests/i18n_smoke.js`, `node tests/i18n_asian_languages_smoke.cjs`, `node tests/i18n_templates_20261113_smoke.cjs`.

대학 신기루 발견 때 쓰는 `{나}` 대사는 한국어 말씨를 입히기 전에 통문장으로 번역하도록 `runtime_20261115.tsv`에 원래 열쇠를 추가했다. 영어 번역에 남은 `{나}` 여섯 곳도 `me`·`I`로 고쳤다.

## 영어 원본의 형식

- `en/*.tsv` — 한 줄에 `한국어 원문<TAB>영어`.
  - 원문에 틀을 쓸 수 있다:
    - `#` 숫자
    - `@` 이름이나 이어지는 글. 번역 쪽에서 이름 표(G.N)·사전·틀로 다시 옮긴다.
    - `(을|를)` 한국어 조사
    - `/정규식/` 그대로 쓰는 틀. `$1`과 `⟦$1⟧`(옮겨 넣기), `⟪R$2⟫`(로마 숫자)를 쓴다.
  - 번역 쪽에서 `#`·`@`는 원문의 차례대로 들어간다. 차례가 다르면 `{1}`·`{2}`처럼 쓴다.
  - 원문이 그냥 글이면 사전(text)에, 틀이면 틀(pat)에 들어간다. 틀은 글자가 많은(덜 넓게 붙잡는) 것부터 맞춰 본다.
- `en_text.py` — 처음 만든 사전·틀과 이름 표(NAMES: 사람·나라·지역·배·음식·물건 이름).
- `en/help.ko.html`·`help.en.html` — 타이틀 「조작 안내」 본문.
- 만들기: `python tools/i18n/build_en.py` → `js/lang/en.js`
- 빠진 글 찾기: `node tools/i18n_missing.js en`
  - 대사·알림 통문장(api)과 화면 조각(dom)을 `tmp/i18n_missing_en.json`에 적는다.
  - 대사는 `docs/번역_말투_영어.md`의 말투 기준을 따른다.
