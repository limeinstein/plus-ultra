# 다국어 번역 원본 (tools/i18n)

`js/lang/*.js`의 번역은 이 폴더에서 만든다. 적용본을 손으로 고치면 다음에 만들 때 덮어써지니, 번역을 고칠 때는 각 언어의 원본을 고친다.

## 아홉 언어 점검 (2026-11-15)

| 언어 | 현재 상태 | 원본 |
|---|---|---|
| 한국어 | 게임 원문 | `js/`의 화면 글·대사 |
| 영어 | 작성된 번역 선택 가능 | `en/`, `en_text.py`, `js/lang/en_names.js` |
| 중국어 간체 | 작성된 번역 선택 가능 | `zh-Hans/` |
| 중국어 번체 | 작성된 번역 선택 가능 | `zh-Hant/` — 간체에서 변환 |
| 일본어 | 작성된 번역 선택 가능 · 주요 화면·도시·교역품 우선, 장문 대사·발견물 상세 등 남음 | `ja/` |
| 베트남어 | 작성된 번역 선택 가능 · 대사 등 미번역 묶음 남음 | `vi/` |
| 스페인어 | 작성된 번역 선택 가능 · `other_g1`·`other_g1h` 반영, 나머지 묶음 남음 | `es/` |
| 포르투갈어 | 기본 화면·설정·이야기 선택·도시·교역·항해·해전 번역 선택 가능 · 장문 본문 미번역 남음 | `pt/` |
| 독일어 | 기본 화면·생성·항해·해전·도시 메뉴 번역 선택 가능 · 긴 본문 미번역 남음 | `de/` |

선택할 수 있다는 것은 전체 번역 완료를 뜻하지 않는다. 현재 동작대로 미번역 문장은 한국어로 나온다. 준비 중인 언어는 해당 언어 폴더에 실제 번역 원본을 채우고 검증한다. 빈 번역에 `_ready`를 만들지 않는다. 베트남어·스페인어의 미완성 부분과 스페인어 가이드북 부재도 [점검 결과](../../docs/qa/i18n-2026-11-15.json)에 남겼다.

## 영어 원본의 형식

- `en/*.tsv` — 한 줄에 `한국어 원문<TAB>영어`.
  - 원문에 틀을 쓸 수 있다:
    - `#` 숫자
    - `@` 이름이나 이어지는 글. 번역 쪽에서 이름 표(G.N)·사전·틀로 다시 옮긴다.
    - `(을|를)` 한국어 조사
    - `/정규식/` 그대로 쓰는 틀. `$1`과 `⟦$1⟧`(옮겨 넣기), `⟪R$2⟫`(로마 숫자)를 쓴다.
  - 번역 쪽에서 `#`·`@`는 원문의 차례대로 들어간다. 차례가 다르면 `{1}`·`{2}`처럼 쓴다.
  - 원문이 그냥 글이면 사전(text)에, 틀이면 틀(pat)에 들어간다. 틀은 글자가 많은(덜 넓게 붙잡는) 것부터 맞춰 본다.
- `en_text.py` — 처음 만든 사전·틀과 이름 표(NAMES: 사람·나라·지역·배·음식·물건 이름).
- `en/help.ko.html`·`help.en.html` — 타이틀 「조작 안내」 본문.
- 만들기: `python tools/i18n/build_en.py` → `js/lang/en.js`
- 빠진 글 찾기: `node tools/i18n_missing.js en`
  - 대사·알림 통문장(api)과 화면 조각(dom)을 `tmp/i18n_missing_en.json`에 적는다.
  - 대사는 `docs/번역_말투_영어.md`의 말투 기준을 따른다.
