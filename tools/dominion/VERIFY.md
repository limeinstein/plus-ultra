# 고증 검증 지침 (2차)

1차 조사 결과(`/tmp/claude-0/dom/out_X.json`)를 **실제 역사 자료로 다시 확인하고 고친다.** 사용자는 실역사 고증을
최대한 반영하길 원한다. 1차 지침은 `/tmp/claude-0/dom/BRIEF.md` (이름 규칙·형식은 그대로 따른다).

## 원칙
- 모든 판단은 **웹 검색(WebSearch/WebFetch)으로 확인**한다. 기억만으로 고치지 않는다. 위키백과 영어판 + 현지어판(포르투갈어·에스파냐어·
  중국어·일본어·아랍어 등)과 worldstatesmen.org, 브리태니커를 교차 확인한다. 두 출처가 다르면 더 1차 자료에 가까운 쪽을 따르고 note에 적는다.
- 연도: 즉위·점령·양도가 **실제로 효력을 가진 해와 달**. 조약 서명과 실제 인도가 다르면 실제 인도(점령) 시점.
- 지도자: 그 나라의 **실제 최고 통치자**. 섭정·공동 통치는 이름에 밝힌다(예: "후아나 1세 (섭정 페르난도 2세)"). 이름은 한국어 통용 표기
  (국립국어원 외래어 표기·한국어 위키백과 표제어 우선). 재위 1년 미만도 빠뜨리지 않는다. 같은 해 교체는 [해, 해, 이름].
- `null`(모름) 칸은 가능한 한 실제 이름으로 채운다. 자료로 끝내 확인할 수 없을 때만 null로 두고 note에 이유.
- 확신이 낮다고 1차에서 보고된 도시는 반드시 다시 확인한다.

## 결과
- 고친 전체 파일을 `/tmp/claude-0/dom/v2/out_X.json` 으로 쓴다(1차와 같은 구조, 고치지 않은 항목도 모두 포함).
- 바꾼 내용을 `/tmp/claude-0/dom/v2/changes_X.md` 에 한 줄씩: `- [도시/나라] 무엇을 → 무엇으로 (근거 URL)`.
- python으로 JSON을 확인한 뒤 짧게 보고: 고친 수, 채운 null 수, 끝내 확인 못 한 것.
