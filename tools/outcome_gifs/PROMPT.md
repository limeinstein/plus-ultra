# 결과 연출 GIF — 다시 그릴 때의 주문서

게임은 `images/outcomes/<이름>.gif` 를 `js/ui/outcome.js`(G.Outcome)로 보여 준다.
지금 들어 있는 그림은 `tools/outcome_gifs/make_outcomes.py` 가 코드로 그린 픽셀 그림이다.
같은 이름으로 새 그림을 넣으면 그대로 바뀐다 (넣은 뒤 `python tools/images.py`).

공통
- 크기 480×300 (가로:세로 = 8:5). 게임 화면에서는 720×450으로 키워 보인다 — 픽셀 그림이면 정수배가 깔끔하다.
- **한 번만 돌고 마지막 장면에서 멈추게** (GIF 반복 없음). 마지막 장면이 결과를 한눈에 보여 주어야 한다.
- 길이: 잠입 3.5~4초, 설득 2.5~3초, 청혼 4초 안팎 (더 길면 `js/ui/outcome.js` 의 `O.KINDS[...].ms` 도 늘린다).
- 글씨는 넣지 않는다 (제목·설명은 게임이 그림 아래에 쓴다). 「!」 같은 기호는 괜찮다.
- 원작(대항해시대 3)의 그림을 옮기지 않는다 — 분위기만 참고한 새 그림.
- 제독: 15~16세기 항해가 — 깃털 달린 챙 넓은 모자, 금단추 남색 외투, 붉은 띠, 장화. `_f` 는 여자 제독(뒤를 이은 딸, 긴 머리).

| 파일 | 장면 |
|---|---|
| `sneak_ok(_f).gif` | 달밤의 성벽과 성문. 망토 두건을 쓴 제독이 몸을 낮추고 발끝으로 걸어와, 미늘창에 기대 졸고 있는 경비(Zzz) 곁을 지나 성문 안 어둠으로 사라진다. 마지막: 잠든 경비와 성문 안의 작은 반짝임 |
| `sneak_fail(_f).gif` | 같은 곳. 살금살금 다가가던 제독 앞에서 경비가 깨어 「!」 — 등불을 들어 비추고 미늘창을 겨눈다. 제독은 펄쩍 놀라 두 손을 든다(식은땀). 마지막: 불빛 속에 두 손 든 제독과 창을 겨눈 경비 |
| `win(_f).gif` | 금빛 조명의 무대. 제독이 몸을 움츠렸다가 주먹을 치켜들며 두 번 뛰어오른다. 색종이와 반짝임. 마지막: 주먹을 든 채 눈을 감고 웃는 제독 |
| `lose(_f).gif` | 푸른 조명이 점점 어두워지는 무대. 제독이 움찔 놀란 뒤 어깨가 처지고, 무릎을 꿇고, 두 손으로 바닥을 짚는다. 머리 위에 먹구름과 빗줄기. 마지막: 바닥을 짚고 고개 숙인 제독 |
| `propose(_f).gif` | 장밋빛 무대. 제독이 한쪽 무릎을 꿇고 반지 상자를 내민다(반지가 반짝). 마주 선 여인이 두 손을 모아 볼에 대고 얼굴을 붉히며 고개를 끄덕인다. 하트가 피어오른다. 마지막: 둘 사이 위에 큰 하트 |
