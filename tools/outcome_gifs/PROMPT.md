# 결과 연출 애니메이션 — 다시 그릴 때의 주문서

게임은 `images/outcomes/<이름>.webp` 를 `js/ui/outcome.js`(G.Outcome)로 보여 준다.
지금 쓰는 원화는 `tools/outcome_gifs/sources/v2/`의 1536×1024 회화풍 PNG이며,
`tools/outcome_gifs/make_cinematic_outcomes.py`가 720×450 애니메이션 WebP로 만든다.
이전 픽셀 GIF와 생성기는 각각 `images/outcomes/_pixel-backup/`, `make_outcomes.py`에 보존했다.

다시 만들기: `python tools/outcome_gifs/make_cinematic_outcomes.py` 실행 뒤 `python tools/images.py`.

공통
- 원화는 가로형 1536×1024 PNG. 빌드할 때 중앙을 8:5로 잘라 720×450 애니메이션 WebP로 만든다.
- 로딩 지구 그림처럼 매끈한 질감의 현대적인 회화풍. 픽셀 아트·스프라이트·블록 형태는 쓰지 않는다.
- 짧은 카메라 움직임은 빌드 스크립트가 넣는다. 원화 한 장만으로도 결과가 즉시 읽혀야 한다.
- 한 번만 돌고 마지막 장면에서 멈춘다. 일반 결과는 약 3.3초이며 `js/ui/outcome.js`가 잠시 더 보여 준다.
- 잠입·교섭·청혼은 각각 `sneak_open(_f).webp`, `negotiate_open(_f).webp`, `propose_open(_f).webp`를 1.4초 먼저 재생한 뒤 동일한 성별의 성공 또는 실패 그림으로 교체한다. 도입부에서는 제목·설명·색상·효과음도 결과를 드러내지 않는다.
- 글씨는 넣지 않는다. 제목·설명은 게임이 그림 아래에 쓴다.
- 제독: 15~16세기 항해가 — 깃털 달린 챙 넓은 모자, 금단추 남색 외투, 붉은 띠, 장화. `_f` 는 여자 제독(뒤를 이은 딸, 긴 머리).

| 파일 | 장면 |
|---|---|
| `sneak_open(_f).webp` | 달빛 항구 성문. 제독은 상자 뒤 어둠에 숨어 순찰 중인 경비의 동선을 살핀다. 경비는 제독을 보지 못했지만 아직 통과하지도 않았다. |
| `sneak_ok(_f).webp` | 달밤의 열린 성문. 망토를 쓴 제독은 잠든 경비와 내려 둔 미늘창 곁을 이미 지나 안으로 들어간다. 손가락을 입술에 대고 안도한 표정. |
| `sneak_fail(_f).webp` | 닫힌 성문. 경비가 든 밝은 등불과 가로막은 미늘창 앞에서 제독이 두 손을 든다. 다치거나 싸우는 장면은 피한다. |
| `win(_f).webp` | 제독과 후원자가 웃으며 악수한다. 탁자 한가운데 서명한 계약서와 온전한 붉은 밀랍 인장이 선명하다. 따뜻한 금빛. |
| `lose(_f).webp` | 후원자가 손바닥으로 거절하고 서명하지 않은 계약서를 밀어낸다. 탁자 위에는 깨진 밀랍 인장, 제독은 실망한 표정. 차가운 푸른빛. |
| `negotiate_open(_f).webp` | 제독이 지도와 서명하지 않은 계약서를 설명하고, 후원자는 턱을 괴고 판단 중이다. 악수나 거절 동작은 없다. |
| `propose_open.webp` | 남성 제독이 여성에게 반지를 내밀지만, 여성은 놀라고 망설이는 중이라 수락·거절 여부가 보이지 않는다. |
| `propose_open_f.webp` | 여성 제독이 남성에게 반지를 내밀지만, 남성은 놀라고 망설이는 중이라 수락·거절 여부가 보이지 않는다. |
| `propose.webp` | 남성 제독이 한쪽 무릎을 꿇고 여성에게 열린 반지 상자를 건넨다. 여성은 웃으며 반지에 손을 뻗고 다른 손은 가슴에 댄다. |
| `propose_f.webp` | 여성 제독이 한쪽 무릎을 꿇고 남성에게 열린 반지 상자를 건넨다. 남성은 웃으며 반지에 손을 뻗고 다른 손은 가슴에 댄다. |
| `propose_fail.webp` | 남성 제독이 여성에게 반지를 내밀지만, 여성은 한 걸음 물러나 아쉬운 표정으로 손바닥을 들어 정중히 거절한다. |
| `propose_fail_f.webp` | 여성 제독이 남성에게 반지를 내밀지만, 남성은 한 걸음 물러나 아쉬운 표정으로 손바닥을 들어 정중히 거절한다. |
