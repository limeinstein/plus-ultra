# 평민형 제독 얼굴상 재작업

내장 ImageGen으로 `sea_dog`(망원경을 든 뱃사람)과 `hat_spinner`(모자를 돌리는 항해사)를 재작업한 원본이다.

- 20대 무릎상을 기준 원화로 생성한 뒤, 같은 인물의 얼굴상과 40대 변형을 정체성 유지 편집으로 만들었다.
- 복식은 금장·훈장·귀족 망토·갑옷을 빼고, 수선한 리넨 셔츠·울 조끼·작업 바지·낡은 가죽띠으로 구성했다.
- 40대는 같은 자세·복장·소품을 유지하고 햇볕과 바람에 그을린 주름, 구레나룻, 관자놀이의 새치만 더했다.
- 얼굴상은 머리·어깨 중심, 무릎상은 머리부터 양쪽 무릎까지의 투명 배경 정사각형 구도다.
- 핵심 소품은 `sea_dog`의 낡은 황동 망원경, `hat_spinner`의 깁맨 평범한 펠트 모자와 든 손가락이다.

게임 파일은 원본을 Lanczos 리샘플링한 512×512 RGBA PNG다.
