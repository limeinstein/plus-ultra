# 자동 플레이 봇

실제 게임 코드(index.html)를 헤드리스 크롬(Playwright)으로 열고, 대화·선택만 봇이 대신 골라 끝까지 플레이한다.
밸런스 확인용이다. 규칙·확률·경쟁자·사건은 건드리지 않고, 화면 그리기만 끈 채 바다 장면의 하루를 직접 돌린다.

- `bot.js` — 대화상자(UI.say/ask/choose/confirm/number/window) 가로채기, 건물 기능(C.visit → 건물 함수) 호출, 바다 항해(경로점 직항 침로), 해전·결투 처리, 기록
- `brain.js` — 무엇을 하러 어디로 갈지: 리스본 → 아프리카 남단 → 지중해(맛보기 향신료·라임) → 인도 → 말라카·향료제도 → 서쪽으로 세계일주
- `run.js` — 실행기. `node run.js --minutes 25 --out 폴더` (체크포인트: 도시에 들를 때마다 `ckpt.json`, 이어하기 `--resume ckpt.json`)
- `report_gen.py` — `final.json`과 `trace.log`로 항해 기록 페이지를 만든다

한 판은 보통 1~2분에 1487년 무렵까지 간다. 운이 나쁘면(태평양 횡단 끝의 굶주림, 신세계 해협~나스카 구간의 피로) 선원이 전멸해 끝난다.
경로와 파일 위치(/tmp/claude-0/…)는 개발 컨테이너 기준이니, 다른 곳에서 쓸 때는 run.js의 DIR·URL과 report_gen.py의 경로를 고친다.
