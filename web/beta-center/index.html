  • 같은 선종의 여러 배는 실시간 모형 하나를 재사용하고, 화면에서 사라진 선종은 최근 3종까지만 보관합니다. 항해를 끝내면 보관한 모형과 그래픽 자원을 모두 해제합니다.
  • 그래픽 장치가 중단되거나 3D 표시를 지원하지 않으면 기존 선박 그림으로 자동 전환되고, 장치가 복구되면 실시간 모형으로 돌아옵니다.
  • 해적선의 돛 색이나 다른 배의 깃발·돛 접힘이 뒤이어 그리는 아군과 상선에 남을 수 있는 상태 오염을 막았습니다.
  • 내려받은 베타판을 파일로 직접 열 때 익명 통계 요청이 CORS 오류를 남기던 문제를 고쳤습니다. 익명 통계는 공개 웹에서만 전송합니다.
