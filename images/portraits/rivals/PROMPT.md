# 경쟁 탐험가 초상 주문서

경쟁 탐험가(`js/data/rivals.js`)는 이 폴더의 그림을 먼저 쓴다. 그림이 없으면 같은 사람의 동료 그림(`portraits/mates/<id>`)을 쓰고, 그것도 없으면 사람마다 정한 역할·양식(`look`)의 그린 얼굴을 쓴다.

- `<이름>.webp`: 384×384 얼굴 (불투명 RGB). 술집 명부 카드와 대화창에 쓴다.
- `<이름>_half.webp`: 1024×1536 무릎상 (투명 RGBA). 대화창 위에 서는 모습으로 쓴다.
- 기준 그림은 `크리스토발 콜론.webp`와 `크리스토발 콜론_half.webp`다. 화풍·빛·크기·무릎에서 자르는 위치를 여기에 맞춘다.

```text
Use case: stylized-concept
Asset type: production-ready 2D game character portrait pair (bust 384x384 opaque + knee-length 1024x1536 transparent)
Input images: Image 1 (크리스토발 콜론.webp / _half.webp) is the style, framing, lighting and rendering reference only.
Primary request: Paint the named real 15th–16th-century explorer described below as a new, distinct person in the same polished hand-painted semi-realistic style.
Subject: one adult man, historically plausible period clothing and gear for his nation, role and decade; expression and pose that show the personality notes.
Composition: bust = head and shoulders, three-quarter view, warm painted backdrop. Half = standing knee-length, three-quarter view facing screen-left, cut at the knees, genuine alpha transparency, no backdrop.
Constraints: no text, labels, watermark, frame, border or extra people; no modern items; consistent face between the two images.
```
