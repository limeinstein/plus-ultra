# 명예혁명과 권리장전 그림 주문서 (2026-10-29)

인물 8명의 1024×1024 얼굴상·1024×1536 투명 무릎상 제작·연결 완료. 메리 2세는 최신 사용자 참고 이미지의 표정·머릿결과 시대풍 의상을 반영했다. 원화·최종 지시문·검사: `docs/art/new-event-portraits-20261029.md`.

이벤트: `js/systems/glory.js` · 대사·인물: `js/data/glory.js`. 넣기만 하면 바로 쓰인다(없으면 그림 없이 대화만, 얼굴은 잉글랜드 귀족·선장 그림을 빌린다).
