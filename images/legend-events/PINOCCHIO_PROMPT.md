# 피노키오와 제페토 — 그림 요청

`js/systems/pinocchio.js`와 `js/data/pinocchio.js`의 사건을 기준으로 한 그림 목록이다. 특정 영화·애니메이션의 인형 디자인을 따르지 않는다. 두 사람 모두 16세기 이탈리아 어촌에서 살아온 실제 사람이다.

- 화풍: 반실사 대항해시대 RPG 키 아트. 얼굴상과 무릎상은 투명 PNG, 장면은 넓은 화면용 PNG.
- 공통 제약: 글자·테두리·워터마크 없음. 얼굴과 복장의 연속성을 지킨다.

## 초상

### 피노키오 (`portraits/legendary/pinocchio.png` · `pinocchio_half.png`)

첨부된 젊은 남자 사진의 얼굴을 참고한다. 짙은 헝클어진 머리와 진한 눈썹, 곧은 코를 가진 가난한 어부. 서른이 가까워도 젊어 보인다. 현대 복장 대신 기운 자국이 많은 갈색 조끼, 거친 밝은 셔츠, 닳은 바지와 밧줄, 낡은 그물을 쓴다. 나무 인형의 얼굴이나 길어지는 코는 그리지 않는다.

### 제페토 (`portraits/legendary/geppetto.png` · `geppetto_half.png`)

피노키오의 아버지. 희끗한 머리와 수염, 주름진 얼굴을 가진 가난한 토스카나의 배 수리 목수. 해진 셔츠와 낡은 가죽 앞치마, 손에 목공 도구를 든다.

## 장면

### `pinocchio_whale.png` — 고래를 쫓는 작은 고깃배

거친 대양에서 피노키오가 낡은 고깃배 위에 서서 지나가는 범선에 도움을 청한다. 뒤로 집채만 한 고래가 물 위로 솟고, 피노키오의 간절함과 위험한 바다를 함께 보여 준다.

### `geppetto_farewell.png` — 부두의 작별

고래에게서 구출된 제페토와 피노키오가 16세기 이탈리아 항구에서 헤어지며 서로 얼굴과 팔을 붙든다. 아침 햇빛, 낡은 그물, 목공 도구와 범선을 배경으로 한다.
