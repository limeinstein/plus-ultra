# 동인도 회사의 탄생 — 그림 요청

2026-11-06 제작 완료: 동료 4명·역사 화자 6명의 얼굴상·무릎상 20장, 이벤트 샷 10장을 전용 경로에 등록했다. [미리보기·원화·지시문·검증](../../docs/art/missing-event-art-20261105.md).

`js/systems/eastindia.js`와 `js/data/eastindia.js`의 사건을 기준으로 한 그림 목록이다. 무대는 런던(1600), 암스테르담(1602), 수라트 앞 수왈리(1612), 자야카르타(1619), 반다(1621), 암보이나(1623)다.

- 화풍: 반실사 수작업풍 대항해시대 RPG 키 아트. 다른 legendary·history 초상과 legend-events와 같은 결로 그린다.
- 초상: 투명 PNG 원화에서 1024×1536 무릎상 WebP(`_half`)와 448×448 얼굴상 WebP를 만든다.
  - 동료 넷의 경로는 `portraits/legendary/<id>`이다.
  - 실존 인물(ei_*)의 경로는 `portraits/history/<id>`이다.
- 장면: 16:9 원화를 게임 표준 1881×836 WebP로 만든다. 경로는 `images/legend-events/<key>.webp`이다.
- 공통 제약:
  - 글자·테두리·워터마크를 넣지 않는다. 증서·장부의 글자는 판독되지 않게 흐리게 그린다.
  - 얼굴·머리·손·무릎에 안전 여백을 둔다.
  - **동료 넷은 아름답고 잘생긴 20대 성인으로 그린다.** 노출이나 선정적인 연출은 넣지 않는다.
  - 각 문화의 옷차림을 존중한다. 학살·고문 장면은 직접 그리지 않고 분위기로만 암시한다.

## 동료 초상 (4명)

### 마리암 하코비안 (`mariam`) — 수라트의 아르메니아 상인 딸
24세의 성인 여성이다.
- 얼굴: 길게 늘어뜨린 검은 머리와 짙은 눈썹, 따뜻한 미소.
- 옷차림: 진홍빛 비단 겉옷과 금실 수놓은 머릿수건, 석류석 귀걸이.
- 소품: 손에 작은 보석 저울.

### 라덴 아유 칸차나 (`kancana`) — 자야카르타 왕가의 아가씨
22세의 성인 여성이다.
- 머리: 높이 틀어 올린 머리에 금 장식 핀.
- 옷차림: 바틱 무늬 카인(치마)에 어깨를 덮는 비단 숄(셀렌당).
- 소품: 품에 그을린 작은 가믈란 징.
- 분위기: 우아하고 단호한 눈빛.

### 이드리스 (`idris`) — 반다 오랑 카야의 아들
26세의 성인 남성이다.
- 얼굴: 햇볕에 그을린 단단한 몸, 깊은 눈, 짧게 묶은 검은 머리.
- 옷차림: 흰 머리띠, 바다에 젖은 면 셔츠와 사롱.
- 소품: 품에 흙을 감싼 육두구 묘목.

### 에드먼드 헤일 (`edmund`) — 잉글랜드 동인도 회사의 서기
24세의 성인 남성이다.
- 얼굴: 헝클어진 금발, 가는 얼굴과 지친 그러나 꺾이지 않은 눈.
- 옷차림: 흰 셔츠에 낡은 검은 더블릿.
- 소품: 손목에 사슬 자국, 품에 젖은 가죽 장부.
