# 서유기 — 네 아가씨의 천축 길 · 그림 요청

`js/systems/xiyou.js`와 `js/data/xiyou.js`의 사건 그림이다. 조선·명·일본·몽골에서 온 네 아가씨가 각자 삼장법사·손오공·사오정·저팔계를 맡아 인도(천축)까지 간다.

- 길: 사카이 → 항주 → (곁길: 연운항 앞바다의 화과산 수렴동) → 아유타야 → 말라카 → 말라카 해협 → 인도(캘리컷·코친·고아)

## 규격과 화풍

- 화풍: 반실사 수작업풍 대항해시대 RPG 키 아트. 다른 legendary 초상(천일야화, 유럽 옛이야기)과 legend-events와 같은 결로 그린다.
- 초상: 투명 PNG 원화로 두 가지를 만든다.
  - 1024×1536 무릎상 WebP (`_half`)
  - 448×448 얼굴상 WebP
  - 동료 넷의 경로는 `portraits/legendary/<id>`이다(history 인물 `xy_misu` 등도 같은 그림을 쓴다).
  - 나머지 인물의 경로는 `portraits/history/<id>`이다.
- 장면: 16:9 원화를 게임 표준 1881×836 WebP로 만든다. 경로는 `images/legend-events/<key>.webp`이다.

## 공통 제약

- 글자·테두리·워터마크를 넣지 않는다.
- 얼굴·머리·손·무릎에 안전 여백을 둔다.
- **네 아가씨는 모두 성인(스무 살 남짓)이다.** 얼굴과 몸매 모두 분명한 성인 여성으로 그리고, 앳된 아이처럼 보이게 그리지 않는다.
- 넷 모두 미형이고 글래머러스한 몸매(풍만한 가슴)를 지녔다. 옷은 보수적이지 않고, 어깨·팔·다리선이 드러나는 화려한 판타지 의상으로 그린다. 다만 노출은 옷차림 안에서만 표현한다(맨몸·속옷 차림·선정적인 자세나 구도는 넣지 않는다).
- 원작 『서유기』의 상징물(석장·염주·금테·호랑이 가죽·쇠스랑 대신 국자)은 넣되, 특정 애니메이션·게임의 캐릭터 디자인을 따르지 않는다.
- 조선·명·일본·몽골·타이·말레이·인도 사람들은 고정관념 없이 존중해서 그린다.
