# 피터 팬 그림 주문서 (js/systems/peterpan.js · js/data/peterpan.js)

J. M. 배리의 희곡(1904)·소설(1911)에 나오는 모습만 씁니다. 뒤에 나온 영화의 옷차림(초록 쫄쫄이 옷, 들쭉날쭉한 옷단, 붉은 깃털이 꽂힌 뾰족 모자, 뾰족한 귀)은 쓰지 않습니다.
그림이 없으면 장면은 글만으로 지나갑니다.
