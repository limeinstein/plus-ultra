# 포카혼타스 장면 그림 주문서 (js/systems/pocahontas.js)

그림이 없으면 장면은 글만으로 지나갑니다. 파일 이름은 `images/legend-events/<이름>.webp` (가로 16:9, 다른 legend-events 그림과 같은 화풍 — 유화풍 역사 삽화, 따뜻한 빛).

| 파일 | 장면 |
|---|---|
| `pocahontas_truce.webp` | 17세기 초 북아메리카 해안의 개척지 밖 옥수수밭. 왼쪽에 화승총을 든 유럽 정착민 민병대(가죽 조끼·모리온 투구), 오른쪽에 활과 곤봉을 든 포와탄 원주민 전사들(사슴 가죽, 작은 깃털 장식). 두 줄 사이에 민소매 사슴가죽 옷과 조개껍데기 구슬 목걸이를 한 성인 포카혼타스가 두 팔을 벌리고 서 있다. 화약 연기가 걷히는 중. 피·상처 묘사 없음. |
| `pocahontas_join.webp` | 해 질 녘 부두. 범선 옆에 통나무 카누가 닿아 있고, 같은 성인 여성이 뱃전에 올라 바다 건너를 바라보며 웃는다. 뒤로 정착지의 나무 울타리와 원주민 마을의 연기. |

초상은 `images/portraits/mates/h_pocahontas(.webp · _half.webp)`를 쓴다. 정착민 민병대장과 포와탄 전사 우두머리는 `images/portraits/history/pocahontas_militia(.webp · _half.webp)`와 `pocahontas_warrior(.webp · _half.webp)`를 쓴다.
