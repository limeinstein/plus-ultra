# 포르투갈과 콩고 그림 주문서 (2026-10-28)

이벤트: `js/systems/kongo.js` · 대사: `js/data/kongo.js`. 넣기만 하면 바로 쓰인다(없으면 그림 없이 대화만). 규격은 기존 전설 장면 그림과 같다(1881×836).
인물 얼굴은 이미 있는 그림을 빌린다 — 주앙 2세 `sponsors/pt_king`, 디오구 캉 `rivals/디오구 캉`, 콩고 사람 `npc-roles/af/*`, 사제 `npc-roles/ib/priest`.

| 파일 | 내용 |
|---|---|
| `kongo_call.webp` | 1482년 리스본 왕궁. 탁자 위에 펼친 아프리카 해도, 그 곁에 문장과 십자가를 새긴 돌기둥(파드랑) 모형. 창밖 테주 강에 카라벨 두 척 |
| `kongo_padrao.webp` | 콩고 강 어귀. 푸른 바다 위로 흙빛 강물이 끝없이 밀려 나오고 풀섬이 떠내려간다. 남쪽 곶에 막 세운 돌기둥, 카라벨 두 척, 깃털 모자를 쓴 소요의 주인과 사람들 |
| `kongo_lisbon1.webp` | 리스본 왕궁, 비단옷을 입은 콩고 사람 넷이 국왕 앞에 섰다. 가장 나이 든 사내(은사쿠)가 성당 쪽 창을 올려다본다 |
| `kongo_return.webp` | 콩고 해안. 비단옷 차림의 젊은이들이 배에서 내리고, 한 여인이 달려와 아들을 끌어안는다. 북과 상아 뿔피리를 든 사람들 |
| `kongo_lisbon2.webp` | 리스본 왕궁, 검은 비로드 옷에 금 십자가를 건 콩고 사절(주앙 다 실바)과 사제·수사·석수들 |
| `kongo_baptism.webp` | 1491년 음반자 콩고 언덕, 지붕이 덜 덮인 성당 앞. 표범 가죽 위의 콩고 왕 이마에 사제가 물을 붓는다. 왕비와 기도서를 쥔 젊은 왕자, 구름처럼 모인 사람들 |
| `kongo_students.webp` | 리스본 돌길, 산투 엘로이 수도원으로 걸어가는 콩고 젊은이 열 남짓. 두리번거리는 얼굴들 |

실존 인물·사건이므로 다른 작품의 그림을 옮기지 않고 새로 그린다. 노예 무역을 떠올리게 하는 사슬·족쇄는 이 장면들에 넣지 않는다.
