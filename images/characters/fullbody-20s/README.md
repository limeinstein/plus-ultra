# 20대 제독 전신상

내장 ImageGen으로 `images/characters/player_half*`의 20대 얼굴·무릎상을 각각 참고해 만든 정면 전신상이다.

## 공통 제작 지시

- 원본과 같은 얼굴, 머리, 모자, 의상, 색, 장신구와 반실사 역사 게임 화풍을 유지한다.
- 머리와 어깨를 수평으로 맞추고, 척추를 곧게 편 정면 정자세로 선다.
- 양팔은 자연스럽게 아래로 내리고 양손은 비운다.
- 망원경, 책, 밧줄, 무기 등은 손에서 내려 허리나 등에 고정하며, 모자는 머리에 쓴다.
- 머리 또는 모자 끝부터 양쪽 부츠 밑창까지 전부 보이는 1024×1536 세로 구도다.
- 인물 한 명만 두고 실제 투명 알파 배경으로 만든다. 글자, 테두리, 풍경, 바닥, 워터마크는 넣지 않는다.
