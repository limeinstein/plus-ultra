# 부하들 사이의 썸 이벤트 그림 5종

`js/data/romance.js`의 사건 흐름에 맞춘 `576×256` WEBP 그림이다. 기존 `images/family-events/`와 같은 영화적 사실화와 9:4 구도를 따르되, 제독과 아내가 아니라 같은 배에서 일하는 남녀 부하를 중심으로 그렸다.

얼굴과 출신이 정해지지 않은 여러 부하 조합에 재사용할 수 있도록 손, 뒷모습, 옆얼굴의 그늘, 행동을 중심으로 구성했다.

## 장면

1. `01_snack_share.webp` — 야간 당직 무렵 빵과 말린 무화과를 슬쩍 나누는 두 부하
2. `02_moonlit_bow.webp` — 달 밝은 뱃머리에서 별자리를 함께 보는 두 부하
3. `03_confession_token.webp` — 돛 그늘 아래에서 작은 표식을 건네며 마음을 고백하는 장면
4. `04_lovers_quarrel.webp` — 난간에서 등을 돌린 사람과 모자를 쥔 채 사과하려는 연인
5. `05_harbor_wedding.webp` — 항구에서 돛천 꽃과 밧줄로 꾸민 소박한 선원 혼례

전체 미리보기는 `../../docs/art/romance-events-preview.jpg`에 있다.

## 공통 제작 지시

- 용도: 15세기 말 대항해 시대 배경의 게임 이벤트 일러스트
- 표현: 기존 가족 이벤트 그림의 따뜻하고 영화적인 색감, 사실적인 목재·밧줄·리넨·가죽 질감
- 화면: 9:4 초광폭 파노라마, 중심 행동이 잘리지 않는 구도, 최종 `576×256`
- 인물: 같은 지위의 성인 남녀 선원, 특정 얼굴·눈·머리색·민족적 특징을 고정하지 않음
- 시대성: 후기 15세기 범선, 항구, 옷과 소품에 맞는 재료만 사용
- 분위기: 건전하고 일상적인 호감, 연애, 갈등, 화해와 축하
- 제외: 글자, UI, 로고, 워터마크, 현대 물건, 선장 표식, 판타지 갑옷, 선정적 자세, 과장된 신체 표현

각 그림은 위 공통 지시에 해당 사건의 행동·장소·빛을 덧붙이고 `images/family-events/`의 관련 장면 2장을 화풍 참고로 사용해 내장 ImageGen으로 만들었다.
