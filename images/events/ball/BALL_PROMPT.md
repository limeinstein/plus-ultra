# 무도회 · 데뷔탕트 — 그림 주문서 (2026-11-03)

없으면 장면 그림은 건너뛰고, 아가씨 얼굴은 궁정 공주 그림(`portraits/princesses/court_princess_*`)을, 마녀 얼굴은 그린 얼굴을 대신 쓴다.
