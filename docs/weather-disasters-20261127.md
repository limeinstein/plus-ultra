# 비·눈, 이동 재해와 극지 유빙

항해·육상 탐험에 눈과 폭설을 연결하고 비·눈의 이동 속력·피로·규율 및 야영 시 대책을 구분했습니다. 강수 상태와 남은 기간은 저장·장면 복귀 뒤에도 이어집니다.

폭우의 물방울·흘러내림·튀김과 폭설의 눈안개·붙은 눈·녹은 물방울을 보강했습니다. 조종 시야를 확보하고 항해·육상·해전에 같은 날씨 연출을 적용합니다.

토네이도·허리케인이 지도 위에서 이동·회전합니다. 접근 경고·진행 방향·우회와 실제 접촉 피해를 연결하고 빠른 이동 중 통과 판정도 보완했습니다.

지진 균열·산의 낙석·강 범람·산불·용암을 실제 지형에 맞춰 표시하고 같은 좌표에서 피해를 판정합니다. 지진 중 정지와 위험 범위 밖 우회를 지원합니다.

북극·남극의 유빙 그림과 통행 판정을 같은 식으로 맞췄습니다. 얼음 옆 열린 물길로 항로를 잡고 옛 저장의 얼음 위 위치·동행선 겹침을 보완했습니다.

기존 번역·발견물 이야기·발견 GIF·여성 제독·네 이야기 모드와 가족·저장 호환을 유지합니다.

규칙 수치는 `G.BALANCE.travelWeather`·`disaster`, 연출 수치는 `G.FX.snowfall`·`weatherGlass`·`water.packIce`·`movingDisaster`·`groundDisaster`에 모았다. 새 강수 갈래가 없는 옛 항해 저장은 비로 해석하며 새 육상 강수·재해 상태는 필요할 때 만든다. 파도 높이 식과 기본 선박 속력 규칙은 유지한다.

검사: `tests/travel_weather_world.cjs`, `moving_disasters_world.cjs`, `polar_ice_world.cjs`, `sea_rain_smoke.js`, `disaster_smoke.js`, `wavecheck.js`. 정식·베타 빌드와 공개 주소에서도 강수·회오리·극지 항해를 실제로 실행한다.
