- 기존 정식·베타 주소의 종료 시각: 2026-11-21 00:00:00 +09:00.
- 기존 `/plus-ultra/`, `/plus-ultra/beta/`는 종료 안내를 표시하며 새 주소로 보내지 않는다.
- 브라우저 차단문은 종료 시각에 문서를 교체하여 실행 중인 게임도 끝낸다. 같은 출처의 HTTP Date와 단조 증가 시계를 함께 확인한다.
- 기존 Pages 작업은 종료 시각 이후 게임 파일을 제외한 종료 안내만 게시한다. GitHub 예약 작업은 지연될 수 있으므로 정각 차단은 브라우저 차단문이 담당한다.
- 새 업데이트 주소: https://limeinstein.github.io/loop-good-hope/ · 베타: https://limeinstein.github.io/loop-good-hope/beta/

- 새 게시 저장소의 Pages 작업을 수동 실행하면 즉시 갱신한다. 15분 간격 예약 검사도 원본 변경을 감지하면 배포한다. GitHub 예약 작업에는 지연이 있을 수 있다.
- 정적 게임의 종료 차단은 일반 웹 접속용이다. 이미 따로 내려받은 게임 파일이나 수정된 클라이언트의 실행까지 원격 회수하는 보안 장치는 아니다.

게임 내용은 기존 공개판 0.344를 유지한다. 작성 중인 작업 트리의 게임 변경은 이번 주소 변경에 포함하지 않는다.
