### 職業與難度

- 年齡獎勵：能力點數 4 + (年齡 − 18) × 0.5，特長點數 3 + (年齡 − 18) ÷ 4。
- 知識獎勵：智力從40起每15點特長點數+1（最多+3），智力99以上則+4。

### 存檔

- **自動存檔** — 遊戲中每1分鐘輪流存入5個存檔位（從最舊的位開始覆蓋）。可以在設定中關閉。
- **旅館日誌** — 在旅館「功能 → 記錄航海日誌（存檔）」或宅邸中，從5個位中選一個留下。
- 難度「嚴格規則」下，只能在母國城市的旅館寫日誌。

### 航海手冊

![航海手冊 — 提督標籤](guide/p05_book)

| # | 標籤 | 顯示內容 |
| --- | --- | --- |
| 1 | 提督 | 年齡·名聲類別·持有金·存款·惡名·健康·爵位·武器·配偶·子女·能力值·特長·語言 |
| 2 | 艦隊 | 紀律·疲勞·船員最少~最多·糧食·水·載貨·船隻列表·艦隊速度（以最慢的船為準） |
| 3 | 夥伴 | 部下們的能力值（體力·智力·武力·魅力）·特長·語言 |
| 4 | 候鳥 | 知道訊息的航海士，以及聽到訊息時他所在的地方 |
| 5 | 隨身物品 | 最多40格 — 裝備·丟棄·閱讀 |
| 6 | 發現物 | 找到的數量·海圖繪製%·各類別卡片（已報告·已發表·未報告·競爭者） |
| 7 | 線索 | 收集到的線索 |
| 8 | 成就 | 成就 |
| 9 | 契約·委託 | 後援者契約和行會委託 |
| 10 | 交易手冊 | 到過的城市的行情記錄，時代需求 |
| 11 | 歐洲局勢 | 歐洲各國之間的關係 |
| 12 | 海圖 | 探索過的海域，航線經驗 |
| 13 | 日誌 | 按日期的記錄（從最近的開始） |

- 在酒館打聽到候鳥的下落後，那隻候鳥會在該港口停留59天。再次打聽同一個人的訊息，期限不會延長，而是告訴你扣掉已過天數後的剩餘天數。在手冊「候鳥」中也能檢視剩餘停留天數。
- 手冊「候鳥」裡只記下親眼見過、打聽過下落或一起航海過的航海士。記下的地點是聽到訊息時的地點，時間一久就會變淡，變成「從前在○○」。
- 對酒館女招待用「拜託打聽航海士的下落」準確寫出見過或有過交情的航海士的名字，只要不是太遠的地方，她就會向周圍的水手打聽，把下落找出來。訊息要過一段時間後再去找那位女招待才能聽到。
- 提督年紀大了，或者部下長時間一起航海，部下可能會去世、身體垮掉，或因為別的事離開船。貨艙裡的藥材、船上的醫生、港口的醫生有時能幫他渡過難關。

## 建築

### 港口

![港口](guide/p10_harbor)

| # | 按鈕 | 作用 |
| --- | --- | --- |
| 1 | 出航準備 | 一次搞定船員·修理·糧食·水·修理材料（下一頁） |
| 2 | 出航 | 出海。如果有熟悉的航線，還會出現「以自動航行出航」 |
| 3 | 補給 | 分別決定糧食·水（天份）和修理材料（桶）。減少的話按補給價的50%賣回 |
| 4 | 艦隊編成 | 最多5艘，最上面是旗艦。更換旗艦·每艘船的人員（自動決定）·從船塢編入·寄存到船塢·報廢 |
| 5 | 城鎮情報 | 買下陌生城市的位置記到海圖上（每條 40 + 城市規模×20枚） |
| 6 | 發表 | 把找到的發現公之於世 — 只獲得名聲（沒有可發表的東西時變灰） |

- 無法出航的情況：沒有船 · 船員不足5人或不足最少人數的1/3 · 糧食或水不足2天份。
- 季風海域的港口還會多一項「季風情況」。
- 「船塢」：寄存從艦隊中撤下的船。母港船塢可無限期寄存10艘，其他港口的船塢可寄存3艘，過了2年就會被報廢（剩90天·30天時會通知）。更換旗艦在造船廠也能辦。

### 造船廠

| # | 按鈕 | 作用 |
| --- | --- | --- |

#### 船首像的效果

| 效果 | 實際作用 |
| --- | --- |
| 速力 | 裝了該船首像的船速力 +%（只限那艘船） |
| 船體 | 海戰炮擊·暴風中受到的傷害 −% |
| 暴風 | 遇到暴風的機率 −(3倍)%（最多 −65%） · 暴風傷害 −(2倍)%（最多 −30%） |
| 怪物 | 海怪按該機率退去 · 受到怪物的傷害 −%（最多 −50%） |
| 海戰 | 我方炮擊命中 +% |
| 幸運 | 平安度過海上事件（幽靈船·冰山·淺灘·熱病·塞壬）的機率 +(2倍)%p |
| 紀律 | 航海中每天紀律 +(2倍) — 魔王像會扣減 |

- 裝在多艘船上時，同樣的效果取最大的一個全額生效，其他船上的只加¼。在「艦隊」視窗下方的「船首像效果」裡可以看到現在生效的合計。
- 神話之獸船首像（仙女·獨角獸·獅鷲·天馬·塞壬·特里同·麒麟·龍·不死鳥·迦樓羅）造船廠不賣。只能從阿瓦隆·獨角獸·波斯波利斯·帕特農·特洛伊·亞特蘭蒂斯·麒麟·黑龍·基輔聖索菲亞·普蘭巴南這類偉大發現的遺物中獲得。
- ★ 7種傳說船首像，要打倒傳說中的海怪（利維坦·巴庫納瓦·扎拉坦·耶夢加得·磯撫·西帕克特利·幽靈船）才能撈到。每一種都有其他船首像沒有的「傳說之力」 — 平靜之海（暴風最多 −88%） · 母親的懷抱（損失的船員減半） · 癒合的龜甲（每天船體1%） · 世界盡頭的低語（每30天一條線索） · 牽引之尾（速力加成作用於艦隊所有船） · 顫抖的炮手（敵方命中 −12%） · 詛咒（魔王像 — 天使像·聖母像·米迦勒像·聖尼古拉像可以擋住）。
- 遺物·傳說船首像拆下，或賣掉·報廢裝著它的船時，會退回到隨身物品裡。

**子女** — 在宅邸「家人」裡和孩子見面、教導、陪玩，也可以讓他們作為見習生上船。

- **天生的器量** — 每個孩子每項能力能成長到的上限由運氣決定（初始能力 + 6~26，天賦才能會更寬裕）。在器量以下長得很快，一碰到器量就很難再升。同樣的教育，每個孩子的成長也各不相同。
- **特長** — 家庭教師也不是每年都一定請得到。等級越高越難，智力越高學得越好，成年（16歲）以前最多到2級。3級要成年後在船艙或行會里習得。
- **每年的運氣**（6~15歲） — 「好年頭」裡有一項能力不論器量 +1，「艱難的一年」（熱病·迷茫）那年自然成長的份就沒有了。
- **母親的語言和手藝** — 每年可以從同住的母親那裡學會一種語言·一項特長（最多到母親的等級）。女招待出身的母親會說家鄉話（熟練）和那一帶通用的語言（普通），還會雄辯·烹飪·音樂·會計中的一兩樣手藝（1~2級）。部下出身的母親則是那個人會的語言和特長。在船上的孩子學不到母親的東西。
- **一同航海** — 成年的兒子和沒出嫁的女兒可以在「家人」 → 「讓他上船一起走」裡成為航海士加入艦隊。船艙·職務乃至其他船的船長都像部下一樣安排，月薪減半，忠誠由與父親的關係決定。作為見習生上船的孩子到十六歲會自動成為正式航海士。在船上學到的特長·語言都會留在孩子身上，選「讓他留在家裡」或解僱的話就會回家（可以再讓他上船）。
- **三十歲以上兒子的獨立** — 沒上船的兒子過了三十歲，在你回宅邸時會出去自謀生路（按成長得最好的能力，成為商船的船長 · 大學的學者 · 某位君主的騎士 · 港口的商人）。可以給盤纏、祝福他，或者說「那就上我的船吧」和他一起航海。要是一直不回去，他會在三十三歲時留下一封信離開。離開的兒子也**可以繼承家業**（隱退時可以選擇，繼承的話就會回來），妻子每年都會轉交他的信，可以用「到我的船上來吧」再把他叫回來。
- **繼承家業時** — 在船上的兒子會從艦隊下來當提督，船上的其他兄弟則作為弟弟航海士繼續留在船上。

| 4 | 求情 | 只在持有金 + 金庫 + 貨物價值在10,000以下時 — 海盜會讓開 |

- 靠近沒有敵意的船，可以選「打聽訊息」（線索或行情）、「買糧食·水」（只限商船，一桶4枚）、「攻擊」等。攻擊商船·艦隊會增加惡名。
- 有王宮的私掠許可狀的話，海盜來襲的頻率減少80%。

### 著名海盜 · 懸賞通緝 · 海盜旗

- 每片海都有青史留名的海盜和傳聞中的海盜率領海盜團出沒（在海盜群中偶爾出現）。
- **餐館「看懸賞告示」**：那座城市所在海域裡現在活躍的著名海盜的告示。點選告示可以放大看肖像·海盜團·旗幟·賞金。打倒那個海盜的艦隊後，在任何港口的餐館都能**「領取賞金」**。
- **海盜傳聞**：餐館「聽客人們講海盜故事」（每次來訪一回，免費，期限短） · 酒館女招待「道謝並打聽訊息 → 著名海盜的傳聞」（要付謝禮，期限寬裕）。在期限內到達聽說的那片外海，那個海盜的艦隊真的會出現。會記在手冊「要做的事」裡。
- **海盜旗**：每個海盜團有一面旗 — 第一次打倒那個海盜團的海盜就能拿到（隨身物品種類「海盜旗」）。拿下巢穴的話，巢穴海盜團的旗也能拿到。在手冊「海盜巢穴」下方可以看到收集的數量。
- 在一片海里打倒三個不同的著名海盜，海盜巢穴就會暴露。傳聞會優先告訴你還沒算進去的海盜。
- **吸收**：打倒著名海盜後，他的殘黨會流入同一片海的其他著名海盜（先流向同一海盜團，一個海盜最多吸收兩股）。被吸收的海盜不會再出現，吸收的海盜每吸收一人就多一艘船，船員·炮術變強，賞金也會提高。告示上顯示「吸收殘黨 1/2」。如果沒有海盜肯收留，被打倒的海盜會重新聚集船隻。

同一種房間設幾間，力量會疊加，但最多為8。

## 能力值 · 特長 · 語言

提督擅長什麼，由三樣東西決定 — **能力值**（天生的底子）、**特長**（學來的本事）、**語言**（聽懂和說話的能力）。這一章不寫數值，而是寫「用在哪裡」。

### 能力值 — 四種

能力值有 **體力 · 智力 · 武力 · 魅力** 四種，在手冊「提督」裡以條形顯示。（酒館的航海士卡和在家教孩子時，體力也叫作「力氣」。）

- **最初決定的** — 年齡越小體力·武力越高，年紀越大智力·魅力越高。按職業會多加一點相稱的能力值，生日的星座會提升一項能力值。年紀越大獎勵點數越多，可以分給想要的能力值。
- **一生中會變的** — 靠做事積累的 **經驗** 一點點提高（見「經驗與成長」頁），也會因爵位·婚姻·環遊世界之類的 **大事件** 而提高。
- **年齡** — 年輕時體力會一點點增長，過了中年，體力和武力每年都會減少。晚年的冒險靠的是智力和魅力。
- **部下的能力值** — 部下也有四項能力值。代為出戰一騎討時、掌管其他船的船長打白刃戰時、在報告·發表場合幫腔時，用的都是那個部下的能力值，說話方式和性格也像他的能力值。
- **招募夥伴** — 每個航海士都有自己喜歡的東西，他喜歡的那項能力值高，就容易一起共事。

### 體力 · 智力

**體力** — 撐下去的力量

- 一騎討中能撐住的體力變大。是部下的話，被打中時也會傷得輕些。
- 在酒館連乾幾杯也不容易醉倒。
- 旅館打雜的工錢變多。
- 經驗：靠美食 · 戰鬥 · 一騎討成長。中年以後每年會一點點減少。

**智力** — 學習的力量

- 特長和語言 **最多能學幾種**，由智力決定（建立提督和行會修習的上限）。
- 建立提督時智力高，會額外得到特長點數。智力最高的還會再多給一次。
- 行會的修習特長·學習語言更容易成功。在旅館打雜學當地語言的速度也會變快。
- 一騎討中佯退·誘敵·虛步之類的計謀更容易奏效，也不容易中對手的計。
- 智力非常高的話，陸戰後能多救回一些倒下的隊員。
- 在宅邸和孩子下國際象棋時，是提督的智力和孩子的智力較量。
- 經驗：靠交易 · 說服 · 社交，以及第一次讀的書成長。

### 武力 · 魅力

**武力** — 戰鬥的力量

- 一騎討的威力變大 — 打得更準、更狠，拔刀更快。
- 一騎討的決定性招式更容易奏效：一擊必殺（武力極高時，對手傷得不重也能嘗試） · 生擒 · 怒喝。
- 掌管其他船的 **部下船長的武力**，就是那艘船的白刃戰攻擊力。（提督所在的旗艦用提督手裡的武器作戰。）
- 催債時「恐嚇」更管用，外交談判中「提醒對方有共同的敵人」也更有分量。
- 經驗：靠戰鬥 · 一騎討成長。中年以後每年會一點點減少。

**魅力** — 贏得人心的力量

- 與後援者的契約談判、用雄辯說服對方接受不感興趣的發現、與外國宮廷的條約談判都會更順利。
- 交易所·市場的討價還價更容易成功。
- 催債時「好言相勸」、叛亂時用話安撫帶頭人都更容易成功。
- 在報告·發表場合，提督在旁幫腔會更順利。魅力極高的話，對異性後援者更加管用。
- 一騎討中更容易用「說服」讓對方收刀，「怒喝」也更有分量。
- 經驗：靠說服 · 社交 · 交易成長，受封爵位或成婚時也會提高。

### 經驗與成長

每做成一件事，那一類的 **經驗** 就會積累，再按各類規定的能力值分進去。

| 經驗 | 積累時機 | 成長的能力 |
| --- | --- | --- |
| 說服 | 說服後援者·談判·消除懷疑 · 與守備隊長交涉 · 安撫叛亂 · 催債（用嘴） · 宮廷條約談判 · 一騎討「說服」 · 在報告場合幫腔 | 魅力 · 智力 |
| 交易 | 在交易所買賣（利潤越大越多） · 討價還價成功 | 智力 · 魅力 |
| 戰鬥 | 海戰 · 陸戰（贏了多，敵人越強越多） | 武力 · 體力 · 智力 |
| 一騎討 | 提督親自交手的一騎討（部下代打不算） | 武力 · 體力 |
| 美食 | 在餐館吃一頓（第一次嚐到的菜加倍） | 體力 · 魅力 · 智力 |
| 社交 | 每次獲得社交名聲時 | 魅力 · 智力 |

- 失敗也能學到一點（說服失敗、打仗輸了，都會積累經驗）。
- **能力值越高，再升1就越難。** 到中等左右很快，越往上越要花上幾年、幾十年。
- 一項能力值每天和每年能積累的經驗都有上限，不能靠反覆做同一件事集中練高。就算傾盡一生，單靠經驗也幾乎不可能達到100。
- 也會因 **大事件** 而提高：受封爵位 · 第一次成婚 · 受封英格蘭騎士（魅力），救出失蹤的王女 · 大海戰勝利（武力），伊麗莎白公主避難（智力），寫出漂流記 · 環遊世界（體力和智力）。已經很高的能力值，事件不會直接提高，而是轉為經驗積累。
- 提高時會有通知，也會留在航海日誌裡。在手冊「提督」下方的「經驗與成長」裡，可以看到各類經驗和到下一點還差多少。

### 特長 — 等級與用法

特長有17種，分 **0~3級**（◇◇◇ → ◆◆◆）。

- **用誰的等級** — 在提督本人、擔任用到該特長職務（副官·航海士·測量士·賬房）的部下、安排在用到該特長船艙的部下當中，取 **最高的等級** 作用於整個艦隊。
- **只要帶著就行的特長** — 烹飪 · 音樂 · 繪畫 · 工藝，就算沒有職務，艦隊裡有會這門手藝的人，大多都能發揮作用。防壞血病的醫學也是船上的任何人都行。
- **每艘船分別生效的特長** — 其他船的炮擊·白刃戰·暴風傷害·修理，由掌管那艘船的船長一個人的特長決定。
- **忠誠低的話**，部下不會使出全部本事。受傷期間也只發揮一半。

**學習特長的途徑**

- **建立提督** — 在職業決定的初始特長上花點數提升。最多能學幾種由智力決定。
- **行會「修習特長」** — 花錢和天數一級一級提升。智力越高越容易成功，等級越高越難。失敗就只白花錢和日子。
- **部下** — 在船艙裡待久了，那個房間的手藝會上身，年復一年等級會提高（副官室是雄辯，操舵室是航海術，瞭望臺是測量）。那個房間的主特長（★）3年·9年·27年分別 +1·+2·+3，輔助特長（☆）慢1.2倍，3.6年·10.8年·32.4年分別 +1·+2·+3（例：陸戰隊待命室 — ★劍術 · ☆射擊術）。特長最多到3。
- **子女** — 在宅邸教導、帶去見習航海就會成長（最多到提督艦隊的水平）。成年（16歲）以前最多2級，等級越高越難，智力越高學得越好。也會學到同住母親的特長。成年後讓他上船，就像部下一樣在船艙裡學習。
- 讀書不會提升特長。不過學術書需要有懂那門學問的人才能讀。

**LV3特長組合 — 隱藏能力**

提督本人把相配的三種特長都練到LV3，人物資訊裡就會出現隱藏能力。只靠部下的實際等級是不會解鎖的。就算同時湊齊多種組合，每個領域也有上限，不會比現有的特長·船艙·裝備強太多。

### 特長 — 船與海（1）

**航海術**（航海士 · 操帆室，其他船看該船船長）

- 減少海上每天積累的疲勞。
- 遇到暴風時減少船·船員·糧食的損失（但避不開暴風）。旗艦的航海術對其他船也有一點影響。
- 船長航海術高的船速度快，逆風走之字形時損失也小。
- 更容易逃離敵人、避開冰山·淺灘、察覺海嘯的徵兆。
- 一個懂航海術的人都沒有的話，出航時副官會勸阻。讀某些航海學術書時需要。

**操船術**（航海士 · 甲板 · 操帆室 · 參謀室）

- 海上船員的紀律下降得少。幾艘船一起走時會拉著慢船，佇列不容易掉隊。
- 陸上探險時走得更快、疲勞積得更少，野營休息的效果更大。沙漠烈日·沙暴的開銷減少，暴風雪·沼澤中也更容易保住隊員。
- 減少災害損失，遇到魚群撈得更多，釣魚也更容易咬鉤。
- 安排在參謀室的話，陸戰計謀（奇襲·陷阱·狙擊）更容易奏效。

### 特長 — 船與海（2）

**測量**（測量士 · 製圖室 · 瞭望臺 · 參謀室）

- **從2級起在海上能看到緯度**（經度要有六分儀才看得到）。
- 尋找未知港口的範圍、海圖顯現的寬度、瞭望臺先察覺的距離都會變大。陸上偵察也一樣。
- 沒有線索也更容易找到海上的發現物、跟著海鳥找到新港口、找到山中的古道。在野營地也能汲到更多水。
- 對陸戰的奇襲·陷阱、察覺災害徵兆有幫助。藏寶圖在測量越高時，能用越多的證據縮小位置。
- 遠征計劃中沒有懂測量的人時會出現警告。讀某些學術書時需要。

**造船技術**（副官 · 船舶修理室，其他船看該船船長）

- 在海上用材料修船（沒有材料就修不了）。船舶修理室能把旗艦修得更好。
- 上岸野營修船時、遇到沉船事件時能修得更多。
- 懂當地語言的話，可以在手冊裡查到還沒去過的城市有沒有造船廠、技術到什麼程度。

### 特長 — 戰鬥

**劍術**（副官 · 甲板 · 陸戰隊待命室，其他船看該船船長）

- 海戰的白刃戰變強。旗艦的陸戰隊待命室會讓它更強。
- 一騎討：提督用 **提督本人的劍術** 作戰（部下的劍術不疊加）。打得更準，暴擊和先手更多，更能看穿對手的招。部下代為出戰時用那個部下的劍術，「換人」時由最強的人出戰。
- 陸戰：步兵·騎兵·提督隊變強，3級時騎兵成為重灌騎兵。劍術·射擊術·炮術都到3級的話，提督隊成為無敵提督隊。
- 狩獵收穫稍有增加，遇到幽靈船也更容易撐住。催債「恐嚇」時也用得上。

**炮術**（副官 · 炮擊室，其他船看該船船長）

- 海戰中裝填更快，炮彈更準。旗艦的炮擊室會增加威力。
- 陸戰炮兵變強，3級時成為加農炮兵。

**射擊術**（副官 · 陸戰隊待命室）

- 海戰中用不上 — 用於陸上的戰鬥和狩獵。
- 陸戰槍兵變強，3級時成為火槍兵。「狙擊」計謀更容易奏效。
- 一騎討「秘密武器」改用手槍代替短劍。
- 在狩獵和野牛群事件中獲得更多糧食。

### 特長 — 照顧船員的本事

**醫學**（副官 · 診療室 / 壞血病方面船上的任何人都行）

- 壞血病開始得晚，蔓延得慢。診療室會讓它更晚。也能有效防止海上熱病。
- 陸上探險時因熱病失去隊員的情況減少，更會找草藥，也更容易熬過暴風雪。
- 減少災害損失，陸戰後能救起部分倒下的隊員。某些學術書和傳說事件也需要它。

**烹飪**（任何人）

- 用船上和野營地的飯菜減輕疲勞。雨天的疲勞也能減輕，狩獵那天的晚餐更豐盛。
- 發生叛亂時可以選「開宴安撫」（烹飪或音樂有一樣就行）。也會發生海上宴會事件。
- 能看出並提高香料·作物之類可食用發現物的價值。
- 廚房的廚師會憑手藝做家鄉菜，減輕疲勞、提高紀律。是提督家鄉菜的話更受歡迎。

**音樂**（任何人）

- 用歌聲和樂器穩住船員的紀律。船歌事件變多，野營休息的效果變大。
- 叛亂時可以開宴（和烹飪相同）。
- 提高人們的歌·舞·儀式之類民族發現物的價值，並讓他們當場敞開心扉。
- 娛樂室照顧紀律，音樂室照顧疲勞。音樂室相鄰就會組成合奏（二重奏·三重奏·四重奏·樂隊·樂團）。

**神學**（副官 · 禮拜室）

- 在海上穩住船員的紀律。禮拜室穩得更牢。
- 向教堂捐獻名聲漲得更多，在教堂祈禱紀律會提高。
- 遇到幽靈船·塞壬也不會動搖。
- 讀神學學術書時需要。

### 特長 — 人與生意

**雄辯**（副官 · 餐廳 · 副官室）

- **有雄辯才能** 嘗試說服後援者接受他不感興趣的發現。
- 與後援者的契約談判更順利，提高預付款或延長期限時損失更小 — 等級越高爭取到的條件越有利。
- 名聲不夠時哄管家、證據薄弱時「請證人作證」都更容易成功。在報告·發表場合會以堂堂正正的語氣開場。
- 入港時與守備隊長交涉更便宜、更順利，偷偷進城也更容易。
- 向原住民搭話獲得線索、用禮物收買人心都更容易成功。
- 用於安撫叛亂帶頭人、一騎討「說服」、挽留想離開的部下·夫人、勸和部下夫妻吵架、催債「勸說」、在酒館打聽藏寶圖的故事。
- 會說當地語言且雄辯高的話，也會知道沒去過的城市的領袖。

**會計**（副官 · 賬房 · 會計室）

- 在交易所講價更管用，砍得更多，每次來訪能講價的次數也會增加。有賬房的話還能再多一次。
- **有會計** 市場裡才會出現「討價還價」。
- 貨物裝得均勻，船能承受的重量增加。
- **3級時** 能進入大港口的後巷黑市（每次交易都會增加惡名）。
- 懂當地語言的話，可以知道沒去過的城市的特產和繁榮程度。
- 有 **賬房** 的話講價會大為有利，與後援者的契約談判可以多來一次，預付款也拿得更多。會計室會減少薪水。

### 特長 — 學問與發現（1）

**歷史學**（副官 · 測量士 · 參謀室）

- 尋找陸上發現物的範圍變大，沒有線索也更容易找到。陸上偵察也看得更遠。
- 更善於察覺災害的徵兆。從2級起更能辨認古代記錄裡留下的災害。
- 知道沒去過的城市的領袖。
- 讀歷史學術書時需要（古抄本中有的要2級才能解讀）。

**科學**（副官 · 診療室 · 飼養室）

- 延緩壞血病，預防海上熱病，更會找草藥。
- 尋找生物·自然發現物的範圍變大。也更善於察覺災害的徵兆。
- 釣魚時更容易釣到珍貴的魚。在斯芬克斯之謎中替你劃掉一個錯誤答案。
- 飼養室能培育出糧食。讀科學學術書時需要。

### 特長 — 學問與發現（2）

**繪畫**（任何人 · 製圖室 · 畫室）

- 所有發現物的價值都會提高 — 名聲 · 報告酬金 · 命名賞金。
- 決定 **證據等級**：越精通繪畫越是「精密圖版」，畫得差是「速寫」，誰都不會畫就成了「口述記錄」，後援者可能會懷疑。以後有擅長繪畫的部下加入，可以重畫以提高等級。
- 把鯨群·瀑布之類的壯觀景象畫進畫冊獲得名聲。我獻上的仿製品也不容易被識破。
- 畫室的部下會畫美術品裝進貨艙。

**工藝**（任何人 · 雕刻室）

- 寶物·遺蹟·民族發現物的價值大幅提高，其他發現物也稍有提高。賣遺物時價格也會提高。
- 在沒有遺物的寶物·遺蹟中能多帶走些值錢的東西。也有助於提高證據等級。
- 仿製品不容易被識破。送飾品給女招待·部下時更能打動人心。
- 雕刻室的部下會製作雕刻品。傳說事件中有的需要工藝才會開啟。

### 語言 — 聽懂

語言有16種（西班牙語 · 葡萄牙語 · 羅曼語 · 日耳曼語 · 斯拉夫語·希臘語 · 阿拉伯語 · 波斯語 · 漢語 · 印地語 · 維吾爾語 · 非洲本土語 · 中南美本土語 · 東南亞本土語 · 東亞本土語 · 朝鮮語 · 北美本土語），等級分 **不會 · 基礎 · 普通 · 熟練**。

- **城市的語言** — 每座城市都有使用的語言，城市畫面上方欄的「語言」格里，用點表示一行人說得怎麼樣。在葡萄牙統治或有葡萄牙商人往來的港口，用葡萄牙語也能溝通。
- **對話視窗** — 提督不太懂那種語言的話，沒聽懂的詞會顯示成那個國家陌生的文字。等級越高聽懂的詞越多，熟練就全都能聽懂。
- **翻譯** — 安排在副官 · 翻譯 · 翻譯室的部下比提督更會那種語言時，對話視窗下方會出現翻譯視窗替你翻譯。翻譯本人也不熟練的話，只能以「大致聽懂」·「斷斷續續聽懂」翻出一部分。
- **原住民** — 就算語言完全不通，比手畫腳也能溝通一點。
- **用誰的語言** — 提督、副官、翻譯、坐在翻譯室的人當中最拿手的那一個。其他職務的部下和其他船船長的語言用不上。（只有在圖書館，帶著的部下會全體一起讀。）不過有 **通譯官**（見下）的話，旗艦上所有部下的語言都能用上。

### 語言 — 碰壁的事與變順的事

**完全不懂語言就做不了的事**

- 交易所的講價和市場的討價還價（買賣是可以的）
- 在酒館聽生意傳聞 · 契約情報 · 目的地 · 酒桌閒話
- 催債，與城門守備隊長交涉
- 拜見後援者（管家不會理你）
- 在酒館招航海士當部下（彼此要有相通的語言才談得攏）
- 在手冊裡查沒去過的城市的特產·領袖
- 那本書的語言誰都不懂時，讀圖書館的書

**越拿手越順的事**

- 交易所·市場講價、城門交涉、催債、外交談判都更順利。
- 偷偷進城更容易。有以那種語言為母語的部下的話，他會當嚮導，更加容易。
- 新招的部下從一開始就更信任你。語言不熟練的話，會聽到「還沒有完全敞開心扉」。
- 在圖書館能讀出書裡更多的段落。語言提高了，重讀同一本書就能得到剩下的段落。
- 遠征計劃中誰都不懂目的地語言時，會出現「請帶上翻譯」的警告。

### 語言 — 學習的途徑 · 安排翻譯

**學習語言的途徑**

1. **建立提督** — 母語是熟練，鄰近的伊比利亞語言從普通開始。剩下的點數可以提升其他語言，最多學幾種由智力決定。
2. **行會「學習語言」** — 花錢和天數，一級一級地學那座城市和附近地區的語言。智力越高越容易成功，等級越高越難。
3. **旅館「打雜」** — 一邊幹廚房活、劈柴，一邊用耳朵學那座城市的語言。智力越高進步越快，但幹活期間名聲會一點點下降，而且不能幹太久。
4. **同船生活** — 每天一點點學會船上部下們的母語。身邊副官的語言進步最快，其他部下的語言進步得慢。部下們也會學提督的母語和彼此的語言。

**安排翻譯**

- 在部下編成中讓人擔任 **翻譯**，那個人的語言就會用於艦隊（翻譯只用語言，不用特長）。
- **副官** 的特長和語言都會用上。
- 在造船廠建 **翻譯室** 安排人員，就能有多個翻譯 — 往來於多片海的艦隊，請平均地帶上會不同語言的部下。
- **通譯官** — 把任命為翻譯的人安排在翻譯室，他就會把提督和旗艦部下會的語言也彙整合「翻譯簿」來翻譯。不懂的語言他會去問懂的人，像「○○告訴我說——」這樣轉述，而且比其他航海士學語言更快（翻譯簿在提督手冊裡）。
- 廚房的廚師會做自己的家鄉菜 — 語言不同的部下越多，船上的餐桌也越豐富多彩。

## 發現與報告

### 發現視窗

![新的發現](guide/p62_disc)

| # | 欄 | 含義 |
| --- | --- | --- |
| 1 | 圖片 | 發現物 |
| 2 | 名稱 · 標籤 | 類別 · 地區 · 價值 |
| 3 | 說明 | 發現物的故事 |
| 4 | 名聲 | 在發現地當場獲得的名聲 |
| 5 | 確定 | 關閉 |

如果獲得了遺物，會一併出現「到手的遺物」 — 向後援者報告就作為證據獻上，在港口自己發表就歸提督所有。

### 報告還是發表

|  | 向後援者 **報告**（王宮·宅邸） | 在港口 **發表** |
| --- | --- | --- |
| 得到的東西 | 酬金 + 名聲 + 信任 | 名聲（發現名聲 × 0.9） |
| 遺物 | 作為證據獻上 | 歸提督所有 |
| 沒有證據時 | 酬金 ×0.55~0.8，名聲 ×0.8 | 名聲 ×0.8 |
| 超過期限時 | 酬金 ×0.35~0.7，名聲 ×0.7 | — |
| 注意 | 沒有契約時，同一年向同一後援者報告，從第二次起酬金會減少 | 發表簽了契約的發現，那份契約就會失敗 |

- **證據等級**：實物 ×1.05 · 精密圖版 ×1.05（繪畫2級以上） · 海圖 ×1 · 速寫 ×0.95（繪畫1級） · 口述記錄 ×0.9。速寫·口述的話後援者可能會懷疑。
- **一併報告·發表**：要報告的發現有兩個以上時，「提議冒險」裡會有「一起報告」，在港口「發表」中可以選多個一起公佈。
- **度假島嶼40處**（自然）：把船靠近蘇梅島·馬爾地夫·巴厘島·塞席爾·聖托里尼·馬德拉·濟州島·塔希提·波拉波拉·模里西斯這類島嶼就能找到。發現那一刻的餘韻「休養」使疲勞 −25 · 紀律 +8（其他自然發現物的「感動」是 −16 · +2）。
- **按類別篩選·排序**：在選擇提議·一併報告·發表視窗上方點選類別按鈕（全部 · 地理 · 自然 · 遺蹟 · 寶物 · 生物 · 民族 · 交易品），就只顯示那一類，「全選可見項」只選顯示出來的。用「排序」可以按價值·類別·名稱·最近發現的順序排列，再次開啟也會沿用。
- **固定隨身物品**：在手冊「隨身物品」·宅邸儲藏室·市場出售視窗裡點選物品前的圖釘就會固定（像收藏一樣）。固定的物品不會被市場出售的「全選」和儲藏室的「全部寄存」選中，可以用種類按鈕「固定」集中檢視。賣掉或寄存後，列表的滾動位置也保持不變。
- **競爭者搶先發表的話**：之後在現場還能找到，但首次發現的榮譽留給競爭者，名聲·酬金會減少。已經簽下的後援契約和相關線索會維持到期限為止。

### 公司成立的時候

獲得國王特許狀的公司每個時代會成立一家。公司成立時會有訊息傳來，總部城市的街道上會出現公司的建築。

- **公司總部**：社員名冊（入會 · 升職） · 公司任務 · 交納專營品 · 股票視窗
- **商館**（海外該公司的城市）：公司倉庫 · 中介訂單 · 公司任務
- **交易所**（安特衛普 1531~1585 · 倫敦 1571~ · 阿姆斯特丹 1602~）：買賣所有公司的股票

### 成為會員以後

在總部的「社員名冊」交出資金加入（綜合名聲200以上）。出資金的80%會以該公司股票的形式返還。**一次只能屬於一家公司**，離開後一年內不能加入任何公司。

| 好處 | 作用 |
| --- | --- |
| 公司倉庫 | 以交易所價格的60%買商館的貨 — 最多到按等級的配額，每60天重新整理 |
| 交納專營品 | 把專營品交給總部可得市價 × 1.25~1.4。**交得越多價格越低**，過一兩個月會恢復 |
| 中介訂單 | 連線商館和大港口的鏈條。每一環都會累積聯動獎勵，連到最後 × 1.5 |
| 公司任務 | 緝私 · 歸航大船隊 · 建設商館 · 俘獲競爭公司（只限當時 **敵對國家的公司**） |
| 海關 | 不是會員的話，帶著該公司專營品駛入總部港口時會被搜查貨物 |

貢獻積累起來就會從社員 → 船長 → 董事 → 總督晉升，配額 · 交納價 · 任務報酬都會提高。

### 股票 · 創立出資

- 股價每月起伏，**每年1月的分紅** 會自動到賬。船隊的歸航 · 沉沒、世上的大事件、提督的公司任務都會影響股價。
- **投資上限**：投入股票的錢（買入價合計）最多金幣 **100萬枚**。賣掉後可以再買那麼多。一家公司的股票最多3,000股。
- **創立出資**：在倫敦（1600） · 阿姆斯特丹（1602 · 1621） · 巴黎（1664）的創立事件中出的錢會成為該公司的股票。在歷史上的認購期內按面值（每股500枚），之後的追加出資按當天行情。
- **創立出資人**：在認購期內出資的人，在公司成立後 **10年內** 只要仍持有當時得到的全部股票，就能不交出資金成為會員。
- 第一次結算（英格蘭東印度公司 1604 · 荷蘭東印度公司 1610 · 西印度公司 1629）按當天持有的每1股分配。
- 交易所的「經紀人的耳語」會提前告訴你即將到來的訊息，但不一定總是準的。

## 常見問題

### 卡住的時候

| 問題 | 回答 |
| --- | --- |
| 在海上經度顯示為「?」 | 要有六分儀才看得到。緯度有星盤·六分儀或測量2級就能看到。故鄉市場總有羅盤·六分儀 |
| 點了港口卻不能自動航行 | 必須在兩個港口之間不停靠其他港口直接走一趟，航線才會開通 |
| 見不到後援者 | 因為名聲不夠。可以向管家請求小活兒，積累名聲和信任 |
| 不能出航 | 船員不足5人（或不足最少人數的1/3），或者糧食·水不足2天份 |
| 書是紅色的 | 是尚未出版 · 系列的前幾本還沒讀完 · 語言或學問不足 · 還沒去過的土地的故事中的一種 |
| 臺詞裡混著陌生的文字 | 是因為不太懂那種語言而沒聽懂的詞。可以在旅館打雜·行會學習語言來學，或者讓擅長那種語言的部下當翻譯（見「能力值 · 特長 · 語言」章的語言頁） |
| 能力值怎麼提高？ | 靠說服·交易·戰鬥·一騎討·美食·社交的經驗一點點提高，也會因爵位·婚姻之類的大事件提高。越高漲得越慢（見「經驗與成長」頁） |
| 不能存檔 | 嚴格規則難度只能在母國城市的旅館存檔。請檢查設定裡是否開啟了自動存檔 |
| 不知道該做什麼 | 請看城市裡的「在這座城市可做的事」和手冊的「發現物」標籤 |
