# 지역 장신구·회복약 확장 — 2026-11-16

장신구 50종(실존 양식·보석 45종, 신화·전승 5종), 약 20종을 추가했다. 지역별 장신구는 4~5종이다. 역사적 양식을 게임 상품으로 재구성했으며 특정 박물관 유물의 진품을 거래한다는 뜻은 아니다. 라 페레그리나는 1560년부터 나온다. 전승 장신구의 마법이나 저주는 실제 전투 효과로 적용하지 않는다.

## 게임 규칙

- 일반 장신구 기준가 3,600~14,000닢. 전설 장신구 300,000~700,000닢. 기존 시장 시세·흥정·되팔기 규칙을 따른다.
- 약은 시장 전체에 0~1종, 수량도 1개만 입고된다. 기본 입고 확률 55%, 7일마다 교체한다. 전설 장신구 입고 확률 3.5%, 입고된 물건은 1점만 살 수 있다.
- 약·전설 장신구는 도시별 입고 기간과 산 품목을 저장해 재방문·저장 복원으로 재구입하지 못한다. 새 저장 필드는 없으면 빈 재고 기록으로 취급한다.
- 수첩 → 소지품 → 약 → 사용. 건강 20~100 즉시 회복, 최대 100. 일기토와 질병이 깎는 동일한 제독 건강 값을 회복한다. 건강이 가득하면 소모하지 않는다. 질병 예방·선원 치료 효과를 새로 부여하지는 않는다.
- 현실의 약 효능·복용법을 재현하지 않는다. 외용약도 게임 속 사용 동작으로만 처리하며 먹는다는 표현을 쓰지 않는다.
- 규칙 수치: `G.BALANCE.marketMedicineDays`, `marketMedicineChance`, `marketLegendChance`; 개별 회복량·가격·지역: `js/data/items.js`.
