# 96 · 새 지역 사건 인물 셋 — 텐징 · 카이 타우 · 아비시니아 수도사

> 사용자 결정(2026-11-23): 셋 다 게임에 넣는다.
> 이 파일은 게임에 넣을 때 필요한 것(만나는 곳 · 동료가 되는 조건 · 말투 · 만남 대사 · 얽힌 발견물 · 자료 모양)을 모은 것이다. 15 보충 표의 「이야기 속 동료」와 같은 자리로 다룬다.

## 1. 텐징 (셰르파 안내인)

| 항목 | 내용 |
|---|---|
| 출신 | 히말라야 쿰부 계곡 남체 마을(557). 야크 몰이꾼 집안 |
| 나이 | 서른 안팎 |
| 만나는 곳 | 557 셰르파 마을 발견 뒤 같은 고장(티베트·네팔 내륙 · 가장 가까운 항구는 캘커타 쪽)에서 「짐꾼 구함」 사건 |
| 동료 조건 | 557을 발견했고, 그 뒤 495 야크 · 556 티베트 유목민 천막 · 에베레스트(2권 3-7) 가운데 하나를 더 발견. 고산 발견물 길잡이 의뢰를 받아 주면 합류 |
| 배역 갈래 | 이야기 속 동료(15 보충 §5와 같은 자리). 성격 배역으로 고를 때는 **베테랑**으로 센다(같은 발견물에 베테랑 장면이 있으면 텐징 줄이 먼저) |
| 특기 제안 | 산길 안내(고산·사막 발견물 탐색 성공률 ↑) · 짐 나르기(육로 탐험 식량 소모 ↓) |
| 말투 | ~하오 · ~지. 말이 적다. 산을 「엄마」라 부르고, 산 꼭대기에 오르는 걸 꺼린다. 서두르는 사람을 말린다 |

**만남 대사**
- 텐징: 바다 사람이 산에 오시오? 산은 바다보다 조용하지만 바다보다 참을성이 없소.
- 텐징: 하루에 조금씩 오르시오. 서두르면 머리가 아프오. 엄마 산은 서두르는 아이를 싫어하오.
- 텐징: 짐은 내가 지겠소. 대신 내가 멈추라 하면 멈추시오. 그게 품삯이오.
- (합류 뒤 첫 출항) 텐징: 배는 처음이오. 땅이 흔들리는구려… 산이 그립소. 그래도 가 보겠소.

**얽힌 발견물**: 495 야크 · 556 티베트 유목민 천막 · 557 셰르파 마을 · 파미르 고원(34권 예정) · 에베레스트(2권 3-7, 다음 손질 때 한 줄 더함)

## 2. 카이 타우 (마오리 길잡이)

| 항목 | 내용 |
|---|---|
| 출신 | 아오테아로아(뉴질랜드) 북섬 바닷가 부족. 카누 길잡이 집안 |
| 나이 | 마흔 안팎 |
| 만나는 곳 | 남태평양 섬 항구(통가 · 피지 · 사모아 쪽)에서 「별로 길을 찾는 사람」 사건. 267 마오리 발견을 했으면 바로, 아니면 547 타니와 바다 동굴 발견 뒤 |
| 동료 조건 | 267 마오리 또는 547 타니와를 발견. 「길고 흰 구름의 땅」으로 데려다 달라는 부탁을 받아 주면 합류 → 619 아오테아로아 합창에서 외침을 맡는다 |
| 배역 갈래 | 이야기 속 동료. 성격 배역으로 고를 때는 **노장**으로 센다 |
| 특기 제안 | 별·파도 항해(대양 한가운데 위치 오차 ↓, 폭풍 뒤 길 잃음 ↓) · 섬 찾기(태평양 섬 발견 범위 ↑) |
| 말투 | ~하오 · ~이오. 조상 이름과 노래를 자주 꺼낸다. 땅과 바다를 사람처럼 부른다. 손님을 극진히 맞는다 |

**만남 대사**
- 카이 타우: 그대 배에는 나침반이 있구려. 우리는 별과 파도와 새를 보오. 둘 다 길이오.
- 카이 타우: 내 조상 쿠페는 길고 흰 구름을 보고 땅을 찾았소. 나는 그 구름 밑에서 태어났지.
- 카이 타우: 나를 고향 앞바다까지 데려다주시오. 그 대신 이 바다의 길을 다 알려 주겠소.
- (합류 뒤 첫 출항) 카이 타우: 이 배는 카누보다 무겁구려. 그래도 바다는 무게를 따지지 않소. 갑시다.

**얽힌 발견물**: 499 키위 · 500 모아 · 547 타니와 바다 동굴 · 574 통가 왕국 · 619 아오테아로아(합창 외침) · 타히티 · 마우나케아 · 마셜 막대 해도(35권 예정)

## 3. 아비시니아 수도사 (이름: 테클레 마리암)

| 항목 | 내용 |
|---|---|
| 출신 | 에티오피아 고원 바위 교회 수도원. 게에즈 말로 경전을 읽는 수도사 |
| 나이 | 쉰 안팎 |
| 만나는 곳 | 161 프레스터 존의 나라 발견(또는 그 합창) 뒤, 가장 가까운 항구(마사와 · 제일라 쪽)에서 「바깥세상을 보고 싶은 수도사」 사건 |
| 동료 조건 | 161을 발견. 수도원장에게 선물(성경 · 책 · 종 가운데 하나)을 바치면 수도사가 길동무를 자청 |
| 배역 갈래 | 이야기 속 동료. 성격 배역으로 고를 때는 **선교사**로 센다. 다만 서양 선교사와 다른 사람이라 말투와 시선이 다르다(「우리는 늘 알았소. 바깥사람들만 몰랐지」) |
| 특기 제안 | 옛 글 읽기(유적·문헌 발견물 감정 ↑) · 약초(병자 회복 ↑) |
| 말투 | ~하오 · ~구려. 느리고 부드럽다. 자기 나라가 오래되었다는 자부심이 있다. 바깥 손님을 형제라 부른다 |

**만남 대사**
- 테클레 마리암: 그대들 나라에선 우리 왕을 프레스터 존이라 불렀다지요. 우리는 그 이름을 몰랐소.
- 테클레 마리암: 나는 평생 이 산 위에서 바다 이야기만 들었소. 죽기 전에 소금물을 한 번 맛보고 싶소.
- 테클레 마리암: 경전 한 권과 약초 자루 하나면 짐은 다요. 형제여, 데려가 주시오.
- (합류 뒤 첫 출항) 테클레 마리암: 이것이 바다로구려. 짜오. 하느님이 이렇게 큰 그릇을 만드셨구려.

**얽힌 발견물**: 161 프레스터 존의 나라(합창에 한 줄 더함 — 아래) · 614 푸른 나일의 샘(합창 환호) · 언약궤 · 르웬조리 · 콥트 수도사(38·34·43권 예정) · 083 랄리벨라 · 084 악숨(다음 손질 때 한 줄씩)

161 합창에 더할 줄(합류 전이라도 그 자리에 있으므로 「지역 인물 · 그 자리」로 나온다):
- 테클레 마리암 (환호 · 그 자리): 바다 건너 형제들이 산을 올라왔구려. 오백 년 동안 기다렸소. 아니, 우리는 기다린 줄도 몰랐소. 어서 오시오.

## 4. 게임에 넣을 자료 모양 (제안)

게임 코드를 아직 못 봐서 이름은 짐작이다. 기존 동료·사건 인물 자료 형식에 맞춰 고친다.

```js
// js/data/eventmates.js (예시)
G.EVENT_MATES.tenzing = {
  name: '텐징', from: '남체 (쿰부)', age: 30, kind: 'story',   // 이야기 속 동료
  roleAs: 'veteran',
  join: { needDisc: ['sherpa_village'], needAnyDisc: ['yak','tibet_tent','everest'], region: 'himalaya' },
  skills: { mountainGuide: 2, porter: 2 },
  lines: { meet: [...], firstSail: '...' },
  discLines: { yak: '...', tibet_tent: '...', sherpa_village: '...' }
};
G.EVENT_MATES.kaitau  = { name: '카이 타우', kind: 'story', roleAs: 'oldhand', join: { needAnyDisc: ['maori','taniwha'] }, skills: { starNav: 3, islandFind: 2 }, ... };
G.EVENT_MATES.teklemariam = { name: '테클레 마리암', kind: 'story', roleAs: 'missionary', join: { needDisc: ['prester_john'], gift: ['bible','book','bell'] }, skills: { oldScript: 2, herbs: 2 }, ... };
```

- 발견물 이야기의 「관계 인물 · 텐징 (… 있으면)」 줄은 `discLines`로 옮긴다. 「있으면」은 기함 선실에 있을 때.
- 합창 장면에서는 관계 인물 자리(맨 먼저 · 자리 우선)로 나온다.
- 셋 모두 **만나기 전**에는 그 줄이 나오지 않는다(161의 「그 자리」 줄 하나만 예외).
