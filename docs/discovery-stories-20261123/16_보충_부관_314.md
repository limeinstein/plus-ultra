# 16 · 보충 — 부관 장면 314곳 (1·2권 14곳 + 3~14권 300곳)

> 부관은 모든 발견물에 들어간다. 1~4순위(관계 인물·지역 사건 인물·라이벌 동료·대응 인원)가 기함 선실에 아무도 없으면 **반드시** 부관이 말하고, 누가 있어도 20%로 부관이 대신 말한다.
> 부관 말투: ~습니다 · ~지요 · ~십시오. 실무(선원·식량·돈·배)부터 본다. 겁날수록 농담. 속이 따뜻하다.
> 부관 자리의 동료에게 성격 배역(예: 헬창·유혹녀)이 따로 있으면, 이 장면은 그 사람 이름으로 나오되 말투는 이 부관 말투를 쓴다(부관으로서 하는 말이므로).
> 형식: 부관 두세 마디 / 제독 한마디. 짧게.

## 1·2권
- A1 칭기즈 칸의 무덤 — 부관: 선원들이 무덤 위에서 말 달리던 기병 이야기를 듣고 다들 발끝으로 걷습니다. 우리 말발굽까지 보태면 영영 못 찾겠지요. / 제독: 말은 기슭에 매어 둬라.
- A2 인어의 정체 — 부관: 인어 봤다는 술값을 돌려받으러 항구마다 들르자는 선원이 셋입니다. 허락하시겠습니까? / 제독: 셋 다 술값 대신 갑판 청소다.
- A3 모스켄 소용돌이 — 부관: 선원들 손바닥 껍질이 다 벗겨졌습니다. 노를 그렇게 세게 쥔 건 처음 봅니다. / 제독: 오늘 밤엔 기름을 넉넉히 나눠 줘라.
- A4 모나리자 — 부관: 선원 하나가 저 그림 사 가자고 합니다. 가진 돈을 다 털어 봤더니 액자 한 귀퉁이 값이랍니다. / 제독: 귀퉁이는 안 판다더군.
- A5 고레 섬 — 부관: 오늘은 노래도 술도 없이 가겠습니다. 다들 그러자고 했습니다. / 제독: 그래.
- A6 후추 — 부관: 후추 냄새에 선원 절반이 재채기를 합니다. 돈 냄새가 이렇게 매울 줄은 몰랐습니다. / 제독: 위 칸에 실어라.
- A7 에베레스트 — 부관: 선원들이 저 산을 본 뒤로 돛대 오르는 걸 겁내지 않습니다. 저기에 비하면 돛대는 계단이랍니다. / 제독: 그건 좋은 일이군.
- B1 기자의 피라미드 — 부관: 돌 하나에 소 몇 마리를 썼을지 선원들이 내기를 겁니다. 판돈은 제가 맡았습니다. 이긴 사람은 없을 겁니다. / 제독: 판돈은 돌려줘라.
- B2 왕가의 계곡 — 부관: 횃불 기름이 반이나 줄었습니다. 무덤 하나에 이만큼이면 예순 개는 못 봅니다. / 제독: 하나만 제대로 보자.
- B3 크노소스 — 부관: 분필을 다 써서 선원들이 벽에 손자국을 찍고 다닙니다. 삼천 년 뒤 사람들이 그걸 보고 뭐라 할지. / 제독: 지우고 나와라.
- B4 페트라 — 부관: 협곡에서 물소리가 들리면 높은 데로 뛰라고 다들 일러 뒀습니다. 사막에서 익사할 순 없지요. / 제독: 잘했다.
- B5 진시황릉 — 부관: 흙 병사 얼굴 중에 제 얼굴 닮은 게 있다고 선원들이 놀립니다. 저보다 잘생겼더군요. / 제독: 그건 맞는 말이군.
- B6 치첸이트사 — 부관: 계단 꼭대기에서 손뼉을 치면 새소리가 납니다. 선원들이 백 번은 쳤습니다. 이제 그만 내려가자고 하겠습니다. / 제독: 한 번만 더.
- B7 모아이 — 부관: 이 섬에는 땔감이 없습니다. 오늘부터 밥은 하루 두 끼, 불은 한 번만 피우겠습니다. / 제독: 나도 두 끼다.

## 3권 · 자연 1
- 001 그랜드 캐니언 — 부관: 저 강까지 내려가려면 물을 사흘 치 지고 가야 합니다. 올라올 때는 빈 통만 들겠지요. / 제독: 위에서 본 걸로 충분하다.
- 002 이구아수 폭포 — 부관: 물보라에 화약이 다 젖을 뻔했습니다. 화약통은 숲 안쪽에 두었습니다. / 제독: 잘했다.
- 003 울루루 — 부관: 원주민 노인이 손짓으로 바위에 오르지 말라고 합니다. 선원들에게 단단히 일렀습니다. / 제독: 둘레만 돌자.
- 004 킬리만자로 — 부관: 적도에서 눈을 봤다고 쓰면 고향 사람들이 우리를 거짓말쟁이라 할 겁니다. 눈 한 줌 병에 담아 갈까요. / 제독: 녹을 거다.
- 005 마의 바다 — 부관: 나침반이 춤을 춘 뒤로 선원들이 성호를 너무 자주 긋습니다. 일을 시키는 게 제일 좋은 약이지요. / 제독: 갑판 닦게 해라.
- 006 젊음의 샘 — 부관: 선원 마흔 명이 물을 마시고 거울을 봤습니다. 아무도 안 젊어졌습니다. 대신 다들 세수는 했습니다. / 제독: 그것만 해도 이득이다.
- 007 천상의 커튼 — 부관: 밤 당번이 하늘 구경하다 키를 놓을 뻔했습니다. 오늘 밤은 당번을 둘씩 세우겠습니다. / 제독: 하나는 하늘, 하나는 키.
- 008 나이아가라 폭포 — 부관: 선원 하나가 급류에 빠졌다 건져졌습니다. 오늘 술은 그 녀석이 사기로 했습니다. / 제독: 살았으니 사야지.
- 009 황산 — 부관: 계단이 끝이 없습니다. 짐꾼 품삯을 두 배로 줘야 할 것 같습니다. 안 주면 짐이 계단 중간에 남겠지요. / 제독: 두 배 줘라.
- 010 장가계 — 부관: 기둥이 다 비슷해서 길 표시를 했는데, 원숭이가 표시한 천을 다 떼어 갔습니다. / 제독: 원숭이한테 진 거군.
- 011 하롱 베이 — 부관: 섬 사이 물길이 좁아 큰 배는 바깥에 두었습니다. 작은 배 둘로 돌겠습니다. / 제독: 해 지기 전에 돌아와라.
- 012 후지산 — 부관: 꼭대기에 오르는 순례자들이 짚신을 몇 켤레씩 들고 갑니다. 우리 선원들 구두로는 반도 못 갑니다. / 제독: 짚신을 사라.
- 013 나치 폭포 — 부관: 신사 문 앞에서 선원들이 모자를 벗었습니다. 시키지도 않았는데요. 좋은 배입니다, 우리 배는. / 제독: 좋은 선원들이다.
- 014 베수비오 화산 — 부관: 산 중턱 땅이 뜨거워 구두 밑창이 녹았습니다. 장부에 구두 일곱 켤레를 올리겠습니다. / 제독: 산한테 청구할 순 없군.
- 015 마터호른 — 부관: 저 산은 보기만 하겠습니다. 오르자는 선원은 없습니다. 이번엔 다들 현명합니다. / 제독: 드문 일이군.
- 016 굴포스 — 부관: 물보라가 옷에 얼어붙었습니다. 불을 크게 피우고 젖은 옷부터 말리겠습니다. / 제독: 그래라.
- 017 에이야퍄틀라이외퀴들 — 부관: 이 산 이름을 끝까지 말하는 선원에게 술 한 잔 걸었는데 아무도 못 받아 갔습니다. 술이 굳었습니다. / 제독: 나도 못 하겠다.
- 018 시나이 산 — 부관: 수도원에서 빵과 물을 받았습니다. 값을 치르려 했는데 안 받습니다. 헌금함에 넣어 두겠습니다. / 제독: 넉넉히.
- 019 올도이뇨 렝가이 — 부관: 하얀 재가 옷에 묻으면 따갑답니다. 선원들 소매를 다 내리게 했습니다. / 제독: 손도 씻게 해라.
- 020 아담스 피크 — 부관: 오천 계단이라기에 선원들이 꾀병을 부렸습니다. 해 뜨는 걸 본 뒤로는 다들 가길 잘했다고 합니다. / 제독: 늘 그렇지.
- 021 카일라스 산 — 부관: 숨이 차서 선원 둘이 주저앉았습니다. 오늘은 반 바퀴만 돌고 내려가겠습니다. / 제독: 반 바퀴면 충분하다.
- 022 성산일출봉 — 부관: 해녀 할머니들이 전복을 줬습니다. 값을 물었더니 웃기만 합니다. 쌀 한 자루 놓고 가겠습니다. / 제독: 두 자루.
- 023 대보초 — 부관: 배 밑창이 산호에 긁힐 뻔했습니다. 측심줄 당번을 셋으로 늘렸습니다. / 제독: 이 바다를 다 지날 때까지.
- 024 블루홀 — 부관: 측심줄이 두 번 이어도 겨우 닿았습니다. 이 구멍에 물통 떨어뜨리면 못 건집니다. / 제독: 아무것도 떨어뜨리지 마라.
- 025 우유니 소금 사막 — 부관: 소금 위로 볕이 튀어 눈이 아프답니다. 선원들 눈에 천을 감게 했습니다. / 제독: 소금은 공짜로 실어라.

## 4권 · 자연 2 · 바다
- 026 운석 구덩이 — 부관: 선원들이 하늘에서 떨어진 쇠를 하나씩 주워 부적으로 삼았습니다. 배가 조금 무거워졌습니다. / 제독: 하늘 쇠면 괜찮다.
- 027 레드우드 숲 — 부관: 선원들이 나무 둘레를 손잡고 재 봤습니다. 열한 명이 들었습니다. 이 나무가 우리 배보다 오래 살 겁니다. / 제독: 우리보다도.
- 028 크레이터 호수 — 부관: 물이 너무 차서 헤엄친 놈이 이를 딱딱 부딪칩니다. 담요를 두 장 주겠습니다. / 제독: 그리고 술 한 잔.
- 029 데빌스 타워 — 부관: 바위 밑에 묶인 천 조각은 아무도 건드리지 말라고 했습니다. 남의 기도는 남의 것이지요. / 제독: 잘했다.
- 030 올드 페이스풀 — 부관: 뜨거운 물로 빨래를 했더니 옷이 반쯤 줄었습니다. 제 셔츠가 소년용이 됐습니다. / 제독: 견습한테 줘라.
- 031 로라이마 산 — 부관: 짐 바구니 하나를 벼랑에 떨어뜨렸습니다. 건빵 이틀 치입니다. 사람은 안 떨어졌으니 됐습니다. / 제독: 그게 중요하다.
- 032 무지개 산 — 부관: 알파카가 짐을 싫다고 주저앉았습니다. 짐을 반으로 나눴더니 일어났습니다. 짐승이 사람보다 셈이 빠릅니다. / 제독: 우리 짐도 나눠라.
- 033 세로 리코 — 부관: 은값이 여기선 바닥이고 광부 품삯은 그보다 더 바닥입니다. 오늘은 장사 안 하겠습니다. 마음이 안 내킵니다. / 제독: 나도 그렇다.
- 034 토레스 델 파이네 — 부관: 바람에 천막 두 개가 날아갔습니다. 하나는 찾았고 하나는 아마 지금쯤 바다 위에 있을 겁니다. / 제독: 바위 뒤에 쳐라.
- 035 모뉴먼트 밸리 — 부관: 물이 귀합니다. 오늘부터 세수는 이틀에 한 번입니다. 냄새는 다 같이 참겠습니다. / 제독: 다 같이.
- 036 킬라우에아 화산 — 부관: 용암이 바다에 드는 데서 김이 솟아 배를 멀리 댔습니다. 노 젓는 놈들이 투덜대도 할 수 없습니다. / 제독: 멀리가 맞다.
- 037 헤라클레스의 기둥 — 부관: 선원들이 기둥 사이를 지나며 침을 뱉었습니다. 겁나서 하는 미신이랍니다. 저도 몰래 뱉었습니다. / 제독: 나도.
- 038 마차푸차레 — 부관: 마을 사람들이 신의 산이라며 오르지 말라고 합니다. 오르자는 놈도 없었습니다. 다들 지쳤거든요. / 제독: 다행이군.
- 039 꽃의 계곡 — 부관: 선원들이 꽃을 꺾어 모자에 꽂았습니다. 저렇게 순한 얼굴은 처음 봅니다. / 제독: 하루쯤은 괜찮다.
- 040 솔로몬의 광산 — 부관: 금은 없고 함정만 있습니다. 함정 둘을 표시해 뒀습니다. 금 찾는 놈들이 또 올 테니까요. / 제독: 표시는 크게.
- 041 코리브레칸 소용돌이 — 부관: 물때 계산을 반 시간 틀렸습니다. 제 탓입니다. 다음부턴 모래시계를 두 개 쓰겠습니다. / 제독: 하나는 내가 들지.
- 042 떠다니는 얼음산 — 부관: 얼음을 깨서 물통을 채웠습니다. 짜지 않습니다. 하늘이 물을 공짜로 줬습니다. / 제독: 얼음산은 크게 돌아라.
- 043 바다에서 솟은 섬 — 부관: 새 섬 이름을 다들 자기 이름으로 하자고 싸웁니다. 해도에는 일단 「뜨거운 섬」이라 적었습니다. / 제독: 그게 공평하군.
- 044 모자반 바다 — 부관: 바람이 열이틀째 없습니다. 물은 반으로 줄였고 노래는 두 배로 늘렸습니다. 노래는 공짜니까요. / 제독: 나도 부르지.
- 045 멕시코 만류 — 부관: 이 물살을 타니 하루 걸이가 갑절입니다. 선원들이 바다가 배를 업어 준다고 합니다. / 제독: 돌아올 땐 내려와야 한다.
- 046 젖빛 바다 — 부관: 등불을 다 껐습니다. 선원들이 누워서 바다를 봅니다. 오늘 밤은 아무도 안 싸웠습니다. / 제독: 드문 밤이군.
- 047 천 개의 고리섬 — 부관: 야자 열매 백 개를 실었습니다. 물통이 부족하니 열매가 물통입니다. / 제독: 껍데기도 버리지 마라.
- 048 검은 해류 — 부관: 깃발 없는 배 두 척이 따라옵니다. 대포에 화약을 재 두었습니다. 쏠 일은 없기를 바랍니다. / 제독: 섬 그늘로.
- 049 사해 — 부관: 선원들이 물에 둥둥 떠서 안 나옵니다. 눈에 소금물 들어간 놈이 셋입니다. / 제독: 맑은 물 준비해라.
- 050 엘도라도 — 부관: 호수 물을 퍼내자는 놈들을 말렸습니다. 일 년을 퍼도 금보다 물이 많을 겁니다. / 제독: 잘 말렸다.

## 5권 · 유적 1
