# 발견물 이야기 통합 — 0.350

전달받은 300·350·450·600·625·825·925c·925d ZIP을 대조해 최신 925d 본문을 사용했다. 1·2권의 14곳과 합창 뒤 재방문 50곳도 연결했다. 98·99의 다음 작업 목록은 발견물로 등록하지 않았다.

- 번호 001~925 전부 연결. 1·2권·재방문을 합친 장면 989개, 같은 발견에 붙은 원고를 합친 대상 937종.
- 기존 발견 487건에 같은 ID로 연결하고 없는 발견 438종을 추가했다. 게임의 전체 발견물은 1,744종이다. 기존 ID와 옛 발견·보상 기록은 유지한다.
- 성격 배역 갈래 3,830개, 지리 합창 67곳, 재방문 50곳, 남편 원문 135곳, 지나 관계 대사 58갈래를 연결했다.
- 새 발견은 실제 좌표 또는 원고의 서식지·전승을 대표하는 게임 지점에서 찾는다. 도시 안 유물·건물은 해당 거리, 야외는 탐험대, 바닷길은 해상 탐색을 사용한다. 새 전용 원화가 없는 438종은 기존 Canvas 기본 그림을 쓴다.
- 원고는 한국어다. 다른 표시 언어에서는 기존의 번역된 발견 관찰을 유지하며, 새 장면 원고를 번역 완료로 표시하지 않는다.

## 누가 말하는가

기함의 부관·항해사·측량사·통역·경리 또는 실제 선실에 배치된 동료만 후보가 된다. 대기 동료와 다른 배 선장은 제외한다. 한 사람은 공주·특수 출신·여성 성격·공통 순서로 배역 하나를 맡는다. `discRole`로 인물별 배역을 지정할 수 있다.

원고 속 실제 관계 인물은 해당 동료가 있을 때만 우선한다. 없는 인물을 합류시키거나 권력자를 동료로 만들지 않는다. 새 창작 길잡이 텐징·카이 타우·테클레 마리암도 발견·지역·선물 조건을 갖춰 정식으로 합류한 뒤에만 발언한다. 프레스터 존 현장의 수도사 환영은 원고가 지정한 예외다.

부관의 대체 확률은 20%다. 부관이 없으면 그 발견물의 갑판장 장면을 쓰며, 1권은 이번에 제공된 전용 세 줄을 쓴다. 1·2권은 대응 네 갈래를 먼저 보고 나머지는 재방문 때 열린다. 긴 부관 장면은 처음 한 번, 그 뒤에는 보충 원고의 짧은 줄을 쓴다. 이미 본 갈래는 다시 고르지 않고 직전 세 번의 주연과 직전 사건 종류는 뒤로 미룬다. 볼 수 있는 갈래를 다 보면 회상 한 줄로 끝난다. 수첩의 발견 카드에서 현장에 다시 왔을 때 「현장 이야기」를 볼 수 있으며, 발견 보상을 다시 주지 않는다. Esc는 그 장면 전체를 건너뛴다.

합창은 처음 한 번만 열린다. 실제 관계 인물부터 자리를 얻고 부관 자리를 남겨 최대 8명으로 제한한다. 외칠 동료가 없으면 망대 선원이 외친다. 출항 항구와 항해 일수는 저장된 실제 항해에서 가져온다. 원고의 고난은 이야기의 지문이며 선원·배의 사망이나 손실을 추가로 정산하지 않는다.

그중 50곳은 두 번째부터 46·47권의 회상하는 장면을 쓴다. 지나는 실제 기함 동료일 때만 우선하며, 유비에게 묻는 말은 유비도 기함에 있어야 나온다. 툰먼·칸발릭 합창에 참여했으면 같은 관계 줄을 다시 쓰지 않는다. 금봉호를 실제 만난 날의 발견 한마디는 하루 한 번이다. 마대인·왕서방을 새 동료로 만들지 않는다.

## 가족과 저장

그 가족이 함께 있으면 장면 끝에서 반응한다. 집에 있으면 보고·발표를 마친 뒤 고향 항구나 자택에서 전한다. 설정의 「발견 소식을 가족 편지로 받기」를 켜면 다음 입항지에서 편지로 받는다. 아들↔딸, 형↔오빠, 누나↔언니, 남동생↔여동생의 가까운 갈래를 우선하며, 없는 가족을 만들어 말시키지 않는다. 여성 제독에게 자녀는 엄마·어머니, 동생은 누나·언니로 부른다.

`state.discStory`는 본 갈래·합창·방문 수·최근 주연·가족 소식·지나의 그날 반응을 저장한다. 없는 새 필드는 기본값으로 읽고, 825본에서 들었던 부관 갈래도 보존한다. 가족 소식은 세대별로 첫 발견·재방문을 구별해 한 번씩이며 다음 세대에 이전 가족의 미전달 소식이 섞이지 않는다. 여성 제독의 배우자 반응은 48권의 남편 원문 135개를 쓴다. `state.wangMerch.lastMet`는 실제 만난 날, `state.discoveryGuides`는 길잡이 합류와 첫 출항 인사를 저장한다. 새 발견의 위치·가치·조건은 `tools/discovery_stories_20261123/mapping.json`에 있다.

쿠쿨칸의 뱀 그림자는 치첸이트사를 먼저 발견한 뒤 게임 달력 3·9월 21일 전후 7일에 찾는다. 마르 둘세·포로로카는 내륙의 동명 지점 대신 아마존 하구, 큰 강과의 만남은 남부 미시시피 강둑, 안전한 집은 실제 월동터에 맞췄다. 마셜 막대 해도는 섬 해안의 카누에서 보는 해상 발견이다. 새 438종은 실제 게임 지형에서 해당 도시·육지·바다로 접근할 수 있는지 검사한다.

카이 타우는 기존 항구 목록에 맞춰 뉴질랜드의 마오리 마을·웰링턴에서도 만난다. 텐징은 히말라야 발견 후 캘커타·라사 권역, 테클레는 아비시니아 인근에서 만난다. 특기 제안은 기존 측량·운용·항해·역사·의학 특기로 연결했고 별도의 중첩 보너스를 만들지 않았다.

## 재생성·검증

`python tools/compile_discovery_stories.py`로 원고와 명시적 ID 대응표에서 게임 자료를 다시 만든다. 실행 중 원고 파일이나 네트워크를 읽지 않으므로 file://도 지원한다. 위치의 Wikidata 출처는 `location-*.json`, 전달본 비교 해시는 `manuscript-*.json`, 생성 결과는 `compile-report.json`에 남겼다. 숫자·좌표는 재배포 시 명시적으로 검토하고 수정한다.

`tests/discovery_stories_20261123_smoke.cjs`는 전체 번호·연결·기본 그림·배역·합창·가족·저장·길잡이 조건을 검사한다. `tests/discovery_stories_925d_smoke.cjs`는 재방문·네 배역 순서·남편 원문·지나의 조건·계절·옛 저장·전체 위치 접근성을 검사한다. `tests/release_0350_smoke.cjs`는 실제 UI로 여성 제독 생성, 청혼, 수첩, 저장 복원, 새 발견, 재방문, 지나, 남편 소식, Esc 건너뛰기, 합창과 편지 설정을 검사한다.
