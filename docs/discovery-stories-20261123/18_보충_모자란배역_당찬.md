# 18 · 보충 — 모자란 배역 당찬 장면 20곳 (대응 인원 다섯째로 더함)

> 3~14권에서 당찬은 4번밖에 안 나왔다. 아래 20곳에 당찬을 다섯째 대응 인원으로 더한다. 그 발견물의 선교사·학자·헬창 장면은 그대로 두되, 당찬이 배에 있으면 고르기 2순위(직전 3번 주연 안 한 사람)에서 앞선다.
> 당찬 말투: ~해요! · 제가 가요! · 먼저 나서고 지휘하고, 틀리면 바로 인정한다.

- **001 그랜드 캐니언 · 당찬** (불상사·대응) — 당찬: 노새가 벼랑 끝에서 발을 헛디뎠어요! 짐 끈 끊어요, 지금! / — 짐이 협곡 아래로 떨어지고 노새는 살아서 버둥거린다. / 당찬: 짐은 다시 사요. 노새는 다시 못 사요. 제가 틀렸으면 나중에 혼내요.
- **009 황산 · 당찬** (대응) — 당찬: 안개가 끼면 계단 끝이 안 보여요. 다들 앞사람 허리끈 잡아요. 제가 맨 앞 설게요. / — 한 식경 뒤 안개를 빠져나온다. / 당찬: 다 있죠? 열둘. 좋아요. 아무도 안 놓쳤어요.
- **023 대보초 · 당찬** (불상사·대응) — 당찬: 바닥 긁혔어요! 물 새요! 펌프 둘, 판자 셋, 따라와요! / — 당찬이 선창에 엎드려 새는 틈에 천을 쑤셔 넣는다. / 당찬: 막았어요. 측심 당번은 누구였어요? …저였네요. 제 잘못이에요. 오늘 밤 펌프는 제가 돌릴게요.
- **034 토레스 델 파이네 · 당찬** (날씨·대응) — 당찬: 천막 그만 붙잡고 바위 뒤로 옮겨요! 바람이랑 싸우지 말고! / — 바람이 잦아든다. 날아간 천막 하나가 바위 틈에 걸려 있다. / 당찬: 봐요, 바위가 잡아 줬잖아요. 우리가 붙잡았으면 우리도 날아갔어요.
- **042 떠다니는 얼음산 · 당찬** — (4권 본문에 이미 있음 — 기준 장면)
- **052 파르테논 · 당찬** (사람·대응) — 당찬: 수비대장님, 화약고 옆에서 병사들이 담배 피워요. 저거 하나면 이천 년이 끝나요. / — 수비대장이 얼굴을 붉히더니 병사들을 내쫓는다. / 당찬: 남의 군대에 참견했어요. 죄송해요. 근데 할 말은 해야죠.
- **059 앙코르 와트 · 당찬** (불상사·대응) — 당찬: 회랑 지붕에서 돌이 떨어지려고 해요! 그 밑에서 비켜요, 스님! / — 돌이 떨어져 바닥에서 깨진다. 스님이 놀라 합장한다. / 당찬: 다행이에요. 이 돌 나중에 다시 올려야 하는데… 그건 우리가 못 하네요. 마을 분들한테 알려 드려요.
- **065 테오티우아칸 · 당찬** (대응) — 당찬: 위에서 사람이 미끄러져요! 계단에 엎드려요, 다들! 굴러 내려오는 거 받아요! / — 굴러 내려오던 선원이 세 단 아래 당찬 등에 걸려 멈춘다. / 당찬: 아파요. 근데 둘 다 살았으니 됐어요.
- **085 팀북투 · 당찬** (사람·대응) — 당찬: 책 상자 나르는 할아버지 허리 굽은 거 봐요. 그거 제가 들게요. / — 당찬이 책 상자를 들고 골목을 세 번 오간다. 할아버지가 낡은 책 한 권을 건넨다. / 당찬: 받으래요. 별자리 책이래요. 품삯으로는 너무 비싸요. 다시 갖다 드리고 올게요. …안 받으신대요.
- **099 몽생미셸 · 당찬** (날씨·위기) — 당찬: 밀물이에요! 뛰어요! 신발 벗어요, 갯벌에 빠져요! / — 당찬이 맨발로 가장 늦은 선원의 손을 잡아끈다. 둘이 마지막으로 성문을 넘는다. / 당찬: 제 신발은 바다가 가져갔어요. 손은 안 놓쳤어요.
- **129 라 페레그리나 · 당찬** (사람·대응) — 당찬: 잠수부 한 분이 안 올라와요! 밧줄 줘요, 제가 들어가요! / — 당찬이 물에 뛰어든다. 잠시 뒤 둘이 같이 떠오른다. 잠수부가 기침을 한다. / 당찬: 조개에 손이 끼었었어요. 진주보다 사람이 먼저예요. 다들 알잖아요.
- **176 노래하는 고래 · 당찬** (대응) — 당찬: 어미 고래가 새끼 데리고 배 밑으로 와요. 돛 내려요, 키 그대로! / — 고래가 배를 지나간다. 아무도 숨을 쉬지 않는다. / 당찬: 됐어요. 다음에 고래 소리 들리면 묻지 말고 돛부터 내려요.
- **193 호랑이 · 당찬** (위기·대응) — 당찬: 덤불 흔들려요! 횃불 들어요! 아무도 혼자 가지 마요! / — 노란 눈이 횃불 빛에 잠깐 비치고 사라진다. / 당찬: 갔어요. 오늘 밤 화장실은 셋씩 가요. 투덜대지 마요.
- **209 메시나의 칼고기 · 당찬** (불상사·대응) — 당찬: 줄 감은 손 놔요! 손가락 잘려요! 줄은 제가 기둥에 감을게요! / — 당찬이 줄을 돛대에 두 번 감자 고기가 끌다 지친다. / 당찬: 손가락 다 있어요? 세어 봐요. 열 개. 좋아요.
- **218 아나콘다 · 당찬** (위기·대응) — 당찬: 저 통나무 움직였어요. 다들 물에서 나와요. 지금. / — 선원들이 물가로 나오자 통나무가 천천히 물속으로 사라진다. / 당찬: 제가 틀렸으면 좋겠는데 안 틀렸네요. 오늘 빨래는 내일 해요.
- **236 오니 · 당찬** (사람·대응) — 당찬: 붉은 탈 쓴 산적이에요! 순례자분들 가운데로! 남자들은 바깥에 서요! / — 산적이 무리의 수를 보고 달아난다. / 당찬: 사람이 많으면 오니도 도망가요. 다 같이 넘어요, 이 고개.
- **244 자라탄 · 당찬** (위기·대응) — 당찬: 섬이 흔들려요! 불 꺼요, 짐 버려요, 배로 뛰어요! 냄비는요? …냄비는 들고 뛰어요! / — 고래가 가라앉는다. 모두 작은 배에 올라탔다. / 당찬: 다 탔죠? 냄비도? 좋아요. 저녁은 먹을 수 있어요.
- **257 스크렐링 · 당찬** (사람·대응) — 당찬: 손 보이게 들어요. 칼은 배에 두고 왔죠? 저 먼저 갈게요. / — 당찬이 빈손으로 해변을 걸어간다. 원주민 여인이 빈손으로 마주 걸어온다. 둘이 마주 서서 웃는다. / 당찬: 됐어요. 이제 와도 돼요.
- **267 마오리 · 당찬** (사람·대응) — 당찬: 칼에서 손 떼요! 저건 시험이에요! 눈 피하지 마요! / — 풀잎이 놓인다. 당찬이 다가가 집어 든다. / 당찬: 제가 주웠어요. 제독님 몫인데 죄송해요. 다들 굳어 있어서요.
- **282 사탕수수 · 당찬** (사람·숙연) — 당찬: 쓰러진 분 그늘로 옮겨요. 감독관이 뭐라 하든 제가 막을게요. / — 감독관이 채찍을 들다가 당찬의 눈을 보고 내린다. / 당찬: 저도 아무것도 못 바꿔요. 오늘 이 한 사람만이라도요.
- **298 라플레시아 · 당찬** (소동·웃음) — 당찬: 토하는 사람 바람 위로! 코 막고 숨 쉬지 마요! 아니, 숨은 쉬어요! 입으로! / — 셋이 토하고 다섯이 웃는다. / 당찬: 웃지 마요! 다음은 당신 차례예요! …저도 좀 토할게요.

> 츤데레(16)·불만(19)·군인(23)·남장(23)은 301번부터 새 발견물에서 더 자주 쓴다.
