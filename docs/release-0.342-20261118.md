# 단계별 동물 추적과 엘프 자매 재회

동물의 흔적을 순서대로 따라가는 진행도를 추가했습니다. 앞의 다섯 자국을 따라가며 25·50·75%에 부하의 관찰을 듣고, 회색 동물 그림에 점차 색이 나타납니다. 거의 따라잡은 동물은 한 번 달아나 새 흔적을 남기며, 측량 특기가 높을수록 덜 달아납니다.

동물을 끝까지 추적하면 발견 명성이 최대 40% 더해집니다. 진행도와 달아난 위치는 저장·불러오기 뒤에도 유지하고, 이동한 자리에서 발견하도록 연결했습니다. 지도에는 동물 이름을 겹쳐 쓰지 않습니다.

새 31종은 떨어지며 흔들리는 깃털, 수중 동물 51종은 거품·물결·물보라로 흔적을 표시합니다. 바다 위를 나는 새와 헤엄치는 펭귄을 구분하고 해상 장면에서는 발자국을 그리지 않습니다.

세계수에서 만나는 엘프를 기존 자매 전사 20명과 연결했습니다. 먼저 승선한 자매가 싸움을 말리고 설득하거나 재회하며, 이미 동료인 인물은 새 조우와 귀환 후보에서 제외합니다.

이전 버전 엘프 6명의 ID·능력치·대사를 저장 호환용으로 보존했습니다. 이미 영입한 동료와 돌아오기로 한 엘프를 유지하고, 게임 첫날의 조우·영입 기록도 중복 처리하지 않습니다.
