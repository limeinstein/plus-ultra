# 0.332 언어 공개와 누락 점검 — 2026-11-14

기준 공개판은 `6f9b68f32`(0.331)이다. 상세 목록·비교 결과·로그·화면은 `artifacts/release-0.332-20261114/`에 보존한다.

- 중국어 간체·번체·베트남어의 원자료와 생성 파일은 있었으나 `ready`가 꺼져 있었다. 세 언어의 `_ready` 원자료 표식을 추가하고 생성 파일을 재생성하여 다시 빌드해도 선택 가능 상태가 유지되도록 했다.
- 중국어 배포 묶음 16개(v23~v42)의 파일 존재를 대조했다. 최신 v42 내용과 원자료는 이미 반영되어 있었고, 생성 파일의 공개 설정만 달랐다. 일본어·스페인어는 실제 번역 내용이 없는 빈 틀이므로 준비 중 상태를 유지한다.
- 게임의 언어 파일과 달리 도감은 영어만 불러오던 누락을 수정했다. 중국어·베트남어를 선택한 뒤 도감에서도 같은 번역을 사용한다. 베트남어의 일곱 분류·빈 목록 안내·인물 이야기 제목을 보완했다.
- 영어 전용으로 만들던 인물 이야기·만나는 곳·가이드북의 일부 안내를 현재 언어의 번역 경로로 연결했다. 기존 영어 도감과 한국어 가이드북 회귀 검사로 이전 표시도 확인한다.
- 그림 목록 17,117개를 디스크 재탐색 결과와 대조하여 미등록·누락 0개를 확인했다. HTML이 참조하는 스크립트 파일도 모두 존재한다. 등록되지 않은 두 스크립트는 현재 구현이 대체하는 이전 갤리온 비교용 호환 파일이다.
- 미추적 그림·지시문 25개는 제작 원본과 교체 전 해적 초상이다. 실제로 선택되는 교체본은 등록·추적되어 있다. 기존 경제 회복·전설 장비 작업은 소스와 회귀 검사로 반영 상태를 확인했다.

검사: `i18n_smoke.js`, `i18n_templates_20261113_smoke.cjs`, `i18n_asian_languages_smoke.cjs`, `catalog_english_detail_smoke.cjs`, `guidebook_smoke.js`, `econ_relief_smoke.js`, `legend_ward_smoke.js`, `i18n_tsv_smoke.py`. 세 언어는 실제 메뉴 선택·화면 설정·새 항해·재접속 유지·도감 일곱 분류·인물 이야기·중국어 가이드북을 확인한다.

정식·베타 압축 웹 빌드와 용량 검사를 실행하고 각 빌드에서 세 언어를 검사한다. 로컬 HTTP 정식판에서는 브라우저 언어 자동 선택을 확인하며, 로컬 베타 UI는 공개 집계 서버의 출처 제한 때문에 file://로 검사한다. 공개 후에는 정식·베타 모두 실제 HTTP와 실제 집계 연결을 사용해 다시 검사한다. 공개 서버 응답은 대체하지 않는다.

미번역 문장은 한국어로 남는다. 베트남어 가이드북 전체 원고는 없으므로 기존 한국어 원고를 사용한다. 빌드 결과물과 임시 검사 파일은 커밋하지 않는다.
