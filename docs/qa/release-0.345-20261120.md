# 0.345 통합 검증 범위

기준 커밋은 `8fdc35b043a3de673ffc83c8551cee47b68ad67b`이며, 완료된 시대별 물가·생물 발견 QA·식물 증거품·원주민 마을과 원화 261장을 통합했다. 작성 중인 해적 초상과 공개 전 이야기 모드는 포함하지 않았다. 일본어·독일어·포르투갈어의 새 번역 본문은 이 작업 환경에서 확보하지 못했다.

원본 변경을 복사 전후 해시로 확인하고 별도 스냅샷을 검증한다. 뒤늦은 편집과 다른 작업의 스테이징은 보존한다. 검증·빌드·게시 후보의 파일 해시를 비교한다.

## 검증 중 보완

- 길찾기의 격자 중심 사이에 놓인 좁은 물길을 건너는 문제를 합성 지형에서 재현했다. 출발·도착점 연결과 격자 사이 이동도 실제 뭍인지 검사하며, 최종 반환 경로의 각 구간을 확인한다. 좁은 물길 3곳의 우회와 연결되지 않은 땅을 회귀 검사한다.
- 생물 시험의 단서를 실제 저장 형식인 객체로 고쳤다. 길찾기 이동 구간은 하루 사건 누적을 미뤄 우연한 사건과 분리하고 실제 육상 장면의 이동을 검사한다. 그림·서비스 오류를 제외하는 필터와 모든 HTTP 요청을 빈 응답으로 바꾸던 시험 코드는 제거했다. 외부 글꼴 CSS만 고정한다.
- 시장 약품 시험은 판매용 20종을 해당 상품군으로 검사한다. 별도의 발견 약재 22종은 시장에 입고되지 않으며, 실제 회복·1회 소모 규칙을 각각 확인한다.

물가, 생물 발견, 좁은 물길, 주소 종료 경계, 교역 성장·중계, 저장 복원, 동물 추적, 식물 단서, 식물 교역, 약재, 다국어, 도감, 개척 도시를 검사한다. 정식·베타 빌드 양쪽의 기능과 원화 261장·도감 7개 범주·포탈 이력·모바일 가로 넘침을 확인한다. 시험별 결과·콘솔 기록·스크린샷·최종 해시는 `artifacts/release-0.345-20261120/`에 남긴다.
