# 0.322 정식·베타 웹 통합 검증 — 2026-11-08

## 반영 내용

- 마젤란 세계 일주: 출자·보급·반란·해협·태평양·막탄 구조·합류, 향료제도·막탄 사건과 중복 방지.
- 드레이크 세계 일주와 누누 구조·합류, 콜럼버스 두 번째·세 번째·네 번째 항해. 날짜별 실제 함대·선장 대화·선택·소식·일지·옛 저장 연결.
- 정화의 유령 보선: 아프리카 소문과 네 해역의 전투, 후퇴·재도전·단계별 보상·막야·종료·옛 저장 복구.
- 피리 레이스의 해도: 다섯 장소의 단서와 선택, 보물·레일라 합류·재도전·짐칸 부족 시 보상.
- 인물 33명 초상 66장·사건 장면 45장, 총 111개 그림 파일. 주요 인물의 기존 초상과 신대륙의 이전 원본은 유지한다. 이번 새 원화 대상 밖의 인물·장면은 기존 그림 또는 코드 그림 선택 순서를 따른다.
- 누누의 합류 전후·여왕 서임식·소문의 뱃사람·도감 연결. 도감에서 빠진 콜럼버스 후속 탐사와 피리 레이스 자료도 추가했다.

## 검토 중 보완

- 유령선의 빛·투명도·맥동·돛과 깃발 색을 `G.FX.battle.ghost`로 모았다. 연출 수치와 전투 규칙은 분리한다.
- 해전 종료 시 임시 유령선 합성 캔버스 참조를 해제한다.
- 생성 파일 두 곳의 끝 빈 줄을 정리했다. 원화 파일은 검사한 내용 그대로 보존했다.
