# 시장 악기 최대 3종·매주 교체 — 2026-11-03

## 바꾼 규칙

- 시장마다 판매 가능한 악기를 최대 3종만 진열한다. 후보가 적으면 있는 종류만 판다.
- 게임 경과일을 7일 단위로 나누어 목록을 교체한다. 주중 재방문·저장 불러오기·게임 재실행으로 다시 추첨하지 않는다.
- 도시마다 섞은 후보 순서에서 한 종류를 차례로 넣고, 나머지는 주마다 무작위로 고른다. 후보가 3종보다 많으면 지난주 목록과 적어도 한 종류가 달라지고, 모든 후보가 언젠가는 입고된다.
- 지역·조선/중국 구분·종교·판매 연도·희귀품 조건을 유지한다. 악기 186종 자체와 구매 수량 규칙은 유지한다.
- 일반 물건의 45일 입고 추첨과 고향 항해 도구·라임 판매를 유지한다.
- 시장 안내와 악기 도감에 최대 3종·7일 교체를 표시한다.

조정값은 `js/data/base.js`의 `G.BALANCE.marketInstrumentMax = 3`, `marketInstrumentDays = 7`이다. 새 저장 필드를 추가하지 않았다.
