# 0.325 통합 검증 — 2026-11-10

0.324 이후의 항해 기록 도감, 사건 인물·장면 연결, 개척 도시 외관을 정식·베타 배포 대상으로 고정했다. 제작 중인 원화가 계속 추가되는 작업 폴더와 배포 내용을 분리하기 위해 Git에 추가한 파일로 배포용 사본을 구성했다. 런타임 소스와 새 그림은 해당 사본을 기준으로 검사한다.

## 기능

- 타이틀에서 여는 플레이어 도감은 항해에서 본 인물·사건, 얻은 소지품·악기·무기, 먹은 음식, 발견물·업적만 표시한다. 일곱 갈래와 발견물 세부 필터·검색·타이틀 복귀를 유지한다. 점검용 전체 보기와 제작용 그림 자료 보기는 별도 주소로 유지한다.
- 도감 기록은 같은 브라우저의 항해 사이에 보존된다. 현재 저장의 발견·업적·동료·소지품·날짜를 반영한다. 기록이 `null`·배열·문자·잘못된 JSON·잘못된 필드·음수나 무한 날짜인 경우 기본값으로 복구한다. 이전 정상 기록과 저장소 접근이 막힌 경우의 실행 중 기록을 확인한다.
- 실제 대화·사건 화면·물건 획득·식사 후 도감으로 이동해 해당 항목만 보이는지 검사한다. 새 기록에서는 모든 갈래가 비어 있으며, 이름이 없는 일반 초상 묶음으로 다른 인물이 함께 열리지 않는다.
- 콜럼버스·피리 레이스 인물 20명의 얼굴상·무릎상 40장과 사건 장면 77장, 감찰관 저택·총독부 외관 2종을 포함한다. 총 119개 파일의 해독·규격·해시와 초상의 투명 영역을 확인한다. 합류 전후 레일라·멘데스의 초상과 여성 인물의 대체 초상 성별도 검사한다.
- 왕실·정세의 전용 장면을 대화 동안 표시하고 종료 때 정리한다. 원화가 없는 경우에는 기존 혼례·기본 표시를 유지하며 소식에도 없는 그림 주소를 요청하지 않는다.
- 개척 도시의 첫 방문·성장 단계와 전용 그림이 없는 경우를 검사한다. 준비와 표시가 동일한 외관 후보를 사용해 대신 쓰는 그림도 미리 읽는다. 실제 개척·식민 회사·외교·조약과 저장·해전 복원 회귀 시험을 함께 수행한다.

## 검증 범위와 보완

JavaScript 534개 문법 검사와 기능별 시험 16개를 통과했다. 최종 목록과 결과는 `artifacts/release-0.325-20261110/regressions-final.json`에 기록한다. 정식·베타 압축 빌드에서 새 그림 119개씩의 해독·경로와 도감·포탈을 확인했으며 브라우저 오류와 390px 화면의 가로 넘침은 0이다.

최초 도감 기록 시험은 새 브라우저 문맥의 기본 탐색 제한 30초를 넘겨 중단됐다. 문맥에 120초 제한을 적용하고 재검사한다. 그림 연결 회귀 시험의 이전 고정 수량 680개와 사용하지 않는 옛 합성 초상 묶음 조건은 현재 자료와 맞지 않아, 유물 1,109종의 실제 그림 선택·민족 유물 18종의 기본 코드 그림·항해사 12명의 완성된 얼굴/몸 한 쌍과 실제 대화 표시를 검사하도록 갱신했다.

누락 사건 원화 제작 계획의 전체 133개 항목을 요구하는 첫 시험은 미완성 장면 때문에 중단됐다. 이번 배포는 완성된 77개 장면과 기존 재사용 그림을 포함한 104개 항목의 실제 표시를 `--partial`로 검사했으며, 이 결과를 전체 133개 원화 완료로 계산하지 않는다. 별도 사건 전달 검사에서는 완성된 왕실 장면의 표시·종료, 원화가 없을 때의 혼례 대체, 외교·세계 소식의 그림/기본 아이콘 분기를 모두 통과했다. 남은 원화 제작·원본 보관 파일은 이번 배포의 완료 범위에 포함하지 않는다.

## 빌드와 공개 이력

정식·베타는 동일한 Git 추가 목록에서 빌드한다. 제작 중인 새 그림이 자동으로 끼어들지 않도록 고정한 사본에서 `tools/build_web.py`를 실행하고 기존 `dist/web`·`dist/web-beta` 출력 위치를 사용한다. 생성한 그림 목록을 같은 Git 추가 목록에 반영해 CI의 파일 구성과 일치시킨다.

베타 포탈에는 기능 중심의 0.325 이력을 추가했다. 기존 공개 이력·배포 노트·게임 출처의 작성 도구 이름 표현이 없는지 확인한다. 실제 역사 인물의 이름은 유지한다. 게시 완료 후 정식·베타에서 119개 그림씩 SHA-256을 비교하고 도감 기록·포탈을 다시 확인한다.

브라우저는 `finally`에서 닫는다. 로컬 서버는 사용하지 않으며, 테스트용 과정이 끝난 후 남아 있지 않은지 확인한다.
