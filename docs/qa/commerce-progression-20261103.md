# 교역 성장·회복 재고·왕실 승급 (2026-11-03)

가까운 항구의 희귀품 한 종류로 함대 성장이 끝나던 흐름을 조정했다. 일반 교역과 원양 교역의 수익은 남기고, 선박·산지 사업·판로·왕실 공적에 돈과 시간을 나누어 쓰게 한다. 유적 발견 규칙과 별도 난이도 배율은 이번 변경에 포함하지 않는다.

## 선박과 임금

조정값은 `js/data/base.js`의 `shipPrices`와 `commerce`, `crewWage`에 있다. 선박 성능과 항해 속력은 바꾸지 않았다.

다른 문화권의 중대형 선박도 같은 성장 단계에 맞췄다. 바르카·코그 등 시작용 소형선은 유지한다. 목재·현지 할인은 기존처럼 적용한다. 구입 화면에 배값의 25%인 권장 여유자금을 표시한다. 실제 운영비의 확정 견적은 아니며 항로와 선원에 따라 달라진다.

새로 산 배는 지불 금액을 매각 평가의 기준으로 보관한다. 기존 배·나포선·선물 배는 종전 기본 가격으로 평가해, 새 배값 인상이 나포 현금 보상까지 몇 배로 키우지 않도록 했다. 선원 월급은 2→6닢, 동료 월급도 공통 계산에서 정확히 세 배다. 무급은 0, 충성 서약 급료는 10→30닢이다. 재등용 급료 기록은 기존 단위를 유지하고 지급·안내 시 한 번만 배율을 적용한다.

## 출자와 도시 사업

- 기본 누적 출자 문턱: 0 / 10,000 / 35,000 / 90,000 / 200,000 / 450,000닢.
- 도시 크기 한 단계마다 문턱 30% 증가. 투자로 개방할 저공급 희귀품이 있으면 해당 등급부터 2.5배. 카사블랑카 용연향 개방은 누적 **87,500닢**이다.
- 거래 우대는 등급당 매입·매각 각각 2%. 투자 명성은 8,000닢당 기본 1이며 기존 교역 명성 배율을 적용한다.
- 출자 전에도 개방할 두 품목과 등급별 누적 금액을 확인한다. 식물 특산물의 목록 보정에서도 미리 보기 인자를 전달한다.
- 기존 저장은 이미 얻은 출자 등급을 보존한다. 새 출자·새 도시부터 새 기준으로 성장한다.

출자 1등급부터 다음 시설을 각각 세 단계까지 건설한다. 시설 공사비는 출자 원금·배당에 더하지 않으며, 추가 가격 할인이나 명성도 주지 않는다.

| 시설 | 단계마다의 효과 | 작은 도시의 단계별 공사비 |
|---|---|---|
| 생산시설 | 공급 한도 +10%, 하루 입하량 +18% | 25,000 / 65,000 / 160,000 |
| 상관·창고 | 교역소 공급 한도 +25% | 20,000 / 55,000 / 140,000 |
| 판로 개척 | 시장 수용량 +18% | 30,000 / 80,000 / 190,000 |

창고는 제독 화물의 보관함이 아니라 교역소의 저장 시설이다. 창고를 넓혀도 하루 생산량 자체는 늘지 않는다. 가격 계산에서 출자 문턱을 반복 조사하지 않도록 도시·시대·소유국·특산물 기준으로 보관하고, 산지 변경 시 비운다.

## 재고가 교역을 막지 않도록 한 처리

기존의 품귀 지수만으로 물량을 계산하던 방식에 실제 소진 물량을 더했다. 사면 해당 수량이 빠지고 게임 날짜가 지나면 품목별 하루 입하량만큼 회복한다. 같은 날 창을 열거나 잘게 나누어 사도 바닥 물량이 새로 생기지 않는다.

- 일반품의 공급 규모를 충분히 남겼다. 식량은 기존 물량의 1.4배, 바닥부터 기본 한도까지 12일 분량을 매일 공급한다. 섬유·주류·광석 등도 비교적 빠르게 회복한다.
- 용연향·사향·보석 등은 천천히 회복하지만, 공급이 영구히 끊기지는 않는다. 작은 시장에서도 품목별 최소 공급 한도를 둔다. 이 최소 한도는 매번 공짜로 다시 주는 바닥 재고가 아니다.
- 사건으로 공급 한도가 급감해도 예전 소진량 때문에 몇 년씩 입하가 막히지 않도록 소진량을 새 한도 안으로 제한한다. 법적인 금수품은 계속 거래할 수 없다.
- 재고 수량과 하루 입하량을 표에 표시한다. 설명에는 공급 한도와 가득 회복할 때까지의 날수를 표시한다. 구입 창에서 3일 입하 대기를 선택할 수 있고 급료·기한도 함께 흐른다.
- 카사블랑카에서 모든 품목을 완판한 검사: 3일 뒤 밀·설탕 각각 77통, 가죽제품·말 각각 30통, 용연향 5통 재입하. 재방문만으로 공급이 생기지 않고, 충분히 시간이 지나면 다시 가득 찬다.

## 역사적 소비시장

기존 시대별 산지·수요 곡선에 도시·국가별 소비 곡선을 더했다. 물건을 사는 값과 파는 값에 같은 시장 수요를 반영한다. 표의 배수는 역사상의 실측 가격이 아닌 게임 조정값이며, 해 사이는 연속 보간한다.

- 카카오: 16세기 에스파냐 궁정·수도원에서 먼저 수요가 생기고, 17세기에 프랑스와 잉글랜드로 퍼진다.
- 담배: 16세기 후반 보급과 1610년대 버지니아 수출 뒤의 잉글랜드·네덜란드 소비, 프랑스 소비를 구분한다.
- 설탕: 17세기 후반 음료·제과 수요로 북서유럽 소비가 늘어난다.
- 차: 네덜란드의 초기 수입과 1662년 이후 잉글랜드 궁정 소비를 구분한다.
- 커피: 오스만 도시 소비, 베니스 유입, 런던 커피하우스 확산을 구분한다.
- 염료: 멕시코 코치닐을 대표하는 수요를 세빌리아·앤트워프·암스테르담·베니스의 직물 시장에 반영한다.
- 모피: 17세기 비버 펠트 모자 수요. 은: 유럽의 공급 확대와 중국의 별도 은 소비시장을 구분한다.
- 아메리카 귀항편의 직물·무기 수요도 시대별로 적용한다. 수첩은 실제 소비 항구의 수요와 10년 뒤 흐름을 보여 준다.

## 왕실 승급과 돈을 쓰는 목표

| 받을 작위 단계 | 헌납액 | 납품량 | 해당 작위 취득 뒤 다음 왕명까지 |

| 3 | 120,000 | 110 | 240일 |

| 6 | 650,000 | 300 | 450일 |

| 8 | 1,500,000 | 520 | 최고 작위 |

모든 단계에서 헌납과 교역품 납품을 선택할 수 있다. 나머지 선택지는 탐험·전투·외교 등에서 뽑는다. 납품은 여러 번 나누어 바칠 수 있고 매입 원산지별 장부에서도 납품량을 뺀다. 하사금은 전량 납품 후 한 번 지급한다. 친서·특사도 직급에 따라 의전·사절단 준비금이 0→220,000닢으로 증가한다. 준비금은 수락할 때 한 번 내며, 설명과 확인 화면에 표시한다. 상위 왕명 기한은 최대 4년으로 늘렸고, 소진된 발견물이나 금수품 때문에 유일한 승급 경로가 막히지 않게 했다.

다른 나라로 바꾸어 즉시 승급하는 것을 막는 공통 간격은 90일이다. 이야기로 얻은 작위도 다음 왕명의 준비 기간에 반영한다. 기존 저장의 작위와 진행 중 왕명은 유지하고, 이전 승급 날짜가 없는 작위는 첫 확인 시점부터 준비 기간을 시작한다. 명성과 돈이 이미 충분하다고 놓은 경계 검사에서 첫 작위부터 최고 작위까지 최소 2,195일(약 6년)이 필요했다. 실제 성장·임무·항해 시간은 별도다.

교역소와 자택의 **도시 후원·기념 사업**에서 뱃사람 쉼터·해도 서고·항해 기념관을 후원한다. 각각 30,000 / 80,000 / 200,000 / 500,000 / 1,200,000닢의 다섯 단계이며, 가문과 제독의 이름·날짜를 새긴 명판이 남는다. 반복 수익·가격·전투 배수·명성을 보상하지 않아 경제력을 증폭시키지 않는다. 출자·시설 투자는 실용적인 목표, 기념 사업은 가문에 남기는 선택적인 목표다.

- `node tests/commerce_progression_smoke.cjs`: 실제 `file://` 실행에서 이전 HEAD와 가격·급료·희귀품 수익 비교, 재고 소진·회복·날짜 역행, 시설 상한, 기존 투자, 동료 재고용과 실제 월말 급료, 후원 저장·재결제 방지, 왕실 8단계·간격 경계·분할 납품·기존 작위, 소비시장 흐름, 경제 화면, `pageerror`·`console.error` 0.
