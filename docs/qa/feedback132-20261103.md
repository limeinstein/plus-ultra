# 익명 #132 — 잔지바르 성문을 나서면 섬에 갇힘

## 재현과 원인

육상 탐험대가 대륙에서 잔지바르 입장 범위 안으로 들어와 도시를 방문한 다음, 성문에서 탐험대로 돌아가면 섬의 도시 중심으로 옮겨졌다. 함대는 원래 출발지에 있으므로 바다를 걸어 건널 수 없는 탐험대가 고립됐다.

실제 지형에서 대륙 좌표 `[38.865, -6.256]`을 사용해 재현했다. 수정 전 `L.resumeFromCity`는 `s.landReturn.lon/lat`을 무시하고 잔지바르 중심 `[39.155, -6.196]`을 복원했다. 회귀 검사가 이 좌표 불일치로 실패하는 것을 먼저 확인했다.

## 수정

- 도시 입장 전 육상 위치 전체를 복귀 기록에 남긴다. 출발지·대원·탈것뿐 아니라 방향·최초 인원·발견 기록·경비도 유지한다.
- 성문에서는 입장 전 탐험대 좌표로 돌아간다. 좌표가 없는 옛 저장만 도시 앞의 가까운 뭍을 찾는다.
- 정상 복귀 뒤에는 방문 복귀 기록을 지워 다음 탐험 위치를 덮어쓰지 않는다. 새 탐험을 시작할 때도 옛 방문 기록을 버린다.
- 오류로 섬으로 옮겨진 육상 저장은 남아 있는 입장 전 좌표와 같은 출발지, 도시 근접 여부, 두 위치의 뭍 연결 여부를 검사한다. 가까운 도시의 다른 땅으로 옮겨졌다면 입장 전 좌표로 복구하고 안내한다.
- 옛 저장에서 정상적으로 같은 땅을 걸어온 위치는 그대로 유지한다. 복구는 남아 있는 좌표가 있는 경우에 적용하며 원래 배·대원·짐·보급을 바꾸지 않는다.

수정 파일: `js/scenes/land.js`. 저장에 새 필수 항목이나 게임 규칙 조정값을 추가하지 않았다. 이미 잃어버린 원본 저장 데이터를 추정해서 복원하지는 않는다.

## 검증

`node tests/feedback132_smoke.cjs`:

- 잔지바르의 실제 대륙 좌표에서 육상 단추로 입장 → 도시 저장 → 페이지 재실행 → 성문 메뉴로 탐험대 복귀 통과.
- 입장 심사·인사·탈것 구입 선택과 건물까지 걷는 연출은 생략하고 실제 도시·성문·복귀 처리를 사용.
- 원래 대륙 좌표·출발지·탐험 일수·대원·경비·발견 기록과 기존 함대의 배·대원·짐·식량·물·자재 유지 확인. 돌아온 뒤 대륙에서 걷기 가능.
- 오류 상태로 저장한 섬 위치의 자동 복구, 반복 불러오기 안정성, 정상 육상 위치 유지 확인.
- 좌표가 없는 옛 도시 방문 기록도 316개 도시 모두 뭍으로 복귀.
- 화면과 `pageerror`·`console.error` 0 확인. 시험 브라우저 종료.

기존 `city_entry_prompt_smoke.js`, `gate_mount_smoke.js`도 설치된 `playwright-core`를 `playwright`로 연결해 Chrome에서 통과했다. 도시 출입 물음·거절·알림 설정과 마구간 구매·기존 탈것 사용·걷기 선택이 유지된다.

결과: `artifacts/feedback132-20261103/report.json`, `returned-to-mainland.png`.

로컬 반영까지 완료했으며 배포와 게시판 상태 변경은 하지 않았다.
