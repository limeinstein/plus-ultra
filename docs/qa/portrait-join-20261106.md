# 얼굴상·무릎상 접합 제보 조치 (2026-11-06)

에든버러의 스코틀랜드 회사 출자 화면 제보를 기준으로 원화와 표시 경로를 조사했다. 현재 패터슨 전용 그림은 정상이나, 전용 그림이 없던 시기에 빌렸던 옛 묶음 무릎상에 얼굴·목·어깨 합성과 반복 몸통이 남아 있었다.

## 검사와 확인 범위

- 매니페스트에 등록된 무릎상 3,101개를 검사했다. 원본 한 장의 하단 45%를 작은 회색조 이미지로 비교해 몸통 재사용 후보 555개·153묶음을 추렸다. 같은 인물의 별칭·시기별 그림 등 정상 재사용도 포함하므로 후보를 곧바로 제외하지 않는다.
- 기존 전체 묶음 검수 기록과 현재 파일의 SHA-256을 대조했다. 수정되지 않은 합성 무릎상은 정확히 720장이다. 새로 적용한 포르투갈·명나라 일반 동료 무릎상 40장은 유지한다. 대표 비교표로 지역·성별·역할별 반복 몸통과 접합 흔적을 다시 확인했다.
- 시녀 전체 검수 기록에서 얼굴·몸의 의상 불일치가 확인된 62장도 현재 해시가 동일했다. 해당 파일을 추가로 제외했다. 문화·성별·얼굴과 다른 몸통을 임의로 빌리지 않는다.
- 몸통 비교만으로 모든 종류의 접합을 자동 판정할 수는 없다. 이번 제외 목록은 실제 검수 기록과 변경되지 않은 파일 해시로 확인한 782장이다. 정상 별칭·시기별 그림은 유지한다.

## 표시 변경

- `js/data/portraitquality.js`: 확인된 782개 무릎상 키를 제외 목록으로 관리한다. 원본과 얼굴상 파일을 삭제하거나 새 얼굴로 바꾸지 않는다.
- `G.Img.has/pick`: 목록에 있는 무릎상을 선택하지 않는다. 게임과 도감에 같은 규칙을 적용한다.
- 대화창은 제외된 무릎상을 다른 역할 그림으로 우회하지 않고, 두 사람 모두 기존 얼굴상으로 표시한다. 검수 완료한 무릎상은 기존처럼 표시한다.
- 역사 화자 372명의 무릎상 후보는 실제 선택된 얼굴상의 정확한 짝 하나로 제한한다. 전용 얼굴은 있는데 무릎상이 없거나 제외된 경우, 다른 사람의 몸통으로 바뀌지 않는다.
- 기존의 원본 한 장 표시 방식은 유지한다. 얼굴상과 무릎상을 새로 잘라 붙이거나 얼굴·몸 조각을 겹치지 않는다.
- 저장 자료·인물 ID·사건 조건·보상은 바꾸지 않는다. 게임을 다시 열면 같은 저장에 적용된다.

## 원화 교체 뒤 해제

제외된 무릎상을 같은 인물·복식의 자연스러운 독립 원화로 교체하고 얼굴상과 함께 직접 확인한 뒤, `portraitquality.js`에서 그 키를 지운다. 파일이 있다는 이유만으로 해제하지 않는다. 이번 작업은 782장을 재제작한 작업이 아니라, 확인된 불량 합성본의 노출을 막은 조치다.

## 검증

- `python tools/audit_portrait_joins.py`: 매니페스트의 실제 파일만 전체 검사한다. `--append`는 기존 보고서에서 미검사 파일만 추가한다. 교체한 파일을 다시 감사하려면 옵션 없이 실행한다.
- `node tests/portrait_join_safety_smoke.cjs`: 제외 782개 선택 차단·원래 얼굴 보존, 검수 완료 40장 유지, 역사 화자 372명 짝 일치, 전용 무릎상 누락, 패터슨 정상 무릎상·옛 합성본·시녀 의상 불일치·명시적 얼굴상 대체의 실제 화면과 단일 이미지 표시를 확인한다.
- `node tests/portrait_face_integrity_smoke.js`: 왕실 전령의 합성 무릎상 대체와 제독·전령 얼굴 보존을 확인한다.
- 결과·후보 비교표·화면: `artifacts/portrait-join-20261106/`. 브라우저는 검사 종료 시 닫는다.
