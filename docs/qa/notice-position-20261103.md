# 알림을 왼쪽에 배치하고 끌어서 옮기기

2026-11-03 사용자 요청: 아래 가운데의 항로 안내가 배와 항적을 가려 게임에 방해가 된다. 기본 위치를 왼쪽으로 옮기고 직접 위치를 조정할 수 있게 한다.

## 변경

- 기본 위치는 왼쪽 띠 안에서 가장 넓은 빈 공간이다. 윗줄·상태판·해도·바람 판·조작줄을 피하며, 글씨 크기나 창 크기가 바뀌면 다시 계산한다.
- 알림을 누른 채 끌어서 옮긴다. 그냥 누르면 닫히고, 끌어 놓은 직후에는 닫히지 않는다. 알림이 새로 오거나 게임을 다시 열어도 옮긴 위치를 기억한다.
- 위치는 기존 HUD 이동 기능을 이용해 이 브라우저의 `pu.hudPos.notices`에 화면 비율로 보관한다. 저장 파일 형식과 기존 위치 설정은 유지한다.
- 오른쪽 클릭으로 기본 위치로 되돌린다. 수첩 설정의 알림 설명에도 사용법을 추가했다.
- 긴 알림 여러 개는 빈 공간의 높이를 넘지 않으며, 넘치면 영역 안에서 스크롤해 읽는다. 새 소식이 보이도록 아래로 맞춘다. 지난 소식에도 그대로 남는다.
- 창·대화·새와 나비 연출 중에는 기존 보호 위치를 사용하고, 끝나면 기억한 위치를 복원한다.

조정값은 `G.FX.noticeLayout`: 왼쪽 여백 16, 장애물 간격 12, 너비 360(UI 좌표)이다. 정상 플레이의 알림 등급·표시 시간·대화 중 보류 규칙은 유지했다.

## 검증

- `node tests/notice_position_smoke.cjs`: 실제 마우스 드래그, 클릭 닫기, 새 알림과 재접속의 위치 복원, 창을 열고 닫을 때 위치 보호·복귀, 960×540·1280×720·1600×900에서 상태판·해도·조작줄과 겹치지 않음, 긴 알림 세 개, 작은 창에서 사용자 위치의 화면 내 제한, 오른쪽 클릭 초기화, 콘솔 오류 0.
- `tests/notices_smoke.js`: 기존 등급·중복 억제·표시 시간·대화 중 보류·지난 소식·설정 검사 통과, 콘솔 오류 0.
- `tests/hud_pin_smoke.js`: 해도·바람 판의 기존 드래그·자리 기억·초기화·단순 클릭과 다섯 창 크기 검사 통과, 콘솔 오류 0.
- 변경한 JS의 `node --check`, `git diff --check` 통과.

Windows Chromium은 `BROWSER_EXE`로 Chrome 실행 파일을 지정했다. 기존 시험의 `playwright` 의존성은 설치되어 있던 `tools/procedural_art/node_modules/playwright-core`를 연결해 사용했다. 시험 브라우저는 모두 `finally`에서 닫는다.
