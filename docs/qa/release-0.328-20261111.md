# 0.328 통합 검증 — 2026-11-11~12

이전 공개판 `ff7d738` 이후 작업 폴더에 추가된 코드·자료·원화를 고정한 소스에서 검사한다. 결과·소스 해시·화면과 로그는 `artifacts/release-0.328-20261111/`에 보존한다.

## 반영 범위

- 중계항의 구입가·재고 조정과 기존 교역품·일괄 매각·교역왕·시장 수량을 확인한다. 물자를 팔아 부족 사정이 풀리는 실제 매각 경로, 일부 해소·완전 해소 기록과 중복 방지, 현지·이웃 주민의 대사·말풍선·언어 수준·지속 기간·이전 저장을 검사한다.
- 방향키·마우스·항로 선택·손 조타를 감도·선종·배속별로 비교한다. 항해 속력 식과 파도 셰이더는 바꾸지 않으며 기존 항해·자동항해·해전 복원을 함께 확인한다.
- 해전 악명·명성, 대규모 역사 해전의 예외, 전설 갑옷 다섯 벌의 시장·한 벌 구매·소문과 이전 저장, 수호 유물 다섯 가지의 실제 일기토·불길·돌진 방어를 물건 유무별로 비교한다. 후원자 보고 뒤 수호 유물 반환도 확인한다.
- 발견물 42종의 등장 시기·발견 자리·시대별 도시·식물 거래·민족 마을과 단서·도감 연결을 검사한다. 자료 추가와 전용 그림 완성을 구분하며, 새 유물 23종은 기본 그림을 사용하고 전용 원화는 별도 제작 중이다.
- 새 소지품 그림 43개, 어머니별 자녀 초상 120개와 교체 왕녀 무릎상 1개의 규격·해독·원본 해시를 확인한다. 자녀 초상은 10살·20살의 아들·딸 얼굴상·무릎상이며 출생 순서·여러 어머니·형제자매·동료·후계 연결과 이전 외형의 대체 표시를 검사한다.

## 검증 도구 보완

새 소지품 시험이 로컬 제작 폴더의 조사 자료를 읽던 것을 버전 관리하는 기준 품목 목록으로 바꿨다. 신규 기능 시험을 정식·베타 빌드와 공개 주소에서도 실행할 수 있게 하고, 선회 시험이 오류 때도 브라우저를 닫고 콘솔 오류를 실패로 처리하도록 보완했다. 그림 이름 검사는 새 자녀 폴더와 40살 그림을 인식한다.

기존 후계 외형 시험은 저장 구조의 정확한 문자열을 비교해 새 `artFamily` 메타데이터 때문에 실패했다. 어머니별 그림이 없는 경우의 빈 필드를 허용하되 성별·폴더·변형 번호와 나이별 실제 그림 검사는 유지한다.

왕실 정원·민족 발견 시험의 실패는 0.327 사본에서도 재현했다. 정원 시험에는 오래전 받은 작위 이력을 명시하고 작위에 맞는 식물 네 종을 준비한다. 민족 발견 시험은 별도 업적 연출만 넘기고 발견·보상 기록을 유지하며, 전체 자료의 상세 설명 검사는 제작용 도감에서 수행한다. 플레이어 도감의 본 것만 표시하는 규칙은 별도 시험으로 확인한다.

첫 로컬 웹 검사에서 그림 동시 요청 중 전송 실패가 있었다. 검증 서버의 요청 대기열을 늘리고 동시 해시 요청을 줄인 뒤 두 웹의 그림 164개씩 해시·규격·표시와 오류 0을 재확인했다.

## 빌드·게시

로컬 파일 실행과 압축 웹 빌드를 함께 확인한다. 웹 그림은 같은 공개 저장소의 커밋 고정 주소를 사용하며, 원본 화질과 캔버스·WebGL 사용을 유지한다. 공용 자산 중복 제거와 게시 용량 검사를 수행한다. 로컬 빌드 검증용 그림 서버와 브라우저는 `finally`에서 닫는다.

베타 포탈의 기존 이력까지 작성 도구 이름이 없는지 확인하고, 버전·도감 일곱 분류·그림 해시·390px 화면·콘솔 오류를 두 채널에서 검사한다. 게시 완료 뒤 공개 주소에서도 같은 검사를 실행한다.

## 최종 소스·빌드 결과

JavaScript 542개 문법 검사와 관련 브라우저 시험 41개를 통과했다. 정식·베타 압축 빌드의 독립 검사 19개도 통과했다. 두 빌드에서 그림 164개씩 원본 SHA-256·규격 일치, 도감 일곱 분류, 포탈 전체 이력의 작성 도구 이름 0건·390px 화면 넘침 없음·콘솔 오류 0을 확인했다. 게시 폴더는 229,474,957 bytes(218.8 MiB)다.

새 소지품 43종은 256×256 투명 배경이며, 처음 조사한 소지품 1,598종의 전용 그림 누락은 0건이다. 새로 등록된 유물 23종은 별도 제작 목록과 기본 그림 사용을 확인했으며 완성 원화로 기록하지 않는다. 자녀 초상은 15명별 아들·딸의 10살·20살 얼굴상·무릎상 120개다.

공개 배포·사후 확인 결과는 같은 결과 폴더의 deployment.json과 public-checks.json에 보존한다. 브라우저·로컬 검증 서버와 실행한 시험 과정을 닫는다.

## 공개 검사에서 발견한 수집 API 오류 보완

최초 공개 검사 19개 중 베타 자녀 외형 검사에서 항해 현황 전송의 413 응답을 발견했다. 수집 서버의 요청 한도 96KB와 발견물 배열 한도 1,200건이 늘어난 도감 1,292종보다 작았다. 기존 통계 서비스의 요청 한도를 256KB, 배열 한도를 2,048건으로 올렸고 길이 헤더가 없어도 실제 UTF-8 바이트 수를 확인한다. 출처·세션 검증과 저장 구조는 유지한다.

서버 시험 세 개에서 발견물 1,292종 전체의 현재·누적 저장, 반복 요청 중복 방지, 과대 요청 거절, 기존 누적 집계와 게시판 보존을 통과했다. 같은 통계 서비스에 빌드·배포한 뒤 실제 베타 자녀 검사를 재실행해 출생 40회·자녀 그림 80개와 이전 저장 호환, 콘솔 오류 0을 확인했다. 실제 100,542바이트 항해 현황 요청이 202로 접수돼 공개 검사 19개가 모두 통과했다. 최초 실패와 재검사 결과는 public-checks.json, live-child-beta.retry.log, live-presence-responses.json에 함께 남긴다.
