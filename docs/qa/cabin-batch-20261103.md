# 부하가 있는 선실 일괄 개조 — 2026-11-03

## 사용 방법

조선소 → 개조 → 기함 선택 → 선실 개조 → **한꺼번에 개조**.

각 번호의 방 용도를 고르거나, 전체를 같은 종류로 지정한다. 원래대로를 누르면 편집 전 구성으로 돌아간다. 편집 중에는 비용·날짜·실제 방과 부하 배치를 바꾸지 않는다. 변경할 방 수·총비용·공사 기간과 방마다 개조 뒤 거주자를 미리 보여 준다. 견적 확인 후 한 번 승인하면 전체 변경을 적용한다. 확인을 취소하면 계속 편집하고, 편집창을 취소하면 원래 상태로 돌아간다.

## 배치와 기존 규칙

- 바꾸지 않는 방의 거주자는 유지한다. 옮겨진 같은 종류의 방, 원래 번호, 나머지 빈자리 순으로 부하 자리를 정한다.
- 한 방에는 한 명만 두고 창고에는 사람을 두지 않는다. 자리가 모자라면 대기 인원과 이름을 미리 알린다.
- 항해사·부관·측량사와 다른 배의 선장·선원 보직은 유지한다. 회계실을 옮겨도 경리는 따라간다. 회계실이 없어지면 해당 경리 보직을 해제한다.
- 바꾼 방의 기존 가격·기간을 합산한다. 새 가격·할인·기간 조정값은 없다. 돈이 부족하면 일부만 개조하거나 결제하지 않는다.
- 짐칸은 전체 개조를 마친 뒤의 용량으로 검사한다. 가득 찬 창고의 위치 교환은 허용하고, 짐이 넘치도록 짐칸을 줄이는 변경은 전체 거부한다.
- 적용 직전에 기함·기존 구성·돈·짐칸을 다시 검사한다. 편집 도중 기함이나 선실이 달라졌다면 오래된 구성으로 덮어쓰지 않는다.
- 고정 자리와 선실 수는 바꿀 수 없다. 새 저장 필드는 없다. 기존 한 칸 개조도 유지한다.

규칙: `js/systems/cabins.js`의 `planRemodel`, `remodelAll`. 화면: `js/ui/cabinview.js`, `css/style.css`.
