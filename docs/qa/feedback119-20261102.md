# 피드백 119 — 자금 및 거래

## 확인한 원인과 수정

- **아덴 조선소 투자:** 기존 「최대」는 소지금 전부를 천 닢 단위로 낼 수 있었다. 기존 코드로 1,234,000닢을 가지고 실행하면 잔액 0닢·누적 투자 1,234,000닢이 되지만 기술은 5등급에서 멈춘다. 이제 도시의 기본 기술과 투자 단계표로 마지막 등급까지 필요한 금액을 계산하여 투자 상한을 정한다. 아덴은 누적 70,000닢까지만 받는다. 단위·실제 지출·잔액을 표시하고 최종 확인 후 결제하며, 잘못된 입력과 결제 시 잔액 부족을 거른다.
- **캘리컷 중국 도자기:** 옛 저장의 교역품 분리 코드가 구매 도시의 지역을 산지로 취급했다. 기존 코드에서 캘리컷산 `porcelain` 7통은 불러오면 `faience`로 변했다. 이제 중계항의 수입품은 변환에서 제외한다. 새 게임과 보정한 저장에 `tradeGoodsVersion: 1`을 적어 품목을 반복 추정하지 않는다. 분리 이전 발렌시아 도자기를 유럽 도기로 바꾸는 옛 저장 호환은 유지한다.

## 검증

`node tests/feedback119_smoke.cjs` 통과, `file://`·헤드리스 Chrome에서 실행했다.

- 실제 투자 금액 창에서 「최대」 선택: 1,234,567 → 1,164,567닢, 투자 70,000닢, 기술 5등급. 저장 후 잔액·투자액도 같다.
- 입력 취소·최종 확인 취소·음수·소수·NaN·무한대·상한 초과 입력은 차감하지 않는다.
- 69,000닢까지 투자한 아덴은 나머지 1,000닢만 받으며 상한 뒤에는 추가 차감하지 않는다. 확인 중 잔액이 부족해져도 차감하지 않는다.
- 캘리컷의 실제 교역 구매 처리 후 저장·불러오기에서 중국 도자기와 함께 실은 유럽 도기의 수량·원가·구매처·구매처별 몫을 보존한다.
- 판 번호 없는 기존 저장도 캘리컷·호르무즈·이스탄불·말라카·고아·오문·나가사키의 중국 도자기를 유지한다.
- 옛 발렌시아 도자기 보정과 보정 후 재저장·재불러오기를 확인했다.
- 실제 일지 저장 → 브라우저 새로고침 → 일지 불러오기에서 품목·구매 기록·자금을 보존했다.
- `pageerror`·`console.error` 0. 시험 브라우저는 `finally`에서 종료한다.

기존 `tests/trade_relay_smoke.js`도 통과했다. 중계항·산지·지역 가격 차이·교역소 중계 표시·옛 저장 보정·도감 열기를 확인했고 콘솔 오류가 없었다. 실행 환경의 `playwright-core`를 대체로 읽도록 보강하고, 큰 파일판은 `domcontentloaded`까지 기다리게 했다.

## 범위

저장되어 버린 과거 손실 금액이나 이미 유럽 도기로 변한 짐을 추정 복구하지 않는다. 수정과 검증 결과는 VERSION 0.305 정식·베타 웹 배포에 포함했다.
