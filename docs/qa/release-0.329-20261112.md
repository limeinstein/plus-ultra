## 검증 도구와 자료

신규 시험이 파일 실행판·압축 빌드·공개 웹 주소를 같은 동작으로 검사하도록 `WEB_BASE`를 받게 했다. 한국어 회귀 검사는 한국어 브라우저 환경을 사용하고 영어 시험은 별도 언어 선택·복원을 확인한다. 영어 시험에서 네트워크 오류를 일괄 무시하던 조건을 제거해 콘솔 오류를 모두 실패로 처리한다. 외부 글꼴 요청만 검증 환경에서 빈 CSS로 대체한다.

번역 원본 60개 파일과 실행 번역 묶음의 일치를 확인했다. 고정 시점의 실행 파일에 없던 번역 원문 14,099개를 최신 원본과 같은 묶음으로 맞추고 다시 검사한다. 영어 안내서 생성 결과도 소스와 일치한다. 이 작업에서는 새 그림을 생성하거나 기존 그림을 다시 인코딩하지 않는다.

발견 설명과 가족 대사의 영어 말씨 보완을 포함하고, 영어 관찰 1,417개와 아이의 Daddy/Father 구분·한국어 복원을 검사했다. 압축 파일판 시험이 폴더 주소를 직접 열던 문제는 `WEB_BASE`에서 `index.html`을 명시하도록 고쳤다. 최초 실패 기록은 별도로 보존한다.

기존 가족 대사 시험의 24건 실패는 이전 공개판 사본에서도 동일하게 재현했다. 이 중 일곱 발견물은 원래 공통 대사를 사용하고, 17문장은 기존 자료의 자연스러운 종결형이었다. 두 판에서 같은 대상을 확인한 기준 자료를 보존하고, 공통 대사의 가족별 표시와 기존 종결형을 정확한 문장으로 검사하도록 시험을 보완했다. 새 누락이나 바뀐 문장을 자동으로 허용하지 않는다.

신규·교체 그림 661개가 등록된 파일과 SHA-256·규격이 일치하며, 이미지 목록 17,039개 키의 파일 누락은 0건이다. 발견 원화 375개 원본이 보존돼 있고, 게임용 발견 세트 42개와 투명 증빙 아이콘 333개의 규격·여백·프레임·해시를 확인한다. 여급 185명·지역 초상 270쌍·도시 316곳·후원자 121자리의 754대와 식민 세력 9개의 대응 검사도 수행한다.
