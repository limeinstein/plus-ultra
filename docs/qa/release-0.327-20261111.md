# 0.327 통합 검증 — 2026-11-11

이전 공개판 0.326 이후의 게시판 수정과 현재 작업 폴더의 기능·원화를 모아 정식·베타를 같은 소스로 만든다. 검증한 소스와 결과는 `artifacts/release-0.327-20261111/`에 보존한다.

## 반영 범위

증거품의 보고·발표 미리보기와 인계 안내, 후계자·통역 언어 표시, 회사 직급별 말씨와 여관 대사, 첫 음식 보상과 이전 미식 기록, 현상수배 벽보와 해적 소문을 검사한다. 일곱 해적섬의 여섯 직업별 주민·등장 비중·이름·보행·초상·대화, 일반 도시와의 공존과 건물 복귀를 포함한다.

자녀 외형의 인물·지역 설정과 이전 저장의 보정, 성장·계승·형제자매와 보관함을 확인한다. 그림은 블랑카의 얼굴·무릎상과 세 사건, 라푼젤 얼굴·무릎상과 두 탑 장면, 여급 무릎상의 새 파일·교체 파일 10개를 검사한다. 실제 게임과 도감의 활성 경로를 함께 확인한다.

배 입항 0일, 출항·성문 입장 쉬움 1일·보통 3일·엄격 10일을 실제 도시 경로로 확인한다. 중복 날치의 발견·보고·계약·소지품 ID와 단서를 병합하고 재실행에도 같은 결과가 나오는지 검사한다. 현지 판매품 조달 의뢰와 자기 도시 발견 확인 의뢰를 제외하며 이전 왕명 목록도 갱신한다.

## 검증 중 보완

- 640×640 창에서 두 열·네 줄 수배서가 최소 크기에서도 아래로 잘렸다. 가로 여유 안에서 열 수를 늘리도록 고치고 1280×720·960×540·640×640 모두 확인한다.
- 날치의 두 ID에 각각 단서 배열이 있으면 한쪽의 단서를 잃을 수 있었다. 배열을 합치고, ID 문자열과 같은 제독 이름·표시 글은 고치지 않도록 보완했다.
- 구형 왕명 목록의 저장 버전을 올려 현지 판매품을 요구하던 이전 목록이 새 조건으로 바뀌게 했다.
- 첫 음식의 차림표 안내에 실제 사교 명성 표시 배수를 적용해 안내와 획득량을 맞췄다.
- 왕녀 시험의 특진 대체금 실패는 0.326 사본에서도 재현했다. 첫 혼인 업적 1,200닢과 왕실 하사금을 구별해 검사한다. 후계 외형 시험은 범위 밖의 무작위 친족 합류창을 열지 않게 하고, 계승·형제자매·자택 보관함은 별도 시험에서 검사한다.

## 빌드와 공개 확인

JavaScript 전체 문법 검사와 관련 기능·저장 호환·원화 시험을 실행한다. 압축한 정식·베타 웹을 만들고 공용 자산 중복 제거와 게시 용량 검사를 수행한다. 로컬 검증에서는 CORS가 있는 임시 그림 서버를 사용하며 `finally`에서 종료한다. 공개판은 같은 공개 저장소의 커밋 고정 그림 주소를 사용해 원본 화질을 유지한다.

두 빌드와 공개 웹에서 버전·도감 일곱 분류·그림 해시·증거품·후계 언어·규칙·첫 음식·자녀 외형·캔버스·WebGL·도감 기록을 확인한다. 포탈의 기존 이력까지 작성 도구 이름이 없는지, 390px 화면 넘침과 콘솔 오류가 없는지 검사한다. 브라우저와 실행한 시험 과정은 끝나면 닫는다.
