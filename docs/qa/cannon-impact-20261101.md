# 대포의 폭발과 피해 표시 — 2026-11-01

## 바꾼 것

대포 10종의 기존 위력·사거리·장전 수치를 바탕으로 서로 다른 발사·명중 그림을 연결했다. 실제 피해·명중률·사거리·장전 계산식은 유지한다.

| 포 계열 | 보이는 차이 |
| --- | --- |
| 세이커·청동 세이커 | 작은 화염, 가벼운 반동, 작은 포탄 |
| 캘버린·롱 캘버린 | 길게 뻗는 포구 화염, 낮고 곧은 탄도, 좁은 파편 방향 |
| 페리에 | 중간 크기의 화염·연기·파편 |
| 페드레로 | 넓게 흩어지는 파편·불티, 기존 선원 피해 2배 반영 |
| 카논·청동 카논 | 굵은 포탄, 큰 화염과 반동·착수 물보라 |
| 중카논 | 가장 큰 화염·연기·반동, 낮은 음의 폭음 |
| 캐로네이드 | 큰 근거리 폭발, 넓은 파편과 짙은 연기 |

명중은 짧은 섬광 → 방향성 있는 불길 → 감속하는 불티와 떨어지는 목재 파편 → 솟아오르며 바람에 흩어지는 연기로 이어진다. 후속 요청에 따라 포격 반동의 물결 고리, 명중 충격파의 원호, 피격 때 겹치던 물보라 시트를 제거했다. 빗나간 포탄에는 각기 다른 높이·속도로 솟고 떨어지는 물줄기와 물방울만 그린다. 침몰의 별도 원호와 옛 착수 효과의 고리도 제거했다.

참고는 사용자가 준 [린반의 「게임이펙트 사슬 폭발 수강생 피드백」](https://www.youtube.com/shorts/Bx41izlk29k)이다. 브라우저에서 ‘피드백 후’ 공격의 약 28~33초를 확인하고, 밝은 순간 속불·가로로 번지는 짧은 빛·갈라지는 잔광·멀리 튀는 긴 불티·빠르게 식는 화염의 순서를 대포 명중으로 옮겼다. 사슬이나 괴물 모형을 옮기는 대신 명중 지점에서 효과가 터지도록 구현했다.

화염·연기는 단순한 빛의 원 대신 여러 크기의 난류를 겹친 질감으로 그린다. 96×96 투명 그림 6장을 코드로 한 번 만들고, 각 화염과 연기에 회전·크기·투명도를 달리해 재사용한다. 외부 이미지나 실행 의존성은 추가하지 않았다.

피해 숫자는 금빛/붉은빛 그라데이션·외곽선·짧은 확대·기울임·떠오름을 사용한다. 포 이름, 명중 횟수, 선원 피해를 표시하고 큰 피해에는 ‘강타!’를 붙인다. 같은 배의 연속 명중은 실제 피해를 합산하며 읽는 시간을 다시 준다. 연기와 물보라 위에 숫자를 그려 가독성을 확보했다. 화면 흔들림을 끈 설정에서는 숫자의 확대·기울임과 화면 번쩍임·떨림을 끈다.

## 조정값과 코드

- `js/data/seafx.js`의 `G.FX.cannonImpact`: 포 10종의 크기·화염 길이·연기량·파편 확산·탄도 높이·포탄 크기.
- 순간 섬광 0.14초, 화염 0.56초, 갈라지는 잔광 0.55초, 피격 연기 약 2.8초, 포구 연기 1.9초.
- 피해 숫자 1.65초, 마지막 명중 뒤 0.38초 이내 합산, 한 묶음 최대 16발, 내구의 16% 이상 피해에 ‘강타!’.
- 효과 목록이 380개를 넘으면 장식 입자를 줄이고, 650개에 도달하면 새 포격 장식 입자 생성을 제한한다. 피해 숫자는 계속 남긴다. 물보라는 기존 별도 상한을 따른다.
- `js/scenes/battle.js`: 포탄에 포 종류를 기록하고 발사·명중·착수·소리·반동·피해 숫자로 전달한다. 옛 저장의 포탄에는 기본 모양을 쓴다.
