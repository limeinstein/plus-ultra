# 제보 126 — 좁은 만 안의 항구에서 맴도는 자동항해

## 검사 결과

북해·러시아 쪽의 항구를 출입할 때 빠른 배가 여러 날 맴돈다는 제보를 기준으로 검사했다. 길찾기 결과가 있어도 배의 선회 반경이 다음 길목까지 거리보다 커지면 길목을 빙빙 돌 수 있었다. 목표 속력만 줄이고 기존 관성 속력은 남겨 두던 감속 처리가 원인이었다. 또한 길목을 통과한 걸음에는 다음 길목을 계산하지 않고 이전 침로로 이동했고, 해안에 밀리면 항로로 돌아가기 전에 물가를 따라 미끄러졌다. 진행 감시는 3일마다 재탐색하므로 이런 문제가 여러 날 이어질 수 있었다.

프리깃의 규칙 속력을 시험에서만 8배로 높인 극단 조건에서, 고정 난수·7월 바람의 오슬로→베르겐 항해는 수정 전 배속 ×1에서 30.36일, ×4에서 9.44일 걸렸다. 이 8배는 정상 플레이의 보너스 상한을 뜻하지 않는다.

## 수정

- 길목을 통과하면 같은 걸음부터 다음 길목으로 조타한다. 목적 항구 도착을 예약한 뒤에는 이동하지 않는다.
- 길목의 거리·선회력·방향 차이에 맞춰 실제 관성 속력도 제한한다.
- 바닷길 항해의 시간 분할에 속력을 반영해 좁은 물길을 한 걸음에 건너뛰는 일을 줄인다.
- 해안에 밀렸을 때 현재 길목까지 물길이 트여 있으면 먼저 항로 방향으로 바로잡는다.

조정값은 `G.FX.ship`의 `pathTurnAngle: 0.35`라디안, `pathTurnBrake: 0.5`, `pathStep: 0.05`도다. `R.shipSpeed`, `R.fleetSpeed`, `R.fleetMotion`의 규칙과 선박 능력치는 바꾸지 않았다. 추가 저장 필드는 없다.

## 검증

`node tests/port_navigation_smoke.cjs`

- 오슬로↔베르겐, 함부르크↔오슬로, 스톡홀름↔리가, 오호츠크↔페트로파블롭스크의 8개 방향.
- 프리깃 속력 1·2·8배, 시간 배속 ×1·×4·×8의 72개 조건 모두 목적 항구의 입항 처리에 도달.
- 고속 오슬로→베르겐: ×1 **4.92일**, ×4 **4.80일**, ×8 **4.80일**. 6일 미만을 회귀 검사로 고정했다.
- 반복 시험은 그림·해도 조사·주변 선박·일일 사건을 제외하고 실제 길찾기·조타·선체 관성·충돌·진행 감시를 돌린다. 바람과 선원 상태를 고정한 물리 검사이며 전체 플레이 시간의 예측값은 아니다.
