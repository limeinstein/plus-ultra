# 동료 명부·인물 상세·해고와 재등용 — 2026-11-01

얼굴 잘림 추가 수정: 초상 생성 함수의 인라인 픽셀 크기가 24px 목록 칸보다 커서 그림의 왼쪽 위만 보이던 문제를 고쳤다. 작은 얼굴의 캔버스에 최대 너비/높이와 블록 배치를 적용해 전체 그림이 정사각형 칸 안에 맞게 표시된다. `matebook_smoke`에서 전체 표·좌측 명단 초상의 경계와 중앙 정렬을 확인했으며 콘솔 오류는 0개다. 수정 화면은 `artifacts/matebook-faces/01-companion-list.png`에 있다.

첨부한 삼국지 인물 목록/상세 화면을 참고해 본편의 양피지·목재 테두리 안에서 동료 화면을 개편했다.

## 화면

- 수첩 → 동료: 작은 초상, 체력·지력·무력·매력·충성, 특기와 언어를 같은 표에서 확인한다. 이름 검색, 이름/능력/충성/애정/월급/특기 합계/언어 합계/각 특기와 언어의 단계로 오름차순·내림차순 정렬한다.
- 동료 클릭: 좌측 동료 명단과 이전/다음 선택을 유지한다. 외형·이름·직위·선실·말투·충성·애정·월급·갈래·능력치 사각형, 특기 17개와 언어 16개, 살아온 이야기를 보여 준다. 초상 높이를 조절해 긴 이름도 능력치 사각형이 화면 안에 남는다.
- 상세의 칸은 글자 길이에 관계없이 108×32px, 전체 표의 작은 칸은 모두 66×20px다. 특기 단계 색은 `#f4e8e9 → #e6bfc7 → #ba7788 → #773f50`, 언어는 `#e5eff0 → #b6d5db → #689eac → #315e72`. 특성 표식은 적색이다. 숫자는 현재 사용하는 단계, 별은 배에서 익힌 솜씨/언어이며 본래 단계는 마우스 설명으로 확인한다.
- 창작 항해사 전원의 고유 이야기와 루카의 이야기를 새로 썼다. 기존 인물 전기·철새의 사연·고유 옛이야기도 표시하며 열람만으로 대화 진행을 바꾸지 않는다.
- 술집·여관 → 부하와 이야기: 같은 명부에서 동료를 고르고 「이야기한다」로 기존 대화·선물·한잔·청혼 등에 들어간다. 선실 배치와 동료 사이 관계도 명부에서 연다. 고용 후보 명부에도 작은 얼굴을 붙였다.

## 해고 규칙

수첩 상세의 해고와 술집/여관 부하편성의 해고는 `G.MateDismiss.fire`를 사용한다. 항구에서 확인을 거치며, 루카의 기존 해고 거절·아내의 귀가·부부 동반 하선·겹친 동료 행 제거를 유지한다.

`js/data/base.js`의 `G.BALANCE.mateDismiss`:

| 값 | 설정 | 뜻 |
|---|---:|---|
| devotionChance | 0.005 | 해고 확인 뒤 잔류 서약 제안 확률 |
| devotionWage | 10 | 서약을 받아들인 동료의 월급 |
| returnMaxDays | 1825 | 함께한 기간이 이보다 짧으면 재등용 가능 |
| returnStayDays | 60 | 하선한 항구에 우선 머무는 기간 |
| rehireRate | 0.25 | 재등용 때 이전 월급에 더하는 비율 |
| rehireMin | 10 | 재등용 월급의 최소 증가분 |

서약은 수락/거절할 수 있다. 수락하면 `m.devoted`로 월급과 충성 유지를 저장하고, 미지급·대기·이야기의 충성 감소와 노장 이별 대상으로부터 보호한다. 이미 서약한 사람을 다시 해고하면 같은 제안을 반복하지 않는다.

짧게 함께한 해고 동료는 `s.mateDismiss[id]`에 재등용 급료와 수련·언어·애정·고유 이야기 진행을 보관한다. 하선 항구의 위치/체류 소식을 기록하며 수첩 「철새」와 술집 후보에 나타난다. 이야기 전용 동료도 재등용 가능하고, 고장이 없는 인물은 하선 항구 주변을 돌아다닌다. 권력자·가족·활약 연도 제한은 유지한다. 짝도 짧게 함께했으면 함께 철새가 되며, 20년 뒤 다른 이름으로 돌아오는 기존 노장 기록이 중복되지 않게 한다. 5년 이상 동행한 경우는 기존 이별/노장 규칙을 따른다.

기존 인물 정의나 ID는 바꾸지 않는다. 새 저장 필드가 없는 저장은 기본 월급·기존 충성을 그대로 사용한다. 재등용 급료는 고용 명부/카드/확인 문구/실제 월급 계산에 같은 규칙을 적용한다.

## 검증

## 추가 조정 — 전체 표와 스크롤 (같은 날)

사용자가 「전체 동료」 범위를 현재 고용한 동료 전체로 정했다. 기본 화면을 한 줄 약 31px의 비교 표로 바꾸고 직위·애정도 함께 표시했다. 특기는 최대 네 칸, 언어는 최대 세 칸을 먼저 보여 주고 나머지는 `+개수`로 알린다. 긴 항목은 마우스 설명으로 전체 이름을 읽고 행을 클릭해 상세에서 모두 확인한다. 모든 열 제목과 기존 단계별 정렬/이름 검색을 사용하며, 「전체 동료 / 동료 상세」 단추로 왕복할 때 선택·검색·정렬·표의 스크롤 위치를 유지한다.

좌측 동료 명단은 이름 11.5px·행 35px로 줄였으며 스크롤바를 항상 표시한다. 살아온 이야기도 별도 스크롤바를 두고 줄 간격을 1.85에서 1.45로, 문단 아래 간격을 10px에서 5px로 좁혔다. 동료마다 이야기 읽던 위치를 기억한다. 애정은 다섯 하트의 채움 정도로 표시하고 마우스 설명/접근성 이름에 수치를 제공한다. 충성은 기호 없는 숫자이며 49까지 적색, 50부터 기본색이다.

`matebook_smoke`, `cabin_growth_display_smoke`, `mate_news_smoke`를 다시 실행했다. 실제 휠로 좌측 명단과 긴 이야기를 각각 스크롤하고, 많은 동료의 표를 스크롤한 뒤 상세 화면과 왕복해 읽던 위치·검색·정렬·선택이 보존되는지 검사한다. 12명 전원이 한 화면에 들어오는 표, 애정 하트, 충성 49/50 경계도 확인했다. 새 표의 많은 인원 화면은 `artifacts/matebook/05-full-roster-scroll.png`다.
