### 职业与难度

- 年龄奖励：能力点数 4 + (年龄 − 18) × 0.5，特长点数 3 + (年龄 − 18) ÷ 4。
- 知识奖励：智力从40起每15点特长点数+1（最多+3），智力99以上则+4。

| 职业 | 初始特长 |
| --- | --- |
| 探险家 | 航海术 2 · 测量 2 · 操船术 1 |
| 发掘者 | 历史学 2 · 雄辩 2 |
| 猎人 | 操船术 3 · 科学 1 |
| 征服者 | 剑术 3 · 炮术 1 |
| 传教士 | 神学 3 · 雄辩 1 |
| 商人 | 会计 3 · 雄辩 1（第一艘船是卡拉维尔） |
| 军人 | 炮术 2 · 射击术 2 |

| 难度 | 出入港 | 初始资金 | 存档 |

### 存档

- **自动存档** — 游戏中每1分钟轮流存入5个存档位（从最旧的位开始覆盖）。可以在设置中关闭。
- **旅馆日志** — 在旅馆「功能 → 记录航海日志（存档）」或宅邸中，从5个位中选一个留下。
- 难度「严格规则」下，只能在母国城市的旅馆写日志。

![航海手册 — 提督标签](guide/p05_book)

| # | 标签 | 显示内容 |

| 2 | 舰队 | 纪律·疲劳·船员最少~最多·粮食·水·载货·船只列表·舰队速度（以最慢的船为准） |
| 3 | 伙伴 | 部下们的能力值（体力·智力·武力·魅力）·特长·语言 |
| 4 | 候鸟 | 知道消息的航海士，以及听到消息时他所在的地方 |
| 5 | 随身物品 | 最多40格 — 装备·丢弃·阅读 |
| 6 | 发现物 | 找到的数量·海图绘制%·各类别卡片（已报告·已发表·未报告·竞争者） |
| 7 | 线索 | 收集到的线索 |
| 8 | 成就 | 成就 |
| 9 | 契约·委托 | 后援者契约和行会委托 |
| 10 | 交易手册 | 到过的城市的行情记录，时代需求 |
| 11 | 欧洲局势 | 欧洲各国之间的关系 |
| 12 | 海图 | 探索过的海域，航线经验 |
| 13 | 日志 | 按日期的记录（从最近的开始） |

- 在酒馆打听到候鸟的下落后，那只候鸟会在该港口停留59天。再次打听同一个人的消息，期限不会延长，而是告诉你扣掉已过天数后的剩余天数。在手册「候鸟」中也能查看剩余停留天数。
- 手册「候鸟」里只记下亲眼见过、打听过下落或一起航海过的航海士。记下的地点是听到消息时的地点，时间一久就会变淡，变成「从前在○○」。
- 对酒馆女招待用「拜托打听航海士的下落」准确写出见过或有过交情的航海士的名字，只要不是太远的地方，她就会向周围的水手打听，把下落找出来。消息要过一段时间后再去找那位女招待才能听到。
- 提督年纪大了，或者部下长时间一起航海，部下可能会去世、身体垮掉，或因为别的事离开船。货舱里的药材、船上的医生、港口的医生有时能帮他渡过难关。

## 建筑

### 港口

![港口](guide/p10_harbor)

| # | 按钮 | 作用 |
| --- | --- | --- |
| 1 | 出航准备 | 一次搞定船员·修理·粮食·水·修理材料（下一页） |
| 2 | 出航 | 出海。如果有熟悉的航线，还会出现「以自动航行出航」 |
| 3 | 补给 | 分别决定粮食·水（天份）和修理材料（桶）。减少的话按补给价的50%卖回 |
| 4 | 舰队编成 | 最多5艘，最上面是旗舰。更换旗舰·每艘船的人员（自动决定）·从船坞编入·寄存到船坞·报废 |
| 5 | 城镇情报 | 买下陌生城市的位置记到海图上（每条 40 + 城市规模×20枚） |
| 6 | 发表 | 把找到的发现公之于世 — 只获得名声（没有可发表的东西时变灰） |

- 无法出航的情况：没有船 · 船员不足5人或不足最少人数的1/3 · 粮食或水不足2天份。
- 季风海域的港口还会多一项「季风情况」。
- 「船坞」：寄存从舰队中撤下的船。母港船坞可无限期寄存10艘，其他港口的船坞可寄存3艘，过了2年就会被报废（剩90天·30天时会通知）。更换旗舰在造船厂也能办。

![交易所](guide/p12_trade)

| --- | --- | --- |
| 1 | 购买 | 买交易品（下一页） |
| 2 | 出售 | 卖交易品 — 在这个交易所买的东西不能高于买价卖出 |

### 造船厂

![造船厂](guide/p14_shipyard)

| # | 按钮 | 作用 |
| --- | --- | --- |
| 1 | 购买 | 本地的船。高于造船技术等级的船会锁住 |
| 2 | 出售 | 旗舰和租来的船不能卖 |
| 3 | 修理 | 「全部修理」或一艘一艘修 |
| 4 | 改造 | 大炮 · 帆（每面300枚） · 索具改良 · 增设炮门（每门250枚） · 船首像（150枚） · 重造船体 · 更改船名 · 改造船舱（仅旗舰）。用最上面的「多艘一次改造」可以一次改所选船只的帆 · 大炮 · 索具 |

- 索具改良（逆风）：加装前三角帆 → 帆的裁剪·绳索改良 → 加固龙骨。价格是船价的8%·12%·16%，需要造船技术1·3·4级。
- 大炮和船首像按该造船厂的造船技术等级解锁。高等级的会锁着显示，用「技术投资」提升等级后就能装上。

#### 船首像的效果

| 效果 | 实际作用 |
| --- | --- |
| 速力 | 装了该船首像的船速力 +%（只限那艘船） |
| 船体 | 海战炮击·暴风中受到的伤害 −% |
| 暴风 | 遇到暴风的概率 −(3倍)%（最多 −65%） · 暴风伤害 −(2倍)%（最多 −30%） |
| 怪物 | 海怪按该概率退去 · 受到怪物的伤害 −%（最多 −50%） |
| 海战 | 我方炮击命中 +% |
| 幸运 | 平安度过海上事件（幽灵船·冰山·浅滩·热病·塞壬）的概率 +(2倍)%p |
| 纪律 | 航海中每天纪律 +(2倍) — 魔王像会扣减 |

- 装在多艘船上时，同样的效果取最大的一个全额生效，其他船上的只加¼。在「舰队」窗口下方的「船首像效果」里可以看到现在生效的合计。
- 神话之兽船首像（仙女·独角兽·狮鹫·天马·塞壬·特里同·麒麟·龙·不死鸟·迦楼罗）造船厂不卖。只能从阿瓦隆·独角兽·波斯波利斯·帕特农·特洛伊·亚特兰蒂斯·麒麟·黑龙·基辅圣索菲亚·普兰巴南这类伟大发现的遗物中获得。
- ★ 7种传说船首像，要打倒传说中的海怪（利维坦·巴库纳瓦·扎拉坦·耶梦加得·矶抚·西帕克特利·幽灵船）才能捞到。每一种都有其他船首像没有的「传说之力」 — 平静之海（暴风最多 −88%） · 母亲的怀抱（损失的船员减半） · 愈合的龟甲（每天船体1%） · 世界尽头的低语（每30天一条线索） · 牵引之尾（速力加成作用于舰队所有船） · 颤抖的炮手（敌方命中 −12%） · 诅咒（魔王像 — 天使像·圣母像·米迦勒像·圣尼古拉像可以挡住）。
- 遗物·传说船首像拆下，或卖掉·报废装着它的船时，会退回到随身物品里。

- 好感达到100就求婚 — 单身的提督娶为正妻，有妻子的话娶为第二夫人（在那位小姐的家乡有个家），儿子则娶为新娘（儿子继承家业后就成为妻子）。王族的嫁妆4万，贵族1万5千枚。

- 不请自来的女巫：蓟草女巫格丽塞尔达会闯进来。请她跳舞，或道歉让出上座，或用剑对抗让她感动，她就会成为伙伴（也会加入船上的女巫聚会）。用卫兵赶出去的话，舞会就会被搅了。


**子女** — 在宅邸「家人」里和孩子见面、教导、陪玩，也可以让他们作为见习生上船。

- **天生的器量** — 每个孩子每项能力能成长到的上限由运气决定（初始能力 + 6~26，天赋才能会更宽裕）。在器量以下长得很快，一碰到器量就很难再升。同样的教育，每个孩子的成长也各不相同。
- **特长** — 家庭教师也不是每年都一定请得到。等级越高越难，智力越高学得越好，成年（16岁）以前最多到2级。3级要成年后在船舱或行会里习得。
- **每年的运气**（6~15岁） — 「好年头」里有一项能力不论器量 +1，「艰难的一年」（热病·迷茫）那年自然成长的份就没有了。
- **母亲的语言和手艺** — 每年可以从同住的母亲那里学会一种语言·一项特长（最多到母亲的等级）。女招待出身的母亲会说家乡话（熟练）和那一带通用的语言（普通），还会雄辩·烹饪·音乐·会计中的一两样手艺（1~2级）。部下出身的母亲则是那个人会的语言和特长。在船上的孩子学不到母亲的东西。
- **一同航海** — 成年的儿子和没出嫁的女儿可以在「家人」 → 「让他上船一起走」里成为航海士加入舰队。船舱·职务乃至其他船的船长都像部下一样安排，月薪减半，忠诚由与父亲的关系决定。作为见习生上船的孩子到十六岁会自动成为正式航海士。在船上学到的特长·语言都会留在孩子身上，选「让他留在家里」或解雇的话就会回家（可以再让他上船）。
- **三十岁以上儿子的独立** — 没上船的儿子过了三十岁，在你回宅邸时会出去自谋生路（按成长得最好的能力，成为商船的船长 · 大学的学者 · 某位君主的骑士 · 港口的商人）。可以给盘缠、祝福他，或者说「那就上我的船吧」和他一起航海。要是一直不回去，他会在三十三岁时留下一封信离开。离开的儿子也**可以继承家业**（隐退时可以选择，继承的话就会回来），妻子每年都会转交他的信，可以用「到我的船上来吧」再把他叫回来。
- **继承家业时** — 在船上的儿子会从舰队下来当提督，船上的其他兄弟则作为弟弟航海士继续留在船上。

- **海盗传闻**：餐馆「听客人们讲海盗故事」（每次来访一回，免费，期限短） · 酒馆女招待「道谢并打听消息 → 著名海盗的传闻」（要付谢礼，期限宽裕）。在期限内到达听说的那片外海，那个海盗的舰队真的会出现。会记在手册「要做的事」里。
- **海盗旗**：每个海盗团有一面旗 — 第一次打倒那个海盗团的海盗就能拿到（随身物品种类「海盗旗」）。拿下巢穴的话，巢穴海盗团的旗也能拿到。在手册「海盗巢穴」下方可以看到收集的数量。
- 在一片海里打倒三个不同的著名海盗，海盗巢穴就会暴露。传闻会优先告诉你还没算进去的海盗。
- **吸收**：打倒著名海盗后，他的残党会流入同一片海的其他著名海盗（先流向同一海盗团，一个海盗最多吸收两股）。被吸收的海盗不会再出现，吸收的海盗每吸收一人就多一艘船，船员·炮术变强，赏金也会提高。告示上显示「吸收残党 1/2」。如果没有海盗肯收留，被打倒的海盗会重新聚集船只。

## 能力值 · 特长 · 语言

提督擅长什么，由三样东西决定 — **能力值**（天生的底子）、**特长**（学来的本事）、**语言**（听懂和说话的能力）。这一章不写数值，而是写「用在哪里」。

### 能力值 — 四种

能力值有 **体力 · 智力 · 武力 · 魅力** 四种，在手册「提督」里以条形显示。（酒馆的航海士卡和在家教孩子时，体力也叫作「力气」。）

- **最初决定的** — 年龄越小体力·武力越高，年纪越大智力·魅力越高。按职业会多加一点相称的能力值，生日的星座会提升一项能力值。年纪越大奖励点数越多，可以分给想要的能力值。
- **一生中会变的** — 靠做事积累的 **经验** 一点点提高（见「经验与成长」页），也会因爵位·婚姻·环游世界之类的 **大事件** 而提高。
- **年龄** — 年轻时体力会一点点增长，过了中年，体力和武力每年都会减少。晚年的冒险靠的是智力和魅力。
- **部下的能力值** — 部下也有四项能力值。代为出战一骑讨时、掌管其他船的船长打白刃战时、在报告·发表场合帮腔时，用的都是那个部下的能力值，说话方式和性格也像他的能力值。
- **招募伙伴** — 每个航海士都有自己喜欢的东西，他喜欢的那项能力值高，就容易一起共事。

### 体力 · 智力

**体力** — 撑下去的力量

- 一骑讨中能撑住的体力变大。是部下的话，被打中时也会伤得轻些。
- 在酒馆连干几杯也不容易醉倒。
- 旅馆打杂的工钱变多。
- 经验：靠美食 · 战斗 · 一骑讨成长。中年以后每年会一点点减少。

**智力** — 学习的力量

- 特长和语言 **最多能学几种**，由智力决定（创建提督和行会修习的上限）。
- 创建提督时智力高，会额外得到特长点数。智力最高的还会再多给一次。
- 行会的修习特长·学习语言更容易成功。在旅馆打杂学当地语言的速度也会变快。
- 一骑讨中佯退·诱敌·虚步之类的计谋更容易奏效，也不容易中对手的计。
- 智力非常高的话，陆战后能多救回一些倒下的队员。
- 在宅邸和孩子下国际象棋时，是提督的智力和孩子的智力较量。
- 经验：靠交易 · 说服 · 社交，以及第一次读的书成长。

### 武力 · 魅力

**武力** — 战斗的力量

- 一骑讨的威力变大 — 打得更准、更狠，拔刀更快。
- 一骑讨的决定性招式更容易奏效：一击必杀（武力极高时，对手伤得不重也能尝试） · 生擒 · 怒喝。
- 掌管其他船的 **部下船长的武力**，就是那艘船的白刃战攻击力。（提督所在的旗舰用提督手里的武器作战。）
- 催债时「恐吓」更管用，外交谈判中「提醒对方有共同的敌人」也更有分量。
- 经验：靠战斗 · 一骑讨成长。中年以后每年会一点点减少。

**魅力** — 赢得人心的力量

- 与后援者的契约谈判、用雄辩说服对方接受不感兴趣的发现、与外国宫廷的条约谈判都会更顺利。
- 交易所·市场的讨价还价更容易成功。
- 催债时「好言相劝」、叛乱时用话安抚带头人都更容易成功。
- 在报告·发表场合，提督在旁帮腔会更顺利。魅力极高的话，对异性后援者更加管用。
- 一骑讨中更容易用「说服」让对方收刀，「怒喝」也更有分量。
- 经验：靠说服 · 社交 · 交易成长，受封爵位或成婚时也会提高。

### 经验与成长

每做成一件事，那一类的 **经验** 就会积累，再按各类规定的能力值分进去。

| 经验 | 积累时机 | 成长的能力 |
| --- | --- | --- |
| 说服 | 说服后援者·谈判·消除怀疑 · 与守备队长交涉 · 安抚叛乱 · 催债（用嘴） · 宫廷条约谈判 · 一骑讨「说服」 · 在报告场合帮腔 | 魅力 · 智力 |
| 交易 | 在交易所买卖（利润越大越多） · 讨价还价成功 | 智力 · 魅力 |
| 战斗 | 海战 · 陆战（赢了多，敌人越强越多） | 武力 · 体力 · 智力 |
| 一骑讨 | 提督亲自交手的一骑讨（部下代打不算） | 武力 · 体力 |
| 美食 | 在餐馆吃一顿（第一次尝到的菜加倍） | 体力 · 魅力 · 智力 |
| 社交 | 每次获得社交名声时 | 魅力 · 智力 |

- 失败也能学到一点（说服失败、打仗输了，都会积累经验）。
- **能力值越高，再升1就越难。** 到中等左右很快，越往上越要花上几年、几十年。
- 一项能力值每天和每年能积累的经验都有上限，不能靠反复做同一件事集中练高。就算倾尽一生，单靠经验也几乎不可能达到100。
- 也会因 **大事件** 而提高：受封爵位 · 第一次成婚 · 受封英格兰骑士（魅力），救出失踪的王女 · 大海战胜利（武力），伊丽莎白公主避难（智力），写出漂流记 · 环游世界（体力和智力）。已经很高的能力值，事件不会直接提高，而是转为经验积累。
- 提高时会有通知，也会留在航海日志里。在手册「提督」下方的「经验与成长」里，可以看到各类经验和到下一点还差多少。

### 特长 — 等级与用法

特长有17种，分 **0~3级**（◇◇◇ → ◆◆◆）。

- **用谁的等级** — 在提督本人、担任用到该特长职务（副官·航海士·测量士·账房）的部下、安排在用到该特长船舱的部下当中，取 **最高的等级** 作用于整个舰队。
- **只要带着就行的特长** — 烹饪 · 音乐 · 绘画 · 工艺，就算没有职务，舰队里有会这门手艺的人，大多都能发挥作用。防坏血病的医学也是船上的任何人都行。
- **每艘船分别生效的特长** — 其他船的炮击·白刃战·暴风伤害·修理，由掌管那艘船的船长一个人的特长决定。
- **忠诚低的话**，部下不会使出全部本事。受伤期间也只发挥一半。

**学习特长的途径**

- **创建提督** — 在职业决定的初始特长上花点数提升。最多能学几种由智力决定。
- **行会「修习特长」** — 花钱和天数一级一级提升。智力越高越容易成功，等级越高越难。失败就只白花钱和日子。
- **部下** — 在船舱里待久了，那个房间的手艺会上身，年复一年等级会提高（副官室是雄辩，操舵室是航海术，瞭望台是测量）。那个房间的主特长（★）3年·9年·27年分别 +1·+2·+3，辅助特长（☆）慢1.2倍，3.6年·10.8年·32.4年分别 +1·+2·+3（例：陆战队待命室 — ★剑术 · ☆射击术）。特长最多到3。
- **子女** — 在宅邸教导、带去见习航海就会成长（最多到提督舰队的水平）。成年（16岁）以前最多2级，等级越高越难，智力越高学得越好。也会学到同住母亲的特长。成年后让他上船，就像部下一样在船舱里学习。
- 读书不会提升特长。不过学术书需要有懂那门学问的人才能读。

**LV3特长组合 — 隐藏能力**

### 特长 — 船与海（1）

**航海术**（航海士 · 操帆室，其他船看该船船长）

- 减少海上每天积累的疲劳。
- 遇到暴风时减少船·船员·粮食的损失（但避不开暴风）。旗舰的航海术对其他船也有一点影响。
- 船长航海术高的船速度快，逆风走之字形时损失也小。
- 更容易逃离敌人、避开冰山·浅滩、察觉海啸的征兆。
- 一个懂航海术的人都没有的话，出航时副官会劝阻。读某些航海学术书时需要。

**操船术**（航海士 · 甲板 · 操帆室 · 参谋室）

- 海上船员的纪律下降得少。几艘船一起走时会拉着慢船，队列不容易掉队。
- 陆上探险时走得更快、疲劳积得更少，野营休息的效果更大。沙漠烈日·沙暴的开销减少，暴风雪·沼泽中也更容易保住队员。
- 减少灾害损失，遇到鱼群捞得更多，钓鱼也更容易咬钩。
- 安排在参谋室的话，陆战计谋（奇袭·陷阱·狙击）更容易奏效。

### 特长 — 船与海（2）

**测量**（测量士 · 制图室 · 瞭望台 · 参谋室）

- **从2级起在海上能看到纬度**（经度要有六分仪才看得到）。
- 寻找未知港口的范围、海图显现的宽度、瞭望台先察觉的距离都会变大。陆上侦察也一样。
- 没有线索也更容易找到海上的发现物、跟着海鸟找到新港口、找到山中的古道。在野营地也能汲到更多水。
- 对陆战的奇袭·陷阱、察觉灾害征兆有帮助。藏宝图在测量越高时，能用越多的证据缩小位置。
- 远征计划中没有懂测量的人时会出现警告。读某些学术书时需要。

**造船技术**（副官 · 船舶修理室，其他船看该船船长）

- 在海上用材料修船（没有材料就修不了）。船舶修理室能把旗舰修得更好。
- 上岸野营修船时、遇到沉船事件时能修得更多。
- 懂当地语言的话，可以在手册里查到还没去过的城市有没有造船厂、技术到什么程度。

### 特长 — 战斗

**剑术**（副官 · 甲板 · 陆战队待命室，其他船看该船船长）

- 海战的白刃战变强。旗舰的陆战队待命室会让它更强。
- 一骑讨：提督用 **提督本人的剑术** 作战（部下的剑术不叠加）。打得更准，暴击和先手更多，更能看穿对手的招。部下代为出战时用那个部下的剑术，「换人」时由最强的人出战。
- 陆战：步兵·骑兵·提督队变强，3级时骑兵成为重装骑兵。剑术·射击术·炮术都到3级的话，提督队成为无敌提督队。
- 狩猎收获稍有增加，遇到幽灵船也更容易撑住。催债「恐吓」时也用得上。

**炮术**（副官 · 炮击室，其他船看该船船长）

- 海战中装填更快，炮弹更准。旗舰的炮击室会增加威力。
- 陆战炮兵变强，3级时成为加农炮兵。

**射击术**（副官 · 陆战队待命室）

- 海战中用不上 — 用于陆上的战斗和狩猎。
- 陆战枪兵变强，3级时成为火枪兵。「狙击」计谋更容易奏效。
- 一骑讨「秘密武器」改用手枪代替短剑。
- 在狩猎和野牛群事件中获得更多粮食。

### 特长 — 照顾船员的本事

**医学**（副官 · 诊疗室 / 坏血病方面船上的任何人都行）

- 坏血病开始得晚，蔓延得慢。诊疗室会让它更晚。也能有效防止海上热病。
- 陆上探险时因热病失去队员的情况减少，更会找草药，也更容易熬过暴风雪。
- 减少灾害损失，陆战后能救起部分倒下的队员。某些学术书和传说事件也需要它。

**烹饪**（任何人）

- 用船上和野营地的饭菜减轻疲劳。雨天的疲劳也能减轻，狩猎那天的晚餐更丰盛。
- 发生叛乱时可以选「开宴安抚」（烹饪或音乐有一样就行）。也会发生海上宴会事件。
- 能看出并提高香料·作物之类可食用发现物的价值。
- 厨房的厨师会凭手艺做家乡菜，减轻疲劳、提高纪律。是提督家乡菜的话更受欢迎。

**音乐**（任何人）

- 用歌声和乐器稳住船员的纪律。船歌事件变多，野营休息的效果变大。
- 叛乱时可以开宴（和烹饪相同）。
- 提高人们的歌·舞·仪式之类民族发现物的价值，并让他们当场敞开心扉。
- 娱乐室照顾纪律，音乐室照顾疲劳。音乐室相邻就会组成合奏（二重奏·三重奏·四重奏·乐队·乐团）。

**神学**（副官 · 礼拜室）

- 在海上稳住船员的纪律。礼拜室稳得更牢。
- 向教堂捐献名声涨得更多，在教堂祈祷纪律会提高。
- 遇到幽灵船·塞壬也不会动摇。
- 读神学学术书时需要。

### 特长 — 人与生意

**雄辩**（副官 · 餐厅 · 副官室）

- **有雄辩才能** 尝试说服后援者接受他不感兴趣的发现。
- 与后援者的契约谈判更顺利，提高预付款或延长期限时损失更小 — 等级越高争取到的条件越有利。
- 名声不够时哄管家、证据薄弱时「请证人作证」都更容易成功。在报告·发表场合会以堂堂正正的语气开场。
- 入港时与守备队长交涉更便宜、更顺利，偷偷进城也更容易。
- 向原住民搭话获得线索、用礼物收买人心都更容易成功。
- 用于安抚叛乱带头人、一骑讨「说服」、挽留想离开的部下·夫人、劝和部下夫妻吵架、催债「劝说」、在酒馆打听藏宝图的故事。
- 会说当地语言且雄辩高的话，也会知道没去过的城市的领袖。

**会计**（副官 · 账房 · 会计室）

- 在交易所讲价更管用，砍得更多，每次来访能讲价的次数也会增加。有账房的话还能再多一次。
- **有会计** 市场里才会出现「讨价还价」。
- 货物装得均匀，船能承受的重量增加。
- **3级时** 能进入大港口的后巷黑市（每次交易都会增加恶名）。
- 懂当地语言的话，可以知道没去过的城市的特产和繁荣程度。
- 有 **账房** 的话讲价会大为有利，与后援者的契约谈判可以多来一次，预付款也拿得更多。会计室会减少薪水。

### 特长 — 学问与发现（1）

**历史学**（副官 · 测量士 · 参谋室）

- 寻找陆上发现物的范围变大，没有线索也更容易找到。陆上侦察也看得更远。
- 更善于察觉灾害的征兆。从2级起更能辨认古代记录里留下的灾害。
- 知道没去过的城市的领袖。
- 读历史学术书时需要（古抄本中有的要2级才能解读）。

**科学**（副官 · 诊疗室 · 饲养室）

- 延缓坏血病，预防海上热病，更会找草药。
- 寻找生物·自然发现物的范围变大。也更善于察觉灾害的征兆。
- 钓鱼时更容易钓到珍贵的鱼。在斯芬克斯之谜中替你划掉一个错误答案。
- 饲养室能培育出粮食。读科学学术书时需要。

### 特长 — 学问与发现（2）

**绘画**（任何人 · 制图室 · 画室）

- 所有发现物的价值都会提高 — 名声 · 报告酬金 · 命名赏金。
- 决定 **证据等级**：越精通绘画越是「精密图版」，画得差是「速写」，谁都不会画就成了「口述记录」，后援者可能会怀疑。以后有擅长绘画的部下加入，可以重画以提高等级。
- 把鲸群·瀑布之类的壮观景象画进画册获得名声。我献上的仿制品也不容易被识破。
- 画室的部下会画美术品装进货舱。

**工艺**（任何人 · 雕刻室）

- 宝物·遗迹·民族发现物的价值大幅提高，其他发现物也稍有提高。卖遗物时价格也会提高。
- 在没有遗物的宝物·遗迹中能多带走些值钱的东西。也有助于提高证据等级。
- 仿制品不容易被识破。送饰品给女招待·部下时更能打动人心。
- 雕刻室的部下会制作雕刻品。传说事件中有的需要工艺才会开启。

### 语言 — 听懂

语言有16种（西班牙语 · 葡萄牙语 · 罗曼语 · 日耳曼语 · 斯拉夫语·希腊语 · 阿拉伯语 · 波斯语 · 汉语 · 印地语 · 维吾尔语 · 非洲本土语 · 中南美本土语 · 东南亚本土语 · 东亚本土语 · 朝鲜语 · 北美本土语），等级分 **不会 · 基础 · 普通 · 熟练**。

- **城市的语言** — 每座城市都有使用的语言，城市画面上方栏的「语言」格里，用点表示一行人说得怎么样。在葡萄牙统治或有葡萄牙商人往来的港口，用葡萄牙语也能沟通。
- **对话窗口** — 提督不太懂那种语言的话，没听懂的词会显示成那个国家陌生的文字。等级越高听懂的词越多，熟练就全都能听懂。
- **翻译** — 安排在副官 · 翻译 · 翻译室的部下比提督更会那种语言时，对话窗口下方会出现翻译窗口替你翻译。翻译本人也不熟练的话，只能以「大致听懂」·「断断续续听懂」翻出一部分。
- **原住民** — 就算语言完全不通，比手画脚也能沟通一点。
- **用谁的语言** — 提督、副官、翻译、坐在翻译室的人当中最拿手的那一个。其他职务的部下和其他船船长的语言用不上。（只有在图书馆，带着的部下会全体一起读。）不过有 **通译官**（见下）的话，旗舰上所有部下的语言都能用上。

### 语言 — 碰壁的事与变顺的事

**完全不懂语言就做不了的事**

- 交易所的讲价和市场的讨价还价（买卖是可以的）
- 在酒馆听生意传闻 · 契约情报 · 目的地 · 酒桌闲话
- 催债，与城门守备队长交涉
- 拜见后援者（管家不会理你）
- 在酒馆招航海士当部下（彼此要有相通的语言才谈得拢）
- 在手册里查没去过的城市的特产·领袖
- 那本书的语言谁都不懂时，读图书馆的书

**越拿手越顺的事**

- 交易所·市场讲价、城门交涉、催债、外交谈判都更顺利。
- 偷偷进城更容易。有以那种语言为母语的部下的话，他会当向导，更加容易。
- 新招的部下从一开始就更信任你。语言不熟练的话，会听到「还没有完全敞开心扉」。
- 在图书馆能读出书里更多的段落。语言提高了，重读同一本书就能得到剩下的段落。
- 远征计划中谁都不懂目的地语言时，会出现「请带上翻译」的警告。

### 语言 — 学习的途径 · 安排翻译

**学习语言的途径**

1. **创建提督** — 母语是熟练，邻近的伊比利亚语言从普通开始。剩下的点数可以提升其他语言，最多学几种由智力决定。
2. **行会「学习语言」** — 花钱和天数，一级一级地学那座城市和附近地区的语言。智力越高越容易成功，等级越高越难。
3. **旅馆「打杂」** — 一边干厨房活、劈柴，一边用耳朵学那座城市的语言。智力越高进步越快，但干活期间名声会一点点下降，而且不能干太久。
4. **同船生活** — 每天一点点学会船上部下们的母语。身边副官的语言进步最快，其他部下的语言进步得慢。部下们也会学提督的母语和彼此的语言。

**安排翻译**

- 在部下编成中让人担任 **翻译**，那个人的语言就会用于舰队（翻译只用语言，不用特长）。
- **副官** 的特长和语言都会用上。
- 在造船厂建 **翻译室** 安排人员，就能有多个翻译 — 往来于多片海的舰队，请平均地带上会不同语言的部下。
- **通译官** — 把任命为翻译的人安排在翻译室，他就会把提督和旗舰部下会的语言也汇集成「翻译簿」来翻译。不懂的语言他会去问懂的人，像「○○告诉我说——」这样转述，而且比其他航海士学语言更快（翻译簿在提督手册里）。
- 厨房的厨师会做自己的家乡菜 — 语言不同的部下越多，船上的餐桌也越丰富多彩。

## 发现与报告

### 发现窗口

![新的发现](guide/p62_disc)

| # | 栏 | 含义 |
| --- | --- | --- |
| 1 | 图片 | 发现物 |
| 2 | 名称 · 标签 | 类别 · 地区 · 价值 |
| 3 | 说明 | 发现物的故事 |
| 4 | 名声 | 在发现地当场获得的名声 |
| 5 | 确定 | 关闭 |

如果获得了遗物，会一并出现「到手的遗物」 — 向后援者报告就作为证据献上，在港口自己发表就归提督所有。

### 报告还是发表

|  | 向后援者 **报告**（王宫·宅邸） | 在港口 **发表** |
| --- | --- | --- |
| 得到的东西 | 酬金 + 名声 + 信任 | 名声（发现名声 × 0.9） |
| 遗物 | 作为证据献上 | 归提督所有 |
| 没有证据时 | 酬金 ×0.55~0.8，名声 ×0.8 | 名声 ×0.8 |
| 超过期限时 | 酬金 ×0.35~0.7，名声 ×0.7 | — |
| 注意 | 没有契约时，同一年向同一后援者报告，从第二次起酬金会减少 | 发表签了契约的发现，那份契约就会失败 |

- **证据等级**：实物 ×1.05 · 精密图版 ×1.05（绘画2级以上） · 海图 ×1 · 速写 ×0.95（绘画1级） · 口述记录 ×0.9。速写·口述的话后援者可能会怀疑。
- **一并报告·发表**：要报告的发现有两个以上时，「提议冒险」里会有「一起报告」，在港口「发表」中可以选多个一起公布。
- **度假岛屿40处**（自然）：把船靠近苏梅岛·马尔代夫·巴厘岛·塞舌尔·圣托里尼·马德拉·济州岛·塔希提·波拉波拉·毛里求斯这类岛屿就能找到。发现那一刻的余韵「休养」使疲劳 −25 · 纪律 +8（其他自然发现物的「感动」是 −16 · +2）。
- **按类别筛选·排序**：在选择提议·一并报告·发表窗口上方点击类别按钮（全部 · 地理 · 自然 · 遗迹 · 宝物 · 生物 · 民族 · 交易品），就只显示那一类，「全选可见项」只选显示出来的。用「排序」可以按价值·类别·名称·最近发现的顺序排列，再次打开也会沿用。
- **固定随身物品**：在手册「随身物品」·宅邸储藏室·市场出售窗口里点击物品前的图钉就会固定（像收藏一样）。固定的物品不会被市场出售的「全选」和储藏室的「全部寄存」选中，可以用种类按钮「固定」集中查看。卖掉或寄存后，列表的滚动位置也保持不变。
- **竞争者抢先发表的话**：之后在现场还能找到，但首次发现的荣誉留给竞争者，名声·酬金会减少。已经签下的后援契约和相关线索会维持到期限为止。

### 公司成立的时候

获得国王特许状的公司每个时代会成立一家。公司成立时会有消息传来，总部城市的街道上会出现公司的建筑。

- **公司总部**：社员名册（入会 · 升职） · 公司任务 · 交纳专营品 · 股票窗口
- **商馆**（海外该公司的城市）：公司仓库 · 中介订单 · 公司任务
- **交易所**（安特卫普 1531~1585 · 伦敦 1571~ · 阿姆斯特丹 1602~）：买卖所有公司的股票

### 成为会员以后

在总部的「社员名册」交出资金加入（综合名声200以上）。出资金的80%会以该公司股票的形式返还。**一次只能属于一家公司**，离开后一年内不能加入任何公司。

| 好处 | 作用 |
| --- | --- |
| 公司仓库 | 以交易所价格的60%买商馆的货 — 最多到按等级的配额，每60天刷新 |
| 交纳专营品 | 把专营品交给总部可得市价 × 1.25~1.4。**交得越多价格越低**，过一两个月会恢复 |
| 中介订单 | 连接商馆和大港口的链条。每一环都会累积联动奖励，连到最后 × 1.5 |
| 公司任务 | 缉私 · 归航大船队 · 建设商馆 · 俘获竞争公司（只限当时 **敌对国家的公司**） |
| 海关 | 不是会员的话，带着该公司专营品驶入总部港口时会被搜查货物 |

贡献积累起来就会从社员 → 船长 → 董事 → 总督晋升，配额 · 交纳价 · 任务报酬都会提高。

### 股票 · 创立出资

- 股价每月起伏，**每年1月的分红** 会自动到账。船队的归航 · 沉没、世上的大事件、提督的公司任务都会影响股价。
- **投资上限**：投入股票的钱（买入价合计）最多金币 **100万枚**。卖掉后可以再买那么多。一家公司的股票最多3,000股。
- **创立出资**：在伦敦（1600） · 阿姆斯特丹（1602 · 1621） · 巴黎（1664）的创立事件中出的钱会成为该公司的股票。在历史上的认购期内按面值（每股500枚），之后的追加出资按当天行情。
- **创立出资人**：在认购期内出资的人，在公司成立后 **10年内** 只要仍持有当时得到的全部股票，就能不交出资金成为会员。
- 第一次结算（英格兰东印度公司 1604 · 荷兰东印度公司 1610 · 西印度公司 1629）按当天持有的每1股分配。
- 交易所的「经纪人的耳语」会提前告诉你即将到来的消息，但不一定总是准的。

## 常见问题

### 卡住的时候

| 问题 | 回答 |
| --- | --- |
| 在海上经度显示为「?」 | 要有六分仪才看得到。纬度有星盘·六分仪或测量2级就能看到。故乡市场总有罗盘·六分仪 |
| 点了港口却不能自动航行 | 必须在两个港口之间不停靠其他港口直接走一趟，航线才会开通 |

| 台词里混着陌生的文字 | 是因为不太懂那种语言而没听懂的词。可以在旅馆打杂·行会学习语言来学，或者让擅长那种语言的部下当翻译（见「能力值 · 特长 · 语言」章的语言页） |

| 不知道该做什么 | 请看城市里的「在这座城市可做的事」和手册的「发现物」标签 |
