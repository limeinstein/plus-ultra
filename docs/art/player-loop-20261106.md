# 걷기·달리기 반복 연결 보강 (2026-11-07 검증)

플레이어 14종의 걷기·달리기 28개 구간에서 반복 정지와 마지막→첫 자세의 도약을 줄였다. 기존 얼굴·복장과 양발 대기 자세는 그대로 사용한다.

[기본 제독 전후 비교](player-loop-20261106-admiral.gif) · [갑옷 항해사 전후 비교](player-loop-20261106-armored_navigator.gif)

미리보기는 경계를 비교하기 쉽도록 기존과 보강한 시트 각각의 한 주기를 2초로 늦춰 반복한다. 실제 게임은 이동 거리와 걷기·달리기의 속도를 따른다.

## 원인과 수정

기존 49칸은 일부 인물에서 같은 자세가 14~23칸 반복되다가 다리가 갑자기 넘어갔다. 출발 대기를 잘라 낸 달리기 중에는 마지막과 첫 자세가 크게 달랐다. 칸을 같은 시간 동안 보여 주던 방식이 이 차이를 더 드러냈다.

연속 중복을 정리한 원본 1,033자세에 중간 1,425칸을 보강해 28개 시트 총 2,458칸으로 구성했다. 인물·동작별로 46~132칸이다. 자세의 원래 시간 순서를 유지하며 마지막→첫 자세에도 중간 칸을 넣었다. 동작을 뒤집어 재생하는 왕복 반복은 사용하지 않는다.

한쪽 인물 윤곽을 이동 흐름에 따라 변형하고, 가장 큰 도약과 반복 경계에는 RIFE 후보도 사용한다. 두 실루엣을 단순히 겹쳐 반투명 다리가 생기는 방식은 피한다. 얼굴 영역은 이웃 원본의 머리 픽셀을 옮겨 유지한다. 발끝이 칸 끝에 닿은 중간 자세는 여백을 넓힌 캔버스에서 다시 계산했다. 일부 변형 가장자리의 알파도 또렷하게 정리했다.

추가한 칸마다 자세 변화량에 맞춰 시간을 배분한다. 작은 변화에 오래 멈추지 않고 큰 움직임에는 이동할 시간을 준다. 반복 경계도 같은 시간표를 사용한다. 이 시간표와 실제 발 디딤 진행도를 별도로 기록해, 몸의 오르내림과 걷기↔달리기 전환에서도 같은 쪽 발의 진행도를 이어받는다.

## 자산과 조정값

- 추가 시트: `images/characters/<look>/motion/stride_walk.webp`, `stride_run.webp` — 8열, 300px 높이의 칸, 인물마다 다른 칸 수.
- 칸 수·격자·자세별 시작 시간·발 디딤 진행도: `G.HERO_MOTION[look].loops.walk/run`, `js/data/heromotion.js`. `times`와 `pose`의 마지막 항목은 각각 전체 시간 1과 주기 수다.
- 이동 거리당 주기와 상하 운동의 크기: 기존 `G.FX.heroGait`, `js/data/seafx.js` 값을 유지한다.
- 실제 재생·반복·Shift 전환: `js/scenes/town.js`.
- [제작 및 픽셀 변화량 기록](player-loop-20261106.json).

원본 `walk.webp`·`run.webp`, 정지·경치 구경·인사·스트레칭·문 입장 시트, 이동 속도와 저장 형식은 바꾸지 않았다. 새 시간표나 시트가 없는 외형은 기존 재생을 사용한다.

## 제작 도구

`tools/repair_player_loops.py`로 기존 그림에서 중간 칸을 만든 뒤 `tools/install_player_loops.py`로 접지·잘림·잔상을 확인하고 등록한다. 생성 후보와 보간 캐시는 `artifacts/player-loop-20261106/`에 있다. 새 캐릭터 원화 생성은 하지 않았다. 게임 실행에는 제작 도구나 Python·OpenCV·RIFE가 필요 없다.

## 검증

- `python -X utf8 tests/player_loop_20261106.py`: 28개 시트·2,458칸의 접지·크기·잘림·연속 중복·단조로운 발 디딤 순서·시간표·원본 보존을 검사한다. 반복 경계의 하체 가중 픽셀 변화량은 원본 유효 자세 기준으로 54~91% 줄었다. 새 시트의 잔상 검사도 모두 통과했다.
- `node tests/player_walk_loops_browser.js`, `node tests/player_run_loops_browser.js`: 실제 `file://` 거리에서 14종 모두 추가한 모든 칸, 마지막→첫 칸, Shift 전환, 원래 대기 자세, 벽 앞 정지와 대기 동작 우선권 통과. 하얀 남방 항해사의 실제 화살표 입력과 키를 뗀 뒤 정지도 통과했다. 콘솔 오류 0.
- `python -X utf8 tests/player_motion_frames.py`, `python -X utf8 tests/player_motion_faces.py`, `node tests/player_motion_atlas_smoke.js`: 기존 원본의 키·발밑·얼굴·문 입장 연결 검사 통과.
- 실제 화면과 결과: `artifacts/player-loop-20261106/browser-walk/`, `browser-run/`.

픽셀 변화량은 알파를 곱한 색과 윤곽의 차이를 하체에 두 배 가중한 지표이며, 실제 이동 거리나 보폭이 줄었다는 뜻은 아니다.

검수용 브라우저와 제작용 보간 과정은 모두 종료했다.
