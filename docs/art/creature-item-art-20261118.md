# 새 발견물·괴물 전리품 원화 54종 (2026-11-18)

사용자 요청: 새 발견물의 아이템을 만들고, 동물 머리 박제는 첨부 참고 이미지의 벽걸이 구도를 바탕으로 번들거림을 빼고 쓸쓸한 분위기로 표현한다.

## 제작

내장 ImageGen으로 품목마다 별도 원화를 생성했다. 참고 사슴 박제는 구도 참고이며 이미지를 편집해 워터마크를 없앤 결과물이 아니다. 기준 호랑이를 새로 그린 뒤 다른 박제의 회화풍·판·질감을 맞췄다. 원문 제작 지시문은 `artifacts/creature-item-art-20261118/prompts.json`, 개별 생성 경로와 지시문은 같은 폴더의 `generation-*.json`에 남겼다.

- 머리 박제 20종: 무광 털·피부·비늘, 낡은 호두나무 판, 다문 입과 낮은 시선. 피·노출된 절단면·공격적인 과장은 넣지 않았다.
- 머리 화석 6종: 검치호·매머드·티라노사우루스·트리케라톱스·스테고사우루스·브라키오사우루스의 광물화한 머리.

- 새끼·알 16종: 추가 생물 13종과 누락 보상인 시베리아흰두루미·울버린·아무르표범 세 종. 살아 있는 새끼는 머리 박제와 분명히 다른 전신 모습이다.
- 유물 10종: 부러진 지팡이·송곳니·은잔·세계수 잎과 괴물 사건의 심장석·로켓·보리 씨앗·장검·뿔·화살촉.

## 연결과 보존

게임 표시본은 `images/creature-items-20261118/<ID>.webp`의 256×256 RGBA 무손실 WebP다. 생성 원본 PNG는 `artifacts/creature-item-art-20261118/originals/`에 해상도와 투명도를 유지해 보존했다. 기존 기본 원화는 덮어쓰지 않았다.

`tools/creature_item_art_20261118/asset-overrides.json`의 논리 키 54개를 `tools/images.py`의 우선 파일 목록에 연결했다. 그림 목록을 다시 생성하거나 웹 빌드에서 재생성해도 이 연결을 유지한다. 기존 아이템·발견물 ID, 가격·능력·보상·저장 상태·게임 규칙은 바꾸지 않았다.

## 확인

54개 원본·표시본의 해시, RGBA·투명 영역·보이는 외곽 여백을 확인했다. file://로 실제 게임을 열어 54개 아이템 자료와 원래 그림 선택 경로가 각 전용 원화로 해독되는 것을 검사했다. 소지품 화면은 박제·화석·부채·새끼·유물 다섯 갈래로 촬영했다. 원화 갤러리 54개도 실제 Chromium에서 해독했으며 검사 중 pageerror·console.error는 0건이다. 브라우저는 finally에서 종료한다.

생성 원화의 시각 검수는 별도 갈래별 미리보기와 소지품 화면으로 수행한다. 이 작업에서는 밸런스·저장 규칙을 변경하거나 배포·커밋하지 않는다.
