# 여자 선원들의 동물 사랑과 앵무새 비행

기존 남자 선원 원화 19장은 유지하고, 여자 선원들만 동물을 귀여워하는 별도 원화 19장을 추가했다. 사건 발생 때 남자·여자 버전 중 하나를 균등하게 고른다. 표정·눈맞춤·볼을 가까이 대는 모습·안거나 쓰다듬는 손동작을 강조했다. 회복 조건과 대상 동물 19종은 기존 사건과 같다.

여자 그림은 `images/crew-pet-events/<발견 id>_women.webp`, 남자 그림은 기존 `<발견 id>.webp`다. 원본 경로와 실제 제작 프롬프트는 `crew-pet-women-flight-20261116.json`에 기록했다. 원본은 생성 폴더에 보존한다.

## 대화 뒤의 새

앵무새와 사랑앵무만 비행한다. `G.CrewPets.daily`가 첫 대화·회복 결과 대화·`showPic.stop()`의 액자 퇴장까지 기다리고 나서 `startFlight`를 호출한다. 오류나 장면 전환으로 사건이 중단되면 시작하지 않는다.

`images/effects/crew_pet_parrot.png`와 `crew_pet_budgie.png`는 내장 ImageGen으로 만든 투명 배경 4열×2행 날갯짓 8프레임 시트다. 실제 이미지 크기에서 셀 크기를 계산한다. 새는 실제 8초 동안 이륙·두 바퀴 회전·복귀하며, 기함의 현재 화면 위치를 따라가므로 항해 중 배에서 떨어지지 않는다. 배속과 정지 여부는 비행 시간에 영향을 주지 않는다. 다른 대화·사건 중에는 비행 시계와 표시를 함께 멈춘다. 항해 장면에서 나가면 효과를 없앤다.

연출은 `G.FX.crewPetFlight`에서 기간·회전 수·이륙/착륙 비중·고도·반경·크기·날갯짓 속도를 조절한다. 저장 상태와 항해 규칙에는 영향을 주지 않는 항해 런타임 효과다.

## 검증

- `node tests/crew_pet_women_flight_smoke.cjs`: 남녀 38개 그림 선택·여자 원화 19종 게임 화면 캡처, 두 대화와 액자 닫힘을 기다리는 순서, 새 2종의 8프레임, 이륙·회전·복귀 경로, 대화 중 정지, 배속과 무관한 실제 시간, 효과 자체의 날짜·식량·물·위치 불변, 비행 종료·장면 퇴장 시 정리, 브라우저 콘솔 오류 검사.
- `node tests/crew_pet_recovery_smoke.cjs`: 기존 확률·피로·규율·대형 동물 제외 회귀 검사.
