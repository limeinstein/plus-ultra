# 동물 발견물의 이동 흔적과 2~4색 지도 그림

2026-11-17 사용자 요청. 현재 동물 발견물 261종(기본 동물·추가 동물·새·어류·곤충·전설 생물)에 적용했다. 식물·유적은 제외한다.

- 그림: `images/animal-tracking/animals-1.png`부터 `animals-17.png`까지, 투명 4×4 원화 시트 17장. 종별 상징색 2~4개로 게임에서 색면을 다시 그린다. 발자국 원화는 `images/animal-tracking/footprints.png`.
- 원화 제작: 내장 `image_gen` 사용. 생성 프롬프트·종별 배치·원본 경로는 `artifacts/animal-tracking-20261117/generation.json`. 반 고양이를 잘못 그린 셀은 별도 생성 수정 후 같은 시트에 반영했고 수정 기록도 보존했다.
- 좌표 추출: 원본 PNG를 변경하지 않고 각 셀의 주 피사체 좌표를 구한다. 다른 칸의 작은 조각을 지도 그림에 섞지 않는다. `tools/animal_tracking_bounds_20261117.py`.
- 이동: 2족은 좌우 교대, 4족은 앞·뒷발 크기와 어긋난 위치, 도약형은 뒷발 두 개와 작은 앞발 두 개. 고양이·개·곰·갈라진 굽·말발굽·코끼리·코뿔소·네 발가락·새·타조·물갈퀴·원숭이·파충류 등을 구분한다. 뱀은 구불구불한 자국, 물고기는 물결, 작은 곤충은 여러 작은 흔적을 쓴다.
- 표시: 4.8도 안에서 흔적, 2.2도 안에서 동물 그림. 그림은 3.6초 주기로 불투명도 0.16~0.58 사이에서 천천히 점멸한다. 발자국도 같은 종의 색 계열에서 두 색을 쓴다. 한 화면에서 가장 가까운 8종을 표시하며 발견한 종은 바로 숨긴다.
- 발견: 기존 범위보다 넓히지 않으며, 최대 뭍 0.65도·바다 0.9도 안에 다가와야 발견한다. 흔적 끝에서 마주친 동물은 단서가 없다는 이유로 확률적으로 놓치지 않는다. 낚시 전용 어류도 그 자리에서 직접 발견할 수 있고 기존 낚시 발견도 유지한다. 이동하는 해상 괴물은 실제 출몰 좌표·조우 흐름을 유지하면서 처음 발견하기 전 지도 그림에 같은 표현을 쓴다.
- 연도·앞선 발견·필수 유물·하루 한 개 발견 제한은 기존 규칙을 따른다. 뭍 좌표가 물에 걸린 기존 동물은 같은 서식 반경 안의 가까운 뭍에 그림과 실제 발견 지점을 함께 옮긴다. 저장 필드는 추가하지 않았다.

조정값은 `G.FX.animalTracking`과 `G.BALANCE.animalTracking`. 자료 연결은 `js/data/animaltracking.js`, 그림 처리는 `js/art/animal_tracking.js`.
