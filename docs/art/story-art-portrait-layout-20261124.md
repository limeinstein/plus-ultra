## 모든 얼굴상의 구도

시녀 양식 270개를 포함한 얼굴상 4,128개를 대상으로 눈높이·얼굴 높이·가로 중심을 연금술사 원화의 실제 얼굴 좌표에 맞췄다. 원본 PNG·WebP를 다시 그리거나 덮지 않고 표시 영역을 `js/data/portraitlayout.js`에 기록했다. 같은 인물의 무릎상이 있으면 그 그림에서 얼굴~가슴을 잡아 옷이 아래까지 이어지게 한다. 기존 투명 원화 보정에 지정된 원본도 유지한다. 사람용 검출기가 읽지 못한 오랑우탄은 실제 눈·입 위치를 직접 기록했다.

표시 기준은 `tools/normalize_portrait_frames_20261124.py`에서 연금술사의 얼굴을 읽어 정한다. 생성된 자료는 `index.html`·`catalog.html`에서 `portraitfaces.js` 뒤에 읽으며, 공통 `G.Art.portraitCanvas`가 사용한다. 무릎상 원화·걷기·전투 시트는 별도의 기존 연결을 유지한다.

대화창 위에 서는 흉상도 공통 구도를 사용한다. 이전에는 수동 `frames`에 있는 127개만 이 경로를 거치고 나머지는 얼굴 원본을 직접 표시해, 같은 얼굴도 대화 화면에서 크기가 달라지거나 원본에 구워진 검은 배경이 나타날 수 있었다. `portrait`와 `chain` 호출 모두 `G.PORTRAIT_LAYOUT`을 먼저 확인하도록 고쳤다. 자료 생성 때도 원본의 알파 채널을 확인하고, 배경이 불투명하면 같은 인물의 투명 원본을 고른다. 제외된 합성 무릎상은 사용하지 않는다.

전체 픽셀 검사 뒤 아즈텍 여성 후원자 1번의 관모 장식을 얼굴로 오인한 좌표를 실제 얼굴로 다시 검출했다. 「열아홉 이사」는 여러 명을 함께 그린 이사회 원화이므로 뒤쪽 이사들의 머리도 남기는 별도 구도를 쓴다. 카베사 데 바카 원화는 최대 알파가 250인 정상 그림으로, 검사는 이 값을 불량 투명도로 오인하지 않도록 했다. 재검출·구도 수정은 원본 파일을 보존한다.

시작 화면에는 「얼굴 모두 보기」를 추가했다. 여성 15종·남성 14종을 번갈아 보여 주고, 성별 필터로 한 번에 고를 수 있다. 여성 얼굴을 직접 누르면 성별·얼굴·이름이 함께 바뀌며 국적·능력·직업 선택은 유지한다.

## 다시 만들기와 검증

1. 원화 등록: `python tools/install_story_art_20261124.py`
2. 그림 목록: `python tools/images.py`
3. 구도 자료: `python tools/normalize_portrait_frames_20261124.py`. 현재 얼굴 좌표·수동 투명 원본·사용 금지 합성본·해적섬 보정을 자동으로 읽는다. 이전 검출 결과를 재사용할 때는 `--reuse`.
4. 실제 화면: `node tests/story_art_portrait_layout_20261124_browser.cjs`.
5. 전체 얼굴상 픽셀 검사: `node tests/all_portrait_transparency_20261124_smoke.cjs`. 실제 선택되는 원본과 공통 그리기를 사용해 투명 여백과 인물이 각각 5% 이상인지 확인한다. 검사 전용 페이지에서 동일한 이미지 로더·그리기 코드를 읽는다.
6. 실제 대화창·흉상 검사: `node tests/dialog_portrait_transparency_20261124_smoke.cjs`. 여급·라이벌의 얼굴 칸, 수동 구도가 없는 얼굴의 흉상, `portrait`·`chain` 두 호출의 결과 일치를 확인한다.

그림 위치 자료·원화 42장의 실제 읽기·대사 연결·여성 선택·나이 경계·원화 회수·수첩을 검사한다. 전체 이야기 진행 검사도 황금의 바다 33항목, 해적여제 30항목을 통과했다. 원화를 기다리는 시간이 생겨 황금의 바다 진행 검사는 실시간 항해 프레임을 멈추고 정해 둔 날짜·좌표로 진행하도록 보완했다.

확인 화면과 결과는 `artifacts/story-art-20261124/`에 있다. 로컬 `index.html`에 적용하며 공개 웹 배포는 수행하지 않았다.
