## 그림과 동작

- 새 투명 WebP 시트 **21장, 102개 외형, 816개 장면**. 칸은 256×256이며, 8개 장면은 대기·보행 두 자세·공격 준비·접촉/발사·반동/후속 동작·복귀/재장전·피격이다. 각 줄 안에서는 같은 배율·발밑 기준선을 유지한다.
- 보병·총병·포병·제독대와 말·낙타·코끼리 기병의 LV0~LV3를 유지한다. 적 정규 부대도 해당 단계의 새 원화를 쓰며 기존 진영 이름표·인원 막대·선택 색으로 구분한다.
- 기마와 짐승은 공격 전에 실제로 전진하며 별도의 보행/질주 장면을 반복한다. 접촉 후에는 공격·복귀 장면으로 이어지고 발밑 흙먼지가 따라온다. 지역 특수 기병에도 탐험대 그림 대신 전투 그림을 쓴다.
- 총병은 어깨 조준→발사→반동→재장전, 포병은 점화→발사→포가 반동→장전 순서다. 같은 부대 안에서도 작은 간격을 두고 쏜다. 탄은 해당 병사·포의 포구에서 출발하고 마지막 탄이 도착한 뒤 피해를 계산한다.
- 활·쇠뇌·돌팔매·투창·부메랑·독침은 원화의 무장과 화면의 발사체를 맞춘다. 안데스 투석병은 활을 없애고 가죽 끈 돌팔매 동작으로 별도 수정했다.
- 화염·연기는 해전과 같은 여러 크기의 난류 질감과 갈라지는 화염 덩어리를 사용한다. 지면 섬광, 낮은 먼지, 상승하는 화약 연기, 불티·흙 파편을 함께 그린다. 질감은 처음에만 만들고 재사용하며 오래된 연기부터 줄인다.
- 전장 그림은 2000×880으로 그려 기존 1000×440 좌표로 보여 준다. 병력·위력·상성·사거리·저장 형식은 유지한다.

## 지역 외형

19개 지역마다 근접·원거리 원화를 따로 두었다. 우두머리는 해당 지역 외형을 쓰며 콩고·안데스는 별도 지휘 외형도 갖췄다.

| 지역 | 주된 구별 |
|---|---|
| 서아프리카·사헬·콩고 | 인디고 직물·누빈 조끼·라피아 직물, 가죽/섬유 방패, 창·도끼·활 |
| 에티오피아·스와힐리 | 흰색·붉은 테두리 직물과 해안의 청록색 직물, 창·굽은 칼·활 |
| 멕시카·마야·카리브 | 흑요석 무기와 채색 방패, 붉은 직물·옥 장식, 밝은 허리옷·패각 |
| 안데스·아마존 | 기하학적 짧은 직물·청동 무기·돌팔매, 섬유 허리옷·붉은 칠·활 |
| 삼림·대평원·푸에블로·북서 해안 | 열린 사슴가죽 옷·구슬, 짧은 가죽옷, 면직물·청록 장식, 삼나무 판갑·수피 |
| 아오테아로아·폴리네시아 | 아마 섬유 치마·녹색 돌 장식·타이아하/투창, 타파 직물·목제 무기 |
| 오스트레일리아·파푸아·미크로네시아 | 흰색 칠·부메랑, 붉은 칠·긴 목제 방패·활, 판다누스 직물·돌팔매 |

동아시아·오스만·서유럽·페르시아/인도·동남아시아의 기존 행도 새 원화로 교체했다. 송가이 말 기병, 라지푸트와 아유타야 코끼리, 키질바시 기마궁수는 별도 지역 탈것 시트다. 이는 작은 게임 화면용 미술 구분이며 모든 시대·집단의 복식을 동일하게 나타내는 자료는 아니다.

## 제작·연결·검증

- **원화 생성:** 내장 ImageGen. [생성 및 수정 지시문과 원본 위치](../../artifacts/landwar-hd-20261105/sources.json), 원화 사본 `artifacts/landwar-hd-20261105/sources/`.
- **포장:** `python tools/landwar_hd/build.py`. 기존 `sprite_repack.py`의 연결된 덩어리 분리를 재사용해 칸을 넘는 창·칼끝·꼬리를 몸통 쪽으로 회수한다. 투명하지 않은 원화는 거부한다. [칸·피벗 검사 자료](../../artifacts/landwar-hd-20261105/packing.json).
- **게임용 그림:** `images/sprites/lw_*.webp`. 메타 자료는 `js/data/landwarmotion.js`. 옛 그림·시트 ID는 보존하며 저장 파일을 바꾸지 않는다.
- **연출 조정:** `G.FX.landwar` (`js/data/seafx.js`). 동작·발사·접촉·탄 비행·해상도·효과 개수의 조정값을 한곳에 둔다. 화염 덩어리 수는 해전 `G.FX.cannonImpact.flameLobes`와 같다.
- **시험:** `node tests/landwar_motion_hd_smoke.cjs` — file://에서 21개 시트 로드, 19개 지역, LV0~3, 포구 일치, 발사 전 준비, 비행 뒤 피해/폭발, 기병·짐승 돌격, 지역별 투사체, 콘솔 오류 검사. [검사 결과](../../artifacts/landwar-hd-20261105/browser-report.json).
- **호환 확인:** 기존 `tests/landwar_sprite_v2_smoke.js` 통과, `tests/landwar_tactics_smoke.js` 27개 항목 통과. 새 검사와 두 기존 검사 모두 콘솔 오류 0. 기존 Playwright 검사에는 저장소에 설치된 `playwright-core`와 Chrome의 ANGLE/SwiftShader 설정을 연결해 사용했다.

이번 범위에는 탐험대 8방향 이동 시트·전투 규칙·소리 파일 교체는 포함하지 않는다. 실제 시험으로 연 브라우저는 모두 종료한다.
