# 육상전 개울·언덕·숲의 재질과 움직임

2026-11-06. 단순한 물결선·반원·삼각형으로 표시하던 전술 지형을 폭발 연출과 같은 고정 난류 질감과 여러 겹의 명암으로 보강했다.

![9개 지역의 실제 전투 화면](../../artifacts/landwar-terrain-20261106/preview.jpg)

- 개울: 원근에 따라 넓어지는 물길, 깊은 수로와 얕은 자갈 바닥, 불규칙한 젖은 둑, 돌의 그림자, 흘러내리는 반사광·잔물결과 흔들리는 갈대. 먼 지면에서 화면 앞쪽 끝까지 하나의 물길로 이어지며 아래쪽은 흐려지지 않고 화면 밖으로 나간다.
- 언덕: 비대칭 능선, 풀·흙의 미세한 재질, 비탈의 골과 명암, 돌·짧은 풀, 바닥으로 번지는 그림자.
- 숲: 개별 나무 그림을 가로 14구간으로 나누고 뿌리의 변위는 0으로 유지한다. 줄기·가지·수관 전체가 높이에 따라 휘며, 이웃 나무는 같은 돌풍을 받되 수종과 크기에 따라 다르게 흔들린다.
- 수면 전체의 명암 질감을 물길을 따라 흘린다. 작은 반사광·길게 늘어지는 물살·돌 주변 잔물결을 겹치고 지역에 따라 유속·폭·굽이·둑과 갈대 밀도를 바꾼다.

## 지역별 별도 그림

이전의 네 가지 공통 색상표를 9개 지역의 개별 자료로 바꿨다. 배경 그림의 흙·돌·식생·눈 색을 기준으로 맞추고, 나무의 종류·밀도·크기와 언덕 형태도 구별한다. 지역별 지면 시작선도 178~210으로 따로 두어 물길과 나무 밑동이 먼 산·안개 위에 뜨지 않게 한다. 실제 전투에 등장하는 지형 종류·효과는 기존 규칙을 따른다.

| 지역 | 식생 | 언덕·물길 |
|---|---|---|
| 초원 | 올리브빛 참나무·갈대 | 마른 풀과 흙이 섞인 완만한 언덕, 회녹색 개울 |
| 초원지대 | 드문 마른 관목 | 낮은 황갈색 비탈, 좁고 느린 물길 |
| 사막 | 드문 우산 모양 아카시아 | 모래 잔결이 있는 사구, 모래색 둑 |
| 숲 | 활엽수·전나무 혼합림 | 낙엽색 흙·이끼, 그늘진 물길 |
| 밀림 | 야자수·넓은 수관·덩굴 | 짙은 이끼와 젖은 흙, 넓고 굽이진 물길 |
| 산지 | 키 큰 전나무 | 거친 능선·자갈 비탈, 좁고 빠른 청회색 물살 |
| 눈밭 | 눈이 얹힌 가문비나무 | 하얀 눈더미·눈 둑, 차가운 청색 물 |
| 툰드라 | 낮은 왜성 관목 | 지의류·돌·일부 눈, 얕고 굽이진 물길 |
| 얼음땅 | 성긴 얼어붙은 가지 | 푸른 얼음 능선·밝은 균열·서리 |

## 앞쪽 끝까지 이어지는 물길

사용자 보완 요청으로 칸별로 잘리던 물길을 없앴다. 개울이 있는 칸이 하나라도 있으면 지면 시작선부터 화면 아래 28px 밖까지 한 번만 그린다. 어느 칸에 배치되든 같은 전장의 물길은 이어지고, 여러 칸에 있어도 중복해서 덧그리지 않는다. 아래쪽 둑·수면·움직이는 물살에는 사라지는 흐림을 적용하지 않는다.

9개 지역에 각각 별도의 경로 기준점을 둔다. 들판의 완만한 굽이, 밀림·툰드라의 큰 굽이, 산지의 곧은 흐름, 설원의 완만한 사선, 얼음땅의 각진 틈을 구별한다. 색이나 폭만 바뀌는 같은 곡선을 반복하지 않는다. [물길 형태 비교](../../artifacts/landwar-terrain-20261106/watercourses.jpg)는 개울을 강제로 넣은 검수용이며 실제 생성 여부를 뜻하지 않는다.

개울이 없는 전장에는 물길을 그리지 않는다. 기존 전장 자료 기준으로 들판·밀림·툰드라에 개울이 있고, 초원지대·사막·숲·산지·눈밭·얼음땅에는 없다. 전투 효과와 발생 규칙은 유지한다.

## 코드와 조정값

- `js/art/landwarterrain.js`: `G.LandWarTerrain.create(terr, width, height)`. 정적 지면과 개별 나무 원화를 전투별 2배 해상도 캔버스에 저장한다. 매 장면에는 수면 이동·갈대·나무 휘어짐만 계산한다. 잎·물결 질감은 색과 변형별로 재사용한다.
- `js/data/seafx.js`: `G.FX.landwar.terrain`. 지면 시작선 118, 해상도 2, 수면 질감 기본 이동 32px/초·물살 52개, 나무 기본 흔들림 4.2px·14구간, `regions`의 9개 색상표·수종·지형 형태·움직임 배율.
- `js/games/landwar.js`: 기존 지형·언덕 소유 진영을 그대로 전달한다. 전투 판정·병력·저장 형식 변경은 없다.
- `index.html`에서 새 그림 파일을 읽으므로 `file://` 실행과 `tools/pages.py`의 포장 경로를 함께 지원한다.

## 검증

- `node tests/landwar_terrain_smoke.cjs`: 세 줄의 개울 경계와 시간별 물살, 9개 지역의 실제 전투 화면, 지역마다 나무 윤곽·수면 전체의 움직임과 같은 시간의 픽셀 재현성을 검사한다. 지역별 그림과 숲·밀림의 연속 프레임도 저장한다. 측정값과 콘솔 오류는 [결과](../../artifacts/landwar-terrain-20261106/report.json)에 남긴다.
- 연속 물길 검사: 9개 지역에서 지면 아래부터 마지막 화면 줄까지 불투명한 물길이 끊기지 않는지, 개울 칸의 위치·중복 개수와 무관하게 하나의 경로가 나오는지, 개울이 없으면 물길 픽셀이 0인지 확인한다. 경로 9종의 중심선도 서로 달라야 한다.
- 최종 검사 통과: 서로 다른 경로 9종, 중간이 끊긴 줄 0, 화면 마지막 줄의 물길 폭 27~57px. 개울을 뺀 9개 전장의 물길 픽셀 합 0, 실제 전투 9종의 개울 유무 유지, 콘솔 오류 0. SwiftShader의 투명 가장자리 반올림은 합성 색과 경계점의 작은 차이를 허용해 비교한다.
- `node tests/landwar_motion_hd_smoke.cjs` 통과: 21개 시트·19개 지역, 병종 단계, 총구·포구, 발사·비행·착탄 순서, 작렬탄, 지역별 원거리 무장, 기병·짐승 돌격. `pageerror`·`console.error` 0.
- 모든 검사 브라우저는 `finally`에서 종료한다. 생성 이미지·외부 런타임 의존성은 추가하지 않았다.
