# 바닷길 노래 초반 발견물·증거품·공연 원화

사용자가 확인한 누락은 용문석굴(`sy_longmen`)과 도다이지 대불(`sy_todaiji`)이었다. 두 발견물은 `js/systems/song.js`에서 뒤늦게 등록되어, 자료 파일만 읽던 전체 그림 검사에서 빠지고 있었다. `js/data/song.js`에서 먼저 등록하도록 옮기고 도감에도 같은 자료를 읽혔다. 이야기 전용 `song`·`needHint` 조건과 보통 항해의 접근 제한을 유지한다.

## 제작한 파일

- 발견 연출 2종: 용문석굴·도다이지 대불. 각각 독립된 16장면 원화를 576×256 GIF(16장·9.82초), 마지막 장면 JPEG, 기존 재생기용 24칸 WebP(3456×1024)로 변환했다. 모형 제작→실제 현장→내부 관찰→낮·밤·새벽의 순서이며 정지화상을 확대하는 연출이 아니다.
- 아이템 3종: 용문석굴 탁본첩, 도다이지 대불 중수 기록, 도현의 지도. 256×256 투명 WebP이다. 두 기록물은 해당 발견 시 받는 종이 증거품이며 후원자 보고·항구 발표에 사용한다. 성물이나 건축 부재를 떼어 가는 보상으로 만들지 않았다. 도현의 지도는 기존 소중한 물건의 수량을 유지하면서 전용 그림 선택용 자료만 등록했다.
- 지도 외관 2종: 용문석굴의 조각 절벽·도다이지의 넓은 목조 대불전. 512×512 투명 WebP, 발견 뒤 해도·항해·육상 지도에서 표시한다.
- 초반 3인 공연 12장: 조선(`kr`)과 지역 `0`~`10`. 소영·황규·박월담의 기존 초상을 참조해 제작했다. 임처사가 합류하기 전에는 이 원화를, 합류한 뒤에는 기존 4인 공연 원화를 고른다. 인원이 모자라거나 원화가 없는 사용자 그림 묶음에서는 기존 인원별 무대를 쓴다.
- 별도 누락 사건샷 4장: 팜므파탈·측천무후·남편들과 함께하는 항해·벨렌 강 사건. 기존 사건의 그림 열쇠에 추가했다.

합계 원화 23종, 게임 파일 27개. 이전 그림 파일은 덮어쓰지 않았다. 그림은 모두 내장 `image_gen`으로 제작했으며 생성 알파를 유지해 규격 변환했다.

## 저장 호환

새로 더한 두 종이 기록에는 `proofOptional`을 붙였다. 기존 저장에서 이미 두 장소를 발견했지만 새 기록물을 받지 못했어도 보고·발표에 증거품 부족 벌점이 생기지 않는다. 새로 발견할 때는 기존 `Disc.find`의 증거품 경로로 정확히 한 개씩 받고, 재발견으로 중복 지급하지 않는다. 다른 발견물의 증거 요구와 보상 수치는 유지한다.
