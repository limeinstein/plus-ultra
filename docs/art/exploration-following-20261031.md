# 제독을 따라가는 탐험대 (2026-10-31)

기존 다이아 편대는 대원들의 위치를 매번 목표 자리에 바로 배치했다. 방향을 바꾸면 대열이 한 덩어리처럼 회전하고, 동료의 걸음도 제독의 보행 주기에 묶여 있었다. 이번 변경은 대형보다 제독을 따라가는 움직임을 우선한다. 기존 동료 시트 12장은 그대로 사용한다.

## 달라진 움직임

- 동료마다 지도 위 위치·속도·바라보는 방향·보행 주기를 따로 유지한다. 갑자기 다른 자리로 옮겨 붙이지 않고 가속·감속하며 가려는 방향으로 돌아선 뒤 걷는다.
- 제독이 실제로 지나온 길을 기록하고 각자 조금씩 늦게 따라간다. 넓고 곧은 곳에서는 느슨한 다이아 모양으로 서서히 벌어지며, 모퉁이·물가에서는 줄이 좁아진다. 대열을 맞추려고 뒤로 돌아가는 대신 잠시 기다려 간격이 생기면 출발한다.
- 제독이 멈춰도 뒤처진 동료는 목표 지점까지 따라온 뒤 각자 멈춘다. 정지 중 제독만 방향을 바꿔도 나머지 사람을 돌려 세우거나 대형을 다시 맞추지 않는다.
- 동료 자신의 실제 이동 거리만큼 보행 자세를 넘긴다. 서 있는 동료는 제자리걸음을 하지 않는다. 카메라 이동·지도 확대도 동료의 이동으로 계산하지 않는다.
- 좁은 곳에서는 걸어갈 구간의 발밑을 확인하고, 안전하게 닿는 앞쪽 발자국을 따라간다. 물가의 다른 자리로 순간 이동하는 보정은 출발·도시 재입장 등 최초 배치에만 사용한다.
- 도보·짐꾼·말·낙타·당나귀·라마·야크·마차·코끼리·순록 썰매와 기존 지역별 외형, 인원·탈것 부족 처리를 유지한다. 야영에는 기존 야영 장면을 쓴다.

실제 이동 속도·시간·보급·저장 파일 형식은 바꾸지 않았다. 표시용 경로와 동료 상태는 `st.unit.formation` 캐시에만 둔다. 날짜 변경선의 경도를 이어 처리하며, 도시 재입장처럼 한 번에 멀리 이동한 경우에만 새 위치 근처에 다시 배치한다.

## 연결과 조정

- `js/art/expedition_formation.js`: 경로 추종·개별 가속/감속·돌아서 걷기·각자의 보행.
- `js/scenes/land.js`: 화면 좌표와 별도로 제독의 지도 좌표·지도 배율·경도 순환 길이를 전달한다.
- `js/data/seafx.js`의 `G.FX.sprites.expedition.formation.follow`: 줄 간격, 곡선에서의 폭, 대열을 좁히고 벌리는 속도, 추종 속도·가속도·회전 속도·안전한 발자국 검사 간격·이동 수단별 보폭.

`test_expedition_following.html`을 파일로 열면 실제 그리기 코드로 움직임을 비교할 수 있다. 10가지 이동 수단, 넓은 땅/좁은 굽은 길, 제독 정지/재출발, 정지 중 회전, 카메라만 이동을 조작한다. 기존 `test_expedition_formation.html`은 방향별 원화·자세 비교표로 유지하고 새 움직임 비교 화면으로 연결했다.

## 검사

`node tests/expedition_following_test.js`:

- 10가지 이동 수단의 연속 추종, 90도 회전, 뒤처진 동료의 도착과 정지.
- 정지 중 제독의 회전, 카메라 이동/확대 때 동료의 위치와 보행 주기 보존.
- 좁은 ㄱ자 길, 넓은 곳에서 좁은 곳으로 들어갈 때 뒤돌아가지 않기, 급반전.
- 30/60프레임의 추종 위치 비교, 도시 재입장과 날짜 변경선.

`node tests/expedition_following_browser.js`:

- 실제 시트를 사용하는 10종의 모퉁이 추종과 프레임 사이 위치 연속성.
- 동료가 따라온 뒤 정지하고 발을 굴리지 않는 것, 제자리 회전, 좁은 길의 실제 표시.
- 실제 게임에서 지도 이동·방향 전환·정지와 기존 저장 필드 보존. 콘솔 오류 0건.

기존 `tests/exploration_formation_smoke.js`와 `tests/expedition_motion_browser.js`에서 시트 384칸·방향/자세 320가지, 기존 동작 424장면과 실제 야영 시작/종료도 회귀 검사한다. 브라우저는 모두 `finally`에서 닫는다.

결과·화면·연속 그림은 `artifacts/exploration-following-20261031/`에 보관한다. `browser-results.json`, `unit.log`, `browser.log`, `formation-regression.log`, `motion-regression.log`, `horse-corner.png`, `narrow-path.png`, `stop-turn.png`, `in-game.png`를 확인할 수 있다.

최종 결과: 경로 추종 단위 검사, 10종 실제 시트 재생, 실제 지도 이동, 기존 시트 384칸/자세 320가지와 기존 동작 424장면·야영 검사 모두 통과했다. 브라우저 검사에서 콘솔 오류는 0건이다. 기존 야영 검사 도구의 요청 가로채기는 파일 실행의 스크립트 읽기를 지연시켜 제거했고, 외부 자료의 전체 로딩 대신 게임 초기화 완료를 기다리도록 고쳤다. 검사 브라우저는 모두 닫았다.
