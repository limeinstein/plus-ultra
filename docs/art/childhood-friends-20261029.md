# 후계자의 성인 소꿉친구 32종

후계자와 같은 항구 골목에서 자란 친구가 성인이 되어 첫 항해에 합류한다. 마을 주민·열혈 항해사 지망생·기사·귀족 영애를 각각 8종으로 만들었다. 지중해·북유럽·동아시아·남아시아·동남아시아·서아시아와 북아프리카·아프리카·아메리카의 외형을 담았다. 실존 인물의 이름이나 신분을 옮긴 인물이 아닌 창작 캐릭터다.

## 그림과 수정

- `images/portraits/childhood-friends/cf_<출신권>_<계층>.webp`: 1024×1024 얼굴상.
- 같은 이름의 `_half.webp`: 1024×1536 투명 무릎상. 얼굴상은 이 원화에서 잘라 동일한 인상을 유지한다.
- 체형과 열린 목선은 명백한 성인 인물에 적용했다. 어린아이로 보이는 참고 사진은 이미지 생성 입력에 넣지 않았으며, 일반적인 머리 모양과 몸짓만 글로 참고했다.
- 손으로 채색한 2D 게임 일러스트로 제작했다. 시대풍 직물·가죽·금속과 출신권별 문양을 썼다.
- 사용자의 표정·얼굴 구도 반복 지적에 따라 32종을 다시 수정했다. 정면·좌우 측면·고개를 들거나 숙인 각도, 큰 웃음·윙크·의심·당황·결의·생각에 잠긴 표정을 개별 지정했다. 얼굴 윤곽·코·눈썹·입매와 짧은 머리·양 갈래 매듭 등도 구분했다.
- 빨간 표시가 있는 얼굴상 8명만 개별 수정했다. 동아시아 영애·남아시아 마을 주민·동남아시아 항해사 지망생과 영애·서아시아와 북아프리카 마을 주민과 기사·아프리카 항해사 지망생·아메리카 항해사 지망생이다. 머리 전체와 장식이 들어오도록 확대를 줄이고 좌우 여백을 따로 맞췄다. 나머지 24명은 일괄 중앙 정렬 전 원래 얼굴상 파일로 복원했다. 표정·얼굴 방향·무릎상은 유지한다. 재출력도 `tools/childhood_friends_20261029_face_layout.json`에 적힌 여덟 좌표만 적용한다. 원래 얼굴상과 검사 기록은 `artifacts/childhood-friends-20261029/face-layout/`에 남긴다.

내장 `image_gen`으로 개별 원화를 생성하고 같은 도구로 표정과 구도를 수정했다. 외부 API나 CLI 생성은 쓰지 않았다.

초기 지시문은 `tools/childhood_friends_20261029_prompts.json`, 최종 수정 지시문은 `tools/childhood_friends_20261029_revision_prompts.json`에 있다. 원화·초기안·최종 결과 경로·검수 모음은 `artifacts/childhood-friends-20261029/`에 보관한다. `draft-generated.json`은 초기안, `revision-generated.json`과 `generated.json`은 채택한 수정안의 생성 기록이다.

## 등장과 저장

`G.OLD_GUARD_FRIEND_LOOKS`가 초상 쌍과 출신 양식을 연결한다. 여성 소꿉친구의 65%는 같은 출신권의 네 계층에서 고르고, 나머지 35%는 현재 알려진 국적 전체에서 고른다(`BALANCE.oldGuard.friendLocalChance`). 다른 출신권의 인물도 이주민 집안의 아이로 같은 항구에서 자란 친구이며, 이름·말·국적은 선택한 초상의 출신권과 맞춘다. 아직 생기지 않았거나 알려지지 않은 국적은 이주민 후보에 넣지 않는다. 이름은 기존 철새 이름 생성 규칙을 쓴다. 마을 주민은 요리·치료·교역, 항해사 지망생은 항해·측량, 기사는 검술, 영애는 교역·학문 계열 솜씨를 받는다.

영애는 지배권 없는 작은 향사 집안이며, 기사는 영지와 지휘권이 없는 독립 기사다. 후원자급 권력자가 부하로 들어가는 설정이 아니다. 어린 시절 나무 칼과 부관 약속을 회상하는 기본 대사에 계층별 합류 대사를 덧붙인다. 초상·계층·출신권은 `state.oldGuard.defs`에 함께 저장한다. 옛 저장의 친족 초상을 새 그림으로 강제로 바꾸지 않는다.

등장 확률·여성 비율·남길 수 있는 동료 수·충성도는 기존 승계 규칙을 그대로 쓴다. 남성 소꿉친구·사촌·외삼촌은 기존 방식으로 생성한다. 서로 다른 저장에 같은 동적 친족 ID가 있어도 지난 게임의 얼굴 캐시를 쓰지 않도록 했다. 합류 장면 외의 일반 대화에서도 같은 무릎상을 찾는다.

## 다시 내보내기와 검사

```powershell
python tools/childhood_friends_20261029.py
python tools/portrait_faces.py --prefix portraits/childhood-friends --merge
python tools/images.py
node tests/childhood_friends_smoke.js
node tests/old_guard_smoke.js
```

검사는 32종의 실제 생성·계층별 솜씨·저장 복원·같은 ID의 다른 저장·옛 저장 호환·합류 대사·64개 이미지의 읽기와 해상도·투명 여백·얼굴 기준점을 확인한다. 표시된 8명의 확대가 줄었는지, 나머지 24명이 원래 파일과 바이트 단위로 같은지, 무릎상이 유지되는지도 확인한다. 피부 검출 상자가 정중앙인지 강제하는 이전 검사는 없앴다. 표시된 8명과 원래 얼굴상 2명의 얼굴상·무릎상을 실제 대화창에서 확인한다. 브라우저는 검사 성공 여부와 관계없이 닫는다. 결과는 같은 아티팩트 폴더의 `browser-results.json`과 `old-guard-results.log`에 남긴다.

검사 결과: 새 소꿉친구 검사와 기존 노장 승계 검사 모두 통과했다. 얼굴 기준점 64개를 찾았고, 표시 16사례와 콘솔 오류 0을 확인했다. 수정 전후 원화와 최종 초상을 눈으로 비교했다. 검사용 게임·브라우저 과정은 종료했다.

검수 모음: `all-faces-preview.jpg`(전체 32명 얼굴), `expression-preview.jpg`(표정·구도 대표 8명), `portrait-preview.jpg`(전체 무릎상), `final-portraits-0.jpg`부터 `final-portraits-3.jpg`(8명씩 나눈 무릎상).

앞선 32명 일괄 중앙 정렬(`center-v1`)은 사용자가 원래 구도가 더 낫다고 하여 취소했다. 현재 채택한 것은 `selected-v2`이며, 위 좌표 파일과 `face-layout/report.json`에 적용 범위를 기록한다. 이전 `comparison-preview.jpg`·`centered-faces-preview.jpg`는 채택하지 않은 이전 검수 기록이다.

선택 수정 검사 결과: 표시된 8명만 원래 얼굴상과 달라졌고 확대가 줄었다. 표시 없는 24명은 보관된 원래 얼굴상과 바이트 단위로 같으며, 무릎상은 유지됐다. 초상 64장과 실제 대화 표시 20사례를 확인했고 콘솔 오류는 0이다. 최종 8명 모음은 `face-layout/selected-v2/marked-final-preview.jpg`, 전체 모음은 같은 폴더의 `all-faces-preview.jpg`다. `comparison-0.jpg`·`comparison-1.jpg`는 원래 구도와 최종 구도를 4명씩 비교한다.
