# 아프리카 동물 장신구 10종·북방 모피 코트 5종 (2026-11-16)

표범·치타·사자에서 착안한 새 장신구 10종과 담비·호피 등 북방 코트 5종을 시장에 추가했다. 장신구는 역사 속 특정 실물 유물을 복제했다고 주장하는 이름이 아니라, 동물 문양에서 착안한 창작 세공품이다.

![새 아이템 15종](../../artifacts/africa-fur-items-20261116/preview.jpg)

## 시장 품목

아프리카 시장(지역 3)에서 파는 장신구:

- 표범 문양 금반지 — 12,000닢·호감 30.
- 표범 꼬리 금팔찌 — 18,000닢·호감 35.
- 표범 도약 브로치 — 9,500닢·호감 27.
- 치타 눈물무늬 귀걸이 — 11,000닢·호감 29.
- 달리는 치타 펜던트 — 14,500닢·호감 32.
- 치타 발자국 은팔찌 — 8,500닢·호감 26.
- 사자 왕 금반지 — 16,000닢·호감 33.
- 사자 갈기 금목걸이 — 20,000닢·호감 37.
- 암사자 홍옥 펜던트 — 13,000닢·호감 31.
- 쌍사자 금목걸이 — 24,000닢·호감 40.

북위 55도 이상인 북유럽·시베리아권·북미 시장(지역 1·7·10)에서 파는 모피 방어구:

- 담비 코트 — 9,000닢·방어 4.
- 호피 코트 — 18,000닢·방어 7.
- 은여우 모피 코트 — 12,000닢·방어 5.
- 순록 모피 코트 — 5,500닢·방어 6.
- 북극곰 모피 코트 — 24,000닢·방어 8.

기준값은 시장 시세·기존 흥정 규칙에 따라 변한다. 코트는 `kind: armor`로 소지품에서 착용할 수 있다. 판매지는 각 아이템의 `reg`와 `marketMinLat`로 제한하며, 따뜻한 도시에서 북방 코트를 팔지 않는다. 기존 코트·아이템 ID는 바꾸지 않았다. 별도 품목 묶음 `africa_animals_20261116`·`northern_furs_20261116`을 사용하므로 기존 수집 업적의 50종·20종·70종 대상과 과거 달성 조건은 유지된다.

## 전용 그림

내장 `image_gen`으로 품목마다 각각 제작했다. 표범의 장미무늬 반점·치타의 검은 눈물줄·수사자의 갈기·암사자의 옆모습을 구별하며, 반지와 목걸이 자체의 비율도 실제 착용 가능한 형태로 잡았다. 코트는 사람·마네킹·동물 머리나 발이 없는 완성된 옷 한 벌이다.

- 게임 그림: `images/items/african_*.webp` 10장·`images/items/furcoat_*.webp` 5장.
- 규격: 256×256 투명 WebP, 가장자리 여백 12px 이상.
- [개별 프롬프트·원본·파일 경로·해시](../../tools/africa_fur_item_prompts_20261116.json).
- [생성 PNG 원본](../../artifacts/africa-fur-items-20261116/raw/) · [전체 파일 검사](../../artifacts/africa-fur-items-20261116/assets.json).
- [어두운 바탕 검수](../../artifacts/africa-fur-items-20261116/preview-dark.jpg).

`tools/package_africa_fur_items_20261116.py`는 생성 원본 보존·투명 여백 맞춤·축소·WebP 포장·검수표를 처리한다. 기존 아이템 그림 600개는 해시를 비교해 보존했다. `python tools/images.py`로 그림 목록을 갱신했다.
