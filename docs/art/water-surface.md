# 항해·해전 수면의 파도와 빛 (2026-11-01)

[실제 게임 전후 비교](water-surface.html) · [연안 선체 움직임 12초](../../artifacts/water-coast-ride-20261101/coast-bobbing.gif)

## 연안 완화와 선체 출렁임 (후속 조정)

연안까지 거칠어 보인다는 피드백에 따라 해안 가까이에서는 파면 경사·명암·반사광을 크게 줄였다. 해안 거리 2→24텍셀에 걸쳐 먼바다 표현으로 부드럽게 전환하며, 먼바다 자체의 반사와 잔물결 세기도 낮췄다. 해전도 같은 연안 완화를 쓴다. 물빛·해안 쇄파·항적은 유지한다.

선체는 잔물결의 떨림보다 긴 너울의 상하·좌우·앞뒤 움직임이 읽히도록 조정했다. 큰 기울기에서 갑자기 멈추지 않도록 목표 자세를 부드럽게 제한하고 감쇠를 늘렸다. 기함과 동행선에 더해 상선·해적·군함의 개별 선박도 자기 위치의 파도를 같은 방식으로 따른다. NPC의 자세 갱신은 그리기 루프에서 시간 갱신으로 옮겼으므로 그리기 횟수에 좌우되지 않는다. 항해 좌표·배 크기·속력은 그대로다.

- `tests/water_ride_browser.cjs`: 먼바다에서 기함·동행선·상선 2척·해적 2척·군함 2척을 실제 `update(1/30)`로 24초 진행. 8척의 3D 표시, 선체의 세 축 움직임, NPC 동행선의 서로 다른 위상, 자세 제한, 정지 중 실제 좌표 보존, `dt=0` 재그리기의 상태 보존을 확인했다. 연안은 별도로 12초/120장 기록. 오류 0.
- 연안 표본의 기함 좌우 흔들림은 전체 폭 약 7.2°, 앞뒤는 약 5.5°였다. 먼바다 표본은 각각 약 14.2°·7.3°였다. 특정 위치·바람·시간의 값이며 모든 바다의 고정 진폭은 아니다.
- `tools/water_coast_preview.py`: 배·뭍·UI가 없는 같은 연안 영역에서 이웃 픽셀의 밝기 차이가 직전 대비 약 90% 줄었다. 이는 시각 명암 비교이며 물리 파고 감소율이 아니다.
- `tests/water_surface_browser.cjs coast-review`: 기본·3배·근접·연안·강풍·따뜻한 빛·해전 7화면 오류 0. 수면 `draw+finish` 중앙값 3.2ms / 95백분위 3.5ms(전체 게임 FPS가 아님).
- `tests/wavecheck.js`, `tests/naval_view_controls.cjs` 재검증 통과. 선박 36종 표시, 확대 추적·메뉴·해전·포격 정지/재개·저장 복원도 유지했다.

초기 비교 영상은 수면 시각만 진행해 선체 감쇠를 갱신하지 못했다. 캡처 도구도 실제 시간 간격으로 장면을 진행하도록 고쳤으며, 현재 비교 페이지는 위의 새 12초 영상을 사용한다. 원본과 측정값: `artifacts/water-coast-ride-20261101/`, 정지 비교: `artifacts/water-surface-20261101/coast-review/`.

## 적용 내용

- 별도로 그리던 등고선을 없애고 너울의 높이·경사에서 밝은 파면과 어두운 골을 만든다.
- 서로 다른 방향·속도의 잔물결 두 겹을 조명 법선에 더한다. 화면에서 너무 작아지는 결은 부드럽게 줄인다.
- 하늘빛과 시선각에 따른 반사, 넓은 은빛 반사와 작은 반짝임을 항해·해전의 공통 함수로 처리한다. 반사는 파면의 기울기에 따라 끊어진다.
- 연안 청록색과 외해 남색, 해안 쇄파·빙산·구름 그림자는 유지한다. 먹구름과 폭풍은 반사광을 줄인다.
- 해전의 정적인 격랑 그림을 기본값에서 끄고, 적함과 사거리·장전 게이지를 위해 반사 밝기의 상한을 낮춘다.
- 수면과 3D 선박의 광원 방향·색을 함께 맞춘다. 금빛 연출값은 지원하지만 자동 낮밤 주기를 새로 넣지는 않았다.

확대 검증 중 기존 연안 파도에서 해안 거리별로 **절대 좌표에 곱하는 방향·파장**이 달라져 물결이 과도하게 압축되는 현상을 확인했다. `renderer.js`와 `waves.js` 양쪽에서 방향·파장을 고정하고 연안의 낮은 너울은 진폭으로 반영하도록 교정했다. 항해 속력·날짜·충돌·저장 형식·선박 크기는 바꾸지 않았다. 물길과 발자국의 1초 유지 후 소멸도 그대로다.

## 초기 적용 검증 기록

Chrome / NVIDIA RTX 3050 / 1600×900 / 해상도 설정 1 / `file://` 실행.

- `node tests/water_surface_browser.cjs before` / `after`: 기본 1배·선박 확대 3배·더 가까운 확대·연안·강풍/먹구름·따뜻한 조명·아군 2척/적 3척 해전의 실제 캡처. 페이지 오류·콘솔 오류 0. 5초/12fps 수면 움직임 60장 기록.
- `node tests/wavecheck.js`: 먼바다 3조건과 연안 거리 2·6·20, 배율 110·330·2400에서 GPU/JS 파도 높이 비교 통과. 기존 허용 오차는 최대 높이의 6%이며, 이번 최대 오차는 약 5.6%다.
- `node tests/naval_view_controls.cjs`: 최대 확대 항해 추적, 좁은 화면 메뉴, 교전 보기, 아군 포격 정지/재개, 백병전 접근, 저장 복원, 선박 36종 표시와 종료 해제 통과. 콘솔 오류 0.
- `node tests/battle_gunnery_guide.cjs`: 쉬움·보통 표시/어려움 숨김, 포별 실제 사거리·장전·포격 정지, 저장 복원과 발사 판정 12조건 통과. 콘솔 오류 0.
- `python tools/water_surface_preview.py`: 7개 화면의 유효 픽셀·명암, 첫/마지막 프레임의 수면 변화 확인. 비교 이미지와 공통 팔레트 GIF 생성.
- 비교 페이지의 장면 전환·키보드 가능한 슬라이더·원본/GIF 로드 확인. 구문 검사와 변경 파일 `git diff --check` 통과.

수면 렌더러의 `draw + finish`를 8회 준비 후 20회 측정한 값:

| 1600×900 해전 수면 패스 | 중앙값 | 95백분위 |
|---|---:|---:|
| 변경 전 | 3.7ms | 5.2ms |
| 적용 후 | 1.6ms | 2.2ms |

같은 장치의 단회 측정이며 전체 게임 FPS가 아니다. 무거운 등고선 잡음 계산을 줄인 결과이고 다른 GPU의 성능은 별도 확인이 필요하다. 원본 측정값은 `artifacts/water-surface-20261101/before/report.json`, `after/report.json`에 있다.

재실행 시 설치된 Playwright의 `NODE_PATH`, Chrome의 `BROWSER_EXE`, 그래픽 검사에 `SHIP3D_GPU=1`을 설정한다. 모든 검사는 `finally`에서 브라우저를 닫는다. `before` 비교는 아티팩트 폴더에 보관한 기존 렌더러/파도 파일을 검사 페이지에만 주입하고 작업 파일은 덮어쓰지 않는다.
