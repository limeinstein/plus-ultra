# 육상 탐험 보행·회전·야영 시트

현재 사용 시트는 내장 이미지 생성 도구로 만든 투명 PNG 22장, 원본 장면 424개다. 기존 v2 파일은 보존하고 보행 10종과 짐꾼·코끼리 회전을 v3로 교체했다.

## 이번 수정

- 보행은 왼발 내딛기 → 교차 → 오른발 내딛기 → 교차의 네 자세를 반복한다. 발을 벌린 자세와 좁힌 자세를 다시 생성했다.
- 도보 정면은 보정한 별도 원본 `on_foot_front`에서 왼발·오른발 접지 자세 두 장면을 교대로 사용한다(`frameOrder: [0,3]`). 같은 발이 반복되던 부분을 보완하며, 상체와 다리를 자르거나 뒤집지 않는다.
- 머리·상체에서 기준점을 구해 다리·꼬리의 외곽 변화로 몸 전체가 흔들리는 현상을 줄였다. 칸은 열마다 따로 나누고 이웃 장면의 작은 조각이 들어오지 않도록 자르는 범위를 보정했다.
- 전체 에셋의 높이를 맞추던 설정을 없앴다. 제독 기준 키는 52이며 원본마다 인물 비율을 보정한 `admiralReferenceHeight`를 사용한다. 앉은 자세는 같은 인물 크기로 환산한다. 화면 배율은 기존 탐험대 배율을 따른다.
- 코끼리는 원본의 탑승자 비율도 수정했다. 같은 크기의 제독이 타며 전체 높이는 도보보다 두 배 이상이다. 보행과 회전 모두 인물 기준으로 그린다.
- 짐꾼 모습에도 제독을 포함했다. 공통 야영에도 같은 인물 크기 기준을 적용한다.

## 방향과 원본 배치

게임에서는 북·북동·동·남동·남·남서·서·북서의 8방향을 사용한다. 기본 보행은 네 자세이며, 도보 정면은 발 교대가 뚜렷한 두 접지 자세를 사용한다. 5행 또는 7행 원본은 동쪽 그림을 뒤집어 서쪽 방향을 보완한다. 실제 행과 뒤집기 여부는 `directionRows`가 정한다.

| 구분 | 원본 배치 | 장면 수 |
|---|---|---|
| 도보·낙타·코끼리 보행 | 4열 × 8행 | 96 |
| 말·짐꾼 보행 | 4열 × 7행 | 56 |
| 당나귀·라마·야크·마차·순록 썰매 보행 | 4열 × 5행 | 100 |
| 10종 회전 | 4열 × 4행 | 160 |
| 도보 정면 보정 원본 | 4열 × 1행 | 4 |
| 공통 야영 | 4열 × 2행 | 8 |

회전은 북쪽부터 시계 방향으로 22.5° 간격을 의도한 16개 자세다. 가까운 쪽으로 회전하고 이후 보행 주기를 이어간다. 야영은 천막·모닥불·제독과 동료가 쉬는 고정 시점의 공통 8장면이며 탈것별 야영 그림은 아니다.

## 파일과 미리보기

- `test_expedition_sprites.html`: 10종 비교. 방향·속도·회전·야영을 바꾸거나 한 장면씩 넘긴다.
- `images/sprites/expedition_v3_*_walk.png`: 수정한 보행 10장.
- `images/sprites/expedition_v3_porter_turn.png`, `expedition_v3_elephant_turn.png`: 수정한 회전.
- 나머지 회전과 공통 야영은 매니페스트에 지정된 v2 파일을 사용한다.
- `docs/art/expedition-motion-manifest.json`: 원본 크기, 칸 좌표, 기준점, 방향 행, 인물 배율.
- `tools/expedition_generation.json`: 내장 도구의 최초·수정·비율 조정 프롬프트와 선택한 원본 경로.
- `docs/art/expedition-motion-sprites.zip`: 현재 사용하는 PNG 22장, 매니페스트, 프롬프트, 독립 실행 미리보기.

`cells`의 항목은 `[x, y, 너비, 높이, 기준점X, 기준점Y]`다. 생성 결과의 여백과 크기가 균등하지 않으므로 이 좌표를 따른다. PNG의 색·투명도는 변경하지 않는다. 픽셀 분석 도구는 좌표와 크기 기준만 기록한다.

## 게임 연결과 검증

`index.html`에서 자료와 그리기 코드를 읽고 `G.Party`에 연결한다. 이동 거리로 보행 주기를 구하고 정지할 때 마지막 자세를 유지한다. 실제 속력·날짜·소모량은 바꾸지 않는다. 야영 선택창이 열리면 야영 모습을 표시하고 닫으면 돌아온다. 그림을 읽지 못하면 기존 표시로 돌아간다.

연출 설정은 `js/data/seafx.js`의 `G.FX.sprites.expedition`에 모았다. `admiralHeight`가 모든 이동 수단의 제독 기준 크기다. 이동 수단별 전체 높이 제한은 사용하지 않는다.

```
python tools/expedition_motion_meta.py
node tests/expedition_motion_test.js
node tests/expedition_motion_browser.js
python tools/package_expedition_motion.py
```

파일 크기·투명도·빈 장면·좌표, 8방향의 네 자세 선택, 인물 크기 계산, 코끼리 전체 크기, 정지/재출발, 양방향 회전, 야영을 검사했다. Chromium 파일 실행에서 22개 시트와 424개 원본 장면, 실제 게임의 코끼리 표시와 야영 시작/종료를 확인했다. 콘솔 오류는 0개였다. 브라우저 검사는 Playwright가 설치된 경로를 `NODE_PATH`로 지정한다.

생성 그림의 대각선 각도·개별 관절·발 접지는 수학적으로 고정된 관절 애니메이션과 차이가 있다. 자동 검사는 재생과 배율을 검증하며 모든 해부학적 보행 자세의 정확성을 보증하지 않는다. 미리보기의 느린 속도와 한 장면씩 보기로 자세를 비교할 수 있다. `edgeContacts`는 원본 칸 경계에 닿는 픽셀을 기록한다.
