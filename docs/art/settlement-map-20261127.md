# 도시·정착지 지도 외관과 해안 배치 (2026-11-27)

도시 대표 건물·이름표를 확대하고 대비를 보강했다. 지도·항해·육상은 같은 시가지·부두·발치·선택 영역을 사용한다. 해안이 좁으면 시가지 전체를 함께 줄이고, 작은 부품 대신 대표 건물이 남도록 배치한다. 도시 데이터의 경위도·선착장 좌표와 통행·속력·개척 비용·보상은 바꾸지 않는다.

해적 소굴은 기존 발견·두목 격파·점령 상태를 읽어 소·중·대 외관을 고른다. 동굴·중간 단계 망루·최종 본부를 구분한다. 개척 도시는 기존 단계 0~4에 맞춰 보급 마차·감찰관·총독청을 표시한다. 쌍서는 `mapHideBuildings` 표시 설정으로 동굴과 작은 부두만 남기며 항구 기능은 유지한다.

원화 다섯 장과 발치는 `images/map-settlements/`·`js/data/city_props.js`, 제작기는 `tools/city_icons/settlement_props.py`·`pack_settlement_props.py`에 있다. 화면 조정값은 `G.FX.cityModels`·`mapRuins`·`natureLandmark`에 모았다. `tests/settlement_props_world.cjs`는 모든 해적섬·개척지, 성장 단계, 확대 단계별 발치·선착장·동굴/부두 선택과 실제 항해·육상·해도 표시를 검사한다. 기존 도시·건축 유적·자연경관 시험도 함께 실행한다.
