# 아직 완성 중인 중세 해도

2026-10-29 사용자 요청. 첨부한 문명 6 화면처럼 미지의 부분을 낡은 양피지와 옛 항해자의 상상으로 채운다. 실제 지형은 거듭 지나오며 조금씩 자세해진다.

## 보이는 모습

미탐사 부분에는 종이의 얼룩·섬유·방위선과 투명 삽화를 배치한다. 2026-10-30에 기존 네 종류(크라켄·용·세계 끝의 낭떠러지·방위표)에 엘도라도·일곱 황금도시·청춘의 샘·자석산·대소용돌이·고래섬·로크새·프레스터 존의 왕국·보물섬·유령선을 더해 총 14종으로 늘렸다. 삽화는 실제 발견물이나 지형을 예고하는 표식이 아니다. 미탐사 픽셀에서는 실제 지형 자료를 읽지 않으며, 삽화도 알려진 지도 위에 남지 않게 미지 영역으로 잘라 낸다. 탐사 경계는 종이로 번지는 먹선처럼 흐트러뜨린다.

종이 가장자리에는 해진 섬유와 두 군데의 작은 찢김을, 표면에는 접힌 자국과 옅은 펜 먹물 방울·흐른 자국을 그린다. 이 마감은 지형 위·지명과 항로 아래에 적용한다. 세기와 길이는 `G.FX.chart.wear`로 조정한다.

해도를 처음 펼치면 현재 알려진 격자의 테두리와 여백에 맞춰 유럽을 크게 보여 준다. 새로운 대륙을 탐사하면 다음에 펼칠 때 그 범위까지 넓어진다. 「전체」는 알려진 해도에 맞추며, 수동 축소·이동으로 세계 전체도 볼 수 있다. 목적지 선택 등 호출자가 중심·확대율을 지정한 지도는 그 값을 따른다.

원화는 내장 imagegen으로 개별 생성했다. 최종 생성 지시문과 원화 경로는 `tools/chart_art_sources.json`, 게임 그림은 `images/chart/{kraken,dragon,edge,compass}.webp`, 내보내기는 `python tools/chart_art.py`다. 기존 원화는 보존하고 투명도를 유지해 크기만 줄였다. 미리보기는 `docs/art/chart-motifs-preview.jpg`.

추가 10종의 생성 기록은 `tools/chart_legend_sources_20261030.json`, 내보내기는 `python tools/north_chart_art.py`, 미리보기는 `docs/art/chart-legends-20261030.jpg`다. 별도 생성한 투명 원화를 640px 이내 WebP로 내보내며, 생성본의 최대 알파가 254인 경우도 원래의 투명도를 유지한다.

| 실제로 지나온 횟수 | 해도에 더해지는 정보 |
| --- | --- |
| 0회 | 미완성 양피지와 상상 속 삽화 |
| 1회 | 육지·바다의 윤곽과 해안 먹선 |
| 2회 | 실제 강줄기 |
| 3회 | 산·산맥의 먹선과 빗금 |
| 4회 이상 | 숲·초원·사막·설원 등의 채색과 수목 표시 |

지형의 색은 이웃 표본 사이를 부드럽게 이어 칸마다 끊기지 않게 했다. 수첩·항구의 항로 선택·항해 및 육상 지도의 공통 바탕에 적용한다. 작은 지도는 삽화를 생략한다. 도시·유적·단서·자동항해 선택은 기존 기능을 그대로 쓴다.

## 조사 횟수와 저장

`G.State.surveyChart`는 배와 탐험대가 실제로 움직인 직후에만 호출한다. 시야 안에 계속 들어 있는 칸은 한 번만 센다. 그 칸이 시야 밖으로 나갔다가 다시 들어오면 한 번 더 센다. 정박·대화·제자리 탐색, 책·임무 등으로 받는 해도 지식은 통과 횟수를 올리지 않는다. 기존 `revealChart`는 지식의 범위만 넓힌다. 시작 때 알고 있는 바다도 첫 실제 통과를 두 번으로 세지 않는다.

기존의 0.5도 격자·탐사 비트와 작성률은 유지한다. `chartPasses`는 같은 격자의 실제 통과 횟수 0~4, `chartLast`는 마지막 시야의 중심·반경이다. 저장할 때는 `chartSurvey`라는 Base64 바이트 문자열로 넣고, 기존 일지의 LZ 압축을 그대로 거친다. 조사 정보와 마지막 시야를 함께 복원해 저장을 불러왔다고 같은 자리에서 횟수가 오르지 않는다.

옛 저장은 탐사 비트 전체를 보존하고 상세도 1로 표시한다. 과거의 실제 통과 횟수는 남아 있지 않아 복원할 수 없으므로, 이후 실제 이동부터 횟수를 쌓는다. 날짜 변경선과 극지의 격자 범위를 함께 처리한다.

## 코드와 조정값

- `js/core/state.js`: 통과 횟수·지식·저장 호환. 최대 단계는 `G.BALANCE.chartSurvey` (`js/data/base.js`).
- `js/art/chart.js`: 양피지·해안·강·산·지형·미지 삽화. 색·그림 크기·종이 질감은 `G.FX.chart` (`js/data/seafx.js`).
- `js/ui/info.js`, `js/ui/chartview.js`: 공통 해도와 단계 안내. 조사 정보·현재 저장·삽화 로딩이 바뀌면 같은 날에도 캐시를 새로 만든다.
- `js/scenes/sea.js`, `js/scenes/land.js`: 실제 이동 연결. 속도·항로·게임 날짜·보상 규칙은 바꾸지 않는다.
