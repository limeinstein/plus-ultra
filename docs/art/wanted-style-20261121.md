# 해적별 현상금 전단지 — 2026-11-21

게임의 `G.Captains.pirates()`와 원본 `G.SEA_PIRATES`를 모두 집계한 현상금 대상은 **156명**이다. 소굴 두목은 별도 14명이며, `images/wanted/`의 초상 170장은 두 명부를 합한 수다. 현상금 대상 156명의 초상 누락은 0명이다.

## 적용

156명의 실제 초상을 크림색 양피지·남색 잉크·금빛 장식·청회색 항해 도안의 공통 틀에 연결했다. 이름과 해적단, 현상금은 게임 자료와 현재 장부에서 글자로 얹는다. 잔당 흡수로 현상금이 오르거나 토벌 상태가 바뀌면 수배서에도 반영된다. 게임 금액 단위는 닢을 따른다.

식당 게시판은 현재 바다의 활동 중인 해적을 현상금 순으로 최대 5명 표시한다. 1~3장은 한 줄, 4장은 2+2, 5장은 3+2이며, 종이의 높이와 기울기를 달리한다. 상세 창과 바다에 날아오는 수배서도 같은 틀을 쓴다.

실제 식당에서 전단지를 누르면 해당 인물의 상세 창이 열리고, 토벌 상태는 붉은 도장으로 표시한다. 키보드 선택과 바다 수배서의 초점 복원·동작 줄이기 설정을 유지한다.

## 검증과 재출력

`node tools/export_wanted_style_20261121.cjs`

156명 전원의 초상 ID·이름·해적단·기본 현상금과 글자 넘침을 검사하고 512×768 투명 PNG를 각각 출력한다. 1600×900, 960×640, 390×844 화면의 1~5장 배치, 전단지 클릭과 상세 인물 일치, 흡수 후 현상금 갱신 및 토벌 도장을 검사한다. 결과는 `artifacts/wanted-style-20261121/report.json`이다. 내보낸 PNG의 금액은 기본 장부 기준이며 실행 중인 게임은 현재 장부의 금액을 계속 사용한다.

`node tests/wanted_sea_reveal_smoke.cjs`
