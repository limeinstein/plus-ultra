# 새 발견물과 누락 증빙 원화 (2026-11-11 추가 자료)

실제 `index.html`의 자료 순서와 시스템의 추가 등록을 읽고, 이야기 모드 전용 기록도
포함해 발견물 1,292종과 발견 유물 1,136종을 조사했다. 북유럽·기마민족·몽골·위구르·
시베리아 묶음(`js/data/steppenorse.js`)의 발견 장면 42종이 없었다.

증빙 유물 289종에는 전용 물건 그림이 없어 발견 풍경이나 코드 그림을 대신 쓰고 있었다.
발견 때 받는 이름 붙은 해도·지도 18종과 술집에서 구입하는 단서 증거품 26종도 함께 조사했다.
전체 제작 목록은 원화 375종이며, 게임용 파일은 발견 연출 세트 42개와 투명 아이콘 333개다.
기존 발견 장면·마지막 장면·시트·증빙 원화 4,597개도 실제로 디코딩해 읽기 오류가 없음을 확인했다.

발견 풍경은 묘사된 지형·유적·보물과 민족 풍속을 따른다. 현대 관광 시설이나 발굴 장비를
추가하지 않는다. 증빙 그림은 해당 물건만 보여 주고, 같은 발견의 풍경을 재사용하지 않는다.
경전과 문서의 작은 글씨는 설명을 대신하는 새로운 문장을 지어 넣지 않는다.

유적 15곳은 스톤헨지처럼 도면 위의 모형에서 실물 답사와 시간대별 외관으로 이어진다.
민족 3곳은 악기 연주·지역 행사·음식 나눔을 16장에 담았고, 보물 11점은 암실에서 여덟 방향의 실물을 두 바퀴 돌려 보여 준다.
자연 5곳은 새벽에서 밤으로 가는 파노라마, 동물 3종은 새끼에 이어 성체가 나타나는 장면,
식물 5종은 식물의 윤곽을 그린 펜화에 색이 들고 실제 모습으로 바뀌는 장면이다.
같은 연출에서 GIF와 마지막 장면을 저장하고, 게임 재생 시트에는 24칸으로 나누어 담는다.
아이콘은 14픽셀 안팎의 투명 여백을 두고 물건과 문서가 잘리지 않도록 맞춘다.

## 재현과 확인

```text
node tools/discovery_art_20261111/audit.cjs --out artifacts/discovery-art-20261111/audit-current.json
python tools/discovery_art_20261111/package.py
python tools/images.py
python tests/discovery_art_20261111_files.py --raw
node tests/discovery_art_20261111_smoke.cjs
node tests/steppenorse_art_smoke.cjs
```

파일 검사는 신규 GIF의 여러 장면, 원색 마지막 장면·시트, 투명 아이콘의 크기·알파 범위·
여백·해시를 확인한다. 전체 발견과 유물뿐 아니라 발견 증거품과 구입한 단서의 파일·등록을
함께 대조한다. `--partial`은 생성된 원화만 변환하고, `--preview-only`는 모음만 갱신한다.
파일 검사의 `--raw`는 로컬 작업 원본 보관 여부도 확인한다. 이 옵션 없이 실행하면
저장소의 게임용 그림과 제작 명세만으로 검사할 수 있다.

브라우저 검사는 신규 아이콘을 실제로 읽고 `G.Disc.proofSrc`가 해당 그림을 고르는지,
소지품에 표시되는지 확인한다. 새 발견 장면의 재생 경로와 대표 8종의 실제 재생도 검사한다.
`file://` 오프라인 실행에서 선택 웹 글꼴은 운영체제 대체 글꼴로 표시한다.
시험 브라우저는 성공·실패 모두 `finally`에서 종료한다.

게임 규칙, 발견물·유물의 ID·이름·값·단서·보상과 저장 구조는 변경하지 않는다.
