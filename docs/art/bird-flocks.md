# 조류 발견물의 무리 연출

2026-10-29 사용자 요청: 모항의 갈매기 배웅처럼 조류 발견물을 여러 마리의 무리로 표시한다. 날지 못하는 새는 종에 맞게 달리거나 헤엄친다.

## 그림

- `images/effects/birds/<발견물 ID>.webp`: 33종, 각 1024×512, 4열×2행, 256×256 투명 프레임 8장.
- 비행 26종: 군함조·신천옹·극락조·홍학·로크·악어새·공작새·뱁새·두루미·독수리·송골매·청둥오리·황새·앵무새·칠면조·봉황·안데스콘도르·벌새·흰올빼미·검은목두루미·코뿔새·신성따오기·흰머리수리·토코투칸·사랑앵무·피닉스(불사조).
- 헤엄 3종: 아프리카펭귄(`penguin`)·마젤란펭귄·황제펭귄. 달리기 4종: 타조·키위새·에뮤·로드러너. 달리기와 헤엄은 지형을 검사한 경로를 따라 이동한다.
- 내장 imagegen 도구로 종마다 별도 생성했다. 최종 생성 지시문과 원본 경로는 `tools/bird_sprite_sources.json`에 있다. 원화의 투명도를 유지해 `python tools/bird_sprites.py`로 내보낸다. 원화가 없는 환경에서는 저장된 WebP로 검토판을 다시 만든다.
- 전체 검토판: `docs/art/bird-sprites-preview.jpg`.
- 펭귄 3종에는 `<ID>_shore.webp` 해안 전용 시트를 더했다. 윗줄 4칸은 서서 걷기, 아랫줄 4칸은 몸을 숙여 뛰어드는 동작이다. 내장 imagegen으로 제작했으며 생성 지시문·원화 경로는 `tools/bird_shore_sources.json`에 있다. 총 33종·36개 시트다.

## 동작과 보상

최초 발견 대화가 끝나면 종에 맞는 규모로 지나간다. 불사조와 봉황은 한 마리, 홍학은 32마리, 두루미·검은목두루미·황새·청둥오리·신성따오기·악어새는 24마리, 신천옹·군함조·흰올빼미는 16마리다. 걷거나 뛰는 타조·키위새·에뮤·로드러너는 날짜별로 1~2마리, 나머지는 8마리다. 개체마다 간격·크기·출발 지연·프레임·날갯짓 속도가 다르다. 벌새는 빠르게, 신천옹과 콘도르는 느리게 날갯짓한다. 대화창과 건물 안에서는 기다렸다가 현장으로 돌아왔을 때 연출한다.

펭귄은 가까운 해안을 찾아 육지에서 걷기(시간의 30%) → 물에 뛰어들기(12%) → 바다에서 헤엄치기(58%) 순서로 움직인다. 해안선을 이분 탐색해 땅과 물의 접점을 찾고, 육상 걸음과 입수 뒤 헤엄 경로는 각각 땅·물 위에 머문다. 입수에는 작은 물결과 뛰어드는 높이 변화를 더한다. 바다에서 관찰한 펭귄도 해안에서 출발한다. 해안 진입은 연출만 바꾸며 저장된 발견 좌표·2년 주기·보상 계산은 그대로다.

마지막 관찰일로부터 달력상 2년이 지난 뒤 발견 위치의 반경 0.65도 안으로 다시 들어오면, 같은 무리 연출과 함께 최초 발견 당시 **실제 지급된 명성의 10%**를 탐험 명성으로 받는다(정수 반올림). 이후에도 마지막 보상일로부터 2년씩 반복한다. 같은 자리에 머물러 시간을 보내는 것으로는 재방문으로 세지 않는다. 발견 수·발견 날짜·보고 상태·유물은 추가 지급하지 않는다.

저장 필드는 기존 `s.disc[id]` 안의 `birdSeen`(마지막 관찰일), `birdFame`(최초 실제 명성), `birdPlace`(실제 발견 좌표·이동 방식·도시 번호)다. 신천옹처럼 넓은 바다에서 만나는 발견물도 실제 관찰 좌표를 기억한다. 새 필드가 없는 옛 저장은 최초 발견일과 자료의 좌표를 사용하고 현재 능력으로 최초 명성을 어림한다. 2월 29일에 관찰했다면 2년 뒤 2월 28일부터 다시 볼 수 있다.

게임 규칙: `G.BALANCE.birdRevisit` (`js/data/base.js`). 연출 조정: `G.FX.birds` (`js/data/seafx.js`). 조류 판정·관찰·그림 재생: `js/systems/birds.js`.
