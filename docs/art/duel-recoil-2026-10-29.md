# 일기토 일반 피격과 패배 착지 분리

일반 피격과 패배가 같은 3장(충격·무릎 굽힘·누움)을 끝까지 재생해,
공격을 맞을 때마다 쓰러졌다 다시 일어났다. 마지막 일격에서도 180ms 만에
누운 그림으로 바뀌어 바닥으로 내려앉는 과정이 보이지 않았다.

일반 피격은 안정된 대기 그림에서 상체가 살짝 젖혀지고 8px 밀렸다 돌아오는
220ms 반동으로 바꿨다. 무릎 굽힘·누운 그림은 일반 피격에 나오지 않는다.
공격·필살기의 피해 계산과 명중 규칙은 그대로다.

체력이 0이 되는 마지막 일격은 100ms 충격 → 380ms 무릎 굽힘 →
500ms 느린 넘어짐 → 280ms 착지 유지다. 무릎을 굽힌 그림을 발밑에 고정해
낮추고 뒤로 기울이며, 별도로 그린 기존 누운 그림으로 부드럽게 잇는다.
중간에 머리가 위로 튀지 않도록 그림 높이를 계속 낮춘다.
완전히 누운 그림에는 회전·찌그러뜨림을 더하지 않는다.

전투원 37명의 기존 PNG 픽셀은 바꾸지 않았다. `tools/duel_fall_geometry.py`가
대기·피격 그림의 발밑, 무릎 굽힘 그림의 볼록 외곽, 누운 그림의 높이를
`js/data/duelart.js`의 `fallGeometry`에 기록한다. 실제 그리기는 이 외곽으로
바닥 접촉을 계산해 외투·장화가 땅 밑으로 내려가지 않게 한다.
브라우저에서 그림 픽셀을 읽지 않아 `file://`에서도 같은 연출을 쓴다.

시간과 반동·기울기·그림 연결 비율은 `js/data/seafx.js`의 `G.FX.duel`에 모았다.
빠르게 모드에서는 피격·패배 시간이 절반이며, 재생 중 배속을 바꿔도
이미 시작한 동작의 진행 위치가 튀지 않는다. 승패 처리가 쓰러짐을 처음부터
재시작하지 않으며 `fastEnd`나 느린 기기에서도 착지가 끝나기 전에 닫히지 않는다.
생포·설득의 무릎 굽힘 자세는 기존 동작을 유지한다.

시트를 교체했다면 아래 명령으로 외곽을 다시 기록하고 검사한다.

```powershell
python tools/duel_fall_geometry.py
python tools/duel_fall_geometry.py --check
node tests/duel_assets_smoke.js
node tests/duel_motion_smoke.js
node tests/duel_finishers_smoke.js
```

검증 내용:

- 전투원 37명의 시트 규격·투명 여백·바닥 위치와 새 외곽 데이터 일치.
- 실제 `file://` 게임에서 좌우 인물의 일반 피격·공격·반격에 쓰러짐 그림이 나오지 않음.
- 보통·빠르게 모드의 마지막 일격 → 무릎 굽힘 → 느린 착지 → 누운 자세 유지.
- 실제 그리기 변환에서 머리 높이가 계속 낮아지고 외곽 아래쪽이 바닥과 일치.
- 실제 승리·패배 처리와 `fastEnd`에서도 마지막 동작 재시작·착지 전 종료 없음.
- 비밀무기·장비 호통·전설 필살기·적 컷인·일격필살과 콘솔 오류 0.
