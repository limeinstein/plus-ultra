# 12신의 사도 · 발견, 만남, 시험과 동행

기존 `output/imagegen/greek-apostles-20261115-v2`의 성인 인물 12명을 그대로 이어 쓴다. 초상과 무릎상은 각각 12개, 새 이벤트 원화는 16개다. 신의 이름은 소속이며, 대화창과 동료 명부에는 인물의 고유 이름을 표시한다. 안정적인 저장 ID는 `apostle_<신의 영문 이름>`을 유지한다.

## 만남과 시험

12신 명단은 기존 초상과 같이 헤스티아를 포함한다. 디오니소스의 이리아 성역은 별도의 발견물이며 이 열두 명 업적의 조건에 넣지 않는다. 다음 도시는 1480년 현존 도시를 기준으로 게임의 거리 함수로 구한 최인접 도시다. 발견 후 만남 위치를 저장하며, 그 도시가 사라졌다면 현존 도시 중 다시 고른다.

- **칼리스테 / 헤라**: 사모스의 헤라 신전 → 간디아 성문 밖. 공작 깃과 밀랍 봉인이 있는 길손 제단에서 선장의 서약을 묻는다. 호위 연습선과 해상전투.
- **멜리사 / 데메테르**: 페르구사 호수 → 시라쿠사 성문 밖. 순례자에게 빵을 나누며 다음 파종에 남길 씨앗을 이야기한다. 곡창 수비대의 육상전투.
- **아가테 / 헤스티아**: 베스타 신전 → 로마 성문 밖. 젖은 소매를 말릴 불가를 내주고 가장 작은 불씨를 돌보게 한다. 세 화로를 옮기는 중급 원반 미니게임.
- **이안테 / 아프로디테**: 밀로의 아프로디테 → 간디아 성문 밖. 보석상과 선원의 다툼 사이에서 겉빛과 마음의 무게를 구분한다. 보석 아홉 개의 중급 천칭 미니게임.
- **다프네 / 아르테미스**: 에페소스의 아르테미스 신전 → 이스탄불 성문 밖. 사슴 앞에서 멈추는지 살핀 뒤 활을 내려놓고 사냥칼로 겨룬다. 일기토.
- **리산드라 / 아테나**: 파르테논 신전 → 아테네 성문 밖. 올리브나무 아래 석판에서 병사를 살릴 배치를 그린다. 방진을 상대하는 육상전투.
- **레온티오스 / 제우스**: 올림피아의 제우스 상 → 아테네 성문 밖. 번개 자국 난 참나무 아래에서 명령의 책임과 판단을 묻는다. 일기토.
- **니칸드로스 / 포세이돈**: 아틀란티스 → 아조레스 성문 밖. 벼랑에서 끊긴 닻줄을 함께 건져 올린다. 파도와 선회를 읽는 해상전투.
- **에우안드로스 / 아폴론**: 델포이 성지 → 아테네 성문 밖. 병든 뱃사람의 목을 축이고 안개 속 당직 신호를 가르친다. 세 가락의 음표 순서를 기억하는 미니게임.
- **드라콘 / 아레스**: 아레티아스섬 → 트레비존드 성문 밖. 붉은 깃 아래서 창끝의 가죽을 벗기지 않고 용기를 시험한다. 일기토.
- **테오도로스 / 헤파이스토스**: 헤파이스티아 유적 → 살로니카 성문 밖. 배의 경첩과 방패의 이음새에서 힘이 모이는 곳을 가르친다. 청동 방진과 육상전투.
- **알렉시스 / 헤르메스**: 킬레네산의 헤르메스 동굴 → 아테네 성문 밖. 날아간 편지의 봉인을 돌려주고 바람이 변하기 전 길을 바꾸게 한다. 전령 연습선과 해상전투.

도시 밖 육상에 들어서거나 근처에서 하루가 흐르면 조건을 채운 사도와 만난다. 하단 **12신의 사도** 단추에서 발견 상태·행선지·시험·고용 상태를 확인할 수 있다. 바다 위·먼 도시·미발견 상태에서는 시험과 고용이 열리지 않는다.

인물별 등장 이야기·자기소개·도전 이유·승리·패배·고용·고용 보류·재회 대사는 각각 별도로 작성했다. 이름이나 신의 호칭만 치환한 공통 대사를 쓰지 않는다. 데이터는 `js/data/olympianapostles.js`, 진행은 `js/systems/olympianapostles.js`가 맡는다.

## 조정값과 저장

모든 조정값은 `G.BALANCE.olympianApostles`에 있다. 능력치 48~84, 주요 특기 2단계, 월급 110닢, 초기 충성 80으로 중급에 맞췄다. 일기토 공격 35·방어 24·기술 2, 육상 연습대 36명 대 상대 30명, 해상전은 같은 캐러벨 한 척씩이다. 미니게임은 기존 중급 난이도를 쓴다. 리라는 3·4·5음의 세 가락, 가락을 보여 주는 시간 2.6초, 실수 두 번 허용이다.

실패·도전 보류 후 하루가 지나면 재도전할 수 있다. 시험 통과와 고용은 분리해 기록하므로 고용을 미뤄도 재시험하지 않는다. 사도는 일반 술집 명부나 떠돌이 후보에 나오지 않으며, 신이나 권력자 자체를 부하로 삼는 설정이 아니다.

육상전은 모의 부대로 진행해 실제 선원 수와 전리품을 바꾸지 않는다. 해상전은 연습선을 쓰며 기본 해전의 함대 손실·나포·전리품 처리 전에 육상으로 복귀한다. 저장 가능한 `olympianNaval`에는 사도 ID·원래 육상 위치·선원 수를 담는다. 발견·현재 동료·`crewEver`로 옛 저장을 복구하며 같은 사도를 중복 고용하지 않는다.

## 업적과 동행 사건

- **열두 신의 순례자** (`olympian_pilgrim`): 위의 성소·발견물 12곳을 모두 직접 발견. 탐험 명성 800, 금화 50,000닢, 같은 이름의 칭호. 열두 상징이 항해일지 둘레를 채우는 원화.
- **올림포스의 동행자** (`olympian_companions`): 사도 12명 모두 한 번 이상 고용. 탐험 명성 1,000, 금화 60,000닢, 같은 이름의 칭호. 12명이 갑판의 해도 위에 손을 모으는 원화. 기존 동료 업적처럼 떠나거나 사망한 뒤에도 고용 기록은 남는다.
- **여섯 항로가 만나는 해도**: 남성 6명의 고용 기록 완성. 갑판에서 서로 다른 항로와 수리 항구를 논의하고 당직 신호를 정한다. 별도 원화·대사, 한 번 재생.
- **먼바다에 남길 불빛**: 여성 6명의 고용 기록 완성. 곡식 장부·비상 배치·서약의 밀랍을 성화 아래 모아 배의 약속을 세운다. 별도 원화·대사, 한 번 재생.

남녀 동행 사건에는 별도 능력치 보상을 추가하지 않는다. 반대 성별 사도를 이미 맞았더라도 각 6명 조건을 채운 순간 재생한다. 둘 다 12명 업적과 구분되는 내용이다.

## 그림과 재현

내장 ImageGen으로 이벤트 원화 16장을 제작했다. 기존 무릎상은 인물 외형 참고로 쓰고 얼굴·복식·상징을 유지했다. 데메테르 만남 원화의 허리 옆 여분 손과 지지되지 않는 밀 다발은 내장 ImageGen 편집으로 제거했다. 두 팔만 남은 수정본을 게임·원본 갤러리 양쪽에 쓴다.

- 게임 그림: `images/olympian-events/meet_<slug>.webp` 12개, `men_fellowship.webp`, `women_fellowship.webp`, `images/achievement-events/olympian_*.webp` 2개.
- 기존 인물 초상 복사본: `images/portraits/mates/apostle_*.webp` 및 `_half.webp`, 24개. 원래 투명도를 유지한다.
- [이벤트 원화 갤러리](../../artifacts/olympian-apostles-20261115/gallery.html).
- 원화·자산 규격·해시·실제 화면: `artifacts/olympian-apostles-20261115/`.
- 최초 업적 프롬프트: `tools/olympian_apostles_20261115/prompts.json`.
