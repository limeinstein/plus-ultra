# 육상전 병사 시트 v2 — 15~16세기 장비와 진영색

## 적용 범위

- 병과: 검병·화승총병·포병·제독대
- 단계: LV0 징집병/초보 → LV1 민병/훈련병 → LV2 직업 군인 → LV3 정예/지휘관
- 아군 표식: 상아색·양피지 베이지·흰색 천
- 적군 표식: 짙은 호두색·암갈색·숯검정 천과 가죽
- 시대: 15세기 말~16세기. 모리온·카바셋·샐릿·브리건딘·흉갑·화승식 아르케부스·초기 머스킷·팰커넷/컬버린 야전포를 중심으로 삼았다.
- 제외: 삼각모·이각모·나폴레옹 제복·플린트록·총검·현대 화기·판타지 갑옷.

## 생성 방식

OpenAI 내장 이미지 생성 도구를 사용했다. 기존 네 시트는 구조 참고이자 편집 대상으로 삼아 네 줄과 동작 순서를 보존했고, 적군판은 완성된 아군판에서 팀 표식 색만 바꾸는 정밀 편집으로 만들었다. 생성 원본은 `artifacts/landwar-units-v2/sources/`, 게임용 재패킹 결과는 `images/sprites/`에 있다.

## 프롬프트 요약

공통 프롬프트는 다음 규격을 사용했다.

> 투명 배경의 등각 역사 전략 게임용 스프라이트 시트. 4개 가로줄은 LV0~LV3이며, 같은 인물과 병과가 징집병에서 정예병으로 발전한다. 15세기 말~16세기 복식과 무기만 사용하고, 전신 3/4 측면·오른쪽 방향·공통 발밑 기준선·프레임 사이 넓은 투명 여백을 유지한다. 대기·준비·걷기·달리기·공격·피격·쓰러짐·복귀·승리 동작을 왼쪽에서 오른쪽으로 둔다. 글자·격자·바닥·받침·로고·워터마크는 넣지 않는다.

병과별로 검병은 곤봉 징집병→민병 검객→브리건딘 직업병→반갑 정예 지휘관, 총병은 사냥꾼→민병 아르케부스병→직업 화승총병→정예 머스킷병, 포병은 조잡한 봄바드→팰커넷→컬버린→정예 포술장, 제독대는 실용적인 원정대장→숙련 선장→갑주 지휘관→전설적 제독으로 지정했다.

적군판 편집 프롬프트는 모든 인물·장비·동작·프레임·알파·조명·치수를 그대로 두고, 상아/베이지/흰색/남색 팀 천만 암갈색·흑갈색·숯검정으로 바꾸도록 제한했다.

## 런타임 규칙

- 아군 병과 단계는 제독과 **모든 동료** 가운데 해당 솜씨의 최고값을 사용한다. 선실·역할 배치와 무관하다.
- 보병=검술, 총병=사격술, 포병=포술, 제독대=세 솜씨 평균(셋 다 3이면 LV3).
- 도적·수비대는 병력 1~25/LV0, 26~50/LV1, 51~75/LV2, 76명 이상/LV3 적군판을 쓴다.
