# 물길·발자국과 기본 선박 보기 — 2026-11-01

## 반영

- 선박 확대 단추는 지도 기준 배율 110 × 3 = 330으로 이동한다. 수동 확대 상한 2400은 유지한다.
- 새 해전은 살아 있는 양쪽 함대의 선체·돛·이름표가 들어오는 교전 보기로 시작한다. 함대가 벌어지면 즉시 시야를 넓히고 가까워지면 천천히 확대한다. 기함 보기·전장 전체·해도 클릭과 수동 확대도 가능하다. 이동·백병전 접근 명령으로 교전 보기가 해제되지 않는다.
- 본편 항해에서 보이는 기함, 동행선, 호위 상선, 상선·해적·군함의 구성 선박마다 별도의 물길 상태를 둔다. 해전은 기존 개별 선박 상태를 같은 표현과 수명으로 갱신한다.
- 가벼운 선체·날렵한 선체·대형선·넓은 동양 선체·노선에 폭과 포말량을 다르게 적용한다. 선수 파문, 끊어진 선측 물살, 선미 소용돌이, 선회 포말, 노의 타원 파문과 작은 물방울을 조합한다. 물보라를 확대해도 둥근 흰 덩어리가 되지 않게 납작하게 그린다.
- 물길과 탐험 자국은 실제 1초까지 유지하고 2.4초까지 부드럽게 지운다. 게임 배속·정지에 영향을 받지 않는다. 짧은 물방울은 종류별로 약 1.2~2.3초 동안 남는다.
- 구두, 말발굽, 낙타 발바닥, 갈라진 발굽, 코끼리 발자국, 수레 바퀴와 썰매 자국에 같은 시간 곡선을 적용했다. 옛 탐험대 표시의 자국과 지도 점선도 함께 사라진다. 이동 경로 배열과 편대 추종은 유지한다.

## 조정값과 비용

`js/data/seafx.js`의 `ship.zoom.shipPreset`, `battleView.combatMax/combatPad/combatHull`, `wake.hold/life/profiles`, `sprites.expedition.formation.tracks.hold/life`에서 조절한다.

선박마다 항적 점 180개, 입자 100개로 제한한다. 빠른 배속에서는 표본 간격과 발생량을 조절하여 수명 전에 오래된 점을 밀어내지 않는다. 화면에서 사라진 선박의 효과는 수명 뒤 회수하며 항해 종료 때 모두 비운다. 카메라 이동·배율·대열 보간은 새 물길을 발생시키지 않는다. 효과 전용 난수를 써서 게임 난수와 선박 성능·저장 상태를 바꾸지 않는다. FPS 수치는 측정하지 않았다.

## 검증

Chrome의 D3D11 GPU 경로로 검사했다. 시험 브라우저는 종료했다.

- `node tests/naval_view_controls.cjs` (`SHIP3D_GPU=1`): 3배율 단추, 확대 이동 추적, 1600/960폭 메뉴, 3대3 양쪽 함대 가시성, 기함/전장/해도 전환, 포격 정지·재개, 백병전, 저장 복원, 36종 3D와 콘솔 오류 0.
- `node tests/battle_gunnery_guide.cjs` (`SHIP3D_GPU=1`): 쉬움·보통 사거리와 장전 표시, 어려움 숨김, 포격 정지 상태, 12개 발사 판정, 옛 저장, 콘솔 오류 0.
- `node tests/water_tracks_browser.cjs`: 10척(기함·동행선·호위·상선·해적·군함)의 실제 항해 물길, 기함 정지 중 NPC 이동, 확대만으로 새 항적 없음, 정지 후 소멸, 화면 밖 상태 정리와 종료 해제, 36종 3D, 12개 탐험 역할의 자국과 경로 보존, 콘솔 오류 0.
- `node tests/water_lifetime.cjs`: 0.5/1/4배속과 30/60Hz로 12초 동안 이동, 점·입자 상한과 2.4초 수명, 카메라 이동·제자리 회전, 날짜 변경선, 해전 픽셀 좌표.
- `node tests/expedition_following_test.js`: 10종 편대의 회전·정지·확대·좁은 길·급반전·30/60프레임 경로 추종.
