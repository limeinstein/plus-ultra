# 나비·나방의 무리 비행과 반복 재관찰

2026-10-31 사용자 요청: 조류보다 작은 나비를 30~60마리씩 무작위로 나타났다 사라지게 한다. 조류와 나비 모두 마지막 관찰로부터 2년 뒤 발견 위치에 다시 오면 최초 발견 명성의 10%를 계속 받을 수 있다.

## 그림 17종

모르포나비·유리날개나비·제왕나비의 겨울 숲·루나나방·88나비·호랑나비·에메랄드제비나비·버드윙나비·왕오색나비·아틀라스나방·가랑잎나비·부탄글로리·마다가스카르 석양나방·혜성나방·아프리카큰제비나비·진주모나비·공작나비를 포함한다. 나방도 함께 처리하며 딱정벌레·사마귀·반딧불이는 이번 연출 대상에 포함하지 않는다.

- 게임 시트: `images/effects/butterflies/<발견물 ID>.webp`.
- 각 1024×512, 4열×2행, 256×256 투명 프레임 8장. 날개를 펴고 접는 연속 자세다.
- 내장 imagegen 도구로 종마다 별도 생성했다. 원화의 투명도를 유지해 게임 크기로 내보냈다.
- 최종 생성 지시문과 원화 경로: `tools/butterfly_sprite_sources_20261031.json`.
- 내보내기·시트 검사·검토판: `python tools/butterfly_sprites.py`.
- 검토판: `docs/art/butterfly-sprites-20261031.jpg`.
- 그림 등록: `python tools/images.py`.

## 움직임

무리마다 `Math.random`으로 30~60마리를 새로 뽑는다. 개체는 최초 2.4초 안에 서로 다른 시점에 등장해 7~11초씩 날며, 마지막 개체까지 사라지면 무리도 정리한다. 개체별 크기·날갯짓 속도·시작 프레임·좌우 움직임·상승 속도·곡선의 진폭·위상·투명해지는 시간을 모두 다르게 정한다. 따라서 보이는 마릿수는 처음에 늘다가 나중에는 줄어든다. 날개의 표식도 프레임마다 달라진다.

개체의 그림 틀 너비는 20.8~35.2px(1600×900 화면 기준)로 기존 조류보다 작다. 무리는 발견 장소를 화면에 투영한 점 주변에서 흩날린다. 조류의 편대·마릿수·달리기·펭귄 입수는 기존 설정을 유지한다. 대화·발견 카드·건물 안에서는 기다렸다가 현장 화면에서 움직인다.

연출 조정값은 `G.FX.butterflies` (`js/data/seafx.js`), 판정과 재생은 기존 `G.Birds` (`js/systems/birds.js`)에 있다. 조류의 `kinds` 목록은 33종을 유지하고 별도 `butterflies` 목록 17종을 연결한다. 발견 처리와 게임 갱신의 기존 진입점을 함께 사용한다.

## 저장과 보상

나비는 기존 발견 기록 `s.disc[id]` 안에 `butterflyFame`(최초 실제 지급 명성), `butterflySeen`(마지막 관찰일), `butterflyPlace`(실제 발견 좌표와 이동 방식)를 저장한다. 조류의 기존 `birdFame`·`birdSeen`·`birdPlace`는 유지한다.

두 종류 모두 `G.BALANCE.birdRevisit`의 달력상 2년·반경 0.65도·최초 명성의 10%(정수 반올림)를 사용한다. 보상 뒤에는 마지막 관찰일만 갱신하며, 기준 명성은 줄이지 않는다. 2년마다 떠났다가 돌아올 때마다 같은 보상을 계속 받는다. 윤일의 다음 관찰일은 2년 뒤 2월 28일이다. 현장에 계속 서 있거나 즉시 다시 들어오는 것으로는 중복 지급하지 않는다.

최초 발견 날짜·발견 수·보고 상태는 유지하며 유물도 다시 지급하지 않는다. 옛 저장의 나비는 최초 발견일·자료의 좌표를 사용하고, 최초 실제 지급 명성이 저장되지 않았으므로 기존 조류와 같이 현재 능력으로 기준을 어림한다. 자신이 발견하지 않은 경쟁자의 발견물은 제외한다.

## 검증

`python tools/butterfly_sprites.py`: 17개 시트 크기·투명도·8칸 모두 그림 포함 검사 통과.

`node tests/butterflies_smoke.js`: 실제 Chromium file://에서 36개 검사 통과. 17종 로딩, 무작위 마릿수 30과 60 포함, 무리별 변화, 작은 크기, 개체별 등장·퇴장, 실제 발견 경로, 실제 발견 좌표, 윤일, 옛 저장, 경쟁자 제외, 조류·나비의 네 번 연속 2년 주기 보상, 저장 뒤 중복 방지를 확인한다. 결과와 현장 화면은 `artifacts/butterflies-20261031/`.

`node tests/birds_smoke.js`: 기존 조류 33종의 38개 검사 통과. 홍학 32마리·불사조 1마리·달리는 새 1~2마리·펭귄의 걸음/입수/헤엄·반복 재관찰을 유지한다. 두 검사 모두 브라우저 오류 0개이며 종료 시 브라우저를 닫는다.
