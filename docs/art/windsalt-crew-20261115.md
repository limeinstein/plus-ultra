# 바람과 소금의 유럽 철새 30명

첨부 사진에서 얼굴과 표정의 특징을 참고한 남성 항해사 30명을 등록했다. 최종 요청에 맞춰 국적과 활동 지역을 영국·스페인·포르투갈·네덜란드 네 나라로 제한했다. 영국 8명·포르투갈 8명·스페인 7명·네덜란드 7명이며, 처음 독일로 배정한 여섯 명은 네 나라로 다시 배정했다. 최종 v3의 서로 다른 동작 30개와 얼굴 수준으로 정돈한 셔츠·몸의 묘사를 사용한다.

![서로 다른 동작의 항해사 30명](windsalt-crew-20261115-preview.jpg)

## 등장 주기

- 1487~1496년 첫 10명, 1497~1506년 다음 10명, 1507~1516년 마지막 10명을 배정한다.
- 1517~1526년은 신규 모집을 쉬고, 1527년부터 다음 40년 묶음을 새 순서로 시작한다.
- 각 묶음에서 고용 중이거나 이미 퇴장한 사람을 제외하고 섞는다. 후보가 30명보다 적으면 앞 기간부터 최대 10명씩 배정하며 남은 인원만 등장한다.
- 한 게임의 시작 난수와 40년 묶음 번호로 순서를 정한다. 다른 게임에서는 달라지고, 한 게임에서는 저장·불러오기와 다른 난수 소비로 바뀌지 않는다.
- 추첨 결과는 `s.windsaltCrew = {cycle, seed, order}`에 저장한다. 필드와 시작 난수가 빠진 옛 저장도 처음 필요한 때 현재 고용·퇴장 상태를 반영하여 명단을 만든다.
- 기간 중 고용하면 그 사람만 후보에서 빠지며 다른 사람을 즉시 보충하지 않는다. 고용한 동료는 모집 기간이나 40년 묶음이 지나도 함대에 남는다.
- 쉬는 기간에는 항구의 위치·체류 기록과 신규 모집이 정리된다. 짧게 고용했다가 해고한 동료의 복귀도 해당 모집 기간을 따른다.

조정값은 `js/data/base.js`의 `G.BALANCE.windsaltCrew = {start: 1487, years: 10, count: 10, cycle: 40}`에 모았다. 인물 정의·고용 제외 추첨은 `js/data/windsaltcrew.js`다. 전용 인물 ID는 `wscrew_pt01~06`, `wscrew_en01~06`, `wscrew_es01~06`, `wscrew_de01~06`, `wscrew_nl01~06`으로 고정한다. 저장 호환을 위해 `de` ID와 초상 파일명은 유지하며, 현재 국적을 뜻하지 않는다.

## 특기와 언어

30명 모두 언어 외 기본 특기 3~6개·언어 3~5개를 갖는다. 특기는 3개인 사람 5명·4개 5명·5개 10명·6개 10명으로, 주된 특기는 3단계·보조 특기는 2단계다. 언어는 3개·4개·5개인 사람이 각 10명이며, 모두 2~3단계이고 모국어는 3단계다. 기존 게임의 언어 구분에 따라 영국·네덜란드의 모국어는 게르만어로 표시된다.

직업과 역할에 맞춰 능력을 정했으며 게임마다 다시 추첨하는 것은 등장 순서뿐이다. 고용 이후 학습으로 얻은 특기·언어는 그대로 쌓인다. 품삯과 필요 명성은 기존 값을 유지한다.

## 활동 지역과 모집

- 포르투갈: 리스본·오포르토·세우타·아조레스·마디라.
- 스페인: 기존 이베리아 이동 구역 중 포르투갈 도시를 뺀 지역.
- 영국: 런던·사우샘프턴·브리스틀·요크·에든버러. 아일랜드의 더블린은 제외한다.
- 네덜란드: 현재 도시 표에서 해당하는 암스테르담. 벨기에의 브뤼즈·앤트워프·브뤼셀과 해외 식민지는 제외한다.

초기 독일 배정의 `de01`은 네덜란드의 코엔라트 판 덴 베르흐, `de02`는 영국의 루커스 브랜트, `de03`은 포르투갈의 엔히크 코스타, `de04`는 스페인의 마티아스 로하스, `de05`는 영국의 올리버 셰일, `de06`은 포르투갈의 펠리스 테이셰이라다. 각자의 이름·모국어·출신 설명·고향을 함께 맞췄다.

각 지역의 술집·여관에서 기존 항해사 이동 규칙을 따라 만난다. 수첩 「철새」에도 해당 기간의 인물이 나타나고, 행방을 들었을 때 기존 철새와 같은 체류 기한을 적용한다. 기간 밖·지역 밖·중복 직접 고용도 차단한다. 옛 저장의 위치나 소문 체류지가 새 활동 범위 밖에 있으면 체류를 풀고 해당 범위로 되돌린다. 일반 철새는 이 30명의 전용 얼굴을 빌리지 않는다.

## 초상과 제작 기록

`images/portraits/mates/windsalt-men/<pt|en|es|de|nl><01~06>.webp`가 얼굴상 512×512, 같은 이름의 `_half.webp`가 무릎상 1024×1536이다. 모두 투명 WebP이며 같은 최종 동작 원화에서 내보냈다. 게임·도감 이미지 목록과 리그 얼굴 자리 60개를 함께 등록했다.

- 원화 제작 당시 인물과 파일 대응: [등록 기록](../../tools/windsalt_crew_20261115_assets.json). 당시의 5개국 구분은 제작 기록이며, 게임의 현재 국적과 이름은 위의 재배정과 `js/data/windsaltcrew.js`를 따른다.
- 등록 도구: `python tools/register_windsalt_crew_20261115.py`.
- 얼굴 자리: `python tools/portrait_faces.py --keys-file tools/windsalt_crew_20261115_keys.json --merge`.
- 원본·내장 ImageGen 최종 프롬프트·국적별 미리보기는 저장소 상위 `output/windsalt-navigators-30-20261115-v3/`에 보존한다.

## 검증

`node tests/windsalt_crew_rotation_smoke.cjs` 통과. 실제 파일 실행으로 30명·초상 60장·얼굴 자리 60개, 네 나라 국적·해당 도시 제한, 전원의 특기 3~6개·언어 3~5개와 실제 고용 뒤 적용, 옛 저장의 지역 밖 위치·소문 체류 수정, 6개 40년 주기의 24개 기간, 게임별 무작위, 고용 뒤 보충 없음, 휴식, 다음 주기 고용 인물 제외, 해고 후 복귀, 실제 저장 복원과 옛 저장을 검사했다. 한 명을 고용하고 다음 40년으로 넘어가면 배정 인원은 10·10·9·0명이다.

기존 일본·중국·조선 순환 동료 검사도 함께 실행했다. 게임·도감의 `pageerror`·`console.error`는 0건이며, 검사 브라우저는 `finally`에서 종료한다.
