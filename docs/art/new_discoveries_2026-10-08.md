# 새 발견물 그림 의뢰 (2026-10-08)

중국·인도·중동 명승지와 건축물(`js/data/eastdisc.js`) 47곳, 민족 발견물(`js/data/folkdisc.js`) 36곳. 지금은 모두 코드 그림으로 나온다.
파일 이름·규격은 기존과 같다: `images/discoveries/<id>.gif`(576×256), `discovery-ends/<id>`, `discovery-sheets/<id>` → `python tools/ruin_gifs/sheets.py <id…>` → `python tools/images.py`.

## 연출 방향
- 자연: 시간 변화 파노라마(기존 nature 15종과 같은 화풍).
- 유적: 복원과 상공 회전(기존 ruin과 같은 화풍).
- **민족: 그 사람들의 음악·춤이 주인공.** 악기를 연주하는 손 → 춤추는 무리 → 잔치 음식이 놓인 자리로 물러나는 순서. 얼굴을 우스꽝스럽게 그리거나 옷차림을 과장하지 않는다. 아래 「풍속」 칸을 그대로 그림 주제로 쓴다.
- 이미 있던 민족 발견물 15곳(khoikhoi·padaung·cannibal·orangutan·aborigine·blemmyes·inuit·skraeling·patagon·antpeople·nestorian·vampire·aztec·inca·aurora)도 글이 풍속 위주로 바뀌었으니, 그림을 만들 때 같은 방향으로.
