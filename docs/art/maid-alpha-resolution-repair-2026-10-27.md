# 여급·여성 NPC의 형광 테두리와 화질 수정 (2026-10-27)

얼굴·의상·노출도·가슴 크기·체형·포즈를 다시 그리지 않았다. 첨부된 얼굴 참고
사진을 이용한 얼굴 교체도 하지 않았다. 기존 원화의 투명도 복원, 녹색 배경
번짐 제거, 보간 확대와 배포용 축소 규칙 수정만 적용했다.

## 확인한 원인과 수정

- 초기 여급 PNG의 알파 1~2 픽셀에 형광 빨강·노랑 RGB가 들어 있었다.
  `restore_initial_maid_archive.py`가 PNG를 RGB로 바꾸고 검정 배경에서
  다시 인물을 분리하면서 이 픽셀을 불투명하게 살렸다. 분리 입력은 원본을
  검정 위에 합성하고, 분리 결과는 영역 선택에만 사용한다. 최종 색·알파는
  PNG 원본에서 가져온다. 초기 여급 98명의 얼굴상·무릎상 196장을 재추출했다.
- `clean_source()`의 `paste(..., mask=alpha)`는 알파를 두 번 곱했다.
  이를 제거해 머리카락·베일의 반투명 경계를 보존한다.
- 녹색 배경에서 제작된 여급 30명은 배경색이 정확한 `#00ff00`이 아니었다.
  실제 배경색으로 혼합을 역산하고 반투명 경계 및 외곽 15px의 녹색 번짐을
  제거한다. 녹색 옷의 내부와 인물 형상·알파는 보존한다. 얼굴상·무릎상
  60장을 같은 원화에서 다시 저장했다.
- 구판 여급 얼굴상 113장은 448/512px에서 1024px로, 여성 여관 주인·사서·
  성직자·술집 주인 4장의 얼굴상은 384px에서 표준 512px로 확대했다.
  Lanczos 보간과 약한 선명화만 사용했다. 원본에서 없어진 세부를 새로 생성하는
  복원은 아니며 기존 인물의 얼굴을 유지한다. 무릎상은 기존 1024×1536이다.
- `slim.py`의 공통 접두어 규칙은 아티팩트용 무릎상도 416~640px로 줄였다.
  여급 무릎상은 긴 변 1024px·품질 86, 공용 NPC 무릎상은 768px·품질 82로
  남긴다. 전체 그림 배율을 낮추더라도 무릎상은 긴 변 640px 미만으로 줄이지
  않는다. 얼굴상 규칙과 다른 그림의 규칙은 유지했다.

각 변환은 이전 변환이 끝난 뒤 순서대로 실행한다. 같은 파일을 동시에 읽고
다시 쓰지 않는다. 확대 도구의 `--write`를 빼면 남은 확대 대상만 확인한다.

- 인물 WebP 5,291장과 PNG 85장을 선별 검사했다. 녹색 깃털 같은 실제 장식은
  색상 수치만으로 지우지 않고 그림을 확인했다.
- 초기 재추출 196장 전체에서 불투명한 형광 RGB 잔여물이 없음을 검사했다.
- 회귀 검사: 거의 투명한 진단색, 알파 이중 곱셈, 피부·빨간 의상·녹색 의상
  내부 보존, 실제 배포용 축소를 거친 무릎상의 크기·투명도를 확인한다.
- 브라우저 검사: 여급 175명의 자료, 새 유럽 여급 46명의 얼굴·무릎상 연결,
  쾰른·코르도바·모스크바 술집 대화와 도감, 콘솔 오류 0을 확인했다.
- 비교 그림과 검사 기록: `artifacts/female-portrait-repair/`.

게임 이미지의 기존 경로와 ID를 유지했다. 배포 파일 생성·게시·설치 파일
제작은 이번 수정에 포함하지 않았다.
