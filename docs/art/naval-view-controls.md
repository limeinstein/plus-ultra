# 확대 항해와 해전 보기·포격 정지 (2026-10-31)

## 확대 항해와 메뉴

종전에는 카메라의 목표 위치만 움직여, 빠르게 항해할수록 추적 지연이 생겼다. 지도 배율 2400에서는 작은 좌표 차이도 큰 화면 이탈로 이어졌다. 이제 한 프레임의 실제 선박 이동량을 카메라에 먼저 반영하고, 진행 방향을 앞서 보는 차이만 부드럽게 따라간다. 급한 확대나 출항 직후의 남은 차이도 화면 90px 안으로 제한한다. 작은 해도는 이동 중 0.3초 간격으로 다시 확인하고, 위치가 0.05도 이상 바뀌었으면 갱신한다.

마우스 따라가기 단추는 마우스 아이콘만 표시한다. 마우스를 올리면 기능·켜짐/꺼짐·단축키 설명이 나온다. 스크린 리더용 이름과 눌림 상태도 제공한다. 하단 메뉴의 바깥 너비만 보던 맞춤 계산을 실제 자식 요소 너비·여백·간격을 합산하도록 고쳐, 오른쪽 마우스와 설정 단추까지 화면 안에 들어오게 한다. 공용 단추를 쓰는 육상에서도 같은 아이콘과 맞춤을 사용한다.

## 넓은 해전

- 기본은 기함 중심 2.2배 보기다. 살아 있는 적 전부를 화면에 넣으려고 배를 작게 줄이지 않는다. 기함은 이동 중 같은 화면 자리에 유지된다.
- 항해와 동일한 실시간 3D 선박을 사용한다. 선회·돛·노·흔들림·피격·침몰을 전달하고, 화면에서 먼 선박은 그리기를 생략한다. 한 선박용 WebGL 장치를 공유하며 종료 시 해제한다. 해상 괴물은 기존 전용 표시를 사용한다.
- 일반 전장의 반지름은 1800에서 3200으로, 두 함대의 시작 간격은 약 760에서 1800으로 늘렸다. 포의 사거리·위력·선박 속력은 유지한다. 괴물과 호수 전투에는 각각 별도의 시작 간격을 둔다.
- 오른쪽 **전장 해도**는 전장 전체의 해안·퇴각 경계·아군(파랑)·적군(빨강)·현재 시야를 표시한다. 먼 적은 해도에서 보이고 접근하면 주 화면에 들어온다. 해도를 클릭하면 그곳을 살피고 **기함 보기**로 복귀한다. **전장 전체**에서는 선박 번호로 전체 배치를 살핀다.
- 휠·두 손가락은 화면 확대, +/−는 기존 해전 배속 조작이다. 전투 알림은 작게 두 개까지 표시해 큰 돛을 가리는 면적을 줄인다.

## 아군 포격 정지

**포격 정지 / 포격 재개(F)**는 기함·동행선·우군·호위선을 포함해 아군 전체에 적용한다. 적의 포격과 이미 날아가는 포탄은 유지한다. 정지 중에도 재장전은 진행하며 재개 때 장전 상태를 초기화하지 않는다.

정지 중 적함을 누르면 기함이 백병전 거리까지 접근한다. **백병전(B)**도 기존 이동 목표와 포격 전술을 풀고 적함으로 접근한다. 백병전 판정·선원 피해·나포 규칙, 충파와 적의 행동은 유지한다.

포격 정지·시점·전장 반지름은 해전 저장에 함께 남는다. 예전 해전 저장에 반지름이 없으면 종전 1800을 사용한다. 해도용 임시 캔버스는 저장하지 않는다.

## 조정과 검증

### 기함 포격 사거리·장전 게이지 추가

쉬움(`easy`)·보통(`normal`)에서는 기함의 좌현·우현 포와, 장착된 경우 선수 포의 범위를 표시한다. 어려움에 해당하는 엄격 규칙(`original`)과 `hard` 등 나머지 난이도에서는 범위와 안내를 모두 숨긴다. 포가 없거나 기함을 잃었을 때도 표시하지 않는다.

- 실제 `gunnery`와 안내가 같은 `gunZones`를 사용한다. 일반 현측 포·갤리의 좁은 선수 포·거북선의 용머리 포구뿐 아니라 약한 근접·추격 사격 범위도 구별한다. 기존 사거리·사격 각도·위력·장전 시간은 그대로다.
- 황금색 면과 호가 장전량에 맞춰 차오르고, 준비되면 청록색 **발사 준비**가 된다. 좌현·우현·선수는 각자의 장전 시간을 사용한다. 사거리 끝을 실제보다 줄이지 않으며, 가까운 호와 남은 시간 안내로 확대 상태에서도 진행도를 읽을 수 있다.
- 포격 정지 중에도 장전은 이어지지만, 표시를 회색으로 하고 **장전 완료 / 포격 정지**로 구분한다. 일시정지 중에는 장전 게이지도 멈춘다.
- 발사 시점의 전체 장전 시간을 `reloadTotal`로 기록한다. 그 주기의 남은 시간과 비교하므로 장전 도중 선원이 줄어도 게이지가 튀지 않는다. 저장·복원에도 유지하며, 해당 값이 없는 옛 해전 저장은 기존 장전 계산식으로 표시한다.
- 색·불투명도·선 두께·가까운 호의 크기는 `G.FX.battleGunnery`에 모았다. HTML 안내는 색 외에도 장전율·남은 시간·준비 여부를 글로 표시한다.

`tests/battle_gunnery_guide.cjs`는 실제 본편에서 난이도별 표시, 양현/선수 포의 범위, 장전·일시정지·포격 정지, 장전 주기 저장과 옛 저장, 12가지 거리·방향에서 실제 포탄 발사를 검사한다. GPU·소프트웨어 결과와 화면은 `artifacts/battle-gunnery-20261031/gpu/`와 `software/`에 나눠 남긴다.
