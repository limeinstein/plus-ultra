# 항해 지도 확대와 기본 선박 선명도 (2026-10-31)

기본 항해 화면의 배 크기는 그대로 두고 선명도를 높였다. 지도를 확대해도 선박이 고정된 픽셀 크기로 표시되던 경로를 수정해, 확대할수록 실제 3D 선박도 커진다. [본편 실행](../../index.html).

## 표시와 조작

- 기본 배율 110에서는 기함 66, 동행선 53, NPC 38의 기존 표시 길이를 유지한다. 선종별 실제 외곽 크기는 모형의 길이·돛대 높이·방향에 따라 다르다.
- 배율 26~2400에서 선박 표시 배수는 `(지도 배율 / 110)^0.55`이다. 최대 확대 시 기본보다 약 5.45배 크다. 기함·동행선·호위선·NPC와 기존 이미지 대체 경로에 함께 적용한다.
- 오른쪽 위에서 지도 배율을 확인하며 `−`, `+`, **선박 확대**, **기본**을 사용할 수 있다. 휠·+/− 키·두 손가락 제스처도 같은 확대 범위를 사용한다.
- 선박이 커지는 프레임에 대열 간격도 함께 조정한다. 가까이 볼수록 간격을 더 벌리고, 카메라가 기함보다 앞서가는 거리는 화면 기준으로 제한한다. 최대 확대에서는 먼 동행선이 화면 밖으로 나갈 수 있다.
- 기본 선박도 256px 이상의 내부 화면과 2배 샘플링으로 그린다. 기함·동행선의 자체 그림자로 망루·난간·갑판의 명암을 구분한다. 근접 내부 화면 상한은 1280px이다. 작은 기본 화면에는 표시할 수 있는 픽셀의 한계가 있으므로 세밀한 줄·못은 확대해서 살핀다.

## 코드와 조정값

`js/data/seafx.js`의 `G.FX.ship.zoom`에서 확대 범위, 기준 배율, 선박 배수, 대열 간격과 카메라 앞서 보기 한도를 조절한다. `G.FX.ship3d`의 `minBuffer`, `maxBuffer`, `supersample`, `shadowMinLen`은 선명도와 그림자 조정값이다.

`js/scenes/sea.js`는 표시용 크기와 기존 크기를 분리한다. 항적·물보라·파도 자세·선택 고리·NPC 선택 범위는 보이는 크기를 따른다. 해안 접근 판정은 종전 배율 26~420의 동작을 유지하고, 새 근접 구간에는 종전 최대 배율 420의 판정을 사용한다. 선속·항로·선박 능력치·저장 형식과 파도 식은 바꾸지 않았다.
