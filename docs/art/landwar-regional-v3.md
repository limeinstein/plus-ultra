# 육상전 지역 병종·기병·동물 V3

2026-10-24에 육상전의 나머지 지역 병종, 기병, 들짐승을 15~16세기 기준으로 다시 그렸다. 모든 원화는 ImageGen의 투명 배경 편집/생성 모드로 만들었고, 원본 출력은 `artifacts/landwar-regional-v3/sources/`에 보존한다.

## 기병 LV0~LV3

- `cavalry_horse`: 정찰 기수 → 경기병 → 베테랑 창기병 → 중장 정예 기병
- `cavalry_camel`: 대상 정찰대 → 사막 경기병 → 갑주 낙타 창기병 → 정예 지휘 기병
- `cavalry_elephant`: 사역 코끼리 → 호위 코끼리 → 전투 코끼리 → 정예 지휘 코끼리
- 우리 편 식별색은 베이지·아이보리·흰색이다.
- 기병 단계도 보병과 같이 제독과 모든 동료의 가장 높은 검술(`R.skillRead('sword')`)을 받는다.
- 탐험대용 8방향 시트와 분리된 전투 전용 시트이므로 공격·피격·쓰러짐·후퇴가 육상전 동작에 맞는다.

## 지역별 적 무장

- 동아시아: 실용적인 시노비 정찰병, 명식 창병·도병, 조선 군관, 산적
- 오스만: 아자브 방패병, 톱추 포병, 예니체리 화승총병
- 서·중앙아프리카/아메리카 지휘 병종: 초자연 효과를 없애고 실제 재료와 무장으로 정리
- 서유럽: 로델레로, 란츠크네히트, 쇠뇌병, 스트라디오트, 스트렐치
- 페르시아·중앙아시아·인도: 키질바시, 아프간 보병, 라지푸트, 무굴 화승총병, 기마궁수
- 동남아시아: 말레이, 자바, 아유타야, 대월, 몰루카·필리핀 병종
- 아프리카: 서아프리카 궁수, 사헬 창병, 콩고 도끼병, 에티오피아 방패병, 스와힐리 해안 경비병
- 메소·남아메리카, 북아메리카, 태평양 지역도 시대·지역별 무기와 직물·목재·방패 재료를 나눴다.
- 모든 적은 고유 복식 색을 유지하면서 짙은 갈색·먹색 띠, 허리띠, 방패 테두리로 피아를 구별한다.

## 들짐승과 악어

- 멧돼지·사자·재규어·호랑이·곰·하이에나의 해부 구조와 종별 무늬를 다시 다듬었다.
- 악어는 긴 몸 때문에 기존 6행 시트와 분리한 `crocodile` 1행 28프레임 시트다.
- 인도, 동남아시아, 스와힐리 해안, 마야·카리브·아마존, 북부 오스트레일리아·파푸아의 사냥/짐승 전투에 악어가 나온다.
- 악어도 걷기·돌진·물기·피격·쓰러짐·꼬리 회전·위협 동작과 피혁 전리품을 가진다.

## 제작과 연결

- 원화: `images/_extra/sprite_src/*.png` (저장소 제외)와 `artifacts/landwar-regional-v3/sources/`
- 게임용 시트: `images/sprites/*.webp`
- 프레임 재포장: `python tools/sprite_repack.py`
- 지역/기병 매핑: `js/data/landwarart.js`
- 전투 렌더링: `js/games/landwar.js`
- 사냥/사건 그림: `js/data/hunt.js`, `js/systems/hunt.js`, `js/art/eventfx.js`
- 그림 프롬프트는 기존 행 순서와 동작 프레임을 보존하는 편집 프롬프트를 사용했고, 기병·악어는 새 투명 스프라이트 시트 생성 프롬프트를 사용했다.
