# 몽골·만주와 국내성의 배경

사용자가 확인한 9곳과 국내성 모두를 반영했다. 같은 곳을 두 번 만들지 않도록 귀화성은 기존 후허호토, 콥도는 기존 호브드, 에르덴 조는 기존 카라코룸에 연결했다. 나머지 7곳을 ID 309~315로 추가했다. 기존 ID·좌표·원본 배경은 보존했다.

| ID | 거점 | 처리·배경 |
| --- | --- | --- |
| 143 | 콥도 / 호브드 | 기존 도시·알타이 산록과 강가 초원 |
| 144 | 에르덴 조 / 카라코룸 | 기존 도시·사원군, 게임의 기존 발견물 연대에 맞춰 1585년부터 새 배경 |
| 296 | 귀화성 / 후허호토 | 기존 도시·초원의 성곽과 사원 |
| 309 | 장가구 / 칼간 | 새 도시·장성 관문과 대상길 |
| 310 | 차하르 올도 | 새 거점·칸의 게르 궁정과 유목민 야영지 |
| 311 | 굴자 / 일리 | 새 거점·천산과 일리 계곡의 교역 마을 |
| 312 | 심양 | 새 도시·성벽과 궁정 지붕 |
| 313 | 길림 | 새 거점·송화강 나루와 목조 마을 |
| 314 | 요양 | 새 도시·성벽과 백탑 |
| 315 | 국내성 | 새 거점·고구려 돌성벽의 옛터와 강가 마을 |

모든 배경은 내장 imagegen으로 개별 생성한 16:9 회화풍 이미지이며 실제 유적의 실측 복원이 아니다. 전경은 게임의 건물·인물이 겹쳐도 읽히도록 비워 두었다. 기존 3곳은 `images/backgrounds/steppe-20261030/`, 새 7곳은 `images/backgrounds/`에 1600×900 JPEG로 저장했다.

차하르 올도는 이동 궁정의 대표 좌표를 사용한다. 굴자는 후기 성곽 도시의 창건을 앞당긴다는 뜻이 아니라, 앞선 시대의 일리 계곡 교역 거점까지 묶은 표현이다. 국내성은 당시 존속하는 고구려 왕국으로 표시하지 않고 옛 왕도 성터로 설명한다. 심양은 1621년 전에는 명의 성곽 도시라는 설명을 쓴다. 역사 배경은 시대를 압축한 게임용 표현이다.

시대별 지배 관계의 추가 자료와 별칭·설명·배경 키는 `js/data/steppecities.js`에 두고 기존 생성 자료 뒤에 로드한다. 도시 원본 목록은 `tools/world/cities_src.py`와 `js/data/cities.js`에 함께 반영했다. 이번 작업에서는 웹 검색 서비스가 503을 반환해 외부 사료의 추가 검증을 완료하지 못했다. 연대 일부는 저장소의 기존 발견물·도시·지배 관계 자료를 따랐으며, 새 관계는 명·후금·청 등 큰 전환을 단순화했다.

생성 지시문·원화 경로: `tools/north_city_sources_20261030.json`. 내보내기: `python tools/north_chart_art.py`. 그림 등록: `python tools/images.py`. 미리보기: `docs/art/north-cities-20261030.jpg`.

`node tests/north_chart_smoke.js`는 실제 Chromium file://에서 육지 좌표·교역품·ID·별칭 검색·시대별 배경 선택·심양 지배 관계·옛 저장의 시장 생성·10곳의 거리 배경과 건물 적용·브라우저 오류를 확인한다. 결과와 실제 거리 검토판은 `artifacts/north-chart-20261030/`에 저장한다.

검증 결과: 새 기능 49개 검사와 10곳의 실제 거리 배경 적용을 통과했다. 기존 `chart_survey_smoke.js` 36개 검사, `chart_hint_marks_smoke.js`의 단서 선택·수첩 이동, `city_backgrounds_smoke.js`의 전체 316개 배경 등록·선택 검사와 거리 화면 검사도 통과했다. 브라우저 오류는 0개이며 시험용 브라우저는 모두 종료했다.
