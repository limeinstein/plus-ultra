# 조선소 돛 모양·문양 작업실

구현·검증: 2026-11-23~24. 조선소 → 개조 → 배 선택 → **돛 모양·문양**. 도안을 찾고 바탕색과 문양색을 고른 뒤 실제 배 미리보기와 항목별 견적을 보고 적용한다. 취소하면 돛과 금화는 유지된다. 같은 설정은 무료다. 계류한 내 배도 개조할 수 있고 빌린 배는 제외한다.

## 모양과 도안

- 선종 고유 범장 복원, 사각돛, 라틴 삼각돛, 사다리꼴 종범장, 대나무 살돛, 기울어진 탄자돛. 선택한 모양에 맞춰 3D 천·활대·돛살과 접기 동작을 함께 만든다. 삼각돛·종범장·탄자돛은 기존 `lat` 성능 계열이다. 거북선은 덮개와 전용 돛 접기 구조를 보존하며 색과 문양만 바꾼다.
- 단색·줄무늬 5종, 국가 290종, 왕실·황실 15종, 귀족·가문 13종, 해적 4종. 총 327종. 국가 목록 전체를 빠짐없이 지원하되 **270종은 국가색·국명으로 만든 창작 표장**이라고 이름과 설명에 명시한다. 20종의 국가 도안도 역사 상징을 간략화한 게임 장식이며 당대 실제 돛이나 정식 문장의 완전한 복원이 아니다. 게임의 시대별 국가 목록에는 17세기 밖의 국가도 포함된다.
- 왕실: 아비스·브라간사·합스부르크·부르봉·튜더·스튜어트·올덴부르크·바사·로마노프·조선·명·청·일본 황실·오스만·무굴. 오스만의 튜그라풍 장식은 특정 술탄의 실제 서명을 복제하지 않은 창작 도안이다.
- 가문: 메디치·파르네세·오라녜나사우·퍼시·더글러스·스포르차·에스테·도쿠가와·도요토미·오다·다케다·시마즈·모리. 동아시아의 용보·가몬은 원형 바탕으로, 서양 문장은 방패형으로 배치한다.
- 해적: 해골과 교차 뼈, 교차 칼, 붉은 줄무늬와 해골, 검은 줄무늬와 해골. 넓은 시대를 아우르는 게임용 도안이다.

첨부 그림은 줄무늬·십자·가문 문장·해골의 배치 참고로만 썼다. 픽셀·워터마크를 재사용하지 않고 Canvas로 그린 원본 도안을 쓴다. 문양 변경으로 실제 국적·외교 관계는 바뀌지 않는다. 다색 표장의 일부 고정색은 유지한다.

## 높은 개조비

`G.BALANCE.sailRefit`에서 관리한다. 기본 선가를 P, 게임상 돛대 수를 N이라 하면 아래 금액에 해당 항구의 배 물가를 곱하고 항목별로 10닢 단위 올림한다. 고른 항목이 바뀔 때만 청구한다.

- 모양·삭구 전체 교체: `max(6,000, P × 22%) + N × 1,800`.
- 바탕 천 염색: `max(1,500, P × 4%) + N × 600`.
- 도안 작업: 아래 최저 제작비와 선가 비율 중 큰 값에 `N × 450` 공임을 더한다.
  - 단색 복원 2,000닢·4%, 줄무늬 4,000닢·8%.
  - 국가 10,000닢·15%, 왕실 22,000닢·30%.
  - 귀족 18,000닢·25%, 해적 7,000닢·12%.
- 기존 「돛 바꾸기」와 「돛 일괄 변경」도 돛 하나당 `max(2,500, P × 8%)`에 같은 물가를 적용한다. 단색 빠른 염색도 새 염색 견적을 쓴다. 싼 기존 메뉴로 우회할 수 없다.

물가 1.0에서 슬루프의 사각돛 교체 + 왕실 문양 + 염색은 32,350닢, 갤리온의 왕실 문양만은 23,800닢, 전열함의 왕실 문양만은 41,850닢이다. 실제 항구·연도에 따라 물가가 붙는다. 1670년 리스본 검사에서는 슬루프 세 항목 합계 69,080닢을 정확히 차감했다. 원래 모양·천·도안으로 복원하는 작업도 유료다.

## 저장·렌더링

`sailShape`, `sailDesign`, `sailInk`, `sailColor`를 배에 저장한다. 값이 없는 옛 저장은 선종 고유 범장과 천을 사용한다. 기존에 돛대별로 개조한 배는 문양만 바꾸면 그 범장을 유지하며, 「원래 범장 복원」을 눌렀을 때만 복원 비용을 낸다.

항해·해전·해전 복원·배 도움말·조선소 미리보기에 같은 설정을 전달한다. 3D 그림 캐시는 모양·도안·바탕색·문양색을 구별하고, 선종이 같아도 서로 다른 장식이 섞이지 않는다. 기존 사전 촬영 시트는 개조된 배에서 건너뛴다. 2D 대체 그림에도 문양을 표시하며, 세밀한 종범장·탄자돛 실루엣은 실시간 3D를 기준으로 한다.

천은 기존 솔기·보강천·직조 지도와 요철을 유지한다. 원본 지도와 독립된 CanvasTexture를 재사용하며 도안을 바꿀 때마다 그래픽 자원을 늘리지 않는다. 제작 원본은 `tools/ship3d/rig_detail.js`, `runtime_rig.js`, `build_runtime.py`, 미술 도안은 `js/art/saildesign.js`, 규칙과 UI는 `js/systems/saildesign.js`, `js/city/sailworkshop.js`다. 생성은 `python tools/ship3d/build_runtime.py`.
