첨부된 얼굴 10장을 참고해 새 성인 여급을 만들었다. 이름 있는 여급이 없던
도시 10곳에 배치했으며 기존 175명과 함께 모두 185명이다. 기존 여급을
교체하거나 저장 파일의 인물 ID를 바꾸지 않는다.

## 그림과 연결

- 실사 사진 질감 대신 기존 게임 여급의 채색 초상화풍을 기준으로 만들었다.
  표정·눈·입 모양은 인물마다 별도로 지정했다. 단순한 천과 지역별 색을 사용한다.
- 생성은 내장 `image_gen` 도구를 사용했다. 입력 역할과 프롬프트는
  `maids1550-prompts.json`, 선택된 원화 기록은 `artifacts/maids1550/`에 둔다.
- `images/portraits/maids/m_1550_<도시>.webp`: 얼굴상 1024×1024.
- 같은 이름의 `_half.webp`: 무릎상 1024×1536. 두 그림은 같은 원화에서 만든다.
- 생성된 투명 PNG의 알파 1~4에 남아 있는 숨은 형광 RGB를 제거하고 원본의
  가로세로 비율을 유지해 배치한다. 녹색 배경으로 다시 누끼를 따지 않는다.
- `js/data/people.js`에 고유 ID·이름·도시·취향과 `from: 1550`을 등록했다.
  기존 `G.maidAvailable`, `G.baseMaidAt`, `G.MaidSwap.at`을 그대로 사용하므로
  1549년까지는 미등장, 1550년부터 술집과 대화에 등장한다. 도감은 등장 연도를
  표시하며 전용 초상을 사용한다. 얼굴 리그 좌표도 새 그림에 맞춰 등록한다.

## 이미지 도구의 제한으로 남은 의상 수정

천주·비즈비의 목선·어깨 노출을 늘리는 생성 요청은 이미지 도구의
안전 필터가 거절했다. 이 두 명은 기존 작업복의 가림 범위를 유지하면서
게임 채색화풍과 원본 표정만 수정했다. 요청한 의상 변경까지 모두 끝났다고
표시하지 않는다. 기능상 등장·얼굴상·무릎상 연결은 다른 여덟 명과 같다.

2026-10-28: 한산도 윤소월은 사용자가 새로 첨부한 한복에 맞춰 옅은 하늘색
저고리, 푸른 속치마와 밝게 흐르는 겉치마, 가는 허리띠와 긴 고름으로
복장을 교체했다. 기존 얼굴·차분한 표정·긴 머리·게임 채색화풍과 쟁반 자세를
유지했으며 같은 원화에서 얼굴상·무릎상을 함께 갱신했다.

```powershell
node tests/maids_1550_smoke.js --browser
node tests/maid_restoration_named_smoke.js
node tests/sea_maidens_as_maids_smoke.js
node tests/maids_europe_smoke.js
```

새 검사에서는 1480·1549·1550·1600·1700년의 선택 결과, 고유 이름·도시,
전용 얼굴상·무릎상과 얼굴 리그 좌표를 확인한다. 브라우저에서는 10곳의
실제 술집 소개·대화 초상과 이미지 20장의 로드를 확인하고, 조선·잉글랜드·
아라비아 여급의 대화창을 저장한다. 시험을 마치면 브라우저를 닫는다.

실행 파일 제작이나 웹 게시까지 진행하지 않고 프로젝트의 자료·그림에 반영한다.
