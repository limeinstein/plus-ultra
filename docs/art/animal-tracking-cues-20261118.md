# 새의 낙하 깃털과 수중 동물의 수면 흔적

2026-11-18 요청을 반영해 새 31종의 흔적은 종별 색을 살린 깃털로, 수중 51종의 흔적은 거품·물결·물보라로 바꿨다. 땅 위의 새도 발자국 대신 깃털을 쓴다. 바다 위를 나는 알바트로스는 깃털을, 바다에서 헤엄치는 황제펭귄·마젤란펭귄은 수면 흔적을 쓴다. 해상 장면은 종 분류와 무관하게 발자국 그리기를 호출하지 않는다.

깃털은 위에서 아래로 내려오며 좌우로 흔들리고 회전한다. 수면에는 거품과 물방울이 생기고 타원형 물결이 퍼지며 옅어진다. 일부 지점에는 튀어 오르는 물보라를 더한다. 방향과 무관하게 깃털은 화면 아래로 떨어지고 물결은 수면에 수평으로 퍼진다. 해상 경로 중 육지 위 구간은 수면 흔적을 그리지 않는다.

현재 게임의 자국 따라가기·진행도·회색에서 색으로 바뀌는 발견 그림·놀라 달아나기·명성 보너스는 유지했다. 첫 안내와 진행 중 부하의 말은 깃털·수면 흔적에 맞췄다. 조정값은 `G.FX.animalTracking.airborne`, `G.FX.animalTracking.aquatic`에 둔다.

게임에서는 Canvas 2D로 매 프레임 부드럽게 그리며 새 이미지 로딩은 필요 없다. 별도로 재사용할 수 있도록 `artifacts/animal-tracking-20261118/cue-sprites.png`에 8프레임×4행 투명 스프라이트 시트도 내보냈다. 한 칸 96×64, 행 순서는 홍학 깃털·알바트로스 깃털·돌고래 수면·고래 수면이다. 깃털 한 주기 4.4초, 수면 2.8초.

전체 261종 갤러리의 흔적도 실제 시간에 따라 움직이도록 갱신했다. 개별 이동 흔적 PNG 261장과 기존 ZIP 묶음도 새 표현으로 다시 내보낸다.

검사: `node tests/animal_tracking_cues_20261118.cjs` — 새 31종·수중 51종, 전체 261종의 해상 그리기에서 발자국 호출 0, 시간에 따른 깃털·물결 변화, 콘솔 오류 0. 기존 전체 원화·근접 발견·뭍/바다 장면·갤러리 검사도 실행한다. 미리보기는 같은 폴더의 `preview.png`.
