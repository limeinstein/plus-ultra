# 전체 발견물 GIF 연결 점검·누락 원화 보완

2026-11-26 작업 기록. 본편·이야기 전용·튜토리얼을 포함해 실제 자료 순서로 읽은 발견물은 1,744종이다.

최초 검사에서 기존 1,306종의 GIF는 모든 프레임이 열리고 실제 장면 변화가 있었다. 최근 발견 대사 원고에서 추가된 `discStoryNew` 438종은 GIF·마지막 장면·재생 시트와 세 종류의 그림 목록 등록이 모두 없었다. 기존 끝 장면 중 18종의 1440×640 원화는 정상 고해상도 그림이므로 그대로 보존한다.

## 제작과 연결

- `tools/discovery_gif_repair_20261126/sources/<ID>.png`: 내장 ImageGen으로 개별 제작한 전용 원화. 각 발견물의 이름·설명·갈래를 지시문에 포함한다. 해당 폴더의 JSON에 실제 생성 지시문과 출처를 남긴다.
- 랄리벨라는 안개 속 접근부터 교회 전경까지의 4×4 원화다. 다른 발견물은 각 대상의 전용 풍경·인물·동식물·유물을 그린 단일 원화에서 완만한 확대·이동 장면을 만든다. 단일 원화의 카메라 이동은 생물의 독립적인 관절 애니메이션을 뜻하지 않는다.
- `images/discoveries/<ID>.gif`: 576×256, 24장면. `G.FX.reveal`의 원본 GIF 재생 시간에 맞춰 식물·보물·교역품은 8.4초, 나머지는 9.82초다. 공통 256색 팔레트로 색 깜빡임을 줄인다.
- `images/discovery-ends/<ID>.jpg`: 576×256 마지막 장면.
- `images/discovery-sheets/<ID>.webp`: 3456×1024, 6열×4행, 24장면. 웹·파일 실행판은 기존 `G.Reel`로 재생하고 원본 GIF 우선 설치판은 기존 GIF 경로를 쓴다.
- `images/manifest.js`에 각 대상의 위 세 경로를 추가한다. 기존 발견물 ID·게임 규칙·저장 형식은 바꾸지 않는다. 표준 경로이므로 `tools/images.py`가 목록을 다시 만들어도 유지된다.

재출력: `python tools/discovery_gif_repair_20261126/build.py`. 원화가 바뀌었거나 결과 파일이 없을 때 해당 세 파일을 만들며, 완료한 파일만 목록에 등록한다.

전체 미리보기에서 메르카토르 지구의(`ds_453`)는 구형 지구의가 크게 보이도록, 상서로운 기린(`ds_828`)은 아프리카 기린 대신 설명의 전설 생물이 나오도록 수정했다. 첫 원화는 `sources/<ID>-v1.png`와 JSON에 보존했다. 최종 438종의 지시문은 `tools/discovery_gif_repair_20261126/prompts.json`, 원화·결과 파일의 SHA-256은 같은 폴더의 `assets.json`에 있다. 전체 그림 모음 9장은 미리보기 폴더의 `contact-01.jpg`~`contact-09.jpg`다.
