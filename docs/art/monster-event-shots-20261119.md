# 인간형 괴물 7종의 만남과 결말 사건샷

내장 `image_gen`으로 기존 괴물 이야기의 만남과 두 갈래 결말, 총 21장을 제작했다. 각 파일은 기존 사건 액자 규격인 1881×836의 독립된 가로형 WebP이며, 두 장면을 한 이미지에 합치지 않는다. 게임 파일은 `images/monster-events/<괴물>_<장면>_20261119.webp`이다.

- 리치 오스발트: 납골당의 부탁, 심장석을 깨뜨린 안식, 심장석을 빼앗긴 끝없는 기다림.
- 흡혈귀 세베린: 일로나의 초상 앞 만남, 창을 연 뒤 햇살 속 죽음과 은 로켓, 창을 닫고 살아서 치르는 죗값.
- 늑대인간 야니스: 보름달 아래 길을 막는 늑대인간, 교구 인도, 놓아준 뒤 받는 보리 씨앗.
- 해골 기사 르노: 탑을 지키는 기사, 원군의 진실을 들은 뒤 안식, 거짓말을 믿고 칼을 내준 뒤 계속되는 수호.
- 트롤 그룬: 빨간 리본을 품은 만남, 새벽빛을 피해 동굴에 숨겨 주기, 리본을 쥔 채 바위가 된 결말.
- 미노타우로스 아스테리온: 별무늬 미궁의 만남, 별 아래 마지막 잠, 문을 열어 주고 떠나는 결말.
- 예티: 새끼를 지키는 어미와의 만남, 길을 돌아 지나가기, 눈밭에 떨어진 털만 얻기. 원래 이야기처럼 어미와 새끼가 살아 있는 장면이다.

만남 대사와 겨루기 선택에 첫 그림을 띄우고, 결투 시작 직전에 닫는다. 결투 뒤 선택한 결말의 대사에는 해당 그림을 띄운다. 물러서기·패배·정상 종료·대화 예외에서 액자를 정리하며, 바깥 발견 그림은 잠시 숨겼다가 복구한다. 승리·패배 직후의 대사에는 별도 신규 원화를 배정하지 않는다. 기존 엘프 사건샷 4장은 유지한다.
