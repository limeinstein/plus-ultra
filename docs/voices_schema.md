# 말투·이야기 자료 규격 (js/data/voices*.js → js/systems/voice.js)

게임: PLUS ULTRA (대항해시대3 풍 웹게임, 1480~1900년대). 플레이어 = 「제독」(대개 남자. 아이들은 「아버지」라고 부른다).
모든 글은 한국어, 이 게임을 위해 새로 쓴다. 영화·애니메이션·현대 소설의 대사나 고유 설정을 베끼지 않는다
(원전이 공개 저작물인 옛이야기·고전 소설·역사 기록에서만 소재를 가져온다). 한 마디는 되도록 90자 안쪽, 길어도 130자.
게임 안 말씨는 쉬운 우리말을 즐겨 쓴다(한자어·외래어를 줄이고 풀어 쓴다). 따옴표 안에 따옴표가 필요하면 「」를 쓴다.
JS 문자열은 작은따옴표 '…' — 글 속의 작은따옴표는 쓰지 말 것(대신 「」).

## 말씨 (reg)
- `hao` 하오체: ~하오 · ~이오 · ~겠소 · ~하시오 (어른 남자 기본)
- `hage` 하게체: ~하네 · ~하게 · ~인가 · 자네 (나이 든 남자, 윗사람 티)
- `yo` 해요체: ~해요 · ~예요 (여자 기본, 다정한 말)
- `sp` 하십시오체: ~합니다 · ~입니까 · ~하십시오 (군인·기사·예의 바른 사람)
- `ban` 반말: ~해 · ~야 · ~냐 (거친 사람·아이·소년 만화형)
부하는 제독에게 말한다. 말씨는 사람마다 한결같이.

## 1. 이벤트 부하 한 사람 (G.VOICES[id])
```js
(function (G) {
  'use strict';
  var V = G.VOICES = G.VOICES || {};
  V.guan_yu = {
    reg: 'hao',
    greet: { hi: ['…', '…'], mid: ['…', '…'], low: ['…'] },     // 마주 앉을 때 첫마디 — 충성 85 이상 / 보통 / 45 아래
    chat: { hi: ['…', '…', '…'], mid: ['…', '…', '…'], low: ['…', '…'] },   // 「요즘 어떤가」 대답 (그 사람다운 근황·생각·버릇)
    love: { a50: ['…', '…'], a80: ['…', '…'] },   // 여자이고 아이가 아닐 때만: 제독에게 마음이 기울 때(호감 50·80 이상) chat 대신
    again: ['…', '…'],                            // 이야기를 이어 갈 때 묻는 말 (「또 무슨 이야기를?」 같은)
    drink: ['…', '…'], drinkDone: '…',            // 한잔 살 때 / 오늘은 이미 마셨을 때
    lifeIntro: ['…'],                             // 「살아온 이야기」를 꺼내기 전 한마디
    stories: [                                    // 「옛이야기를 청한다」 — 한 번에 한 편씩 차례로. 4~6편, 한 편 3~5마디
      { t: '제목', l: ['첫 마디', '둘째 마디', '셋째 마디'] }
    ],
    wife: {                                       // 여자이고 제독의 아내가 될 수 있는 사람만 (아이·마녀 빼고)
      greet: ['…', '…'], away: ['…'], nokids: ['…'], preg: ['…{n}달…'], home2: ['…', '…']
    }
  };
})(window.G = window.G || {});
```
- 이야기(stories)는 그 사람만의 일화: 원전의 한 장면을 제 입으로 회상하거나, 게임 속 사건(제독과 만난 일)을 돌아보거나, 엉뚱한 버릇·꿈·두려움.
  마지막 편은 제독과 함께하는 지금에 대한 속마음으로 맺으면 좋다.
- greet/chat 은 짧고 성격이 드러나게. 같은 말을 되풀이하지 않게 서로 다르게.
- `{p}` 를 쓰면 제독 이름으로 바뀐다 (드물게만).
- wife: greet = 고향 자택에서 제독을 맞을 때, away = 오래(300일 넘게) 집을 비웠다 돌아왔을 때, nokids = 아이가 없을 때,
  preg = 배 속 아기 이야기({n} = 몇 달 남았는지 숫자), home2 = 둘째 부인으로 제 집에서 맞을 때.

## 2. 보통 부하의 말투 갈래 (G.VOICE_TYPES[key]) — 같은 모양 (stories·wife 없음)
key: `rush` 돌진형 · `noble` 귀공자형 · `merch` 상인형 · `hidden` 숨은 능력자형 · `genius` 천재형 · `shonen` 소년 만화형 (남자)
     `charm` 매혹녀형 · `cute` 귀여운형 · `tsun` 츤데레형 · `grumpy` 항시 불만형 · `plain` 일반형 · `polite` 예의바른형 (여자)
     `old_m` 나이 든 남자 · `old_f` 나이 든 여자 · `child_m` 소년 · `child_f` 소녀 · `witch` 마녀
각 갈래: reg, greet{hi,mid,low} 3·3·2마디, chat{hi,mid,low} 4·4·3마디, (여자 갈래만) love{a50,a80} 3·3마디, again 3, drink 3, drinkDone 1, lifeIntro 2.

## 3. 요령 (G.VOICE_TIPS[특기]) — 말씨마다
```js
G.VOICE_TIPS = { nav: { hao: '…', hage: '…', yo: '…', sp: '…', ban: '…' }, med: {…}, acct, sword, gun, theo, survey, ship, speech, def }
```
뜻은 그대로(아래 원문), 말씨만 바꾼다. 원문(하게·해요):
- nav: 긴 항해 전에는 물을 넉넉히 싣게. 바람이 멎으면 물이 먼저 바닥나는 법이지.
- med: 괴혈병은 신 과일과 싱싱한 채소로 막을 수 있소. 항구에 닿으면 꼭 챙기시오.
- acct: 멀리 갈수록 값이 오르지만, 상하는 물건은 오래 싣지 마시오.
- sword: 일기토에서는 상대의 첫 수를 흘려 보내는 게 좋소. 급한 놈은 제풀에 무너지지.
- gun: 바람을 등지고 쏘면 포연이 눈을 가리지 않소.
- theo: 낯선 땅의 사람들에게도 그들의 신이 있소. 존중하면 길이 열리지.
- survey: 곶마다 방위를 적어 두면 돌아올 때 길을 잃지 않소.
- ship: 자재를 넉넉히 실어 두시오. 바다 위에서 배를 고칠 수 있으니.
- speech: 처음 가는 항구에서는 먼저 웃고, 나중에 흥정하시오.
- def: 바다는 늘 한 걸음 앞을 보는 사람 편이지.

## 4. 아내 (G.WIFE_VOICES[like]) — 여급의 성품 like 8가지
`brave` 용감한 · `bold` 당당한 · `kind` 친절한 · `steady` 견실한 · `delicate` 섬세한 · `generous` 통이 큰 · `strong` 강인한 · `willful` 의지가 강한, 그리고 `witch` 마녀
각각: greet 4 · away 2 · nokids 2 · pregHint 2 (아직 말 안 했을 때 넌지시) · preg 2 ({n}달) · lowKid 2 ({kid} = 아버지와 서먹한 아이 이름) · baby 2 (갓난아기 이야기) · home2 3 (둘째 부인으로 제 집에서) · kids2 2 ({kids} = 그 집 아이들 이름, 「…이/가」 다음에 이어질 말: 예 「아버지를 기다려요.」로 시작하지 말고 완결된 문장으로, {kids}로 시작)
아내는 제독에게 해요체(때로 하오체·반말 섞인 부부 말씨도 좋다). 성품이 드러나게.

## 5. 아이 (G.KID_VOICES)
```js
G.KID_VOICES = {
  tod:   { m: { lively: { hi: [..2], mid: [..2], lo: [..2] }, calm: {…}, warm: {…}, stubborn: {…} }, f: {…} },   // 3~5살 (아빠라고 부름, 아기 말씨)
  kid:   { … },   // 6~11살 (아버지, 해요체)
  teen:  { … },   // 12~15살
  adult: { … },   // 16살 넘음 (아들: 하십시오체·해요체, 딸: 해요체)
  aboard: { m: { lively: [..2], … }, f: {…} },   // 견습으로 배에 탄 아이가 집에서 아버지에게
  react: { lively: { play: [..2], tale: [..2], story: [..2], storyCold: [..1] }, calm: {…}, warm: {…}, stubborn: {…} }
}
```
hi = 아버지와 가까움(사이 65 이상), mid = 보통, lo = 서먹함(30 아래).
성격: lively 활발(장난꾸러기) · calm 차분(책벌레) · warm 다정(정 많음) · stubborn 고집(말대꾸, 지기 싫어함).
react: play = 함께 놀아 준 뒤, tale = 옛날이야기를 들은 뒤(3~5살), story = 항해 이야기를 들은 뒤(6살~, 사이 30 이상), storyCold = 사이가 서먹할 때.
