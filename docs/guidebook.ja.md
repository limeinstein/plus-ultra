### 職業と難易度

- 年齢ボーナス：能力ポイント4 +（年齢 − 18）× 0.5、技能ポイント3 +（年齢 − 18）÷ 4。
- 知識ボーナス：知力40から15ごとに技能ポイント+1（最大+3）、知力99以上では+4。

### セーブ

- **自動セーブ** — プレイ中は1分ごとに5枠を順番に使い、古い枠から上書きします。設定で無効にできます。
- **宿屋の日誌** — 宿屋の「機能 → 航海日誌を記す（セーブ）」か自宅で、5枠から選んで記録します。
- 難易度「厳格なルール」では、自国の街の宿屋でのみ日誌を記せます。

#### 船首像の効果

| 効果 | 実際の働き |
| --- | --- |
| 速力 | 装備した船の速力+%（その船のみ） |
| 船体 | 海戦の砲撃・嵐による被害−% |
| 嵐 | 嵐の遭遇率−（3倍）%（最大−65%）・嵐の被害−（2倍）%（最大−30%） |
| 怪物 | その確率で海の怪物が退く・怪物からの被害−%（最大−50%） |
| 海戦 | 味方の砲撃命中率+% |
| 幸運 | 海上事件（幽霊船・氷山・浅瀬・熱病・セイレーン）を無事に乗り切る確率+（2倍）ポイント |
| 規律 | 航海中は毎日、規律+（2倍）。魔王像は減少 |

- 複数の船に装備した場合、同じ効果は最大のものを全量適用し、他の船の分は¼ずつ加えます。「艦隊」画面の下の「船首像の効果」で合計を確認できます。
- 神話の生物の船首像（妖精・一角獣・グリフォン・ペガサス・セイレーン・トリトン・麒麟・竜・不死鳥・ガルーダ）は造船所では売りません。アヴァロン・ユニコーン・ペルセポリス・パルテノン・トロイ・アトランティス・麒麟・黒竜・キーウの聖ソフィア・プランバナンなど、偉大な発見の遺物としてのみ得られます。
- ★伝説の船首像7種類は、伝説の海の怪物（リヴァイアサン・バクナワ・ザラタン・ヨルムンガンド・磯撫で・シパクトリ・幽霊船）を倒すと得られます。それぞれ特有の力があります。静かな海（嵐−88%まで）・母の懐（船員の損失半減）・癒える甲羅（毎日船体1%回復）・世界の果ての囁き（30日ごとに手がかり）・引く尾（速力効果が全艦に適用）・震える砲手（敵命中−12%）・呪い（魔王像。天使像・聖母像・ミカエル像・聖ニコラウス像で防止）。
- 遺物・伝説の船首像は取り外すか、その船を売却・廃棄すると所持品へ戻ります。

### 名の知れた海賊・指名手配・海賊旗

- 各海域では、歴史上や噂の海賊が海賊団を率いています。海賊集団の中にまれに現れます。
- **食堂の「手配書を見る」**：その街の海域で活動中の名の知れた海賊を表示します。クリックで肖像・海賊団・旗・懸賞金を拡大できます。艦隊を倒せば、どの港の食堂でも**「懸賞金を受け取る」**を選べます。
- **海賊の噂**：食堂の「客の海賊話を聞く」は訪問中に一度、無料で期限は短め。給仕の「謝礼を渡して情報を聞く → 名の知れた海賊の噂」は有料で期限に余裕があります。聞いた沖合へ期限内に向かうと、実際にその海賊艦隊が現れます。手帳の「やること」に記録されます。

## 能力値・技能・言語

提督の得意分野は、**能力値**（生まれ持った資質）、**技能**（学んだ技術）、**言語**（聞き取り話す力）の三つで決まります。この章では数値よりも「何に使うか」を説明します。

### 能力値 — 四つの資質

能力値は**体力・知力・武力・魅力**の四つで、手帳の「提督」にゲージで表示します。酒場の航海士カードや子供の教育では、体力を「力」と呼ぶこともあります。

- **初期値** — 若いほど体力・武力が高く、年齢が高いほど知力・魅力が高くなります。職業に合う能力が少し加わり、誕生日の星座が能力一つを後押しします。年齢が高いほど配分用のボーナスポイントも増えます。
- **人生で変わるもの** — 仕事で得た**経験**によって少しずつ上がり、爵位・結婚・世界一周などの**大きな出来事**でも上がります。
- **年齢** — 若いうちは体力が少しずつ増えますが、中年以降は毎年、体力と武力が減ります。晩年の冒険は知力と魅力が頼りです。
- **部下の能力値** — 部下にも四つの能力があります。代わりに一騎討ちへ出るとき、僚艦の船長として白兵戦を行うとき、報告・発表を助けるときに使い、口調や性格にも表れます。
- **仲間の加入** — 航海士ごとに好みがあり、相手が重視する能力値が高いと加入させやすくなります。

### 体力・知力

**体力** — 耐える力

- 一騎討ちで耐えられる体力が増えます。部下の場合、攻撃を受けても負傷しにくくなることがあります。
- 酒場で何杯飲んでも酔い潰れにくくなります。
- 宿屋の雑用で受け取る賃金が増えます。
- 経験：美食・戦闘・一騎討ちで成長します。中年以降は毎年少しずつ減ります。

**知力** — 学ぶ力

- 覚えられる技能と言語の**種類の上限**を決めます。提督作成や組合での修行の上限に関わります。
- 提督作成時に知力が高いと技能ポイントが増えます。最高水準の知力では追加ボーナスがあります。
- 組合の技能修行・言語学習が成功しやすくなります。宿屋の雑用で当地の言語を学ぶ速度も上がります。
- 一騎討ちで偽装退却・誘導・虚歩などの策が成功しやすく、相手の策にはかかりにくくなります。
- 非常に高い知力があれば、陸戦後に倒れた隊員を少し多く救えます。
- 自宅で子供とチェスをすると、提督と子供の知力を競います。
- 経験：取引・説得・社交、初めて読む本で成長します。

### 武力・魅力

**武力** — 戦う力

- 一騎討ちで攻撃が当たりやすくなり、威力が増し、先に剣を振るえます。
- 一騎討ちの決め技、一撃必殺・生け捕り・一喝が成功しやすくなります。非常に高い武力なら、相手の負傷が少なくても一撃必殺を狙えます。
- 僚艦を任された**部下船長の武力**は、その船の白兵戦攻撃力になります。提督の乗る旗艦は提督の武器で戦います。
- 借金の取り立てで「脅す」が通りやすくなり、外交で「共通の敵を思い出させる」に説得力が増します。
- 経験：戦闘・一騎討ちで成長します。中年以降は毎年少しずつ減ります。

**魅力** — 心をつかむ力

- 支援者との契約交渉、関心外の発見の説得、外国宮廷との条約交渉が成功しやすくなります。
- 交易所・市場の値引き交渉が成功しやすくなります。
- 借金の取り立てで「穏やかに諭す」、反乱の首謀者を言葉でなだめることが成功しやすくなります。
- 報告・発表の場で提督がそばで助けると成功しやすくなります。非常に高い魅力は異性の支援者に一層有効です。
- 一騎討ちで「説得」により剣を収めさせやすくなり、「一喝」にも威力が加わります。
- 経験：説得・社交・取引で成長し、爵位の授与や結婚でも上がります。

### 経験と成長

仕事を成し遂げるたび、その分野の**経験**がたまり、分野ごとに決まった能力値へ配分されます。

| 経験 | 獲得する場面 | 成長する能力 |
| --- | --- | --- |
| 説得 | 支援者の説得・交渉・疑いを解く・守備隊長との交渉・反乱の鎮静・借金の取り立て（言葉）・宮廷の条約交渉・一騎討ちの説得・報告の補助 | 魅力・知力 |
| 取引 | 交易所の売買（利益が大きいほど多い）・値引き交渉の成功 | 知力・魅力 |
| 戦闘 | 海戦・陸戦。勝つと多く、強敵ほど多い | 武力・体力・知力 |
| 一騎討ち | 提督本人が剣を交えた一騎討ち。部下の代理戦では獲得しない | 武力・体力 |
| 美食 | 食堂の一食。初めて味わう料理は二倍 | 体力・魅力・知力 |
| 社交 | 社交名声を得るたび | 魅力・知力 |

- 失敗からも少し学べます。説得に失敗しても、戦いに敗れても経験がたまります。
- **能力値が高いほど、1上げるのが大幅に難しくなります。**中ほどまでは早いものの、高い値では数年、数十年かかります。
- 一つの能力に一日・一年でためられる経験には上限があり、同じ仕事の繰り返しで一気に育てることはできません。一生かけても、経験だけで100に届くのはほぼ不可能です。
- **大きな出来事**でも上がります。爵位・初婚・イングランドの騎士叙任は魅力、消えた王女の救出・大海戦の勝利は武力、エリザベス王女の避難は知力、漂流記の刊行・世界一周は体力と知力です。すでに非常に高い能力は、直接上げず経験へ加算します。
- 上昇すると通知と航海日誌に残ります。手帳の「提督」の「経験と成長」で分野別経験と、次の1までの必要量を確認できます。

### 技能 — 段階と使い方

技能は17種類、**0〜3段階**（◇◇◇ → ◆◆◆）です。

- **誰の段階を使うか** — 提督、対応する役職（副官・航海士・測量士・主計）の部下、対応する船室の部下のうち、**最も高い段階**を艦隊全体に使います。
- **同行だけでよい技能** — 料理・音楽・絵画・細工は、役職がなくても技能を持つ人が艦隊にいれば多くの場面で使えます。壊血病を防ぐ医学も、誰か一人が乗船していれば有効です。
- **船ごとに使う技能** — 僚艦の砲撃・白兵戦・嵐の被害・修理は、その船の船長一人の技能で決まります。
- **忠誠が低い場合**、部下は十分に技能を発揮しません。負傷中も半分になります。

**技能の習得方法**

- **提督作成** — 職業の初期技能にポイントを加えて上げます。習得種類の上限は知力で決まります。
- **組合の「技能を鍛える」** — 金と日数をかけ、一段ずつ上げます。知力が高いほど成功しやすく、高段階ほど難しくなります。失敗しても費用と日数は消費します。
- **部下** — 船室で長く働くと、その部屋の技能が身に付きます。副官室は弁論、操舵室は航海術、見張り台は測量です。主技能★は3年・9年・27年で+1・+2・+3、補助技能☆は1.2倍遅く、3.6年・10.8年・32.4年で+1・+2・+3。例：海兵待機室は★剣術・☆射撃術。上限は3です。
- **子供** — 自宅での教育や見習い航海で成長し、提督の艦隊の技能まで学べます。成人（16歳）前は2段階が上限で、高段階ほど難しく、知力が高いほど学びやすくなります。同居する母の技能も学び、成人後に乗船すれば部下と同じく船室で学べます。
- 本を読んでも技能は上がりません。ただし学術書を読むには、その学問を知る人が必要です。

### 技能 — 船と海（1）

**航海術**（航海士・帆走作業室。僚艦ではその船の船長）

- 海上で毎日たまる疲労を減らします。
- 嵐に遭った際の船・船員・食料の被害を減らします。嵐そのものは避けません。旗艦の航海術は僚艦にも少し影響します。
- 船長の航海術が高い船は速く、向かい風を間切りで進む際の損失も減ります。
- 敵からの逃走、氷山・浅瀬の回避、津波の兆候の察知が成功しやすくなります。
- 航海術を知る人が一人もいなければ、出航時に副官が止めます。一部の航海学の本を読む際にも必要です。

**運用術**（航海士・甲板・帆走作業室・参謀室）

- 海上で船員の規律が落ちにくくなります。複数隻では遅い船を助けて曳航し、隊列の遅れを減らします。
- 陸上探検では歩みが速く、疲労が少なくなり、野営の休息効果が増えます。砂漠の酷暑や砂嵐の費用を減らし、吹雪や沼で隊員を守りやすくなります。
- 災害の被害を減らし、魚群から多くの魚を得て、釣りの当たりも増えます。
- 参謀室では陸戦の計略（奇襲・罠・狙撃）が成功しやすくなります。

### 技能 — 船と海（2）

**測量**（測量士・地図製作室・見張り台・参謀室）

- **2段階から海上で緯度が表示されます。**経度には六分儀が必要です。
- 未知の港を探せる範囲、海図を明らかにする幅、見張りの感知距離が広がります。陸上偵察も同様です。
- 手がかりなしでの海の発見物探し、海鳥を追っての新港発見、山の古道探しが有利になります。野営地で汲める水も増えます。
- 陸戦の奇襲・罠、災害の予兆の察知に役立ちます。宝の地図では、測量が高いほど多くの証拠で場所を絞り込めます。
- 遠征計画で測量を知る人がいないと警告が出ます。一部の学術書を読む際にも必要です。

**造船技術**（副官・船舶修理室。僚艦ではその船の船長）

- 海上で資材を使って修理します。資材がなければ修理できません。船舶修理室は旗艦の修理量を増やします。
- 上陸して野営中に船を直すときや、難破船の事件で修理量が増えます。
- 当地の言語が分かれば、未訪問の街の造船所の有無や技術水準を手帳で確認できます。

### 技能 — 戦闘

**剣術**（副官・甲板・海兵待機室。僚艦ではその船の船長）

- 海戦の白兵戦が強くなります。旗艦の海兵待機室がさらに強化します。
- 一騎討ちでは提督は**本人の剣術**で戦い、部下の剣術は加わりません。命中・会心・先制が増え、相手の技を読みやすくなります。代理戦ではその部下の剣術を使い、「交代」では最も強い人が出ます。
- 陸戦では歩兵・騎兵・提督隊を強化します。3段階で騎兵が重装騎兵になります。剣術・射撃術・砲術がすべて3段階なら、提督隊が無敵提督隊になります。
- 狩りの収穫が少し増え、幽霊船にも耐えやすくなります。借金の取り立ての「脅す」にも使います。

**砲術**（副官・砲撃室。僚艦ではその船の船長）

- 海戦で装填が速くなり、砲弾が当たりやすくなります。旗艦の砲撃室は威力を高めます。
- 陸戦の砲兵を強化し、3段階でカノン砲兵になります。

**射撃術**（副官・海兵待機室）

- 海戦には使わず、陸の戦いと狩りに使います。
- 陸戦の銃兵を強化し、3段階でマスケット銃兵になります。「狙撃」の計略も成功しやすくなります。
- 一騎討ちの「秘密武器」で、短剣の代わりに拳銃を撃ちます。
- 狩りやバイソンの群れの事件で、より多くの食料を得ます。

### 技能 — 船員の世話

**医学**（副官・診療室。壊血病の予防は乗船者なら誰でも）

- 壊血病の発症と拡大を遅らせます。診療室はさらに遅らせ、海上の熱病も防ぎやすくなります。
- 陸上探検の熱病による隊員喪失を減らし、薬草を見つけやすく、吹雪にも耐えやすくなります。
- 災害の被害を減らし、陸戦後に倒れた隊員の一部を救います。一部の学術書や昔話の事件にも必要です。

**料理**（誰でも）

- 船や野営地の食事で疲労を軽減します。雨の日の疲労も減らし、狩りの日の夕食はさらに充実します。
- 反乱では「宴を開いてなだめる」を選べます。料理か音楽のどちらかでよく、海上の宴の事件も起こります。
- 香辛料や作物など、食べ物の発見価値を見抜き、高めます。
- 調理室の料理人は故郷の料理を腕前に応じて作り、疲労を減らし規律を上げます。提督の故郷の料理なら、さらに喜ばれます。

**音楽**（誰でも）

- 歌と楽器で船員の規律を保ちます。船歌の事件が増え、野営での休息効果も高まります。
- 料理と同じく、反乱時に宴を開けます。
- 人々の歌・踊り・儀式など、民族の発見物の価値を上げ、現地の人々の心を開きます。
- 娯楽室は規律を、音楽室は疲労を改善します。隣り合う音楽室では、デュエット・トリオ・カルテット・バンド・グループの合奏になります。

**神学**（副官・礼拝室）

- 海上で船員の規律を保ちます。礼拝室がさらに補助します。
- 教会への寄付による名声が増え、祈ると規律が上がります。
- 幽霊船やセイレーンに遭遇しても動揺しにくくなります。
- 神学の学術書を読む際に必要です。

### 技能 — 人と商売

**弁論**（副官・食堂・副官室）

- 支援者の関心外の発見を提案するには、**弁論が必要**です。
- 契約交渉が成功しやすく、前金の増額や期限延長で不利になりにくくなります。高段階ほど有利な条件を得られます。
- 名声不足のとき執事を説き伏せたり、証拠不足で「証人を立てる」ことが成功しやすくなります。報告・発表も堂々とした口調で始めます。
- 入港時の守備隊長との交渉が安く、成功しやすくなります。忍び込むのも容易になります。
- 現地の人々に話しかけて手がかりを得たり、贈り物で好意を得たりしやすくなります。
- 反乱の首謀者の説得、一騎討ちの「説得」、去ろうとする部下や妻の引き留め、部下夫婦の仲裁、借金の取り立ての「諭す」、酒場で宝の地図の話を聞く際に使います。
- 当地の言語が分かり弁論が高ければ、未訪問の街の指導者も分かります。

**会計**（副官・主計・会計室）

- 交易所の交渉が成功しやすく、値引き幅と訪問ごとの交渉回数が増えます。主計がいれば、もう一度交渉できます。
- 市場で「値引き交渉」を行うには、**会計が必要**です。
- 荷を均等に積み、船が耐えられる積載重量を増やします。
- **3段階**になると大きな港の裏路地の闇市に入れます。取引のたびに悪名が付きます。
- 当地の言語が分かれば、未訪問の街の特産物と繁栄度が分かります。
- **主計**がいれば交渉が大幅に有利になり、支援者との契約交渉をもう一度行えて、前金も増えます。会計室は給料を減らします。

### 技能 — 学問と発見（1）

**歴史学**（副官・測量士・参謀室）

- 陸上の発見範囲が広がり、手がかりがなくても探しやすくなります。陸上偵察も遠くまで見渡せます。
- 災害の兆候を察知しやすくなります。2段階からは古い記録に残る災害も見抜きやすくなります。
- 未訪問の街の指導者が分かります。
- 歴史の学術書を読む際に必要です。古い写本には2段階が必要なものもあります。

**科学**（副官・診療室・飼育室）

- 壊血病を遅らせ、海上の熱病を防ぎ、薬草を見つけやすくなります。
- 生物・自然の発見範囲が広がり、災害の兆候も察知しやすくなります。
- 珍しい魚が釣れやすくなります。スフィンクスの謎では誤答を一つ消します。
- 飼育室では食料を育てます。科学の学術書を読む際にも必要です。

### 技能 — 学問と発見（2）

**絵画**（誰でも・地図製作室・画室）

- すべての発見価値が上がります。名声・報告の謝礼・命名による下賜金が増えます。
- **証拠の等級**に影響します。得意なら「精密図版」、未熟なら「スケッチ」、誰も描けなければ「口述記録」となり、支援者に疑われることがあります。後で絵の上手な部下が加われば、描き直して等級を上げられます。
- クジラの群れや滝などの壮観を画帳に残し、名声を得ます。献上した贋作も見破られにくくなります。
- 画室の部下は美術品を描き、船倉へ積みます。

**細工**（誰でも・彫刻室）

- 宝物・遺跡・民族の発見価値を大きく、他の発見物も少し高めます。遺物の売値も上がります。
- 遺物のない宝物や遺跡から、さらに価値のある品を持ち帰れます。証拠等級の向上も助けます。
- 贋作が見破られにくくなります。給仕や部下に装身具を贈ると、より心を動かせます。
- 彫刻室の部下は彫刻品を制作します。昔話の事件には細工が必要なものもあります。

### 言語 — 聞き取る

言語は16種類。スペイン語・ポルトガル語・ロマンス語・ゲルマン語・スラヴ/ギリシャ語・アラビア語・ペルシャ語・中国語・ヒンディー語・ウイグル語・アフリカ/中南米/東南アジア/東アジアの現地語・朝鮮語・北米現地語です。段階は**未習得・基礎・標準・熟達**です。

- **街の言語** — 街ごとに言語があり、上段の「言語」欄に一行の習熟度を点で示します。ポルトガル領やポルトガル商人が出入りする港では、ポルトガル語も通じます。
- **会話画面** — 提督が言語をよく知らないと、聞き取れない単語がその国の見慣れない文字で出ます。段階が上がるほど分かる単語が増え、熟達すればすべて理解できます。
- **通訳** — 副官・通訳・通訳室の部下が提督より堪能なら、会話の下に通訳欄が出ます。通訳も未熟なら「大まかに理解」「断片的に理解」と、一部だけ訳します。
- **現地の人々** — 全く言葉が通じなくても、身振り手振りで少しは意思を伝えられます。
- **誰の言語を使うか** — 提督・副官・通訳・通訳室の部下のうち、最も堪能な人です。他の役職や僚艦船長の言語は使いません。図書館だけは同行者全員で読みます。ただし後述の**通訳官**がいれば、旗艦の部下全員の言語を使えます。

### 言語 — 制限と上達の効果

**全く言語を知らないとできないこと**

- 交易所の交渉と市場の値引き。売買自体は可能
- 酒場の商売の噂・契約情報・目的地・酒の席の話を聞く
- 借金の取り立て、城門の守備隊長との交渉
- 支援者への謁見。執事が取り次がない
- 酒場で航海士を雇う。共通言語が必要
- 手帳で未訪問都市の特産物・指導者を調べる
- 本の言語を誰も知らなければ、図書館の本を読むこと

**上達するほど有利になること**

- 交易所・市場の交渉、城門での交渉、借金の取り立て、外交交渉が成功しやすくなります。
- 忍び込みやすくなります。その言語を母語とする部下がいれば案内役となり、さらに容易になります。
- 新しく雇う部下の初期忠誠が高まります。熟達していなければ「まだ十分に心を開いていない」と言われます。
- 図書館で本のより多くの部分を読めます。言語が上達してから再読すれば、残りを読み取れます。
- 遠征計画で目的地の言語を誰も知らないと、「通訳を置くように」と警告されます。

### 言語 — 学び方と通訳

**言語の学び方**

1. **提督作成** — 母語は熟達、隣のイベリアの言語は標準で始まります。残りポイントで別の言語を上げられ、種類の上限は知力で決まります。
2. **組合の「言語を学ぶ」** — その街や近隣の言語を、金と日数をかけ一段ずつ学びます。知力が高いほど成功しやすく、高段階ほど難しくなります。
3. **宿屋の「雑用をする」** — 台所仕事や薪割りをしながら、当地の言語を耳で覚えます。知力が高いほど早く上達しますが、働く間は名声が少しずつ減り、長期間は続けられません。
4. **同じ船で暮らす** — 部下の母語を毎日少しずつ覚えます。そばにいる副官の言語を最も早く、他の部下の言語はゆっくり学びます。部下も提督の母語や互いの言語を覚えます。

**通訳の配置**

- 部下の配置で**通訳**を任せると、その人の言語を艦隊で使えます。通訳の役職は技能ではなく言語のみを使います。
- **副官**は技能も言語も使います。
- 造船所で**通訳室**を作り人を配置すると、通訳を複数置けます。各地の海を巡る艦隊なら、異なる言語の部下をそろえましょう。
- **通訳官** — 通訳に任命した人を通訳室に置くと、提督と旗艦の部下の言語を「通訳帳」にまとめて使います。知らない言語は分かる人に聞き、「○○が教えてくれたが…」と訳します。他の航海士より早く言語を学びます。帳面は提督の手帳にあります。
- 調理室の料理人は故郷の料理を作ります。異なる言語の部下が多いほど、船の食卓も多彩になります。

## 発見と報告

### 発見画面

![新たな発見](guide/p62_disc)

| # | 欄 | 意味 |
| --- | --- | --- |
| 1 | 絵画 | 発見物 |
| 2 | 名前・ラベル | 種類・地域・価値 |
| 3 | 説明 | 発見物の物語 |
| 4 | 名声 | 発見現場ですぐに得る名声 |
| 5 | 確認 | 閉じる |

遺物を得ると「手に入れた遺物」も表示します。支援者へ報告すると証拠として渡し、港で自ら発表すると提督の所有物になります。

### 報告か、発表か

|  | 支援者に**報告**（王宮・屋敷） | 港で**発表** |
| --- | --- | --- |
| 得られるもの | 謝礼+名声+信頼 | 名声（発見名声×0.9） |
| 遺物 | 証拠として献上 | 提督の所有物 |
| 証拠がない場合 | 謝礼×0.55〜0.8、名声×0.8 | 名声×0.8 |
| 期限を過ぎた場合 | 謝礼×0.35〜0.7、名声×0.7 | — |
| 注意 | 契約なしで同じ年に同じ支援者へ報告すると、二回目から謝礼が減る | 契約した発見を発表すると契約失敗 |

- **証拠等級**：現物×1.05・精密図版×1.05（絵画2段階以上）・海図×1・スケッチ×0.95（絵画1段階）・口述記録×0.9。スケッチや口述では疑われる場合があります。
- **一括報告・発表**：報告対象が二件以上なら「冒険を提案」に「まとめて報告」が現れます。港の「発表」でも複数を選んで一度に公表できます。
- **保養地の島40か所**（自然）：サムイ・モルディブ・バリ・セーシェル・サントリーニ・マデイラ・済州島・タヒチ・ボラボラ・モーリシャスなどの近くへ船を寄せると発見できます。発見時の余韻「保養」で疲労−25・規律+8。通常の自然発見の「感動」は−16・+2です。
- **分類と並べ替え**：提案・一括報告・発表画面の分類ボタン（すべて・地理・自然・遺跡・宝物・生物・民族・交易品）で絞り込みます。「表示中をすべて選択」は見えるものだけを選びます。価値・分類・名前・最近の発見順に並べ替えられ、再度開いても設定が残ります。
- **所持品の固定**：手帳の所持品、自宅の保管庫、市場の売却画面で品の前のピンを押すと固定できます。固定品は売却の「すべて選択」と保管庫の「すべて預ける」から除外され、「固定」で一覧にできます。売却や保管後もスクロール位置は保たれます。
- **競争相手が先に発表した場合**：後から現場で発見できますが、初発見の栄誉は相手に残り、名声と謝礼が減ります。契約済みの依頼と手がかりは期限まで維持されます。

### 会社の設立時期

- **商館**（海外の会社都市）：会社倉庫・仲介注文書・会社任務

### 会員になると

本部の「社員名簿」で出資金を払い入会します。総合名声200以上が必要です。出資金の80%は会社株式で戻ります。所属できるのは**一度に一社**のみ。脱退後は一年間、どの会社にも入れません。

| 利点 | 働き |
| --- | --- |
| 会社倉庫 | 商館の品を交易所価格の60%で、階級ごとの割当量まで購入。60日ごとに更新 |
| 独占品の納入 | 本部に納めると市場価格×1.25〜1.4。**多く納めるほど値下がり**し、一、二か月で回復 |
| 仲介注文書 | 商館と大港を結ぶ連続注文。段階ごとに連携ボーナスがたまり、最後までつなぐと×1.5 |
| 会社任務 | 密輸取締・帰還大船団・商館建設・競合船の拿捕。その時点で**敵対国だった会社**のみ対象 |
| 税関 | 非会員が本部港へその会社の独占品を運ぶと、積荷を検査される |

貢献を積むと社員 → 船長 → 理事 → 総督と昇進し、割当量・納入価格・任務報酬が増えます。

### 株式・設立出資

- 株価は毎月変動し、**毎年1月に配当**が自動で入ります。船団の帰還や沈没、世界の大事件、提督の会社任務が株価に影響します。
- **投資上限**：株式に投じた金額（購入額の合計）は**金貨100万枚**まで。売ればその分を再投資できます。一社につき3,000株までです。
- **設立出資**：ロンドン（1600）・アムステルダム（1602・1621）・パリ（1664）の設立事件で出した資金は株式になります。史実の募集期間内なら額面（1株500枚）、以後の追加出資は当日の相場で受け付けます。
- **設立出資者**：募集期間内に出資し、受け取った株をすべて保持していれば、設立後**10年以内**に追加出資なしで入会できます。
- 初回決算（イングランド東インド会社1604・オランダ東インド会社1610・西インド会社1629）では、当日保有する1株ごとに分配されます。
- 取引所の「仲介人の耳寄りな話」は、先の出来事を教えますが、必ず当たるわけではありません。

## よくある質問

### 困ったときに

| 質問 | 答え |
| --- | --- |
| 海上で経度が「?」になります | 経度には六分儀が必要です。緯度はアストロラーベ・六分儀、または測量2段階で表示されます。故郷の市場には羅針盤と六分儀が常設されています |
| 港を選んでも自動航海になりません | 二つの港の間を、他の港に寄らず一度直接航海すると解放されます |
| 支援者に会えません | 名声不足です。執事に小さな仕事を頼み、名声と信頼を積めます |
| 出航できません | 船員5人未満、最低人数の1/3未満、または食料・水が2日分未満です |
| 本が赤く表示されます | 刊行前、前巻を未解読、言語や学問が不足、未知の土地に関する本のいずれかです |
| 会話に見慣れない文字が混ざります | 言語をよく知らず聞き取れない単語です。宿屋の雑用や組合で学ぶか、堪能な部下を通訳にしてください。「能力値・技能・言語」の言語のページもご覧ください |
| 能力値を上げるには？ | 説得・取引・戦闘・一騎討ち・美食・社交の経験で少しずつ上がり、爵位や結婚などの大きな出来事でも上がります。高いほど成長は緩やかです。「経験と成長」をご覧ください |
| セーブできません | 厳格なルールでは自国の街の宿屋でのみ記録できます。自動セーブは設定で有効か確認してください |
| 何をすればよいか分かりません | 街の「この街でできること」と、手帳の「発見物」タブをご覧ください |

幸運を、提督。さらに遠い海へ！
